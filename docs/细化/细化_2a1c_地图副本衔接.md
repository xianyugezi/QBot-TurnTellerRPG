## 0. 总览

### 0.1 一句话流程

```
世界图节点(可挂副本入口 dungeon_entrances)
  → /进入 <入口名|序号>  进副本（校验 entry_item / entry_limit）→ 落在副本入口区（safe_zone 缺省=入口区）
  → 副本内 /进入 <方向>  按 4 方向通道推进（仅限本副本 maps 集合）
  → 非战斗状态离开副本 → 回进入时世界节点坐标 + 副本重置（下次满状态重打）
  · 战斗中断=快照续玩｜安全区 /休息≠离开｜死亡复活≠离开（三例外，见 §2.2）
```

## 1. 地图节点挂副本入口（dungeon_entrances 字段）

### 1.1 谁能挂（挂载资格）

- **可挂节点 = 世界地图节点**（任意 maps.json 节点均可成为某副本的入口所在地——策划全权决定哪里是洞口/门牌，不限制特定类型图）。进入后落在副本**入口区**（【副本】L91「进入副本的起始区（入口区）」）。
- **副本内部地图禁止再挂**：即该节点若 ∈ 某副本 `dungeon.maps` 集合（【副本】L191/L207），不得再配置 `dungeon_entrances`——防「副本内开副本」嵌套/递归与「回绕出副本」歧义。装载校验器红拦（工程护栏，校验思路对齐【怪物】L295-301 校验器）。
- **外部入口 ↔ 内部入口区一一对应**：进入副本 = 切入副本入口区；入口区缺省即安全区（【副本】L213「safe_zone：默认=入口区」；L91）。

### 1.2 入口字段设计（衔接层字段，2a1a 未覆盖）

> 细化_2a1a 已定义节点级 7 字段（id/name/desc/spawns/exits/mechanics/gate_guard，见该文档 §1），未含与 dungeon.json 的挂接点——本节点补 `dungeon_entrances` 为 **8 号可选字段**，语义衔接【副本】§四 dungeon.json（L191/L203 副本 id、L211 entry_item、L213 safe_zone）。

```json
// maps.json 节点内（只加一层，其余字段见细化_2a1a）
{
  "id": "mountain_foot",
  "name": "山脚营地",
  "exits": { "up": "molten_entrance", ... },
  "dungeon_entrances": [                 // 2a1c 新增：本节点挂载的副本入口（可选；空/缺失=非入口节点）
    { "dungeon": "molten_dungeon",       // 引用 dungeon.json 副本 id（【副本】L204 "id": "molten_dungeon"）
      "name": "熔岩洞窟·讨伐" }           // 可选：入口对外名（缺省用 dungeon.name）；/进入 <入口名> 匹配用
  ]
}
```

- `dungeon`：dungeon.json 中副本 id，引用必须存在（红拦）；循环引用（dungeon → maps → 该图再挂另一 dungeon 指向当前）由 R2 拦截。
- `name`：可选，入口展示别名；用于 `/进入 <入口名>`（R17 名称优先级第一层）。缺省 = dungeon.json `name`（【副本】L189/L203）。
- 一个节点可挂**多个**副本入口（数组），如正门/后门、同一洞口挂探索+BOSS 两版（【副本】L188/L204 两副本 id，L229 共用地图）。

### 1.3 副本入口与通道（exits）的关系

- 副本入口是**非方向性挂接**，与 exits（上/下/左/右通道）并列共存（细化_2a1a §2）：进入副本不走方向通道，`/进入 <入口名|序号>` 命中入口 → 切换进副本上下文；`/进入 <方向>` 在世界图为外部通道行走。
- 副本内部地图仍按 4 方向通道组织（【副本】L46-47），由 dungeon.maps 集合界定（R5）。
- 世界图节点若同时有 exits 与 dungeon_entrances：`/进入 <方向>` 走通道、`/进入 <入名|序号>` 进副本，互不干扰（R20 上下文路由）。

## 2. 副本进入与离开

### 2.1 进入副本（/进入 <入口>）

```
玩家位于入口节点 → /进入 <入口名|序号>
  → [入场校验] entry_item（R4：探索版 null 不扣；BOSS 版扣钥匙）→ entry_limit（超次数拦截）
  → 记录外部锚点 = 当前世界节点坐标（R8 离开回位用）
  → 位置切换到副本入口区（safe_zone 缺省=入口区）→ 副本身份激活（当前副本 = 该 dungeon）
  → 副本内走图按 4 方向推进（R5）；子任务 zone=副本 ID 开始计数（R21）
```

- 场所校验先于消耗：entry_item 不足 / entry_limit 超限 → 拦截提示，不扣道具、不消耗次数（工程约定，防误扣）。
- 进入提示含恢复入口明示文案「战斗中断可续玩，离开副本将重置」（【副本】L82）。
- 子任务联动：进副本自动激活该副本 subquests（zone 限定，不占板槽位）——承载见任务系统定稿 L104/L251，本文档只声明「进入/离开触发激活与保留」。

### 2.2 离开副本与回原地图坐标

| 情形 | 处理 | 定稿依据 |
|---|---|---|
| **主动离开（非战斗状态）** | 回进入时世界节点坐标（R8）＋ 副本重置（下次满状态重打） | 【怪物】L100；【副本】L81/L106/L130 |
| 战斗中断（退出/超时/锁屏） | 快照续玩（ai_state+combo_state 保留），不离开副本、不回坐标 | 【副本】L80 |
| 安全区 /休息 | 位置不变、进度/BOSS 血量/快照全保留，不重置 | 【副本】L83/L104-106 |
| 副本内死亡 | 复活回副本入口区（仍在副本内）；BOSS 状态 keep/reset 按配 | 【副本】L115/L129-131 |
| 死亡后主动离开 | 触发重置（等价离开语义） | 【副本】L130 |

- **回原坐标口径（R8，工程约定）**：进入时记录的「外部锚点」即世界节点坐标；副本地图不产生世界坐标位移，故离开即回到进入时的世界节点（不另存进入前世界内部坐标——副本外无「内部坐标」概念）。配合 R7 重置。
- **副本重置范围**：副本进度/BOSS 血量/PV/换区 chasing 标志/子任务推进清空；下次进入满载状态（衔接细化_2a2 §5.4）。

### 2.3 副本内地图与副本外地图隔离

- **上下文隔离（主隔离手段）**：副本内部移动仅限 `dungeon.maps` 集合（【副本】L191/L207）——入口区的 4 方向通道只在集合内互指；`/进入 <方向>` 在副本内 = 副本通道（R20），世界图方向通道不可直达副本内部（集合外 exits 目标不在副本内区）。
- **地图共用不复制（R6）**：探索版与 BOSS 版引用**同一组地图 ID**（【副本】L229「两组副本引用【同一组地图 ID】」/L230「地图配置完整保留」/L231「同一地图 + 额外 BOSS 房 + 守门怪」）——物理上同一批 maps 节点，隔离靠「当前副本身份」上下文（副本 A 与副本 B 各自持 maps 快照语义），不做文件复制。
- **副本内当前区持久化**：副本会话记录当前区域/已清区域（规划_路2a M30），退出续玩从换区点/checkpoint 继续，跨内容包不读错会话。
- **换区追击跨界**：BOSS 换区目标 ∈ 本副本 maps 集合内候选（【副本】L144 / 细化_2a2 §1.4）；追击全程不出副本（衔接细化_2a2，本文档不重复展开）。

## 3. `/进入` 参数解析

> 依据：空白分隔规范（【分隔符】L15）+ 序号不带 `*`（【怪物】L13；【分隔符】L35）+ 紧凑/空格双认（【分隔符】L109-111）+ 名称优先（【分隔符】L70-71）

### 3.1 语法与判定

```
/进入                     # 无参 = 便捷指令 P1 预留（R19，本版本不自动走）
/进入 <方向>              # 汉字方向：上/下/左/右（别名 北/南/东/西 可选，R15）
/进入 <序号>              # 纯数字：地图列表序号 / 入口列表序号（R16，不带 *）
/进入 <入口名>            # 名称：入口名 → 副本名 → 地图名 逐级匹配（R17）
紧凑等价：进入上 / 进入2   # 空格与紧凑双认（R12）
```

**判定优先级（R14）**：
1. `方向字面量`（上/下/左/右）→ 通道行走；
2. `纯数字`（紧跟指令名、不含 `*`）→ 序号（地图/入口）；
3. `名称匹配`（入口名 → 副本名 → 地图名）→ 名称优先，失败回退序号后返回候选列表；
4. 含 `*`（如 `熔岩洞窟*2`）→ 数量语义，`/进入` 无数量位 → 保留字符违规报错（【分隔符】L73/L112）。

技术要点：
- 参数内拆解顺序固定：先 `,` 拆列表 → `*` 拆数量 → `=` 拆键值（【分隔符】L70）；`/进入` 只消费 1 个位置参数，无列表/键值位。
- 序号口径：`/进入 2` = 2 号地图 / 2 号入口（【分隔符】L35）；数字判别 = 指令名后紧跟数字（【分隔符】L112）。
- 换区追击：`/进入 <方向>`（空格）走通道追 BOSS（【副本】L12/L76；【怪物】L13/L95）——衔接细化_2a2 §4.2，本文档只声明解析，不重复流程。

### 3.2 上下文路由（R20）

| 当前上下文 | `/进入 <方向>` | `/进入 <序号>` | `/进入 <名称>` |
|---|---|---|---|
| 世界图 | 外部通道行走（细化_2a1a exits） | 地图列表序号移动 | 命中入口 → 进副本；否则地图名移动 |
| 副本内 | 副本内通道行走（仅本副本 maps） | 副本内地图序号移动 | 副本内入口名/地图名（副本内不挂入口，R2 → 通常不命中） |

- 方向/序号含义按上下文切换，解析管线不区分，由「当前是否处于副本身份」路由（工程约定，R20）。

### 3.3 错误处理（统一 4 类模板，【分隔符】L73）

| 错误 | 输出（人话） |
|---|---|
| 缺参 | `/进入` 需要参数：方向 / 序号 / 入口名（便捷指令未开放） |
| 超参 | `/进入 上 下` 参数过多，一次只走一步 |
| 未知分隔符 / 非法方向 | `『斜』不是方向（上/下/左/右），也没有叫这个名字的入口` |
| 保留字符/数量违规 | `/进入` 不支持数量 `*`：`熔岩洞窟*2` 无法解析 |
