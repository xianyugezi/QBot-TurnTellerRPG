# 检查工具指南（长期保留 · 复查检测用）

> 用途：一套固定的「怎么复查项目状态」的工具清单与用法。**本目录脚本为长期保留设定，
> 不随里程碑清理**——以后任何时候开新对话复查项目，都按本文档操作。
> 最后更新：2026-08-28（M7 收官）

## 一、一键入口（日常复查用这个）

```bash
# 快速检查（默认）：ruff/mypy 静态 + 架构门禁 + 内容包校验 + 单元测试
python scripts/check_all.py

# 全量验收（里程碑收尾用，慢 ~5 分钟）：M0~M7 门禁 + 覆盖率 ≥80% + 全量 pytest
python scripts/check_all.py --full

# 只查某一项（可组合）
python scripts/check_all.py --lint        # 只查 ruff/mypy
python scripts/check_all.py --arch        # 只查架构分层
python scripts/check_all.py --content     # 只查内容包
python scripts/check_all.py --unit        # 只查单元测试
python scripts/check_all.py --verify 7    # 只查某里程碑门禁（0~7）
```

检查结果自动归档到 `docs/verify/check_report.md`（每次覆盖，含时间戳）。

## 二、工具清单

| 工具 | 用途 | 命令 | 通过标准 |
|---|---|---|---|
| `scripts/check_all.py` | 统一入口（**日常首选**） | `python scripts/check_all.py` | 全部 ✅ |
| `scripts/run_all_tests.py` | 全量回归（里程碑验收） | `python scripts/run_all_tests.py` | EXIT=0，M0~M7 门禁全绿 |
| `scripts/check_architecture.py` | G0 架构分层门禁 | `python scripts/check_architecture.py` | ARCH-OK（TC-01~04） |
| `scripts/check_m7_content.py` | 内容包校验器（隐藏要素可达性/条件键/占位符） | `python scripts/check_m7_content.py` | 提示性，RED/YELLOW 清单 |
| `scripts/verify/verify_m0~m7.py` | 各里程碑门禁 | `python scripts/verify/verify_mN.py` | 段式全绿，EXIT=0 |
| `scripts/e2e_mX_smoke.py` | 各里程碑冒烟 | 见各脚本头 | 脚本断言全绿 |

## 三、里程碑门禁说明（verify_mN.py）

- `verify_m0~m7.py` 每份对应一个里程碑的验收门禁（m0 基础→m7 交互补全），
  段落式断言 + 归档报告到 `docs/verify/mN/verify_mN_日期.md`。
- **新增里程碑时**：按 `verify_m7.py` 模式复制为 `verify_mN.py`（N=下一个），
  写对应门禁段；`run_all_tests.py` 会自动纳入全量。

## 四、查看历史复查记录

- 每次运行自动归档：
  - 一键入口报告：`docs/verify/check_report.md`（最新一次）
  - 里程碑门禁报告：`docs/verify/mN/verify_mN_日期.md`
  - 覆盖率报表：`docs/verify/coverage_latest.txt`
  - 里程碑验收单：`docs/verify/mN_checklist.md`

## 五、约定

1. **长期保留**：`scripts/` 下所有 check/verify/run_all_tests/e2e 脚本 + 本指南
   = 项目检查工具集，**不随里程碑清理**。
2. **快速复查**：日常用 `check_all.py`（几秒到十几秒）。
3. **完整验收**：里程碑收尾用 `check_all.py --full`（~5 分钟，含覆盖率）。
4. **代理注意**：push 到 GitHub 需 mihomo 代理（`https_proxy=http://127.0.0.1:7890`）；
   代理死了先重启 mihomo 再 push。
