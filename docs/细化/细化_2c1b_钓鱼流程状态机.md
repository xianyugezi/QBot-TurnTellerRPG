## 一、/钓鱼 指令（列钓点 · 下钩）

> 依据：【钓鱼】§6 L110、§1 M1 L15、§五 生活系统页 L103、§七 指令表 L121；规划 T05/T06。

### 1.1 列钓点（`/钓鱼` 无参）

- 输出**当前地图**全部可钓鱼点【钓鱼】L110；垂钓点 = 地图采集点变体（时段偏好 + 稀有度标记，素材取自 maps 采集点）【钓鱼】L15 / L103。
- 每钓点展示字段（规划 T05）：名称、时段偏好、（当前时段命中性）、稀有度标记；候选规则 = 当前季节/时段存在候选鱼种的钓点（消费 2c1a §1.4 时段匹配契约）。
- 固定附注**鱼讯参考说明**（【钓鱼】L110 原话语义，逐字保留三类关键词）：
  > `微动=小鱼 / 拉扯=中鱼 / 猛烈=大鱼或鱼王！`
- 无钓点地图 → 空态文案（含"本图暂无可钓鱼点"），不输出任何钓点实体（规划 T05 验收）。
- `off` 模式：`/钓鱼` 一律拒绝（GU-01）。

### 1.2 下钩（`/钓鱼 <钓点id>`）

- 触发：`/钓鱼 <钓点id>`；缺省参数时默认选中第一个可钓点（实现层约定）。
- 前置守卫：GU-01（mode）/ GU-02（每日上限）/ GU-03（钓点属于当前地图）/ GU-04（同玩家仅一局）。
- 效果（抛竿 M3）【钓鱼】L17：
  1. **扣饵**：1 次 = 1 饵【钓鱼】L96；饵池为空仍可下钩（无饵保底不卡死），仅不吃对口饵加成【钓鱼】L16。
  2. **日计数 +1**：走 quest_daily 懒计算（默认 20）【钓鱼】L77；当日第 21 次被拦截（GU-02）。
  3. **注册懒计时期**：等待区间 `[wait_sec.min, wait_sec.max]` 内随机，复用 farming.harvest_sec 懒计算（无实时倒计时，跨会话可结算）；`wait_sec=0` 即收【钓鱼】L17 / L76。
- 消息节奏对齐：下钩 1 条 →（到期）鱼讯 1 条 →（收杆）结算 1 条，核心出鱼 2-3 条消息/次【钓鱼】L93。

## 二、钓鱼状态机（空闲 → 下钩 → 等待鱼讯 → 咬钩 → 收杆 / 跑鱼）

> 依据：【钓鱼】M3 L17、M4 L18、M5 L19、M6 L20、节奏 L93；simple/off 路由 L4 / L73 / L67。

### 2.1 状态集（共 6 态）

| 状态 | 编号 | 语义 | 引用 |
|---|---|---|---|
| **空闲** | S0 / IDLE | 无进行中钓局；接受 `/钓鱼` 开启 | 【钓鱼】L110 |
| **下钩** | S1 / CASTING | 抛竿动作已受理：扣饵、日计数+1、注册懒计时期 | L17 / L96 / L76 |
| **等待鱼讯** | S2 / WAITING | 等待期（懒计算，跨会话可结算，默认 300-900s，0=即收） | L17 / L76 |
| **咬钩** | S3 / BITE | 鱼讯已触发并携带讯类；等待玩家三选一；进入收杆决策窗 | L18 / L110-111 |
| **结算**（终态） | ST / REELED | 收杆成功路径：满力/自动→出鱼；止损→空收（无鱼讯收益） | L20 / L111 / L19 |
| **跑鱼**（终态） | SL / LOST | 决策窗超时 / 换区 / 新钓局被动脱钩 → 空手回，饵已计耗不返还 | 实现层（见注） |

> 注：`SL 跑鱼` 为**实现层会话语义**（定稿未单列此态），作为"挂机无趣"风险对策【钓鱼】L131 在收杆环节的决策压力点——不属于新增机制（仍为零新增纯配置组合）；`跑鱼` 名与定稿 M5"止损收杆（提前收）"区分：止损=玩家**主动**放弃，跑鱼=玩家**被动**超时。`simple`/`off` 模式不实例化 S2/S3（见 §2.4）。

### 2.4 模式前缀（full / simple / off）

- **full**：`S0→S1→S2→S3→{ST, SL, BOSS}` 完整状态机（等待+鱼讯+收杆三选一+鱼王）【钓鱼】L73。

- **off**：所有钓鱼指令（`/钓鱼 /收杆 /鱼讯`）拒绝，不进入任何状态【钓鱼】L73。

## 三、鱼讯三类（意图预告）

> 依据：【钓鱼】M4 L18、§6 L110、M7 L21；意图映射为真实预告（消费 2c1a §3.2 金闪接线）。

### 3.1 生成时机与机制

- 在 S2 等待期**到期时刻**（TR-03）按本局出鱼目标生成**意图预告**；复用怪物 AI 意图预告机制（机制零新增）【钓鱼】L18。
- 实现约定（TR-03 细则）：目标鱼种经 2c1a §1.4 时段/季节匹配选出后，其基础稀有度直接决定讯文案——`normal→微动`、`rare→拉扯`、`gold→猛烈`；鱼王命中时覆盖为**猛烈+金闪**。讯类**真实预告**本局出鱼档位（对齐【钓鱼】L18"对应小/中/大鱼"）。

### 3.2 三类鱼讯表

| 讯类 | 文案词 | 预告意图 | 出鱼目标 | 引用 |
|---|---|---|---|---|
| **微动** | 微动 | 小鱼 | normal 档为主 | 【钓鱼】L18 / L110 |
| **拉扯** | 拉扯 | 中鱼 | rare 档可命中 | L18 / L110 |
| **猛烈** | 猛烈；鱼王命中附加**金闪** | 大鱼 **或鱼王** | gold 档可命中 / 鱼王 BOSS | L110 / L18 / L21 |

### 3.3 金闪标记（鱼王预告）

- 猛烈鱼讯在鱼王事件命中（`king_event.enabled=true ∧ chance=0.3 ∧ 当日未达 window_daily=2`）时携带**"金闪"**标记、【钓鱼】L21 / L79；此时 `S3→(BOSS)`（TR-10）进 enemies BOSS 战，接线契约见 2c1a §3.2。
- 金闪**只可能出现在猛烈鱼讯**上；微动/拉扯永不携带金闪（TC-13）。

### 3.4 鱼讯的决策含义

- 鱼讯是**意图预告**（信息），对玩家"下一步三选一"提供依据、**不锁死结局**【钓鱼】L110；配合"说明特点不教攻略"【钓鱼】L113，讯文案只给提示词不给判定数值。
- 决策窗口：鱼讯发出后进入 S3 咬钩，玩家在收杆决策窗（carry_sec，默认 90s 可配、0=不限）内三选一；超时走 TR-07 跑鱼【钓鱼】L131 挂机对策 / 实现层。

## 四、/收杆 三选一（满力 / 自动 / 止损）

> 依据：【钓鱼】M5 L19、§6 L111、§四 概率 L94、饵耗 L96、删 M5 小游戏 L6 / L133；规划 T09。

### 4.1 三选一语义与决策差异

| 选项 | 语义 | 决策定位 | 代价/风险 | 引用 |
|---|---|---|---|---|
| **满力收杆** | **升级 roll**：+稀有度/冠级概率（配合对口饵达满配 54/37/9） | **进攻**：押注本局出好鱼——讯为`拉扯/猛烈`（目标档高）时收益最大 | 无显式代价（定稿未设体力/次数惩罚）；对`微动`小鱼档属浪费 roll 升级 | 【钓鱼】L19 / L94 |
| **自动收杆** | **基础概率**出鱼（70/25/5） | **稳健默认**：不投入决策，讯为`微动`时亦成立 | 不叠加任何加成 | L19 / L94 |
| **止损收杆** | **提前收**；饵已计耗照常消耗，**不触发鱼讯收益** | **放弃本局**：`微动`不划算 / 回避猛烈+金闪鱼王 BOSS 战 / 赶时间 | 浪费本轮已扣 1 饵与已排队日次数 | L19 / L96 |

> 三者为**纯决策分发**，无任何蓄力条/点按/时序判定小游戏（M5 蓄力小游戏用户拍板删除）【钓鱼】L6 / L19 / L133；`/收杆` 缺省参数默认 `自动`（实现层默认，可配）。

### 4.2 roll 概率锚点（种子 42/2026 复现）

| 档 | 条件 | normal / rare / gold | 引用 |
|---|---|---|---|
| AUTO | 自动收杆（无加成） | **70 / 25 / 5** | 【钓鱼】L94（基础） |
| FULL · 对口饵 | 满力 + 对口饵（满配） | **54 / 37 / 9** | L94（满配） |
| FULL · 无对口饵 | 满力，无对口饵 | 60 / 31 / 9* | *实现层插值默认，位于 `pull_odds` 可配置键，**非定稿值** |

- 对口饵加成语义：对口饵 稀有+8% / 金+2%【钓鱼】L16；定稿只给两**整体锚点**（基础 70/25/5、满配 54/37/9），中间档（满力无对口饵）不拆定稿数值，由 `pull_odds` 配置承载并在种子化对账中复现（TC-15/16）。

### 4.3 冠级与满力的冲突登记（CF-1）

- 定稿 L19 定义满力收杆"+稀有度/**冠级概率**"；而 2c1a §2.1 将 size%/weight% 定为 v1 **固定均匀**独立生成【2c1a §2.1】（冠级纯收藏，TC-10 差分 = 0）。
- **v1 决断**：满力**仅升级稀有度 roll**（§4.2 表），冠级仍走均匀百分位——不破坏 2c1a 纯收藏差分约束。
- 若后续需要满力真正抬升冠级频率：走【钓鱼】L29"均匀分布**可配**"语义，为满力配置 `crown_dist` 分档分布（预留字段，**默认关**）；登记为 **CF-1 待定稿澄清**，不静默违反任何一稿。

### 4.4 出鱼结算接线（M6）

- 收杆成功（TR-04/05）→ 结算链路：鱼种 × 大小 × 重量 × 冠级 → 图鉴点亮 + 熟练经验 + 奖励（reward 统一发放器）【钓鱼】M6 L20。
- 大小/重量数值由 2c1a §2.1 百分位插值**同源供给**；结算记录落日志含 size/weight/crown【钓鱼】L20 / 规划 T10。
- 图鉴点亮：首获即创建 codex_state `type=fish` 条目并点亮，`caught_count+1`、best/min 极值与 reverse_crown_count 按 2c1a §4.2 更新【2c1a §4 / 【钓鱼】L125】。

- 节奏约束：`/鱼讯` 为**辅助查询**，不计入出鱼核心消息数；一轮出鱼核心消息保持 2-3 条（下钩 / 鱼讯 / 收杆）【钓鱼】L93。
