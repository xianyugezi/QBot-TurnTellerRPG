### 0.2 一句话契约

> 存储层 = **单一 SQLite 库（WAL + 单写连接队列 + busy_timeout）**，7 张表承载五类持久化语义（【框架】L225-231）；**每指令单事务**（BEGIN IMMEDIATE → 业务写 → 幂等键写 → COMMIT，失败全回滚），购买/合成/强化/签到/战斗结算等原子操作绝不拆多事务；**message_id 幂等键与业务写同事务提交**，崩溃窗口内不双结算不双扣；**存档含 content_pack_id + version + schema_version**，换包/升级走**字段级迁移（缺补默认/多忽略）**，引用按 ID 存储、显示按名字，热重载换包后旧条目仍可显示（缺失红名+一键清除，进行中会话按旧配置结算）；**30 天回收**覆盖会话僵尸（自动按退出结算）、回收站、备份保留，VACUUM 周级/超阈值治理，文件权限 600/700。

## 二、存档读写（RW ×6）

### 2.1 流程 F1：读写管线（写死顺序）


## 四、幂等（IDEM ×5）

### 4.1 流程 F4：幂等判定（写死顺序）

```
指令到达
  → 幂等键查询 idempotency_keys(message_id, group_id, player_qid)
      ├─ 命中 → 幂等返回：直接回放 result_hash 摘要或「该指令已处理」，不执行业务（防重复结算）
      └─ 未命中 → per-player 串行队列 → 引擎处理 → 单事务【业务写 + 幂等键插入】→ COMMIT → 发送

崩溃窗口分析：
  · COMMIT 前崩溃 → 幂等键未插入、业务未提交（单事务原子）→ 重试 = 全新处理，无半执行

```

### 6.2 流程 F5：迁移管线（写死顺序）

```
检测（启动 + 首次访问懒迁移）：
  meta.db_schema_version vs 代码预期 → 不符 → 迁移
换包（players.content_pack_id vs meta.current_pack_id 不符）→ 按编辑器设置的换包策略执行：
  ① 自动迁移：同 ID 保留；缺失物品红名显示 + 一键清除（字段级：缺补默认/多忽略）
  ② 全服重置：二次确认后清空玩家数据（编辑器中触发，storage 提供事务清空接口）
  ③ 双存档并行：旧包存档保留可切回（players 保留旧 content_pack_id 快照字段）
执行：
  迁移前强制 .bak 快照（VACUUM INTO）→ 逐级迁移 vN→vN+1（每级单事务）
  → round-trip 校验（写回后读一致）→ 写 meta.migration_log 履历 → 提交
失败：
  整体回滚 + 人话提示；服务携带旧版 schema 继续运行（绝不因迁移起不来）
```

### 7.2 用例明细

**原子性（TC-01~04）**

| 编号 | 场景 | 步骤 | 断言 | 依据 |
|---|---|---|---|---|
| TC-01 | 购买结算原子性 | 构造有效购买请求；注入失败点：**扣货币后、入包前**抛异常 | 货币未扣、物品未入包、库存/限购未变化（整体回滚，无半写）；重试后正常完成 | 【框架】L2303；【规则】L323 |
| TC-02 | 合成原子性 | 配方 N 材料入→1 出；注入失败点：材料扣毕、产出入包前抛异常 | 全部材料退回（或全部未扣），产出未入包；无幽灵材料损耗 | 【框架】L394 |
| TC-03 | 强化原子性 | 强化请求（扣材料+概率判定+装备实例写入）；注入失败点：概率判定后、装备属性写入前抛异常 | 强化材料未扣、装备属性未变、锁定概率字段未变（同事务） | 【框架】L1899；配套《细化_2c3b_强化流程契约》 |
| TC-04 | 单指令单事务 | 任意指令处理中途抛领域异常（mock 引擎层） | DB 回滚至指令前状态（玩家/会话/世界状态全一致），无任何残留行 | 【框架】L1625；【规则】L117 |

| 编号 | 场景 | 步骤 | 断言 | 依据 |
