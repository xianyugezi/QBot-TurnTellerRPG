## §一 数据模型

### 1.1 combatant `stance` 字段（JD-F1 核心 · RU-CFG-01/02）

| 编号 | 字段 | 类型 | 默认 | 语义 | 引用 |
|---|---|---|---|---|---|
| F-01 | `stance` | enum(`"ground"` \| `"airborne"` \| `"down"`) | `"ground"` | 三态姿态：地面（常态全能）/ 跃空（身位优势，打地面 +1/3 命中）/ 倒地（起身窗口，地面防御 -30%）。玩家默认地面；怪物默认地面、`initial_stance` 可配（字段本体归 JD-F3） | 底座 L41/L47-49；规范 L230；CD L164；底座 L95 |

- 枚举名对齐 CD L164 `stance`(ground/air/down) 与底座 L47-49（地面 ground / 跃空 airborne / 倒地 down）；玩家可见文本用 地面/跃空/倒地（规范 12.2 L403 状态行模板）。
- **快照持久化**：`stance` 为 combatant 快照字段，随战斗快照保存（底座 L41「姿态 = combatant stance 字段，快照持久化【F-1】」），落点 = [1g1c] sides.player / sides.enemy 单位块（1g1c L40-63），随中断恢复全保留（[1g3] S1 精神）。
- **战斗结束清理**：战斗结束（胜负/逃跑/平局/丢失退出结算）→ 当轮事件末尾统一快照清理（数值 L64；[1g3] S2/L141），`stance` 及姿态辅助字段随快照清除，无持久残留。

### 1.3 formula.json `stance` 配置段（RU-CFG-04/05 · 【工程补白】落点）

```json
"stance": {
  "down_break_immunity_after": 3,      // F-05 连续断起身 N 次触发免疫（默认 3，可配；0=关闭）
  "down_break_immunity_turns": 2,      // F-06 免疫窗口时长回合（默认 2，可配；0=无上限）
  "down_defense_penalty": 0.3,         // F-07 倒地减防 30%（默认建议值，可配）
  "initial_stance_default": "ground"   // F-08 玩家/怪物默认姿态（怪物 initial_stance 覆盖 → JD-F3）
}
```

- 默认值与参数名对齐【规范】HC-10 L132 / 5.1 L232（`down_break_immunity_after` 默认 3、`down_break_immunity_turns` 默认 2）；`down_defense_penalty=0.3` 为规范「防御-30%」（L230）/ 底座 F-1「倒地减防 30%」（L104）的数值化【补白】。
- 生效参数在战斗开始时解析一次：默认取 formula.json.stance，per-职业/怪物可覆盖（HC-4 数值全可配 L126；底座 L123）；参数本身不入快照（配置只读）。

### 2.4 跃空受伤害判定（2.3 全量 · 护盾联动）

```
   · 其他伤害 → 落地（回地面，不倒地）
推论：重击是唯一「击落」手段；非重击只能把空中目标打回地面（底座 L70）
```

### 2.5 起身与断起身（JD-F5）

- **起身动作替换（RU-ST-06/RU-ORD-03）**：倒地目标选择任何非闪反行动（技能/普攻/防反/道具）→ 该行动被替换为「起身」：回地面、占行动、免费、不耗该技能 MP/冷却、技能不结算（底座 L60/L84；规范 L231）；道具同样不消耗【补白，按「任何行动均替换为起身」精神】。
- **起身可被打断（RU-ST-07/RU-ORD-05，B-02）**：跃空重击命中倒地目标且先于其起身结算 → 起身被打断，目标保持倒地（控制链），目标本回合动作被消耗，down_break_count+1，触发特殊派生（三光剑士 陨星击 L163「[我方:跃空]+[目标:倒地]+重击 → 陨星击：160% + 破防30% + 断起身」）。
- **断起身判定顺序（RU-ORD-05）**：跃空重击命中（先手/行动序在前）→ 检查目标起身是否未结算 → 断起身 → 计数/免疫检查 → 特殊派生。

### 2.6 倒地免疫（RU-IMM-01~05 · v1.1 拍板）

- **触发（RU-IMM-01）**：目标连续被断起身达 `down_break_immunity_after`（默认 3，可配）次 → 进入倒地免疫窗口；触发时 down_break_count 清零【补白】。
- **窗口（RU-IMM-02）**：窗口时长 = `down_break_immunity_turns`（默认 2 回合，可配）；immunity_turns_left 随回合结束 tick 递减。
- **窗口效果（RU-IMM-03）**：窗口期间目标**不被击倒、断起身无效**（重击命中跃空 → 落地而非倒地；跃空重击打倒地 → 起身照常结算、不计数）——变相削减连控难度（玩家控制一定次数后触发，非首次即免疫）。
- **计数清零（RU-IMM-04 补白）**：`down_break_count` 在成功起身（起身/闪反起身，非被打断）时清零；触发免疫时清零；窗口期间断起身不计数。「连续」语义：中间成功起身一次即重新计数。
- **参数 0 语义（RU-IMM-05，B-04）**：after=0 关闭倒地免疫；turns=0 无上限窗口。

### 2.7 必中标记（RU-MH-01~03 · JD-F6）

- **授予（RU-MH-01）**：倒地时使用闪反且闪避判定成功（起身闪避）→ 授予必中：`must_hit_turns=1`，**下一回合**全部攻击 100% 命中。
- **生效（RU-MH-02 补白）**：must_hit_turns>0 的回合，攻击命中率强制 100%（跳过命中判定或命中率 clamp 强制为 100%）；作用范围为下回合内全部攻击（定稿未限定单次，按「下回合必中」整回合语义）。
- **清除（RU-MH-03 补白）**：授予回合的回合结束 tick 不扣减；生效回合的回合结束 tick 归 0（B-06 时序）。

## §三 结算顺序

### 3.1 姿态判定在伤害管线中的挂点（RU-ORD-01/02）

```
命中 → 会心 → 格挡 → 双通道（物理/元素独立取整后相加）→ 防御率 → 伤害拦截链（减伤→护盾→…→扣血）→ 扣血 → 【姿态判定挂点】
```

- 判定顺序写死（数值 L16；属性 L99/L104）。姿态判定（跃空受伤害：护盾→重击→其他；倒地减防）挂点 = **拦截链扣血后**【补白挂点，定稿未显式给出姿态判定在管线内的位置，按「护盾未破」需在拦截链护盾段结算后判断的自然顺序定义】。
- 命中修正（±1/3）本体归 JD-F2（damage 层乘区，数值 L16 命中步内），本文不实现；命中结果（miss/命中）由 JD-F2 产出，本文消费。

### 3.2 受伤害判定优先级（RU-ORD-01，写死）

```
优先级：① 护盾（未破→不落地） > ② 重击（→倒地） > ③ 其他（→落地）
```

- 有护盾未破时，即使重击命中也不击落（护盾=空中保护层，底座 L58/L65）。
- 护盾被本次伤害打破 → 降级进入 ②③：重击→倒地；其他→落地。
- 免疫窗口内 ② 被覆盖：重击不击倒 → 落地（RU-ST-09）。

### 3.3 倒地减防挂点（RU-ST-08 / RU-ORD-06 · 补白）

- 倒地状态防御 -30%（规范 L230；底座 L104）：`有效体质 = 体质 × (1 − 破防%) × (1 − down_defense_penalty)`，再入防御系数 `K_def/(有效体质 + K_def)`（数值 L31）。
- 与打类型内置破防 20% 独立乘区（互不稀释）【补白】。

### 3.4 起身动作替换结算顺序（RU-ORD-03/04/05）

```
倒地目标行动阶段：
① 动作类型路由：闪反 → 起身闪避（T7/T8）；其他 → 替换为「起身」（T9）
② 起身替换：占行动、免费、不耗该技能 MP/冷却、技能不结算、道具不消耗
③ 打断检查：本回合先于起身结算的跃空重击命中 → 断起身（T10，保持倒地，动作消耗，计数+1）
    · 免疫窗口内 → 断起身无效（T11），起身照常
④ 起身成功 → 回地面，down_break_count 清零
```

### 3.5 回合边界 tick（RU-IMM-02/RU-MH-03）

- 回合结束 tick（数值 L58 ⑥：持续回合扣减/冷却递减/效果衰减）新增：
  - `immunity_turns_left > 0` → −1（归 0 退出免疫窗口）
  - `must_hit_turns` 生效回合 → 归 0（B-06）
- 快照只落回合边界（数值 L70-71；[1g1c] B4），回合内姿态转换随行动结算即时生效、回合边界落盘。
