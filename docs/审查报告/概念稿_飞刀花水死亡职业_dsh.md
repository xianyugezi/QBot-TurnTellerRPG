# 职业概念深度设计草案 ·「花葬客」

> 性质：概念稿/头脑风暴（非实现契约）。关键词：**飞刀（打系远程）× 花（绽放/凋零/撒种）× 自然与死亡（复苏/凋零）× 水（滋养/潮汐/淹没）**。
> 目标：2~3 个系统深度咬合的职业幻想草案，供拍板后转《细化_6a 职业库契约》系。
> 落点备注：本作已有 连段链（1c）/ 印记系统 9 原语（1d）/ 自定义资源轴（G.1/P0-2）/ 生存模板（1b）四条引擎通道，本草案全部**挂靠既有语法**，不另造平行系统（详见 §六 对接映射）。

## ① 一句话定位

> **幻想句**：我在敌人的每一个伤口里种花——飞刀是种子，血是土壤，而潮水决定这朵花是替我活，还是替敌人死。
> **机制句**：双面收割型慢热输出+续航；用飞刀在目标体内铺"园艺位"，随潮汐周期把刀印浇灌成会生长、会盛放、也会溺死的潭花；盛放是唯一收款窗口——摘之（活水·生面）续你自己的命，断之（葬花·死面）取对面的命，而每次收割都会反过来改写全战场的水位走势。
> **我玩的是**：一个把"种田"与"送葬"压进同一朵花的农夫兼杀手——读水位像读命运，在潮汐顶点的花海里做一次生死一掷。

## ② 机制骨架（四大系统 + 联动线）

### 系统 A · 飞刀·园艺位（快 / 精准 / 暗器 → 铺陈）
- **飞刀 = 种子**。飞刀系连段技命中即向目标身上**插一枚「刀印」**（印记，挂在敌方表；applier=player / polarity=positive 资源印 / max_stack=5，**战斗内永续战至战斗结束清零**）。
- 刀印=「园艺位」：花只能种在刀印上。**刀印层数 = 你的耕地面积**。
- 打系远程 + 内置破防 20%（沿用 type_affinity.blunt_pierce），落刀式自带 +5% 命中（精准主题）→ "飞刀最擅长在甲胄缝隙里找水"。
- 连段标签推动飞花手链：连段被打断只断"节奏"，**刀还插着**——打断技伤不到你的地，只有敌方消除技/你的自选题能拔刀。

### 系统 B · 潭花 · 生长状态机（花 → 蓄爆的中枢）
- **播种**：消耗水（潮位+mp）把 1 枚刀印淬成一朵「潭花」种子（印记：潭花，挂在敌方表，applier=player）。
- 每回合每朵花自动生长一阶：
  ```
  种子🌰 → 抽芽🌱 → 含苞🌷 → 盛放🌺 → 老花🥀
  ```
- **盛放 = 仅有的收款窗口**：盛放当回合与下一回合可被处置（生/死二选一）→ 之后转为老花，只配进春泥（小额保底）。→ 收割有**时限**，决策紧凑。
- **花期受潮位驱动**（与系统 C 的第一处咬合）：高潮回合花 **+2 阶**（快熟），低潮回合**不涨甚至 +失水 -1 阶**（停滞，但可被"补浇"救回）。潮位 = 天气，天气决定收成时间表。

### 系统 C · 潮汐 · 水位周期轴（水 → 节拍器与双刃）
- 自定义资源轴「潮汐」，值域 **0–6**（0 死水 / 3 平潮 / 6 满潮），reset=battle。
- **自动钟摆**：每回合开始潮汐向"当前极性相反"方向走 1 格（0↔6 之间震荡，自带节奏，无需 AI 操作——1v1 文本局里是稳定且可读的节拍器）。玩家用技能可 引潮(+)/泄洪(−)/锁潮(0)。
- **潮位的三面**：
  - **效率面**：高潮=浇灌便宜、花熟得快、断根伤害高；低潮=种下去花不肯长。
  - **威胁面（自己身上）**：高潮期你「湿身」，受击伤害 +8%、若被挂上"溺水"额外吃 dot；低潮期你「干涸」，免疫溺水类伤害并小额回蓝——**水既滋养你也淹你**。
  - **窗口面**：满潮（=6）当回合是唯一的大招窗口。
- 玩家每回合至少被逼回答一次：**这回合我往哪个方向推潮？**（推=赌接下来的花期与大招窗口；不推=跟着钟摆走，稳但慢；泄=保命但让花停长）。

### 系统 D · 生死双面 · 收割决策（自然与死亡 → 决策中枢）
每朵**盛放花**可以被一次性处置，代价与收益互为镜像：
| 处置 | 面 | 收益 | 代价 |
|---|---|---|---|
| **梳花·活水** | 生 | 回 HP（%上限）+ 回蓝 | 潮位 **−2**（滋养被带走，花在退潮期，其余花变慢） |
| **断根·葬花** | 死 | 高额伤害（按花龄/阶段）+ 目标「溺水」debuff | 潮位 **+2**（血水泄洪，战场推向高潮——把自己也推向湿身/大潮） |

→ 每次收割都**反过来改写全战场的潮位走向**：生面是"向低潮换生存"，死面是"向高潮换输出"。**水往哪边流，就是你的战略往哪边走。**

### 联动线总图（谁咬谁）
```
飞刀连段 ──插刀──→ 刀印(园艺位) ──浇水──→ 潭花(生长) ──盛放──→ 生面摘/死面断  ─┐
     │                        ↑                                  │              │
     │                  潮汐钟摆部件(浇灌价/花期/湿身)            │              │
     └──被打断只断节奏，刀印永续 ────────────────────────────────→ └─每次收割改写潮位─┘
                                      满潮+花海 → 大招「枯荣·满潮花祭」 → 落潮归零 → 重新开局
```
咬合点为：**①潮位↔花期（天气决定收成）②收割↔潮位（你的选择改变天气）③刀印↔花（地决定上限、断连段不毁地）④大招↔全系统（满潮+花海双条件兑现蓄爆）**。没有一处是单纯的堆砌。

**被动 ×2**：
- **汐语**（常驻）：每回合开始潮汐自动向极性端摆动 ±1（0↔6 钟摆循环）；高潮（≥5）你的断根/大招伤害 +15% 但受击 +8%；低潮（≤1）你免疫溺水类伤害。
- **葬花经**（常驻）：老花自动转「春泥」（上限 3）；春泥满 3 施放大招时，花海额外 +1 且大招后按层回血。

**节奏流派**（build 分化来自此）：
- **A 快种流（高潮手气）**：巡花刃+引潮推高 → 湍流连浇一次种满 → 等花海连片盛放 → 大招。求快熟、高天花板、风险是把自己的湿身期顶在敌人脸上。
- **B 慢热深耕流（低潮手气）**：把潮压在低处猥琐叠刀印+抽刀保命 → 中期一波引潮拉高种花 → 借助高潮伤害冗余决战。保稳、慢、上限略低但几乎不裸奔。

## ④ 核心循环与博弈点

### 标准循环（一场 1v1 的时间轴）
```
【0–3 回合 · 铺陈】
  落刀式×2~3 叠刀印(园艺位) → 潮位按钟摆自然走，顺手用小推拉调试潮向。
  伤害低（≈普通远程职业一半），玩家在"多插刀"与"插刀+护命"间取舍。

【2–4 回合 · 播种】
  引水播种 1~2 朵，把地转成会自己长大的花。
  决策：现在种（占行动位、分掉插刀节奏）还是再攒刀印（刀印上限 5，地不等人）？

【4–6 回合 · 收割决断（决策最密）】
  花连片进入盛放窗口。每回合同时面对：
    D1 插刀(再铺) vs 浇水(快手) vs 收割(变现) —— 三线抢同一个行动位。
    D2 推潮引高(赌大招) vs 压低护命(保湿身不掉血)。
    D3 这朵盛放花：摘(生·续航) or 断(死·重创) or 留(攒大招计数) —— 留要算好"下一回合会不会变成老花"。
    D4 是否贯月抽刀(弃花期换即时爆发) —— 斩杀线/防对方消除技的止损手段。

【6–8 回合 · 终局】
  满潮当回合 + 花海达标 → 大招「枯荣·满潮花祭」(生/死二选一) → 落潮归零 → 用春泥残值渡重建期。
```
> 文本显示需要三行状态位：`🌊潮汐 ▓▓░▒▒▯ 4/6（涨）` / `🔪刀印×3 🌸潭花2(1盛放) 🌱芽·🌺盛放` / `椿泥：1/3`。

### 博弈点（对敌 / PVP）
1. **节奏 vs 经济**：敌方打断技清零你的连段，只削"当前刀伤节奏"，**刀印/潭花仍在**——结构上鼓励你被打断也不崩盘，但"巡花刃推潮"这种要连段的内容被打断会拖慢你的晒种节奏。反之，**敌方消除印记技可直接拔刀/拔花** → 你被迫提前收割（哪怕没盛放）或改用 贯月·抽刀 止损——形成"敌方清你地、你弃地换刀"的互读。
2. **潮位是公开的天气**：你每次推潮都在向对手预告"我两回合后会干什么"。高手局里，泄洪可以是假动作（骗对方把爆发技能留到高潮），推潮也可以是陷阱（把对手也骗进你们的湿身对拼）。
3. **生存即节奏**：大潮前你的湿身窗口=对手的集火窗口；低潮你敢贴脸但不产花。生存抉择被绑进水轴——不是"要不要奶"而是"要不要往低潮走"。

### 成长感 / 蓄爆曲线
| 阶段 | 层面 | 玩家感受到的成长 |
|---|---|---|
| 前期 | 刀印→花 | "我在铺一片我看不到的形状"——伤害低但盘面在长大 |
| 中期 | 花→收割 | 每一次正确收割都在改写潮位，打出"半年前的我在布局"的爽感 |
| 后期 | 满潮花祭 | 一次性把 2~3 回合的准备全部引爆，数字暴涨 + 主题高潮（葬礼/丰收） |
| 循环 | 落潮重开 | 归零但不挫败：春泥与刀印记忆感留住"上一局的遗产" |

## ⑤ 这个职业独有的记忆点（2~3）

1. **"在自己刺出的伤口里种花"的诗性暴力**——你的敌人是一座农田：伤口是垄、刀是种、血是土。这场战斗既是种田也是送葬，输赢结束时你会记得"那朵花我们谁都没来得及收"，这种胜负之外的留白是文本 RPG 独有的回味。

2. **跟看不见的潮汐共舞**——战场水位每回合自动涨落，它不看你脸色，只按钟摆走。熟练玩家能在 3 步之前预判"满潮会在第 7 回合来"，于是所有选择（推潮/留花/攒大招）都被压进一个"你早就在读的天气"里——**读水位像读命运**，这是别的职业没有的节奏感。

3. **同一朵花，一条命，两用**——盛放的潭花可以救你，也可以杀对面，且无论选哪边都会推着潮水往一个方向走。每一场战斗都会被玩家打出"湿的"与"干的"两种截然不同的样子（快种席卷 vs 慢热深埋），这是职业性格而非数值强弱。
