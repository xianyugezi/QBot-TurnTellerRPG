## 世界基调

**苍穹界 · 群脊荒原**——蚀脉（地下晶化能量）大陆的裂谷带。脉晶沿裂缝渗出地表，猎师以脉晶为刃、兽骨为甲，猎杀蚀脉哺育异变的巨兽。

**驻地**：龙骨驿站（唯一安全聚落）｜ **货币**：脉晶币 ｜ **通用素材**：脉晶碎片

## 生态混居规则（v2 新增）

1. **怪群不局限本区**：每张图的主怪 + 混居怪（前后相邻区）。
2. **下区怪提前露脸**（出现在上区靠后图）：给中期探路玩家"前方有大家伙"的警示 + 提前采素材机会，但下区怪刷得少/在图深处。
3. **上区怪残留**（出现在下区靠前图）：生态过渡自然（幼兽在巢区外游荡、狼群跟着猎物迁徙），也让玩家刷旧素材不用回老图。
4. **混居跨度 ≤1 个区段**（A 图不直接出 C 怪），难度平滑。

## Boss 召唤行动总规则（v2 新增，所有 Boss 适用）

1. **召唤/呼唤类行动单场次数限制 1-3 次**（各 Boss 上限见上表）。
2. **召唤间冷却 ≥3 回合**（砾冕/无召唤 Boss 不受限）。
3. 召唤行动**通常绑定姿态/血线**触发（如进姿态 II 才可召），不在普通行动池高频出现。
4. 目的：召唤只做节奏点缀与压力峰，**不让玩家陷入"清小怪→再清"的重复劳动**；召唤物偏弱（玩家 1-2 刀清），纯干扰/打断蓄力用。
5. 实现载体（落地时查证）：special_actions once/trigger_cooldown/enemy_mark 计数(max_stack) 组合，纯配置。
