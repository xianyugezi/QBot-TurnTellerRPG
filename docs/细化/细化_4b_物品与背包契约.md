### 1.1 条目 JSON 样例（四条：装备 / 消耗品 / 素材 / 装饰珠）

```json
{
  "id": "iron_sword",
  "name": "铁剑",
  "type": "weapon",                      // 装备子类=部位键（weapon/armor_head/armor_body/armor_hand/armor_leg/armor_foot）
  "icon": "🗡️",
  "desc": "新手铁匠铺出品的基础武器",
  "quality": "fine",                    // 品质四档唯一注册表（普通/精良/史诗/传说 ↔ normal/fine/epic/legendary）
  "stack_max": 1,                        // 装备不可堆叠
  "price": 500,                          // 基准价（商店/掉落/赠送/出售通用）
  "sell_price": 120,                     // 可选：出售价单条覆盖（不写=基准价×出售比率 30%）
  "bound": false,
  "sellable": true,
  "level": 1,                            // 装备等级门槛（0=不限，可配开关 level_gated）
  "slots": [],                           // 孔位（装饰珠插槽 slot_level 1/2/3；锻造节点 slots 覆盖本条）
  "stats_bonus": {"str": 5, "ele_atk_fire": 8},   // 加成层数值 flat（元素攻击力=装备承载）
  "stats_pct": {"str": 0.05}             // 加成层百分比 pct（+5%）
}
```
