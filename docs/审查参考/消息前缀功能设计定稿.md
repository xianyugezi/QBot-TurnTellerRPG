# 消息前缀功能设计定稿（message_prefix）

> 版本：v1.0 · 2026-08-16
> 定位：**回复显示层功能（非战斗机制）**——机器人回复玩家消息时，首行显示玩家身份标识（等级/玩家名/称号/群名/职业）
> 来源：用户拍板需求（2026-08-16，新功能批 C）+ 建议_harness_v4p_新功能.md 第 4 条（成就墙与称号佩戴）联动配套——前缀是称号的「每条回复展示出口」
> 核心：默认格式 **"Lv[等级].[玩家名] -[称号]-"**；占位符体系可自由组合；开关+格式+显示规则全部由内容包作者（settings 段）配置；[称号] 读玩家当前佩戴称号（来源=成就奖励/职业王称号/品评会冠军，见成就批设计）
> 配套：配置段落点 = settings.json 新增 `message_prefix` 段（**框架 settings 段登记由成就批执行，本定稿只写登记要求引用，不碰框架主文档**）；玩家佩戴称号状态落点由成就批登记（3.7 存档），本定稿只读引用

---

## 一、设计哲学

1. **显示层功能，非战斗机制**：前缀不改任何数值/判定/存档逻辑，纯渲染层拼接——战斗/任务/商店等系统零感知、零耦合；战斗一轮一条消息的合并策略不受影响。
2. **身份标识**：多玩家同群场景下，机器人回复「是谁的」一目了然；私聊场景同样生效（默认），玩家自己看也清楚。
3. **称号展示出口**：王称号（炼金王/锻造王等）、品评会冠军、成就奖励称号随每条回复首行展示——称号系统（成就批设计）最自然的炫耀出口，联动价值高。
4. **全可配（只建议不限制）**：开关默认开（内容包可关）、格式/占位符组合/显示规则全部 settings 配置；未知占位符不拦截（原样输出 + 黄色提示）；前缀长度超限提示截断、不拒绝加载。
5. **防刷屏不冲突**：前缀只加首行、不增加消息条数；前缀不计入消息长度限制（正文防刷屏语义不变，见 §七）。

## 二、默认格式（验收示例先行）

```
默认 format：Lv[等级].[玩家名] -[称号]-
```

**验收口径示例**（玩家：阿伟，35 级，佩戴称号「斩龙者」= 成就奖励）：

```
Lv35.阿伟 -斩龙者-
🔥 你施放火球术！造成 18 伤害（史莱姆 7/25）
🟢 史莱姆反击！你受到 4 伤害（HP 21/30）
你 21/30 | 史莱姆 7/25 → /攻击[技能] /道具 /防御 /逃跑
```

- 前缀 = 回复**首行**；正文从第二行开始（合并消息策略不变：一轮战斗仍 1 条消息）。
- 无称号时默认：`Lv35.阿伟 - -`（[称号] 输出空称号文本 "-"）；`hide_when_empty:true` 时整段省略：`Lv35.阿伟`（见 §六）。

## 三、配置段（settings.json 新增 message_prefix 段）

```json
// settings.json 新增段（框架 settings 段登记由成就批执行，见 §十一）
"message_prefix": {
  "enabled": true,              // 总开关（默认开，内容包可关——总纲「默认开」原则）
  "format": "Lv[等级].[玩家名] -[称号]-",   // 格式模板，占位符自由组合（见 §四）
  "show_on_system": false,      // 系统公告/群广播是否也加前缀（默认不加，可配 true）
  "per_channel": "all",         // all 群聊+私聊都生效 / group 仅群聊 / private 仅私聊
  "hide_when_empty": false,     // 无称号时整段省略 [称号] 及其相邻装饰符（默认 false 显示空称号文本）
  "empty_title_text": "-",      // 无称号时 [称号] 的输出（可配 "" 则仅隐藏占位符本体，不省略装饰符）
  "prefix_max_len": 40          // 前缀渲染后最大长度（0=不限），超长截断+黄色提示（见 §七）
}
```

### 3.1 字段元数据表（落点：框架 4.2 settings 元数据，由成就批登记）

| 字段 | 中文名 | 类型 | 默认 | 范围 | 引用目标 |
|---|---|---|---|---|---|
| enabled | 启用开关 | bool | true | 可配（内容包可关） | - |
| format | 格式模板 | str | "Lv[等级].[玩家名] -[称号]-" | 占位符自由组合 | 占位符体系 §四 |
| show_on_system | 系统消息加前缀 | bool | false | 可配 true | - |
| per_channel | 生效渠道 | enum | all | all/group/private | - |
| hide_when_empty | 空称号整段省略 | bool | false | 可配 true | §六 |
| empty_title_text | 空称号文本 | str | "-" | 可配 "" | §六 |
| prefix_max_len | 前缀最大长度 | int | 40 | 0=不限 | §七 |

## 四、占位符体系

| 占位符 | 含义 | 取值来源 |
|---|---|---|
| [等级] | 玩家当前等级 | 玩家存档 level（框架 3.7） |
| [玩家名] | 玩家名 | 角色名（无则 QQ 昵称兜底） |
| [称号] | 当前佩戴称号名 | 成就批登记的佩戴称号状态（3.7 存档）；无称号 → empty_title_text |
| [群名] | 消息所在群名 | 当前消息群；私聊 = "私聊"（可配，见 §五） |
| [职业] | 当前职业名 | jobs.json 职业名（当前职业） |

- **自由组合**：任意顺序、任意重复、可只用一个（如 format 只写 `[玩家名]` 也合法）。
- **未知占位符**：原样输出 + 校验器黄色提示（只建议不限制，不拦截加载）。
- [称号] 的特殊规则（空称号处理、hide_when_empty 整段省略）见 §六。

## 五、显示规则

1. **仅玩家相关回复加前缀**：玩家指令触发的回复（战斗结算/状态/商店/签到/任务/探索/NPC 对话等）首行加前缀；机器人主动推送、系统公告、群广播**默认不加**（show_on_system:false 默认；可配 true 则也加）。
2. **群聊 + 私聊默认都生效**：per_channel 默认 all；可配 group（仅群聊）/ private（仅私聊）。
3. **前缀只加合并消息首行**：一轮战斗 = 1 条消息（玩家行动+怪物反击合并），前缀只出现在该消息第一行；多行回复仅首行带前缀。
4. **前缀不影响指令解析**：解析用指令原文，前缀是渲染层产物（不进解析器、不进条件键、不进存档）。
5. **私聊群名兜底**：[群名] 在私聊渠道输出 "私聊"（建议值，可配——跟随 per_channel 语义由内容包定）。

## 六、与称号系统联动

- **[称号] 读取玩家「当前佩戴称号」**：佩戴状态落点由成就批设计并登记（3.7 玩家存档，键名以成就批定稿为准）；本定稿只读引用，不另立存储。
- **称号来源（成就批设计）**：成就奖励 / 职业王称号（炼金王、锻造王等，职业熟练度与生活系统定稿 §2.1）/ 品评会冠军称号——三来源统一进「可佩戴称号池」，前缀只展示佩戴中的那个。
- **无称号默认显示 "-"**（empty_title_text 默认 "-"）：`Lv35.阿伟 - -`。
- **hide_when_empty:true → 整段省略**：无称号时省略 [称号] 占位符**及其相邻装饰符**（如默认格式中的 "-" 和 "-"），输出 `Lv35.阿伟`（尾随空格清理）。
- **empty_title_text:""（不带 hide_when_empty）**：仅隐藏占位符本体，保留装饰符 → `Lv35.阿伟 - -` 变为 `Lv35.阿伟 - -`（即 "-" 与 "-" 之间空，装饰符仍在）——两种口径都提供，作者自选。
- **前缀 = 称号展示出口**：王称号/品评冠军/成就称号随每条回复展示（成就批联动价值），不新增任何额外消息。

## 七、前缀与消息长度限制（选型说明）

**选型：前缀不计入消息长度限制。**

- 理由：消息长度限制的语义 = 正文防刷屏（正文是战斗/任务内容，超长会刷屏）；前缀是固定短文本的身份标识（默认 ≤40 字符），由内容包作者控制，不参与正文长度判定。
- **防御兜底**：`prefix_max_len`（默认 40，0=不限）——渲染后前缀超长 → **截断 + 黄色提示**「前缀过长已截断」（提示归属发起指令所在群，不阻断正文输出）。
- 校验器对 format 模板超长（>80 字符）黄色提示（可加载）。

## 八、编辑器（通用设置页 message_prefix 卡片，零代码）

- [开关] 启用消息前缀（enabled）
- [格式模板] 文本框 + **占位符下拉插入**（[等级] [玩家名] [称号] [群名] [职业] 五个按钮/下拉项，点击插入光标处）
- [实时预览] 示例玩家渲染：默认展示 `Lv35.阿伟 -斩龙者-`，改模板即时刷新预览（含无称号/有称号两种预览态切换）
- [显示规则] show_on_system 开关 / per_channel 下拉（all/group/private）/ hide_when_empty 开关 / 空称号文本输入 / prefix_max_len 数值

## 九、校验器提示（message_prefix 行）

**硬拦（红，拒绝加载）**：
- enabled 非布尔 / format 非字符串 / prefix_max_len 负数（→ 已按 0=不限 提示修正）
- 结构错误（必填缺失 / JSON 格式坏）→ 人话模板

**黄提示（可加载）**：
- 未知占位符（不在 §四 表中）→ "模板里有不认识的东西 [xxx]，会原样显示，确认？"
- format 为空 → 已按默认格式补全提示
- format 超长（>80 字符）/ 占位符过多（>10 个）→ "模板有点长，注意前缀别刷屏"
- per_channel 枚举值非法 → 已按默认 all 补全提示
- prefix_max_len 超常见区间（>200）→ 确认提示

## 十、配置示例

```json
// 示例 1：默认开箱即用
"message_prefix": { "enabled": true, "format": "Lv[等级].[玩家名] -[称号]-" }

// 示例 2：职业版（作者自定格式）
"message_prefix": { "enabled": true, "format": "[职业] Lv[等级].[玩家名]" }

// 示例 3：群名片版
"message_prefix": { "enabled": true, "format": "【[群名]】[玩家名]" }

// 示例 4：无称号整段省略 + 仅群聊
"message_prefix": { "enabled": true, "format": "Lv[等级].[玩家名] -[称号]-", "hide_when_empty": true, "per_channel": "group" }
// 阿伟 35 级无称号群聊回复首行 → "Lv35.阿伟"

// 示例 5：关闭前缀
"message_prefix": { "enabled": false }
```

## 十二、风险与对策

| 风险 | 对策 |
|---|---|
| 前缀干扰阅读/刷屏感 | 仅首行 + 不计入正文长度限制 + enabled 可关（默认开，内容包可关） |
| 称号/群名过长撑爆消息 | prefix_max_len 默认 40 截断 + 黄色提示（0=不限，作者自定） |
| 未知占位符作者笔误 | 原样输出 + 黄色提示（只建议不限制，不拦加载） |
| 私聊无群名 | [群名] 输出 "私聊"（建议值可配） |
| 与成就批耦合（佩戴状态未登记前） | 只读引用 + 无称号兜底 "-"，缺状态按无称号渲染，不报错 |
| 系统公告误带前缀 | show_on_system 默认 false（系统公告/群广播豁免） |
