## 二、verify_m6 两段式定义（VM6×4）

**VM6-1（段一·接线闭环门禁）**：verify_m6 段一 = SCP-4 八项验收单的可执行断言：
1. 热重载接线回退（watcher 启动装载 + 调度驱动 + /重载 真实后端 + ReloadResult→人话翻译 + P0-1 续战世代绑定重绑定 + F5 验收③快照冗余断言）→ 细化_M6_热重载接线 D3
2. 冒烟闭环（四件套 validator 矩阵 + 真实 BattleEngine 模拟一局「注册门槛→锁定→攻击→结算」逐步断言 + 五档包 validator 全绿）→ 细化_M6_内容包冒烟 D4
3. 故障注入六类（tests/fault/ 六脚本全过 + `--only fault` 分支）→ 细化_M6_故障注入 D5
4. 覆盖率 ≥80%（qbot_rpg/core + engine + content 各自实算 + 报表归档 docs/verify/）→ 细化_M6_质量门禁 D7
5. ruff/mypy/pytest 全绿（pyproject [tool.ruff]/[tool.mypy] 快速门）→ 细化_M6_质量门禁 D7
6. 内容包 validator 全绿（红拦真拦截/黄提示可过，子进程 PYTEST_FILES 载体）→ 细化_M6_verify门禁与承接 D8
7. 里程碑验收单（对照【规划】任务勾选，产物 docs/verify/m6_checklist.md）→ 细化_M6_verify门禁与承接 D8
8. CHANGELOG + verify 输出归档（docs/verify/）→ 细化_M6_质量门禁 D7

**VM6-2（段二·承接 M2-M5 DELAYED）**：图鉴分级（1f-TC-11/12）、防嵌套红拦（2a1c-TC-22）、锻造 TPL-10/11（3d TC-16/17）、/注册（4f TC-01~04/06）、/状态（4f TC-07/09/10）、快捷解绑/列表（4f TC-17/22/23）——各转 `pytest:` 承载落 verify_m6 断言或显式残留登记（残留登记含到期日与原因，杜绝永久死缺口）。依据【仲裁】二·项7；【审查·批3组B】P1-2。

**VM6-3（不假绿铁律）**：run_all_tests 对未实现门禁显式失败——`--only m6` 在 script is None 时 exit≠0；全量回归遇 m6=None 置 fail 并提示「M6 未接入 → 门禁不完整」。依据【仲裁】二·项3；【审查·批3组B】P0-2。

**VM6-4（DELAYED 到期扫描）**：t_coverage_self_consistent 升级为「DELAYED 到期扫描」——解析每个 DELAYED 的「依赖 M<N>」目标，对比 verify_m<N>.py COVERAGE 是否承接；过期未翻转即失败。verify_m4 批次7-01（test_e2e_m4_smoke.py 已落盘）立即翻转 `pytest:test_e2e_m4_smoke.py::test_smoke_*`。依据【仲裁】二·项3；【审查·批3组B】P1-1 /【审查·批2组B】P2-1。
