## 〇、v0.5 → v0.6 关键修正（推演反馈结论）

| # | 修正 | 原因 |
|---|---|---|
| 1 | **方位与 combo 彻底解耦**：height 是独立快照字段，不塞进 combo 6 态 | combo 是成熟独立状态机（idle/in_combo/derivable/deriving/at_max_reset/at_max_hold），融合会组合爆炸 |
| 2 | **"技能永远可施放"→"方位永远不导致技能拒绝"**：施放资格（MP/能量/冷却/季节/职业/连段/印记门禁）与方位命中资格解耦 | 现状 _do_action_inner 有大量拒绝门禁，语义必须兼容 |
| 3 | **部位 = EnemyDef.parts[] 数组**（非单数 part）；支持同方位多部位 + target_priority | 一个方位可挂多部位（前+地=头/胸），需解析规则 |
| 4 | **破坏力按 damage segment 逐段结算**，输入用独立 break_damage_basis（默认 raw_damage，DamagePipeline 前） | 一次攻击是 segments[] 多段独立结算；防护盾吞伤归零/防破位增伤自反馈膨胀 |
| 5 | **本次破位不吃本次增伤**（硬时序：按破位前状态算伤害→结算破坏力→若破位→下次起效） | 防自反馈：破位→增伤→伤害↑→破坏力↑ |
| 6 | **即时调合不是 BattleEngine 原生 action**；空中落地通过战斗行动接线层 air_policy，不在 BattleAlchemyEngine 内改位置 | 即时调合走 command→BattleAlchemyEngine→use_battle_item→_resolve_item_action 子流程；防 core 层反向依赖 battle 状态机 |
| 7 | **on_break 默认触发 + 部位可覆盖**（knockdown: 0 允许） | 用户拍板"任何破位即倒地"=框架默认；断尾/断须未必都完整倒地，自由度留给配置 |
| 8 | **熟练度乘区 = alchemy_proficiency_mult 配置变量**（settings battle_alchemy.proficiency_multiplier {min:0.6, max:1.2, curve}），不硬编码 | 现 BattleAlchemyEngine 只有大师门槛（_master_ok），强度公式无熟练因子——真缺口，按框架公式+内容配置补 |
| 9 | **素材语义修正**：现 BattleAlchemyEngine 只有 count_item/remove_item hook（素材源由壳层注入），无原生容器；BattleEngine.start() 冻结 battle_resources.materials 进快照 | 快照=战斗唯一权威状态 |
| 10 | **怪物方位行动走 effects 新原子 reposition**（set/rotate），不新增 battle.py 特殊函数 | 现有"敌方行动 effects 通道"已验证（battle.py 敌方 effects 装配） |
| 11 | **空间寻址与实体寻址分离**：ActionCore 统一加 position_rule（side[]/height[]），不复用 target | target=enemy_single/enemy_all 是目标选择范围，不是空间覆盖 |
| 12 | **新增 T8 结算时序**（见 §四） | 行动/伤害/破位/方位/落地插入点不定，开发必打架 |
| 13 | **快照双轨架构前置**：新字段先进真实 _snap dict；data/battle.py BattleSnapshot dataclass 收敛另设独立迁移 | data/battle.py 自记"真实实现仍是 dict，与 dataclass 不同" |
| 14 | **测试基线表述修正**：仓库完整依赖（.venv）下基线=10 failed（既有集合，不得新增红）；外部审查环境缺 aiosqlite 致 collection 18 errors 属环境问题，不反映功能基线 | 防误读 |

## 一、定位

8 方位（前/后/左/右 × 空/地）+ 部位破坏 + 空中规则 + 战斗调和联动，作为框架通用原语。veinborn 是第一个适配载体。

## 二、机制定稿（用户拍板，保留）

1. **方位模型**：玩家相对怪物站位 {前/后/左/右}×{空/地}；永远朝向怪物；方位不导致技能拒绝（只决定落点/部位/破坏力累计/高度可达性）。
2. **空中规则**：攻击延续连段→保持空中至连段终结；终结技打出→落地；防反/闪反成功派生→保持、未成功→落地；主动落地技存在；中断连段类行动（道具/待机/即时调合）→落地 [游戏规则保留；实现走 air_policy 见 §三.6]。
3. **伤害三层**：任意攻击打整体 HP；已破部位方位=常驻增伤；倒地窗口（1-2 回合）内打已破部位=叠加增伤。任何部位破位触发倒地 [框架默认 on_break.knockdown=1，允许部位配置覆盖]。
4. **部位与破坏力**：部位无独立血条；破坏力=技能固有值+√(max(0, 本次伤害−基准))；与伤害解耦（秒杀低级怪不破位）；破位通用效果=倒地+素材掉落。
5. **怪物方位行动**：置换原语（冲锋=前方玩家→后方；转身=前↔后、左↔右 重映射）。
6. **组队**：1v1 现状；组队同场独立里程碑（方位原语按多玩家可扩展设计）。
7. **战斗调和**：M8 BattleAlchemyEngine 主体复用；熟练度乘区 60~120% 为真增量；配方解锁上移 recipe/proficiency 层。

## 三、七原语（JSON schema 定稿）

### 1. PositionState（战斗快照内）
```json
"combat_position": {
  "relative_to": "enemy",
  "side": "front",            // front | back | left | right
  "height": "ground"          // ground | air
}
```
- 每个 combatant 一份；facing 不单独建模（玩家恒朝敌；怪朝向 = 决定 side 的参照，存怪物侧 `"facing": "front"` 如需显式）。
- 新增字段先进 core/battle.py `_snap`（权威）；data/battle.py BattleSnapshot 收敛另设迁移（§五）。

### 2. PositionRule（ActionCore 统一扩展——技能/怪物行动/特殊行动共用）
```json
"position_rule": {
  "side": ["front"],              // 缺省=全部
  "height": ["ground", "air"]     // 缺省=全部
}
```
- 语义：**命中资格**——行动打得到哪些 side/height 的玩家（对怪）或怪部位（对玩家）。
- 不叫 target（空间寻址与实体寻址分离）；不做 can_hit_air/can_hit_ground 双套。
- 怪物侧示例：地面扫尾 `{"side":["left","right"],"height":["ground"]}`；跃空玩家不在其内=该行动对空中玩家无落点（miss 语义见 §四 时序）。

### 3. PartState（EnemyDef.parts[]，非独立 parts.json）
```json
"parts": [
  {
    "id": "shell", "name": "龟壳",
    "positions": {"side": ["front","back","left","right"], "height": ["air"]},
    "break_threshold": 100,
    "target_priority": 0,          // 同方位多部位：priority 高优先，同值随机
    "on_break": {
      "knockdown": 1,              // 默认=1；0 = 该部位破位不倒地（覆盖框架默认）
      "marks": [],                 // 破位附加印记（如素材掉落标记）
      "effects": []                // 破位附加效果（如断尾削扫尾范围=此处挂行动禁用/替换）
    }
  }
]
```
- 战斗快照内每部位：`"parts_state": {"shell": {"break_value": 0, "broken": false}}`。
- 部位共享模板未来引入 part_templates，第一版不做。

### 4. BreakPowerEvent（每 damage segment 一次）
- 公式输入变量契约（formula_engine 中文占位符消费）：
```
break_damage_basis   // 默认 = raw_damage：命中/会心/格挡/防御/乱数后、DamagePipeline 最终拦截前
skill_id / segment_index / hit / crit / blocked
position.side / position.height / target_part
part_break_value（当前部位累计破坏值，破位判定用）
```
- 结算：`break_delta = skill.break_power + √(max(0, break_damage_basis − 基准伤害))`；基准伤害与 √ 系数走 formula 配置 [数值阶段定]。
- 多段技能 hits=N → 破坏力计算 N 次（写死，防多段/单段量级失衡）。

### 5. RepositionEffect（effects 新原子动作——怪物方位行动载体）
```json
{"type": "reposition", "target": "player", "mode": "set_relative", "side": "back", "height": "ground"}
{"type": "reposition_all", "mode": "rotate", "mapping": {"front":"back","back":"front","left":"right","right":"left"}}
```
- 走现有"敌方行动 effects 通道"；冲锋=伤害段 + reposition_all(rotate 前→后)；扫尾转身=reposition_all(rotate 180°)。
- 玩家机动技/跃空 = 玩家侧技能 effects 里 reposition（set_relative 任意格 / height 切换）。

### 6. AirPolicy（行动结束后的高度策略，与 combo 完全分离）
```json
"air_policy": "preserve" | "land" | "preserve_height"
```
- 落点：行动定义（技能 action/skill 顶层键；即时调合=战斗行动接线层传 `action_category="alchemy", air_policy="land"`，不在 BattleAlchemyEngine 内改位置）。
- 语义：preserve=保持当前高度；land=无论当前高度行动后落地；preserve_height=保持（显式别名，兼容默认）。
- 游戏规则映射：攻击延续连段 → preserve；连段终结技 → land（终结=强击落地）；防反/闪反成功 → preserve、失败 → land；道具/待机/即时调合 → land（与 combo 是否打断无关——道具现状不打断 combo，两者正交，改 air_policy 不动 combo 引擎）。

### 7. BattleResourceState（战斗携带素材冻结）
```json
"battle_resources": {"materials": {"herb": 3, "iron": 5}, "battle_alchemy_used": 0}
```
- BattleEngine.start() 时从玩家背包快照允许携带的素材冻结进 _snap；即时调合只读写 battle_resources.materials（现有 count_item/remove_item hook 绑到该容器），不碰玩家实时背包。
- battle_alchemy_used 已实现于快照顶层（M8），并入此状态段统一管理。

## 四、结算时序（T8 定稿——BattleEngine 插入点）

现状主链：action_start → action → segment → damage → death check → action_end → next actor

方位系统插入后（每 action / 每 segment）：
```
action_start
  ├─ position resolve      （reposition 类效果结算于此处先行的效果段）
  ├─ height check          （行动 position_rule vs 玩家当前 side/height）
  │    └─ 无命中资格 → miss 语义：技能照常消耗、不产生伤害/破坏力，文案"够不着"（不拒绝施放）
  ├─ part resolve          （resolve_part_target(position, action)：candidate parts → target_priority 高优先/同值随机；无部位方位=纯本体）
action
  └─ per segment:
       ├─ 现有伤害链（命中/会心/格挡/防御/乱数）
       ├─ position_bonus × knockdown_bonus    （modifier：基础伤害→技能倍率→现有公式→position_bonus→knockdown_bonus→DamagePipeline）
       ├─ break power       （按 break_damage_basis 逐段；破位判定：累计 ≥ break_threshold）
       │    └─ 破位事件：本次伤害不享受本次破位增伤（按破位前状态结算）→ 置 broken → on_break 效果（knockdown/掉落/附加）
       ├─ damage pipeline → 扣血 → death check
  └─ action_end
       └─ air_policy 结算（land → height=ground；preserve → 保持）→ next actor
```
硬规则：破位增伤自下一段/下一次攻击起效（本次破位的这一下不吃）；破坏力不被 DamagePipeline 拦截影响（护盾吞伤不吞破坏力）。

## 六、边界纪律（防污染成熟模块）

| 不做 | 替代 |
|---|---|
| 方位塞进 combo_state | height 独立字段 + air_policy |
| position → 单一 part 映射 | position + action → candidate parts → resolve_part_target |
| part state 塞进 marks | parts_state 独立快照段（marks 仍可作破位附加印记/增伤读取） |
| BattleAlchemyEngine 直接操作 battle 位置 | 战斗行动接线层 air_policy |
| recipe 解锁逻辑下沉到即时调合 | recipe_resolver.resolve_available(player, recipe_id)，解锁归 recipe/proficiency 层 |
| battle.py 加 turn_monster/charge_replace 特殊函数 | effects reposition 原子动作 |
| 伤害新乘区模糊塞入 | position_bonus/knockdown_bonus 明确 modifier 位置（§四） |
| 双套 can_hit_air/can_hit_ground | ActionCore 统一 position_rule |
