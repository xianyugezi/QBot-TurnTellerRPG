## 0. 证据口径（先说清"消费点为空"怎么判）

1. **登记类**：定义处取 file:line；消费点用
   `grep -rn "<键>" --include=*.py qbot_rpg | grep -v <登记文件>`。
   若命中全部落在「登记文件 / 字段元数据 / 校验器 / 预设定义 / 文档字符串」，即判定 **无引擎消费点**。
   校验器只校验"结构合法"不等于"生效"——本审计额外区分。
2. **死代码**：AST 收集 `qbot_rpg/**` 全部 `def`，统计其名字在
   `qbot_rpg + tests + scripts + qbot_rpg_bridge` 全部 `.py` 原文（含注释/字符串）中的出现次数；
   **出现次数 ≤ 定义次数（通常 1）** 即候选，再人工复核动态引用（`getattr`/注册表/插件）。
   该法把字符串引用也算作消费，故对 `__all__`/`getattr("name")` 是**保守**的；但名字出现在
   `__all__` 里会掩盖真实无调用，故另跑一轮"扣除 `__all__`"。
3. **动态引用复核**：已检查 `getattr(obj, <变量>)` / `globals()` / `vars()` / pytest 钩子 /
   `scripts/verify/*` 的存在性断言，逐条注明。

> 复核工具：`ruff 0.16.7`（仅查未用 import/变量，函数级死码靠上述 AST 脚本）；无 `vulture`。
