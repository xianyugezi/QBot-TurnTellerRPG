## 〇、契约总则

### 0.1 术语表

| 术语 | 定义 | 依据 |
|---|---|---|
| 职业变换 transform | 战斗内职业技能形态切换——使用触发技能后在战斗中变换职业形态；**职业特色机制，非框架级常态换职业** | 【笔记 L101-105】「使用技能后在战斗中变换职业形态…这是职业技能特色（变身系职业专属）」 |
| 触发技 transform_skill | 一次行动（耗 MP+回合）的变身技能，成功结算后触发变换 | 【笔记 L132】；【狂战士 L90-97】 |
| 形态 form | 变换到的战斗形态标识（job_form 的值域），如 berserker_form | 【狂战士 L97/L134】 |
| 形态状态 form status | 挂在单位身上的 L1 强化状态（如 rage_form），可被驱散，是「形态」在效果系统里的可见载体 | 【狂战士 L97/L252/L315-322】（状态细节见细化_1b，本文只定义联动钩子） |
| 技能位重排 | 技能位随形态切换为独立形态技能组（transform_skills）；被动/触发槽双形态独立装配 | 【狂战士 L175】「常态技能位…↔ 形态技能位…被动/触发槽双形态独立装配（…job_form 字段限定）」；【笔记 L139】 |
| state_policy | 变换瞬间/还原瞬间的资源处理策略（连段/印记/buff 三键 clear|keep） | 【狂战士 L128-133】；【笔记 L118-122】 |
| 形态冷却 cooldown | 从「触发」起算的形态冷却，防无限变身滚雪球 | 【狂战士 L106/L142】；【笔记 L117】 |
| job_form | 技能侧挂点字段：标记技能仅在某形态下可用（形态限定技能） | 【狂战士 L193/L200/L210/L215】 |
| revert_form | 技能侧挂点字段：使用后立即还原形态（主动还原钩子，非 L0 效果动作） | 【狂战士 L116/L201】 |
| dispel_reverts | transform 段字段：形态被驱散→触发还原；false=形态免疫驱散 | 【狂战士 L121/L301】 |
| job_scope | 派生链作用域：链仅对指定形态/职业生效，切换后重新评估 | 【狂战士 L226/L328】；【笔记 L179】 |

### 0.2 一句话契约

> 【狂战士 L4 定位段】「常态攒怒气 → 怒满施展『狂暴』→ 战斗中变换为『狂战士形态』→ 形态技能组爆发吸血 → 狂暴结束/被驱散/主动还原回常态」。
> 变换引擎 = **触发技效果先结算 → 变换（不额外耗回合）→ 技能位重排 + state_policy 处理 → 形态持续回合 tick → 还原（自然结束/主动 revert_form/被驱散 dispel_reverts 三路）→ state_policy 执行 + 形态冷却 → 形态专属派生链重评估**；
> `job_form + remaining + cooldown` 随 battle_state 快照持久化，中断恢复还原形态，战斗结束（死亡/胜利/失败/逃跑）形态清零回常态【狂战士 L90-111 / L113-123 / L125-135】【笔记 L132-140】。

### 0.3 决策记录（ADR，对定稿空白的显式收敛，标注【补白】或【仲裁】）

| 编号 | 决策 | 理由 | 影响用例 |
|---|---|---|---|
| D-01 | transform 段为 jobs.json 单例：**一职业一个 transform 段**，`transform_to` 单一目标形态；多级变身（A→B→C）由内容包用多职业+多 transform 段组合实现 | 【笔记 L146】「多形态职业（多段变身）：A→B→C 逐级变身（每段独立冷却）」— 定稿未规定单段结构是否允许多目标，收敛为单例防状态机歧义【补白】 | TC-18 |
| D-02 | **形态状态（rage_form）与形态指针（job_form）双轨**：form status 是效果系统视野（可被驱散、吃 stat_modifier），job_form 是引擎视野（技能位/派生链/快照的形态判定键）；两者通过 dispel_reverts 字段决定是否联动，不隐式绑定 | 【狂战士 L97】（变换瞬间同时施加状态+切 job_form+重排技能位）三动作并列 → 双轨是定稿三动作的显式拆分；【狂战士 L247】「形态切换本身是框架级职业机制…不是效果系统效果」 | TC-07/TC-08 |
| D-03 | 兑换节奏约束：形态持续/冷却计时**挂在回合 tick 推进**，与回合结束 tick 同拍（1g1a ⑥）；变换/还原瞬态不占行动权、不落快照 | 【狂战士 L108】还原在回合结束 tick；【笔记 L134】turns 口径=玩家行动回合计数 | TC-05/TC-13 |
| D-04 | `battle+revert 矛盾`裁定为**红拦**（结构死配置类）——与规划_路3 B5 的「黄提示」规划分歧按细化层仲裁：以【规则】L157 与细化_3e2 BLK-1 登记字面为准（红拦 5 类含「battle+revert 矛盾」），理由=矛盾配置令还原时序二义（battle=整场不还原 vs revert=结束后还原），红拦更安全且与技能库校验器「死配置」口径一致【仲裁】 | 覆盖审计_H L106 仅记录现状（路3 B5 黄提示），P0-1 L191 要求「校验 6 条」落契约 → 本文在此收口 | TC-18 |
| D-05 | 形态被驱散的结算时点=**下一回合结束 tick**（与自然结束同规则），而非驱散命中即时；即时生效的仅主动还原（revert_form） | 【狂战士 L122】「被驱散还原与自然结束还原同规则（回合结束 tick 结算…）」；L115 主动还原「使用后立即结束形态」— 定稿两路时点不同，显式固化 | TC-07 |

```text
② 读 transform_state：form=berserker_form → 恢复形态上下文                    【狂战士 L134】【笔记 L140】

```
