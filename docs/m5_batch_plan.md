## 批0 公共接线（D1 + 3h）——2 路

### M5-01 消息前缀消费接线
- **内容**：message_prefix settings 段全字段消费——`show_on_system`（系统公告/群广播豁免，默认 false，true 时也加）、`per_channel`（all/group/private 渠道限定）、`enabled` 总开关（默认 true，false 完全无前缀）；前缀渲染结果注入玩家指令回复**首行**（装配层统一入口，非各指令自行拼装）；**截断黄提示发射**——消费 `render_prefix_result().truncated` → 输出「前缀过长已截断」（归属发起指令所在群，不阻断正文，3d §3.3/TC-13/【前缀】L100）。
- **依据**：shared_contract §一 / 细化_3d §1.5/§3.3 / 【前缀】§五/§七 / 3h §6.1
- **实现位置**：qbot_rpg/commands/ 装配层（router 或 sender 注入点）+ 一个 settings 读取 helper；用真实签名 `render_prefix(level, name, title, *, format_template, hide_when_empty, empty_title_text, prefix_max_len, extra)`（[群名]/[职业] 经 extra 传入）
- **验收**：① show_on_system=false 时系统公告无前缀，true 时加 ② per_channel=group 仅群聊加/private 仅私聊加 ③ enabled=false 完全无前缀 ④ 玩家指令回复首行带前缀、多行仅首行 ⑤ 前缀不影响指令解析 ⑥ 前缀超 prefix_max_len → 截断 + 「前缀过长已截断」黄提示，正文照常输出（TC-13）

### M5-02 message_prefix 校验器接线（规则源【前缀】§九 + 3d 附校验器行）
- **内容**：settings.json message_prefix 段校验器——硬拦（enabled 非布尔/format 非字符串/prefix_max_len 负数/结构错误）+ 黄提示（未知占位符原样输出、format 空按默认补全、format>80 字符/占位符>10 个、per_channel 非法按 all 补全、prefix_max_len>200）。
- **依据**：【前缀】§九（L112-121）/ 细化_3d 附·校验器行（L358）/ shared_contract §1.4；注意 **3h V9~V12 明确不覆盖 message_prefix**（3h §6.1「本契约 V9~V12 不重复覆盖」）
- **实现位置**：qbot_rpg/content/ 校验器（settings 段注册）
- **验收**：非法包产生红/黄分类正确（对齐 3d 附·校验器行 L358 一览）

## 批1 战斗渲染实装（D5 核心，最大块）——3 路

### M5-03 battle_render 骨架 + 玩家行动战报（BREP-01~09）
- **内容**：按**现有骨架签名**实装 render_battle_start/render_battle_round/render_battle_end + 玩家行动模板——BREP-01 前缀行（委托 prefix_render）/02 攻击命中（`✅ 你{攻击动作}{目标}，造成 {伤害} 伤害（{目标} {剩余HP}/{最大HP}）`——HP 后缀必须保留；{目标} 可选仅指动作短语）/03 未命中/04 会心·格挡附注（会心档 ×2.2/1.7/1.3、格挡 ×0.5）/05 防御/06 防御受击/07 技能释放/08 状态资源差分行（只渲染变化轴，状态数前 5+「还有 N 个状态」）/09 操作提示行（`你 {HP}/{最大} | {目标} {HP}/{最大} → /攻击[技能] /道具 /防御 /逃跑`，多怪取第一存活怪）。
- **依据**：5e BREP-01~09 + TC-07~11 / shared_contract §5.2 / 铁律 3/8/10/11
- **输入**：`TurnReport`（outcomes 流水）+ `ActionOutcome`（**实际字段 ok/hit/crit/blocked/raw_damage/final_damage/target_hp/side_effects/message/battle_ended/status**——无 rating/damage/outcomes；战报伤害取 `final_damage`、目标 HP 取 `target_hp`）；**⚠️ 不直接复用引擎 message**（5e P2-8）
- **验收**：TC-07/08/09/10/11 逐字对齐（TC-07 含 `（史莱姆 7/25）` HP 后缀）；无装饰 emoji（✅/❌ + 排版符号豁免）

### M5-04 怪物行动 + 结算战报（BREP-10~20）
- **内容**：怪物行动——BREP-10 反击命中/11 未命中/12 意图预告（`{怪物} 蓄力中（下回合发动「{招名}」）` 固定句式 D-5E）/13 特殊行动/14 拦截链效果行（盾吸收/反弹/免疫）；结算——BREP-15 击杀（**紧跟伤害行**，扣血后立即查）/16 玩家死亡/17 胜利/18 失败/19 互杀平局（默认 draw，可配 player_loss）/20 经验与掉落（**只在战斗结束消息输出一次**，不逐怪逐段刷——军规5）。
- **依据**：5e BREP-10~20 + TC-12~20 / shared_contract §5.2 / 铁律 9/11
- **验收**：TC-12~20 逐字对齐；击杀行紧跟伤害行；先手击杀不渲染怪反击行（写死）；胜利/掉落与汇总同消息且只输出一次（军规5）；BOSS/最后目标死亡立即结束、后续段数作废

### M5-05 连段 + 开始/结束/明细战报（BREP-21~25）
- **内容**：连段——BREP-21 段行（`第 {N} 段：…` 每段独立一行，每段独立取整，段号=收集器 seg）/22 结算行（套完结/鞭尸/BOSS 提前结束/派生封顶 ≤1.5× 附注）；开始/结束——BREP-23 战斗开始（+意图/弱点情报行）×1 条 /BREP-24 汇总（`战斗结束：{胜负}｜回合数 {N}｜输入 /战斗记录 查看明细`）/BREP-25 木桩明细块（摘要行 `总伤害 {N}｜最大单段 {M}｜会心 {K} 次｜格挡 {G} 次` + 条目行 `{来源} {总伤害}（{占比}%）` + 5 条/页分页 + **≤16 行折叠** TPL-09，普通战斗默认不展示）。
- **依据**：5e BREP-21~25 + TC-21~27 / shared_contract §5.2 / 铁律 4/11
- **验收**：TC-21~27；战斗开始 1 条/结束 1 条（合并策略）；木桩 5 条/页 + TPL-08 + ≤16 行折叠（**TC-06 折叠断言**：BOSS 45 回合单条消息 ≤16 行）
