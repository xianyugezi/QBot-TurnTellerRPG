## 一、属性清单（9 项 · 用户中文名 + 怪猎映射）

| # | ID | 名称 | 怪猎映射 | 作用 |
|---|---|---|---|---|
| 1 | hp | 生命 | hp | 生命值，归 0 战败 |
| 2 | mp | 魔法 | mp | 技能消耗资源 |
| 3 | str | 力量 | **atk** | 物理攻击基础（斩/打/突 共用） |
| 4 | int | 智力 | **mag** | 魔攻/法强（魔攻击类型专用） |
| 5 | con | 体质 | **def** | 物理防御（物理减伤） |

> 属性 ID = 用户中文名体系（str/int/con/spr/foc/agi/lck）；映射表供旧内容包/公式层桥接（atk→str、mag→int、def→con、spirit→spr、luck→lck）

### 双轨（物理/魔法）
```
攻击侧：力量(str) → 斩/打/突 伤害    智力(int) → 魔攻击伤害（法强）
防御侧：体质(con) → 物理减伤        精神(spr) → 魔法减伤
减伤：体质/(体质+K) 除算（无悬崖无封顶，K=100 可配）
```

## 二、会心体系（用户拍板：A+B 结合）

### 2.1 会心率（频率）
```
会心率 = min(95%, √最终幸运 × crit.p_coef%（默认 0.5 → √幸运×0.5%，可配） + crit_bonus)
- √幸运×0.5%：属性驱动基础（借绮谭必杀率口径，用户拍板保留）
- crit_bonus：装备/技能/效果提供的会心加成（怪猎原味：看破/弱点特效类）
- 双通道共用一次会心判定（物理+元素同判）
```

### 2.2 会心倍率计算（用户定稿）

> 数值源 = formula.json crit.*（可配），本表为默认值展示——p_coef（会心率）/ tier_p（降档）/ tiers（各档倍率）/ crit_mult_up（超会心档）均以 formula.json 为准，作者改 crit.* 后以公式配置为准。

```
P = √幸运 ÷ 2
随机数 r = 1~100

r ≤ P        → 高级会心：2.2 + 0.05×超会心等级
r ≤ P×3      → 中级会心：1.7 + 0.05×超会心等级
r > P×3      → 低级会心：1.3 + 0.05×超会心等级

超会心档数与每档倍率：由 formula.json crit.crit_mult_up 配置——默认 Lv1-3 = 0.05/0.10/0.15（Lv0=无加成），每档倍率可配（效果系统按档提供超会心等级）

倍率矩阵验证：
            低级会心  中级会心  高级会心
基础         1.3      1.7      2.2
超会心 Lv1   1.35     1.75     2.25
超会心 Lv2   1.4      1.8      2.3
超会心 Lv3   1.45     1.85     2.35
（“超会心 Lv1-3”档位表为默认 4 档 0-3 展示；档数与每档倍率可配，见 crit.crit_mult_up）

- 示例：幸运 100 → P=5 → 高级会心 5% / 中级会心 10% / 低级会心 85%
- 负会心 ×0.75（可选，怪物配置）
```

### 2.3 幸运职责
```
幸运 = 会心率（频率）+ 会心三级（质量）+ 概率修正（强化成功率/异常赋予/特效触发，√体系）
低成长（+0.8/级）——万金油但单点收益小
```

## 三、专注/命中/格挡（用户新增项 + 格挡减半特色）

### 3.1 命中率（用户指定公式 + 边界）
```
命中率 = clamp(专注 / (专注 + K × 对方敏捷), 10%, 95%)
- 命中 K 唯一源 = formula.json hit.k（默认 1.0，可配；战斗数值层/玩家属性/效果表达式引用同键）；对方敏捷 0 → 100% 命中
  - 【2026-08-24 用户拍板】K 统一为 1.0 唯一权威（contract_deviations P1-1）：本行原默认 0.2 为拍板前旧口径，已按拍板改为 1.0——战斗路径 HitParams.k / damage.hit_rate 默认均已落 1.0，3b §5.2 派生口径同 1.0；formula.json hit.k 可配覆盖。
- 双方都 0 → 100% 命中（0/0 兜底）
- 怪物敏捷缺省 → 按等级换算兜底
- 战斗提示显示当前命中率（"命中率 72%"）
```

### 3.2 格挡（专注提供 + 格挡减半特色）
```
格挡率 = min(40%, 专注 / (专注 + 150))
- 格挡 = 会心后最终伤害减半（与 /防御 指令乘算）
- 【格挡减半特色（绮谭参考）】：每次触发格挡后，当回合格挡率减半，下回合恢复
  · 1v1 一轮单次攻击：格挡后本回合已无二段攻击，减半规则不消费（不触发二段）
  · 【组队模式预留】：未来组队/多段攻击场景下减半规则生效（防无限格挡坦克）
- 格挡判定在命中→会心之后（串行：命中 → 会心 → 格挡）
```

### 3.3 判定顺序（写死）
```
命中 → 会心 → 格挡 → 双通道伤害（各自取整后相加）→ 防御率 → 伤害拦截链 → 扣血
```

## 四、元素双通道（怪猎核心，装备承载）

### 4.1 元素攻击力（7 元素，修正 8→7 笔误）
```
- 7 元素：地水火风雷晶月（无属性 = 无元素攻击力，靠高白值补偿）
- 元素攻击力不进玩家基础属性（默认 9 项为预置模板，stats.json 支持注册自定义属性）
- 由装备/武器承载：stats_bonus {"ele_atk_fire": 8}
- 运行时进入【加成层 flat】→ 参与三层管线（白值 0 → 加成 flat → ×(1+临时%)）
- formula.json channels.element 声明；校验器查注册表
```

### 4.2 元素通道公式
```
元素伤害 = floor(装备元素攻击 × 元素动作倍率 × 会心 × 元素弱点 × 元素减伤)
总伤害 = floor(物理通道) + floor(元素通道)   （独立取整后相加）
- 弱属性的怪用元素武器收益大（怪猎双通道灵魂）
- 元素弱点：怪物配置弱点表（×1.3 或自定义）
```

### 4.3 元素抗性（装备词条承载）
```
- 元素减伤率 = elem_res / (elem_res + 100)
- elem_res 不进基础属性，由装备/饰品词条提供（加成层 flat，默认 0）
- 玩家无法加点；PVE 怪物可自带
```

## 五、三层数据结构（用户核心设计）

```
玩家属性 = 三层：
① 白值——永久（基础 + 职业成长）
② 加成层——非战斗也存在（装备永久 + 药剂有时效）
   数值层 flat：固定值（+5 力量）
   百分比层 pct：百分比（+10%）
③ 临时层——战斗 buff（战斗内，结束清除）
```

### 计算模型（防无限叠乘）
```
① 基础合计 = 白值 + 加成层数值（装备固定 + 药剂固定）
② 加成后属性 = 基础合计 × (1 + 加成层百分比)（装备% + 药剂%）
③ 条件加成 = 基于【基础合计】触发（每点力量+1智力——防循环）
④ 战斗临时 = 基于【加成后属性】计算（战斗 buff 吃到装备+药剂百分比）
最终属性 = 加成后属性 × (1 + 战斗临时%) + 条件加成
```

### 药剂 = 加成层/临时层（按使用场景，用户拍板）
```
- 药剂定义在 items.json（带 duration）
- 【战斗外服用】→ 加成层（现实时间计时，带到期时间，到期自动移除重算）
- 【战斗内服用】→ 临时层（回合计时，战斗结束清除）
  · 回合计时在回合结束 tick 扣减，入战斗快照（中断恢复）
- 同类药剂不叠加（新覆盖旧）
- 与 3.14 药剂冷却共用规则
```

## 六、成长设计

```
- 升级：全属性自动成长（职业成长率 jobs.json 可配）+ 自由加点可选（加点=白值层）
- 职业成长率（默认示例）：
  · 战士：力量 2.0 / 体质 1.5 / 专注 1.0
  · 法师：智力 2.0 / 精神 1.5 / 幸运 1.0
  · 刺客：敏捷 2.0 / 专注 1.5 / 幸运 1.0
  · 盾卫：体质 2.0 / 生命 1.5 / 精神 1.0
- 属性点保留（换职业不重算——偏科=自然成本）
- 资源轴（剑气/怒气）不占基础属性
```

## 七、与其他系统衔接

```
效果系统：幸运修正（√我方−√对方）｜物理穿透无视体质 ｜魔法穿透无视精神
强化系统：幸运影响成功率（√幸运）
技能派生：敏捷 = 逃跑成功率（agi/(agi+敌agi)）
锻造：元素武器 = 元素通道来源（ele_atk_*）
药剂：炼金产出 → 加成层（有时效）
装备/效果系统：crit_bonus（会心加成）｜超会心（效果系统提供等级，档数/倍率按 crit.crit_mult_up，默认 Lv0-3 可配）
属性分层：白值永久/加成非战斗/临时战斗内
```
