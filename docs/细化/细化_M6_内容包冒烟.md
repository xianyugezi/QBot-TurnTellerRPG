## 〇、冒烟形态仲裁（承接【总纲】ADR-01/02/03）

### 0.1 内容包冒烟 ≠ 服务器冒烟

承接【总纲】ADR-01：内容包冒烟（F6/D4）与服务器冒烟（【规则】L435）是两种冒烟形态，语义与断言对象不同，**F6 不引入 /注册 /锁定 命令形态**。

- **服务器冒烟** = 发布检查单形态（【规则】L435「服务器 冒烟验证（/注册 /锁定 /攻击 一轮闭环）」）：走真实 QQ 网关与指令管线，属发布流程，不在 M6 范围。
- **内容包冒烟** = 数据包质量闭环（【规则】L285「对 content/ 全部预置包跑 validator + 模拟一局战斗（锁定→攻击→结算）」）：零 NoneBot、不进网关，断言对象为 validator 输出与真实 BattleEngine 的引擎级行为。本档落此形态。

冒烟链三形态归口（承接【批2A】P2-6）：① 内容包冒烟 = 「注册门槛→锁定→攻击→结算」（注册为**前置门槛断言**，非命令流程）；② 服务器冒烟 = 「/注册 /锁定 /攻击」一轮闭环（【规则】L435）；③ G0 架构前置（【5d】L221「注册→锁定→攻击→结算」）= 服务器冒烟的冒烟形态。本档只落 ①，②③ 仅登记归口不实现。

**G0 冒烟延期欠账登记**（承接【批2A】P2-7）：按【5d】L221，该冒烟本应 M0 开工前全绿；实际 M0-M5 期间 G0 以「validator 全量 + 最小装载」（tests/contract/test_e2e_smoke.py）为暂代口径，本档（M6 F6 内容包冒烟）承接闭环补位。
