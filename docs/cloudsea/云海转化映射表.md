## 六、行动值→回合换算映射节（批次 209 · 2026-09-13）

> **换算律（九期裁决 #1＝方案 B）**：设计稿保留行动值叙述轴（`12` §B `ACTION_VALUE_FULL`=1,000，零改动），转译层机械换算——**N×1,000 行动值 ≡ N 回合；X 个出手序列 ≡ X 回合**。速度频率收益（出手比 1.3–1.6）不搬运，速度流职业数值重校授权归 211（裁决 #2）。本节为**纯映射文档**，零引擎改动（0 行 hook）。

### 6.1 四型→框架原语

| 设计稿表述型 | 语义 | 框架原语（QBot 通道） | 转译示例 |
|---|---|---|---|
| ① 周期触发 | 每 N×1,000 行动值触发一次 | `tick_round_end` N 回合计数器（同族＝207 #11 period 周期器 `field_periods→period_events`） | 「每 3×1,000 行动值寒潮爆发」→每 3 回合回合末触发 |
| ② 持续窗口 | 维持 N×1,000 行动值 | marks `duration: N`（turns 计） | 「充盈态持续 2×1,000」→marks turns: 2 |
| ③ 次数限制 | N×1,000 行动值内至多 X 次 | 局内 turn 计数窗（battle 回合计数） | 「4×1,000 内至多 2 次」→前 4 回合内 ≤2 次 |
| ④ 窗口延长 | 延长 N×1,000 行动值 | control_state `turns +N` | 「束缚延长 1×1,000」→控制态 turns +1 |

### 6.2 G1B 耗时四型接口（预留，215D–H 落细目）

| 耗时型 | 换算 | 框架口径 |
|---|---|---|
| 前摇 N | ≡ 预告 N 回合后落地 | ❓/🌀 分级渲染归 215（intent windup 扩展字段） |
| 冷却「施放后 N 回合不可用」 | ≡ N 回合 | `unified_cooldown_turns`（207 #12：玩家 N／怪 N+1，raw=生成器已偏移） |
| 持续 duration | 施加回合算第 1 回合 | marks turns；tick 挂回合末（全局回合末统一时点，211 增量裁决） |
| 间隔每 N 回合 | ≡ 型①同族 | tick_round_end N 回合计数 |
