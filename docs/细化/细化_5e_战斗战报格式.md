## 〇、契约总则

### 0.1 术语表

| 术语 | 定义 | 依据 |
|---|---|---|
| 战报（BREP） | 战斗过程对玩家暴露的消息模板，以 BREP-xx 统一编号登记（§1.4），战斗渲染器按 ID 引用，禁止散落硬编码文案 | 本契约 D-5A（消费【模板规范】D-05） |
| 单回合单条 | 一轮战斗 = 1 条消息（玩家行动+怪物反击合并），前缀只在该消息第一行 | 【前缀】L17/L34/L82/L170 |
| 先手 / 后手 | 先手=玩家行动（含连段/多段）；后手=怪物反击；被先手击杀的怪物本身不执行反击（写死） | 【数值层】L53/L58-61 |
| 击杀判定 | 每次扣血后立即检查，非等整回合；连段套中击杀后续段照常执行（鞭尸浪费伤害，套内稳定哲学） | 【数值层】L54-57 |
| 结算时机 | 胜负/奖励/掉落/快照清理统一在当轮事件末尾结算一次；BOSS/最后目标死亡 → 立刻结束 | 【数值层】L68-69 |

### 0.2 一句话契约

> 战斗战报 = **25 条模板注册表（BREP-01~BREP-25）+ 5 条核心军规**（§1.2「五条军规」；总则速览 ④⑤⑥ 为辅助约束：④ 并入军规4/D-5C、⑤ 并入军规5、⑥ 归 §1.3 长度控制，不单列为军规）：
> ① 单回合单条消息，前缀只加首行（【前缀】L34/L82）；
> ② 少 Emoji 只留 ✅/❌，定稿验收示例 L28-31 的 🔥/🟢 按【模板规范】D-01 降级；
> ③ 渲染顺序完全对齐【数值层】回合死亡判定顺序 L44-72（先手 → 击杀判定 → 后手 → 结算）；
> ④ 每一段伤害一行，击杀行紧跟伤害行（扣血后立即查，L54）【辅助：并入军规4/D-5C】；
> ⑤ 经验/掉落只在战斗结束消息一次性输出（当轮事件末尾统一结算，L68）【辅助：并入军规5】；
> ⑥ 战报正文超长走折叠（16 行上限）与 5 条/页分页（【模板规范】D-02/D-03；【数值层】L348 复用 5 条/页分页规则）【辅助：归 §1.3 长度控制】。
> 全部模板可被战斗渲染器引用；前缀字段消费 message_prefix settings 段（【前缀】§三 L41-49）。

### 1.2 五条军规（本契约的不可违背项）

1. **前缀军规**：玩家指令触发的战斗回复首行渲染前缀（默认 `Lv[等级].[玩家名] -[称号]-`，【前缀】L22/L43）；前缀只加**合并消息首行**，一轮战斗 = 1 条消息，多行战报仅首行带前缀（【前缀】L34/L82/L170）；前缀**不计入**正文长度限制（【前缀】L17/L97-99/L176），渲染后超 `prefix_max_len`（默认 40）→ 截断+黄色提示「前缀过长已截断」，正文不受影响（【前缀】L48/L62/L100）。
2. **少 Emoji 军规**：战报行首只用 ✅（成功）/ ❌（失败）两个功能性标记（【模板规范】D-01/L194-196）；装饰性 emoji 全局禁用（禁用清单见【模板规范】L201）；【前缀】L28-31 验收示例中的 🔥（玩家行动行）/ 🟢（怪物反击行）**不复制到实现层渲染**，一律降级为纯文本 + ✅/❌（【模板规范】L202-209）；前缀区禁止任何 emoji 含 ✅/❌（【模板规范】L196；【前缀】L22 纯文本身份标识）。
3. **单回合单条军规**：先手玩家行动 + 后手怪物反击合并为**同一条消息**发送（【前缀】L34/L82/L170）；战斗过程没有逐段刷屏——每段伤害一行（D-5C），但行都合并在同一条消息内；BOSS 战 40-60 回合（【数值层】L141/L147）→ 总消息数 = 回合数，不回合成倍膨胀。
4. **时序渲染军规**：战报行序 = 【数值层】L44-72 回合死亡判定顺序的执行序：回合开始 dot（L49）→ 回合开始即死（L50-52）→ 先手行动（L53）→ 击杀判定（L54-57，扣血后立即）→ 后手行动（L58-61）→ 回合结束 tick（L62）→ 互杀判定（L63-67）→ 战斗结束结算（L68-69）。**行序不允许绕过判定顺序**（如未查击杀就渲染怪物行动）。
5. **结算一次性军规**：胜负/奖励/掉落/快照清理统一在当轮事件末尾结算一次（【数值层】L68）；经验/掉落行只在**战斗结束消息**输出，不逐怪逐段刷（【数值层】L68/L171）；BOSS/最后目标死亡 → 战斗立刻结束，未执行的后续事件作废、不渲染（【数值层】L57/L69）。

### 1.3 长度控制（两级）

| 场景 | 处理 | 依据 |
|---|---|---|
| 前缀渲染后超 `prefix_max_len`（默认 40，0=不限） | 截断 + 黄色提示「前缀过长已截断」（归属发起指令所在群），**不阻断正文** | 【前缀】L48/L62/L100/L176 |
| 正文防刷屏判定 | **前缀不计入**正文长度限制；限制语义 = 正文防刷屏 | 【前缀】L17/L97/L99/L176 |
| 一条消息总渲染行数超上限（默认 16 行，含前缀/正文/页脚；折叠行 TPL-09 亦计入，口径同 3d D-03/L184） | 按「正文尾部 → 中间过程行」优先折叠为省略行（TPL-09，`…（其余 {N} 条已折叠，输入 /{指令} {页码} 查看）`） | 【模板规范】D-03/L184/L82 |

## 二、玩家行动战报（先手，【数值层】L53）

> 渲染时机：行动阶段先手行动结算（含连段/多段）【数值层】L53；**行序内嵌击杀判定**——每段伤害行（BREP-02）渲染后立即查击杀（L54），击杀成立则渲染 BREP-15（击杀行紧跟伤害行）并按 L55-57 分支处理连段/BOSS 提前结束，**未查击杀不得渲染后续段或后手行**。

### 2.1 攻击（命中）

- 渲染链：判定顺序（命中→会心→格挡→双通道→防御率→拦截链→扣血，【数值层】L16）跑完后，按结果渲染：
  - 命中 → BREP-02：`✅ 你{攻击动作}{目标}，造成 {伤害} 伤害（{目标} {剩余HP}/{最大HP}）`
  - 会心跳过（high/mid/low ×2.2/1.7/1.3，L25-26）→ 行尾拼 BREP-04 附注：`（会心·高阶 ×2.2）`；低级会心可视作者配置省略（防噪声，遵循 D-5D 差分精神）
  - 格挡成功（自带/对方格挡率，L27）→ 行尾拼附注 `（被格挡，伤害减半）`
  - 魔攻击无视格挡 → 不产出格挡附注（L27）
- 伤害值取**拦截链后实际扣血值**（最终值，【数值层】L38「拦截链→最终扣血」）；`{目标} {剩余HP}/{最大HP}` 是**扣血后即时值**（击杀判定基于扣血后 HP，L54）。
- 示例：
  ```
  ✅ 你挥动铁剑攻击史莱姆，造成 12 伤害（史莱姆 18/25）
  ✅ 你施放火球术攻击史莱姆，造成 27 伤害（会心·高阶 ×2.2）（史莱姆 1/25）
  ```

### 2.2 防御

- 防御指令：总伤害公式含 `防御指令(×0.5)` 环节（【数值层】L36）——防御是**本回合受击减半**状态，不占攻击动作。
- 渲染两条分支：
  - 进入防御（指令发出、尚未受击）：BREP-05 `✅ 你进入防御姿态（本回合受到伤害减半）`
  - 防御中受击：BREP-06 `✅ 你防御了{目标}的{攻击动作}，受到 {伤害} 伤害（HP {剩余}/{最大}）`（因 ×0.5 生效，玩家视角标记 ✅）
- 防御回合通常**不产出攻击行**；若防御指令与反击同轮，行序为：BREP-05（或省略，短防御可折叠进受击行）→ BREP-06（后手受击）。
- 示例：
  ```
  ✅ 你进入防御姿态（本回合受到伤害减半）
  ✅ 你防御了史莱姆的撞击，受到 2 伤害（HP 19/30）
  ```

### 2.3 技能释放（非攻击类）

- 覆盖治疗/增益/控制/护盾类技能：BREP-07 `✅ 你施放{技能}：{效果描述}（{资源变化}）`；资源变化（MP 消耗随倍率：普攻 0 / 小技 5-10 / 大招 15-25，【数值层】L168）走 BREP-08 差分行。
- 效果类结果（护盾/回血/免伤）走对应拦截链/效果行（BREP-14），控制命中/抵抗信息并入效果描述（纯文本，禁 emoji）。
- 示例：
  ```
  ✅ 你施放治疗术：回复 30 点 HP（MP 22/60）
  ✅ 你施放冰霜结界：获得护盾 20（吸收 20 点伤害）（MP 35/60）
  ```

## 三、怪物行动战报（后手，【数值层】L58-61）

> 渲染时机：后手行动判定【数值层】L58——目标未死 → 正常执行（L59）；目标已死（先手击杀）→ **怪物本身不执行反击，无战报行**（写死，L61）；目标已死但有剩余目标 → 普攻兜底打向剩余目标（L60），按兜底目标渲染攻击行；无剩余目标 → 空挥/待机（可配 skip=直接跳过），空挥渲染为纯文本提示行（无 emoji）。

### 3.1 反击 / 攻击

- 命中：BREP-10 `❌ {怪物}{攻击动作}，你受到 {伤害} 伤害（HP {剩余}/{最大}）`——玩家视角标记 ❌
- 未命中：BREP-11 `✅ {怪物}的攻击被你躲开（HP {剩余}/{最大}）`——miss → 伤害 0（【数值层】L24）
- 玩家防御中受击 → 走 BREP-06（§2.2），不再输出 BREP-10。
- 示例：
  ```
  ❌ 史莱姆反击，你受到 4 伤害（HP 21/30）
  ✅ 史莱姆的攻击被你躲开（HP 21/30）
  ✅ 史莱姆攻击空挥（你的防御姿态生效）   ← 防御+miss 合并，纯文本无 emoji
  ```

### 3.2 意图预告（蓄力 / 读招）

- BOSS 蓄力 / 读招是玩家操作依据：BOSS 蓄力时用打断技，防打断用霸体派生（【数值层】L153/L292）。
- 固定句式 BREP-12（D-5E）：`{怪物} 蓄力中（下回合发动「{招名}」）`——预告行出现在怪物进入蓄力的那个回合，**不计入怪物回合行动行数**（预告不是行动）。
- 玩家打断成功 → 输出 BREP-13 变体 `✅ 打断成功：{怪物}的「{招名}」未发动`（打断行为本身是玩家技能，走 BREP-07/02 渲染色调，打断行以 ✅ 收口）。
- 示例：
  ```
  史莱姆王 蓄力中（下回合发动「毒雾吐息」）
  ✅ 打断成功：史莱姆王的「毒雾吐息」未发动
  ```

### 3.3 特殊行动（狂暴 / 召唤 / 印记）

- BOSS 阶段机制：HP 阈值触发行为变化（狂暴/召唤/印记反制，【数值层】L149/L292-294）。
- BREP-13：`{怪物} {特殊行动}（{效果变化}）`——效果变化以纯文本表述（攻击提升/召唤援军/叠印记/清除印记），禁 emoji。
- 召唤行动附带被召唤怪物挂名行：`史莱姆王 召唤了 史莱姆 ×2`（后续回合按战场多目标渲染）。
- 示例：
  ```
  史莱姆王 进入狂暴状态（攻击提升，持续 3 回合）
  史莱姆王 叠印记 2 层（当前印记 3/5）
  史莱姆王 召唤了 史莱姆 ×2
  ```

### 3.4 拦截链效果行

- 拦截链：减伤→护盾→反弹→吸收→免疫→续行→扣血（【数值层】L38/L240，顺序以效果系统为准）。
- 各环节触发时输出 BREP-14：`{盾} 吸收了 {n} 点伤害` / `反弹 {n} 伤害给{目标}` / `免疫了{效果}` / `战斗续行触发：锁 1 血`。
- 反弹伤害对先手方是**派生伤害**：单独一行、不触发对侧反击/反弹，渲染在段行之后、击杀判定之前（扣血后即查，L54）。
- 示例：
  ```
  ❌ 史莱姆反击，你受到 8 伤害（HP 13/30）
  冰霜结界 吸收了 5 点伤害（剩余护盾 15）      ← BREP-14
  反弹 3 伤害给史莱姆（史莱姆 4/25）          ← BREP-14 派生伤害行，随后即查击杀
  ```

## 四、结算战报（【数值层】L68-69）

> 渲染时机：胜负/奖励/掉落/快照清理统一在**当轮事件末尾**结算一次（L68）；BOSS/最后目标死亡 → 立刻结束，未执行的后续事件作废、不渲染（L57/L69）；快照只落回合边界（L70-71），结算输出不依赖快照时机。

### 4.1 击杀与死亡

| 玩家击杀怪物（扣血后立即查） | BREP-15 `✅ 你击败了{怪物}！`，紧跟造成击杀的伤害行 | 【数值层】L54 |

| 回合开始即死（dot 结算死亡） | 死亡者本回合行动跳过：玩家死→BREP-16；怪物死→BREP-15，且**不渲染其本回合行动行** | 【数值层】L49-52 |

### 4.3 经验与掉落

## 五、多段 / 连段战报

> 依据：先手行动结算含连段/多段（【数值层】L53）；多段每段独立取整（L132）；伤害构成统计 per-action 每段一条、seg 字段记录段号（L314/L319）；击杀发生在连段套中 → 后续段数照常执行，套完结后目标退出战场，下一回合自动消失（L55-56）；BOSS/最后目标死亡 → 立刻结束不清算后续段数（L57/L69）；派生累计倍率封顶 ≤1.5×（L133）。
> 注（P2-8）：对外战报文案一律由 **battle_render 按 BREP 模板生成**（§1.4 注册表），**不直接复用引擎内部 `ActionOutcome.message`**（引擎 message 句式仅作机制日志，不作对外战报）。

### 5.1 连段计数与每段行

- 每段独立一行 BREP-21：`第 {N} 段：{动作} 造成 {伤害} 伤害（{目标} {剩余HP}/{最大HP}）`——`{N}` 与伤害构成统计 seg 字段一致（L319），段行即收集器记录的人类可读镜像（D-5C）。
- 段内判定各跑一次完整管线（命中/会心/格挡/双通道/拦截链，L16/L132），段行尾可拼 BREP-04 会心附注。
- 连段条数上限/段结构由技能派生定稿定义（本契约不重复定义），战报只按段渲染。
- 示例：
  ```
  第 1 段：突刺 造成 6 伤害（史莱姆 19/25）
  第 2 段：突刺 造成 6 伤害（史莱姆 13/25）
  第 3 段：突刺 造成 11 伤害（会心·中阶 ×1.7）（史莱姆 2/25）
  ```

### 5.2 连段结算行与派生附注

- 套完结：BREP-22 `连段 {N} 段已结算（{备注}）`，备注三态：
  - 正常完结：`连段 3 段已结算`（无备注）
  - 鞭尸：目标套中击杀 → `连段 {N} 段已结算（目标已倒下，下一回合退出战场）`（L55-56）
  - 提前结束：BOSS/最后目标套中击杀 → `连段 {N} 段已结算（BOSS 已倒下，战斗结束，后续段数作废）`（L57/L69）
- 派生附注：技能派生累计倍率触及封顶（≤1.5×，L133）时，段行尾附 `（派生倍率已达上限 1.5×）`——纯文字提示，禁 emoji。
- 示例：
  ```
  第 4 段：突刺 造成 8 伤害（史莱姆 0/25）
  ✅ 你击败了史莱姆！
  连段 4 段已结算（目标已倒下，下一回合退出战场）
  ```

## 六、战斗开始与结束消息

### 6.1 战斗开始

- BREP-23：`与{怪物}的战斗开始！{怪物} {HP}/{最大HP}`——战斗开始是**独立一条消息**（非玩家指令回复也走玩家名前缀，属玩家相关回复，【前缀】L80）。
- 附情报行（作者可配开关，默认开）：类型/元素弱点信息（×1.3，【数值层】L106-107）与 BOSS 阶段机制预告（HP 阈值触发狂暴/召唤/印记，L149），帮助玩家决策循环切换（L152）。
- BOSS 战开场可附 BREP-12 意图预告（`{怪物} 蓄力中…`），对齐「BOSS 蓄力 → 打断技读招」（L153/L292）。
- 示例：
  ```
  Lv35.阿伟 -斩龙者-
  与史莱姆的战斗开始！史莱姆 25/25
  弱点：火（×1.3）
  ```

### 6.2 战斗结束汇总

- 战斗结束消息 = BREP-24 汇总行 + 胜/负/平横幅（BREP-17/18/19）+ 经验掉落（BREP-20）+ 明细入口。
- BREP-24：`战斗结束：{胜负结果}｜回合数 {N}｜输入 /战斗记录 查看明细`——回合数对照斩杀回合基准（普通 3-8 / 精英 10-15 / BOSS 40-60，【数值层】L139-141/L147），供玩家自评节奏。
- 明细入口仅在作者开启战后明细时出现（普通战斗默认不展示明细，L350）。

### 6.3 战报详情 / 木桩明细块（分页 + 折叠）

- 木桩战后默认展示伤害构成明细（【数值层】L347）：一行摘要 + 折叠明细；**复用 5 条/页分页规则**（L348；【模板规范】D-02）。
- 明细条目行：`{序号}. {来源} {总伤害}（{占比}%）`，按来源聚合、占比降序（【数值层】L340/L347），每页最多 5 条 + 页脚 TPL-08（多页时），溢出部分折叠 TPL-09（16 行上限，【模板规范】D-03/L184）。
- 摘要行（一行）：`总伤害 {N}｜最大单段 {M}｜会心 {K} 次｜格挡 {G} 次`（对齐收集器聚合字段，【数值层】L340）。
- 示例：
  ```
  摘要：总伤害 520｜最大单段 82｜会心 3 次｜格挡 1 次
  1. 火球术 520（42%）
  2. 普攻 310（25%）
  3. 灼烧 210（17%）
  …（其余 3 条已折叠，输入 /木桩 2 查看）     ← TPL-09 折叠（L348 分页规则下第 2 页）
  ```
