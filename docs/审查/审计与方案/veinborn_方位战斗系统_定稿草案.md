> 用途：为部位破坏服务的方位系统 + 战斗调和配套——设计共识稿，内容包/数值阶段的施工图前身

## 一、动机

现有部位破坏体系（印记二段式：破坏值印记累积→破技→已破印记→增伤）没有"打哪儿"的概念。方位系统把部位挂到怪物身体的方位上，让"选方位打部位"成为玩家的主动战术；怪物用转向/冲锋把玩家甩出目标方位，形成博弈。战斗调和为战斗中提供"用素材换即时收益"的行动面，与空中/落地规则联动。

## 二、机制定稿（已拍板）

### 1. 方位模型
- 玩家相对怪物站位 = {前/后/左/右} × {空/地}，共 8 格；玩家永远朝向怪物。
- 技能永远可放出，不存在"丢失目标/够不着"判定——方位只决定：伤害落点、破坏力累计对象、以及高度层面的技能可达性。

### 2. 高度语义与空中规则
- 查证确认：跃空（脊剑士机动色技能 rb_leap）、倒地（破位增伤窗口）均为 veinborn 已有设计词面；地面为默认态。
- 高度规则：地面技能打不到空中玩家——跃空是躲避地面类攻击的手段。
- **空中保持与落地**：
  - 出攻击技延续连段 → 保持空中，直到连段终结；
  - 连段终结技打出（例：轻击×3→派生重击落地；轻击→重击→轻击→派生轻击末击落地）→ 落地，终结技通常为强化一击；
  - 用防反/闪反且**触发成功派生** → 保持空中；
  - 用防反/闪反**未触发成功派生** → 落地（失败的惩罚：失去空中优势）；
  - 主动落地技 → 落地（存在，作战术出口）；
  - 中断连段的行动（道具、待机、**战斗调和**等）→ 落地。
- 后续试点验证：主动落地技形态、中断即落地的体感（§四.3）。

### 3. 伤害三层规则
1. 任何攻击（无论方位）都对怪物整体 HP 造成伤害。
2. 攻击**已破坏部位**所在的方位 → 额外伤害加成（常驻，破位即永久开启该方位输出窗口）。
3. 怪物**倒地窗口**期间（1-2 回合），攻击已破坏部位 → 在常驻加成之上再叠加额外增伤。
   - 倒地触发：**任何部位被破坏即触发**——规则全局一致，不区分第几次破位。
   - 倒地期间最优解=集中打已破部位。

### 4. 部位、破坏力与破位效果
- 部位**没有独立血条**。部位 = 每怪自定义一条：{ 可攻击方位集合, 破坏阈值, 破坏效果 }。
- **破坏力结算**：
  - 技能声明固有破坏力（固定值，不随等级/装备成长）；
  - 伤害加成公式：破坏力 = 固有值 + √(max(0, 本次伤害 − 基准伤害))——伤害超基准部分按平方根折算，略微体现成长，边际递减防失控；基准值与√系数[数值阶段定]；
  - 与伤害数值解耦：满级打低级怪可秒杀，但破坏力仍小于阈值 → 不破位。
- 玩家每次攻击，破坏力累计到"当前方位上的部位"，过阈值 → 部位破坏；累计仅在怪物存活时进行（本体死亡即战斗结束）。
- 方位上无部位：只造成本体伤害，破坏力无累计对象（浪费）。
- **破位瞬间效果**：通用 = 触发倒地窗口 + 掉落素材；招牌怪逐怪定制附加效果（如断尾削扫尾范围），内容阶段配。

### 5. 机动与怪物方位行动
- 玩家：跃空/机动技能 = 修改自己的方位（可配置：目标方位、消耗）。
- 怪物方位行动以"置换"为原语，作用于全场玩家（组队时多人，单人时自己）：
  - 冲锋：攻击前方玩家 + 将前方玩家置换到后方。
  - 扫尾转身：方位重映射（前↔后、左↔右）。
- 玩家可用机动技能移动到怪物攻击覆盖区外（攻击覆盖 = 技能声明覆盖的方位集合）。

### 6. 组队边界
- 非组队：各打各的（保持引擎 1v1 现状）。
- 组队同场共打一只：引擎级新功能（共享怪物实例/回合序/部位状态），**拆为独立里程碑，本系统范围外**。

### 7. 部位挂载自由度
- 部位方位集合完全按怪设计，不绑定固定骨架。示例：
  - 龟类怪物·背壳：只有跃空（空中）状态可攻击——方位集合 = {空×前/后/左/右}。
  - 巨型翅翼怪·翼：左右两侧、空/地均可攻击——方位集合 = {地/空×左、地/空×右}。

### 8. 战斗调和系统（2026-09-08 全部拍板）
- 战斗中可直接**合成道具并立即使用**（调和 = 合成与使用一步完成，占用行动）。
- **与框架炼金系统的关系**：框架已有炼金系统（M8：upgrade.py 炼金合成引擎——配方合成/成品合成/珠升阶；recipe 配方模块；proficiency 熟练度模块；8 元素 地水火风雷晶月无）。战斗调和 = 炼金在战斗内的延伸：同一配方体系，战斗中即时合成 + 立即使用，无需找炼金台。
- **熟练度**：效果系数读取**框架炼金熟练度**（与炼金系统一体，不另设）；战斗调和视同一次炼金行为，计入熟练度成长。效果 = 道具基础值 × 熟练度系数（60%~120%）。
- **配方解锁**：基础配方素材凑齐自动解锁（门槛天然在素材）；部分高阶配方需专门学习或达到对应炼金熟练度等级（学习机制落地时核对框架 recipe 模块现有解锁手段）。
- **可调和品范围**：先治疗/增益药水 + 投掷物（闪光/爆弹类）两类，内容阶段扩。
- **素材来源**：背包素材（战斗外获得：掉落/商店/采集）。
- **与方位联动**：空中使用战斗调和 → 落地（与"中断连段的行动=落地"同规则）。
- 战斗外炼金产出 = 标准道具；战斗内调和 = 效果按熟练度系数浮动。

## 四、待定与细化项

### 已确认（2026-09-08）
A 空中落地规则（连段保持/防闪成功派生保持、失败落地；主动落地技存在；中断连段行动=落地）
B 破位即倒地 1-2 回合
C 固有破坏力 + √(超额伤害) 公式
D 破位通用效果 = 倒地 + 素材掉落
E 战斗调和：战斗内合成即用、占行动、空中调和落地
H1 熟练度与炼金系统一体——复用框架炼金熟练度（M8 proficiency），战斗调和计入熟练度成长
H2 基础配方素材凑齐自动解锁；高阶配方需专门学习/熟练度等级门槛
H3 可调范围：药水 + 投掷物起步
H4 素材 = 背包素材（战斗外获得）
H5 熟练度归属框架生活体系（非职业专属）——随 H1 一并解决

### 内容阶段细化（非机制分叉）
1. 破坏力公式基准值与 √ 系数；部位阈值档位（按怪/区域）；
2. 落地两默认的体感（主动落地技形态、中断即落地）随试点验证；
3. 各怪部位表与方位行动设计（§二.7 示例起步）；
4. 调和配方清单与 60%~120% 熟练度映射曲线；
5. 高阶配方"专门学习"形态——核对框架 recipe 模块现有解锁机制后定；
6. 战斗调和指令形态（词面/帮助组）走指令规划流程，不在此发明。
