## 二、锚点计算（整除公式 + 确定性伪随机）

> 依据：§1.3 L50-58、§1.4 L83-85、§三 L167。

### 2.1 世界锚点

```
ANCHOR = 2000-01-01 00:00:00 UTC+8   （世界起点 = 春季 · 晨 · 天气第 0 抽）
now    = 当前 UTC+8 时间戳
```
（【时间天气】L50。）

> 实现要求：全引擎统一按 **UTC+8** 解释 `now`（含 2026 年之后的任意时刻），避免跨时区漂移导致整除点错位。

### 2.2 三周期整除公式

```
season_idx   = floor((now - ANCHOR) / (season_days  × 86400)) % 4   # 0春 1夏 2秋 3冬
period_idx   = floor((now - ANCHOR) / (period_minutes × 60))   % 5   # 0晨 1午 2昏 3夜 4午夜
weather_tick = floor((now - ANCHOR) / (weather_minutes × 60))        # 全局统一变化节拍（不取模）
```
（【时间天气】L53-55。）

### 2.3 天气取值（确定性伪随机抽签）

```
有效池 keys(map_id) = maps.json[map_id].weather_pool 非空 ？ 该池 : weather.default_pool   # L138/L167
生效池键列表 = 排序后（字典序）拼接                      # L58「生效池键列表(排序后)」
seed = sha256( 生效池键列表(排序后) + str(weather_tick) )   # L58
pick = int(seed 十六进制摘要前 8 字节) %  len(生效池)         # 实现注：取摘要数字对池长取模
map_weather(map_id, weather_tick) = 生效池[ pick ]          # L57
```

- **确定性**：seed 绑定「池键列表 + tick」，同一 tick 全世界同值（同池时），重启不重抽——懒计算刚需（【时间天气】L58/L84）。
- **等概率抽取**：每次变化（weather_tick +1）从生效池等概率抽一个；权重为后续版本预留，v1 不做（L83）。
- **覆盖池语义**：有覆盖从覆盖池抽、无覆盖（缺省/空数组）从默认池抽（L138/L167）。
- 池编辑（增删天气）→ 抽签序列整体重排（可接受，黄色提示「时间配置已变更，周期重新铺排」，不拦截）（L85/L346）。

### 2.4 倒计时展示（/时间 /天气 用）

```
距下次变化 = ANCHOR + (floor((now-ANCHOR)/周期长) + 1) × 周期长 − now
```
- 季节倒计时输出「X 天 Y 小时」、时段/天气输出「X 分钟」（示例见【时间天气】L253/L258；倒计时预览实时重算 L303）。

## 三、懒计算（整除推进 · 配置即重排 · 独立推进）

> 依据：§1.3 L47-64、§9.2 L366-372、§六 L287。

### 3.1 零定时器整除推进

- **不存历史、不跑定时器**：任何时刻三周期值均可由公式重算（对齐 3.6「玩家操作时按时间差补刷」）（【时间天气】L61）。
- **变化检测钩子**：每条指令处理前调用 `time_engine.check_changes(player, map_id)`，比较世界状态 `time_state` 缓存索引与公式重算值，产出变化列表 → 广播（L62/L287）。
- **离线跨越多周期**：只按「最新值」播报一次，不逐条追报（对齐 3.6 补刷上限思想，防刷屏）（L63）。

### 3.2 配置即重排

- 改 `season_days` / `period_minutes` / `weather_minutes` / 池 → **后续周期全部按新配置推进**，旧缓存索引失效自动重算（【时间天气】L64）。
- 列为**黄色提示不拦截**：提示「时间配置已变更，周期重新铺排」（L64/L346）；存档 `time_state` 缓存值随重算刷新（§六 L273-282）。

### 3.3 独立推进（共锚不共界）

| # | 规则 | 引用 |
|---|---|---|
| 1 | **各自整除**：三周期都从同一锚点整除取索引，互不读写对方状态，实现无耦合 | L368 |
| 2 | **时段跨季节边界**：季节整点整除（00:00），时段按自身分钟推进；换季时刻时段处于中段既不重置也不补算，继续走自己节拍 | L369 |
| 3 | **天气与时段独立**：两侧 tick 各自整除；同一时刻可同时变化（默认 60 分整点对齐时 00:00 常重合），按固定顺序合并播报，互不影响数值 | L370/L90 |
| 4 | **边界重合 = 自然现象**：默认配置下季节边界必与时段/天气整点边界重合，属正常；合并一条播报，去重防刷屏 | L371/L90 |
| 5 | **一次指令最多播 3 条**（季节+时段+天气），离线跨多周期只播最新值 | L372/L63 |

### 3.4 战斗内懒读（不打断）

- 战斗会话内**每回合开始**重读当前时段/天气（懒计算），仅用于数值与状态行提示；天气/季节**不驱逐战斗中怪物**（对齐 3.16「怪物出没时段边界」只影响怪物存在性；3.16 时段边界移除有语义——"对方逃跑了"，【时间天气】L91/L209/L210）。
- 战斗天气修正（可选默认关）若开启：**每回合开始**读取、中途天气变化 → 下一回合生效 + 状态行提示一次，不打断战斗流；播报挂到**战斗结算后**（L91/L229）。

## 四、世界对齐（全葡萄 = 全局唯一）

> 依据：§0 语义裁定 L18、§二 L127（引 3.8 全局世界对齐）、§1.5 L93、§六 L278-282。

### 4.1 全局统一节拍

- **全葡萄一个季节 / 一个时段 / 一个天气节拍**：三个周期值对全世界所有群、所有玩家同时刻一致（【时间天气】L18「变化节奏与周期锚点全局统一——同一时刻全世界一起进入下一天气周期（全世界一个 weather_tick）」、L127「全部为全局唯一配置（世界只有一个季节/时段/天气节拍，3.8 全局世界对齐）」）。
- 锚点公式天然满足：`floor((now-ANCHOR)/周期长)` 与群无关、与进程无关、与玩家无关（L53-55/L58）。

### 4.2 天气「全局节拍 · 按图取值」的唯一例外

- **变化时刻**全世界一致（全世界同一 weather_tick）；**取值**按玩家所在图的生效池（覆盖池/默认池）抽取 —— 故同一时刻不同图天气可不同（【时间天气】L18）。
- 地图覆盖池：maps.json 每图顶层 `weather_pool`（可选），元素必须在默认池已注册键内（校验器 V5 硬拦），缺省/空数组 = 用默认池（L138/L166/L167）。

### 4.3 跨群去重（全局世界，3.8）

- `world_state.time_state` 记录「各周期已播报索引」+ `map_weather_seen`（各图已播报天气节拍，惰性增长）→ **跨群不重复广播**（【时间天气】L93/L278-282）。
- 去重口径：比较缓存索引与公式重算值，相等不播（L287）。

### 4.4 消费方对齐（同一当前值）

- 钓鱼（seasons/periods）、采集（weather_mods）、怪物（seasons/periods/weather_weights）、事件活动窗口、图鉴情报、战斗天气修正——**全部消费同一当前季节/时段/所在图天气**，上下文绑定语义一致（【时间天气】L182「季节/时段为全局值；天气按玩家所在图取值」）。

## 五、条件键（季节 / 时段 / 天气键格式）

> 依据：§4.0 条件引擎新键 L174-183、L45。互译表 4.2.3.1 新增 **3 行**，单口登记。

| 条件英文键（机器键） | 变量大全中文变量（展示/公式键） | 判定语义 | 引用 |
|---|---|---|---|
| `{ var: "season",  param: X }` | `[季节:X]` | 当前季节 == X（X ∈ 四季枚举 spring/summer/autumn/winter） | 【时间天气】L178 |
| `{ var: "period",  param: X }` | `[时段:X]` | 当前时段 == X（X ∈ 五时段枚举 dawn/noon/dusk/night/midnight） | L179 |
| `{ var: "weather", param: X }` | `[天气:X]` | 玩家**当前所在图**的当前天气 == X（X ∈ 注册天气集） | L180 |

**语义与约束：**

- **季节/时段为全局值**；**天气按玩家所在图取值**（上下文绑定，与 `{var:"item_count"}` 同构）（【时间天气】L182）。
- 键格式与既有条件键一致（英文小写，L45）。
- **消费方零新增机制**：任务 / NPC / 签到活动表 / 副本 / 成就引用新键即可，事件/活动窗口 = 配置组合（L183/L215-218）。
- 例：`{var:"season",op:"eq",param:"summer"}` → 夏季限定任务；`{var:"period",param:"midnight"}` + `{var:"weather",param:"storm"}` → 午夜雷雨限定事件（L216-217）。
- `enabled=false` 时 `[季节]/[时段]/[天气]` 条件键**全部失效**（附 K K.2，L101）。
- 校验：消费方枚举引用须 ∈ 注册表（校验器 V6 硬拦，L335）。
