### 0.2 字段对齐订正（v1 → 实现；这是 v2 的第一类修订）

| v1 草案声明 | `deep_craft.py` 实际读取 | v2 订正 |
|---|---|---|
| 材料 `quality_rank` | `mdef.get("material_quality")` | 改名 **`material_quality`** |
| `craft_rules.craft_cost{base,per_kind}` | `r.get("cost_base")` / `r.get("cost_per_kind")` | **平铺**两键，不嵌套 |

## 3. 投入暴击参数表（§七 裁定 · 批44 落地）

> 触发点：**投料提交时**（`plan_craft` 品质经验算出后、品质等级判定前）**掷 1 次**；
> 随机源 = 批40 玩家级随机流（`rng_stream:"player"`），可用注入 RNG 验证两条路径、不 flaky。
> 只加**品质经验**，不改等级、不改 cost、不改相性累计。

| 参数 | key | 铜 | 银 | 金 | 彩 | 可调范围 |
|---|---|---|---|---|---|---|
| 暴击概率 | `chance_by_grade` | 0.15 | 0.10 | 0.07 | 0.05 | 0–1，逐档独立（§七 建议值：低档更高、高档更低） |
| 暴击倍率 | `mult_by_grade` | ×2.0 | ×2.0 | ×2.0 | ×2.0 | ≥1.0（先占位，待实测校准） |
| 暴击加成（可选加项） | `additive_exp` | 0 | 0 | 0 | 0 | 默认关，与倍率二选一 |
| 适用档 | `enabled` / `grades` | ✅ | ✅ | ✅ | ✅ | 可只开高档 |
| 影响品质等级判定 | `affects_quality_level` | true | true | true | true | false = 只影响展示经验 |
| 经验封顶 | `exp_cap` | `last_threshold`(1080) | 同 | 同 | 同 | `none` / `last_threshold` |
| 每次打造掷数 | `rolls_per_craft` | 1 | 1 | 1 | 1 | 1–2（>1 会显著抬高期望，建议 1） |

### 3.1 逐档「常规上限 vs 暴击上限」（取 §4 的最优可行解，数字可手算复核）

| 档 | 常规上限 QE | → 品质等级 | 暴击上限 QE（×2） | → 品质等级 | 该档 q10(1080) 是否可达 |
|---|---|---|---|---|---|
| 铜 | **265.2** | q5 | **530.3** | q7 | 否（`exp_cap` 封顶亦不可达） |
| 银 | **335.8** | q6 | **671.6** | q8 | 否 |
| 金 | **619.2** | q8 | 1238.3 | q10 | ⚠️ 是（见下方备注） |
| 彩 | **939.3** | q9 | **1878.7** | **q10** | **是 —— 这正是 §七 要解的彩档 q10 可达性** |

> **金档备注（显式假设，需用户裁一下）**：只要 `mult_by_grade.gold=2.0`，金档常规上限 619.2 暴击后
> 1238.3 ≥ 1080 → **金档也能以 7% 概率碰 q10**。若希望 q10 为彩档专属，把金档倍率降到
> **×1.7**（619.2×1.7=1052.6 < 1080 → q9 封顶）；本表默认仍按 §七 的「×2 占位」。
> 反向也成立：若把 `mult` 降到 ×1.5，彩档 939.3×1.5=1409 ≥1080 仍可达 q10，金档 928.8 <1080 → 安全。

## 4. 自洽手算（每档 1 条 + 1 条反例）

### 4.0 通用算式（与 `deep_craft.py` 逐项对齐）

```
件数边际   S(n) = Σ_{j=0..n-1} max(0, 1 − 0.25·j)      → 1.0 / 1.75 / 2.25 / 2.5 / 2.5(n≥4)
单料贡献   c_i  = Q(material_quality_i) × (1.5 若 相性键∩图纸相性键≠∅ 否则 1.0) × S(count_i)
品质经验   QE   = Σc_i × type_bonus^(种数−1) × Π(互动 exp_mult)        type_bonus = 1.03
装备等级   Lv   = floor( Σ_role (角色权重/used_w) × Σ(等级×件数)/Σ件数 )   main .60 / free .40
品质等级   q    = max{ l : QE ≥ 阈值[l] }，阈值=[0,25,60,110,180,275,400,560,780,1080]
成本       cost = 60 + 20×种数 + Σ(craft_cost×件数)
有效       ⟺ 等级带 min ≤ Lv ≤ max 且 cost ≤ blueprint_cost_cap
```
（互动：`conflict` ×0.75 / `amplify` ×1.15 / `reverse` ×1.0；每条规则每次打造最多触发一次。）

### 4.5 反例 · 银档用「廉价铜料」刷品质 → 被等级带硬拦

同一张 `bp_hunter_vein_edge`（band 9–16，主槽 `ore`），改投**铜档廉价料**（全部 ≤90 cost，够得到主槽的是 ore）：
`wind_ridge_shell ×4`(#6 ore lv8 blue)、`ridge_ore ×4`(#4 ore lv6 green)、`mossvein_herb ×4`(#2 herb lv3 green lunar)、`bone_ash ×4`(#5 bone lv5 green)。

| 项 | 计算 | 结果 |
|---|---|---|
| 等级 | main={#6 lv8×4, #4 lv6×4}→(32+24)/8=7.0；free={#2 lv3×4, #5 lv5×4}→(12+20)/8=4.0；`0.6×7.0+0.4×4.0=5.8` | **Lv 5 < 9** ❌ |
| 判定 | `REJECT_LEVEL_BAND`（`blueprint_level_band.min=9`，硬拒绝并给人话提示） | **无效打造** |
| （若放行的假设值）cost | `60+20×4+(90+40+25+30)×4=140+740` | 880（**比正解 1960 便宜 55%**） |
| （若放行的假设值）QE | 65+40+60+40=205 → `205×1.09273×1.15=257.6` | 约 q5 |

**结论**：`blueprint_level_band` + 主材料槽确实**独立于 cost / QE** 起作用 —— 廉价料即使 QE 性价比更高
（0.293 QE/cost vs 正解 0.171），也**无法**把银档品质刷上去；两道防线分工为
①等级带与主材料槽（**主力拦截**，本例生效）、②cap（**兜底**，四档正解均在 cap 处紧绑定，见 §4.1–4.4 的 cost 行）。
