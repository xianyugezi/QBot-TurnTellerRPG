## 0. 总览

### 0.1 一句话流程

```
settings.json time_cycle.weather.default_pool（内容包自定义天气集，非空键唯一）
  → 每次变化 weather_tick+1（weather_minutes 整数 ≥30，默认 60）等概率抽一签（v1 无权重）
  → seed = sha256(生效池键列表排序 + str(weather_tick)) → 确定性伪随机（同 tick 同池全世界同值、重启不重抽）
  → 生效池 = 地图 weather_pool（有覆盖）/ 默认池（空数组或缺省）；池元素必须 ∈ 默认池已注册键
  → 玩家所在图当前天气用于 [天气:X] 条件判断（上下文绑定）、怪物 weather_weights、采集 weather_mods、战斗 weather_mult
```

## 1. 天气枚举（内容包自定义）

### 1.1 枚举定位（R1 / R2）

- **内容包自定义**：天气键**不**如季节（spring/summer/autumn/winter）与时段（dawn/noon/dusk/night/midnight）那样固定写死（【定稿】L44）；天气枚举由内容包通过默认池配置定义，引擎只消费「注册天气集」，不内置固定集合（【定稿】L42）。
- **键格式**：英文小写，与既有条件键格式一致（【定稿】L45）；互译表新增天气一行（【定稿】L174/L408）。

### 1.2 默认池结构（R3 / R4）

```json
"time_cycle": {
  "weather": {
    "weather_minutes": 60,
    "default_pool": [
      {"key": "clear",  "name": "晴",   "emoji": "☀️"},
      {"key": "cloudy", "name": "多云", "emoji": "☁️"},
      {"key": "rain",   "name": "雨",   "emoji": "🌧️"},
      {"key": "storm",  "name": "雷雨", "emoji": "⛈️"},
      {"key": "fog",    "name": "雾",   "emoji": "🌫️"}
    ]
  }
}
```

- 条目结构 = {key, name, emoji} 三元组（【定稿】L73-77）：`key` 为机器键（英文小写、全池唯一），`name` 为中文展示名，`emoji` 为播报/展示用图标。
- 硬约束：默认池**非空**（≥1 种）、**键唯一**、**key+中文名齐全**——校验器 V4 硬拦（【定稿】L110/L333），编辑器删到 0 红色拦截（【定稿】L300）。
- 框架默认值即上表 5 键（晴/多云/雨/雷雨/雾）（【定稿】L73-77）。

### 1.3 内容包自定义扩展（R5 / R6）

- 内容包通过**编辑 default_pool** 增删/替换天气条目，即注册自己的天气集合；增删后该 tick 起抽签序列整体重排（【定稿】L85/L346，黄色提示不拦截）。
- 全内容包消费方（怪物 weather_weights、采集 weather_mods、战斗 weather_mult、事件/NPC/任务条件、图鉴 condition）的天气引用，统一校验 ∈ 注册天气集（【定稿】L336 V6 / L337 V7）——改池删天气时，残留引用被校验器硬拦截住（【定稿】L425）。
- 注册集 = `default_pool` 的 keys；地图覆盖池、权重修正、条件键均只允许引用注册集成员（第 §3 / §4 / §5）。

## 2. 确定性抽签

### 2.1 节拍与懒计算（R7 / R8 / R9）

```
weather_tick = floor((now − ANCHOR) / (weather_minutes × 60))   # ANCHOR = 2000-01-01 00:00 UTC+8，天气第 0 抽
map_weather(map_id, weather_tick) = 生效池[pick(seed)]
  seed = sha256(生效池键列表(排序后) + str(weather_tick))
```

（【定稿】L50/L55/L57/L58）

- **全局统一节拍**：全世界同一个 weather_tick，同一时刻所有地图一起进入下一天气周期；「全局统一」指**节奏与周期锚点统一**，而非取值统一（取值可因地图池不同而不同，见 §3）（【定稿】L18/L127）。
- **懒计算**：不存历史、不跑定时器，任何时刻的天气可由公式重算（对齐 3.6 补刷，【定稿】L61）；玩家操作/战斗每回合开始时重算当前值，变化经变化检测钩子识别（【定稿】L62/L229）。
- **参数校验**：weather_minutes 整数且 ≥30（默认 60）——V3 硬拦（【定稿】L109/L332）。

### 2.2 等概率抽签（R10）

- 每次变化（weather_tick +1）从**生效池**等概率抽一个（用户原话「随机抽取一个」的工程实现）（【定稿】L83）。
- **v1 不做概率权重**：权重（如雷雨概率减半）为后续版本预留，v1 一律等概率（【定稿】L83）。权重修正字段（§4）是「联动倍率」，与抽签概率无关——抽签层保持等概率纯净。

### 2.3 确定性 seed（R11 / R12 / R14）

- **seed 构成**：`sha256(生效池键列表排序后 + str(weather_tick))`（【定稿】L58）——绑定「池键列表」+「tick」两个因子。
- **确定性语义**：同一 tick + 同一生效池（同池），全世界同值、跨群/跨进程/重启一致、重启不重抽（【定稿】L58/L84）——这是懒计算刚需（无定时器也能重算出与上次一致的值）。
- **池编辑即重排**：增删天气改变「池键列表」→ seed 输入变化 → 后续抽签序列整体重排（【定稿】L85，黄色提示「时间配置已变更，周期重新铺排」不拦截，【定稿】L346）。
- **可预测性说明**：确定性抽签序列从设计上可被推演，但 v1 不做真随机（懒计算刚需）；若后续要真随机 → 存档落「当前天气+下次变化时刻」仍可懒推进（【定稿】L422 预留路径）。

### 2.4 与其它周期正交（R15）

- 季节 / 时段 / 天气三周期**互相独立、共锚不共界**：各自从同一锚点整除推进，互不读写对方状态（【定稿】L19/L368）；天气 tick 与时段 tick 同刻可同时变化（默认 60 分整点经常重合），属自然现象（【定稿】L370/L371），播报合并顺序固定（季节→时段→天气，每指令最多 3 条，离线只播最新一次）（【定稿】L90/L372）。

## 3. 地图 weather_pool 覆盖

### 3.1 配置落点（R16）

```json
// maps.json 每图顶层（可选字段）
{
  "id": "misty_forest",
  "name": "迷雾森林",
  "weather_pool": ["fog", "rain"]     // 覆盖池：只引用默认池已注册键；缺省/空数组 = 用默认池
}
```

（【定稿】L134-138）

- 落点：maps.json 每图顶层可选字段（【定稿】L405 登记）；编辑器以「多选下拉（选项 = 默认池全部天气键）」呈现，下拉天然保证引用合法（【定稿】L310/L311）。

### 3.2 取值语义（R17 / R18 / R19 / R20）

| 图配置 | 生效池 | 依据 |
|---|---|---|
| 配置了 weather_pool（非空） | 覆盖池 | 【定稿】L166-167 |
| 未配置或 `[]` | 默认池 | 【定稿】L138/L166 |

- 该图天气 = `map_weather(该图, weather_tick)`：有覆盖从**覆盖池**抽、无覆盖从**默认池**抽（【定稿】L167）。
- **覆盖池只改取值不改节拍**：两图覆盖池不同 → 同一 tick 两图天气可以不同；但变化**时刻**全世界一致（同一 weather_tick 基准）（【定稿】L18）。
- **缺省即默认**：旧地图不配 weather_pool = 一直用默认池，语义与前版一致、零改动（【定稿】L138/L168）。

### 3.3 引用合法性（R17）

- `weather_pool` 元素必须 ∈ 默认池已注册键——校验器 **V5 硬拦**（【定稿】L166/L334，报错如「迷雾森林的天气『雪』没有在默认天气池里注册」）。
- 黄色提示：覆盖池仅 1 种 → 「这张图天气永远不变（恒定）」；天气池 > 12 种 → 「抽到单种概率很低」（【定稿】L343-344）。

## 4. 权重修正（可选字段，不配置不联动）

### 4.1 可选总则（R21 / R22）

- 所有天气权重/修正字段（怪物 weather_weights、采集 weather_mods、战斗 combat.weather_mult）**全部可选**；**不配置 = 该条目不参与天气联动**——向后兼容，旧地图零改动可跑（【定稿】L168）。
- 所有联动字段的天气引用键必须 ∈ 注册天气集：V6（消费方枚举）/ V7（战斗 mults 键）硬拦（【定稿】L335-336）。

### 4.2 怪物出现率倍率（R23 / R24）

```json
"weather_weights": {"fog": 2, "rain": 0.5}   // 可选；默认 1；0 = 该天气不刷
```

（【定稿】L147）

- 语义：作用于**刷新计时**——`有效刷新间隔 = respawn_minutes / weight`：weight ≥1 刷更快，0<weight<1 更慢，weight=0 该天气下**不刷**（【定稿】L210）。
- **只影响刷新/补刷，不驱逐已在场怪物**：天气不打断战斗，与 3.16 时段边界（会移除场上怪物）刻意区分（【定稿】L210/L424）。
- 缺省 = 权重 1（正常刷新，不联动）（【定稿】L147/L168）。

### 4.3 采集概率与稀有度（R25）

```json
"weather_mods": [
  {"weather": "rain",  "rate_mult": 1.5, "rarity_shift": 1},
  {"weather": "storm", "rate_mult": 0}        // 0 = 该天气下不出
]
```

（【定稿】L156-159）

- `rate_mult` 乘采集概率（0 = 该天气不出）；`rarity_shift` 平移稀有度档位（普通/稀有/金色/✨，clamp 到 4 档，炼金金色素材链路自动受益）（【定稿】L203）。
- 例：雨天山蘑菇出率 ×1.5 且稀有档+1 → 天气驱动采集策略（【定稿】L204/L393）。

### 4.4 战斗天气修正（R26）

```json
"combat": { "weather_mult": { "enabled": false,
  "mults": { "rain": 0.95, "storm": 1.1, "fog": 0.9 } } }
```

（【定稿】L117-122）

- **默认关**（respect 战斗数值层定稿的伤害公式纯净性，防数值倾斜）（【定稿】L228/L427）；开启属运营选择。
- 开启后：总伤害 × 当前图当前天气倍率（【定稿】L228）；计算时点 = **每回合开始**读取当前天气（懒计算），战斗中途天气变化 → 下一回合生效 + 状态行提示一次，不打断战斗（【定稿】L229）。
- 不改 formula.json 伤害公式本体——倍率为外挂层（【定稿】L230）；`mults` 键必须 ∈ 注册天气集，V7 硬拦（【定稿】L336）。

## 5. 天气条件判断（`[天气:X]`）

### 5.1 条件键契约（R28 / R29 / R30）

- 条件英文键 = `{ var: "weather", param: X }`，展示/公式键 = `[天气:X]`，互译表 4.2.3.1 **新增 1 行**、单口登记（【定稿】L174/L180/L408）。
- **语义 = 玩家当前所在图的当前天气 == X**（上下文绑定，与 {var:"item_count"} 同构）——天气不是全局值，按玩家所在图取 `map_weather(该图, 当前tick)`（【定稿】L180/L182）。
- `X` ∈ 注册天气集（默认池已注册键）（【定稿】L180）；引用未知天气 → 校验器 V6 硬拦（【定稿】L335）。

### 5.2 消费方式（零新增机制）（R28 / R31）

- 消费方（任务 quest.json / NPC npc.json / 签到活动表 checkin.json / 副本事件 dungeon.json / 成就 achievements.json / 图鉴情报 condition / 鱼王事件 king_event.weather）引用 `[天气:X]` **零新增机制**——事件/活动窗口 = 配置组合（【定稿】L183/L216）。
- 例：`{var:"season",op:"eq",param:"summer"}` → 夏季限定任务；`{var:"period",op:"eq",param:"midnight"}` + `{var:"weather",op:"eq",param:"storm"}` → **午夜雷雨限定事件**（多条件 AND 叠加 = 联合触发）（【定稿】L216-217）。
- 签到活动表 start/end 仍为现实时间（懒计算），天气/时段/季节键作为**叠加条件**（活动期内 + 周期窗口），互不冲突（【定稿】L218）。
- 与既有周期键叠加语义一致：怪物 seasons/periods 限定、鱼种 seasons/periods 偏好、现实钟点 active_time 与五时段键**并存正交**（AND 叠加）（【定稿】L235）。

### 5.3 懒重算与变化识别（R32）

- 天气值在**玩家操作时**与**战斗每回合开始**重算（懒计算，零定时器）；变化经变化检测钩子比较缓存的 world_state.time_state 索引识别（【定稿】L62/L229）。
- 战斗会话内天气变化**不打断战斗**：仅用于每回合数值/状态行提示，播报挂战斗结算后（【定稿】L91/L229）；跨群不重复广播（time_state.map_weather_seen 去重）（【定稿】L278-281/L266）。
