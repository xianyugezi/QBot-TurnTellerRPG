## ① battle_state 数据结构（字段级定义）

### 1.1 总体约束（定稿写死，不可偏离）

| # | 约束 | 来源 |
|---|---|---|
| B0 | `battle_state` 是本场战斗的**唯一权威状态**，回合状态机边界在本层写死（不可配） | 【战斗定稿 L41-42】 |
| B1 | 当前回合数：普通怪 3-8 回合 / 精英 10-15 / BOSS ≈40-60，作为数值/超时审计基准 | 【战斗定稿 L133-137/L143】 |
| B2 | 行动记录按「段」写入（每段独立取整、独立记录），收集时机=拦截链→扣血后 | 【战斗定稿 L49/L314/L319】 |
| B3 | 结果标记（win/lose/escape）在**当轮事件末尾统一结算一次**；BOSS/最后目标死亡则立刻结束 | 【战斗定稿 L64-65】 |
| B4 | 中断快照只落回合边界（回合开始前 / 回合结束 tick 后），回合内不落快照 | 【战斗定稿 L66-67】 |
| B5 | `combo_state` 入战斗快照全程保留，随战斗结束清零（任何原因） | 【派生定稿 L59/L182/L183/L382】 |
| B6 | `ai_state` 随快照全保留（BOSS 阶段/行动表指针/读招/印记） | 【派生定稿 L183】【战斗定稿 L66】（框架 3.18 对齐） |

### 1.3 结果标记（status / result.flag）状态机

```
active ──┬─ 怪物死（普通怪，当轮末结算）──────────────→ win
         ├─ BOSS/最后目标死（立刻结束）──────────────→ win   （【战斗定稿 L53/L65/L239】）
         ├─ 玩家死（当轮末结算 / 回合开始即死）────────→ lose  （【战斗定稿 L46-48/L64】）
         ├─ 逃跑成功（行动阶段判定）────────────────→ escape（【派生定稿 L57】）
         └─ 同回合互杀 ── 平局 draw（可配 player_loss=玩家败）（【战斗定稿 L59-63/L236-237】）
任何出口（win/lose/escape/draw）⇒ 连段一律清零（战斗内资源，【派生定稿 L59/L182/L382】）
⇒ 当轮事件末尾统一结算奖励/掉落/快照清理（【战斗定稿 L64】）
```

### 1.4 关键字段核对（防悬空）

- `turn` 与 `timestamps.snapshot_at.turn` 一致性：快照恢复端只需读一处即可确定续战点（B4 语义落地，对齐 1g3）。
- `dead_mark` 与 `result` 写入先后：死亡判定先于当轮末结算、先于快照写入（【战斗定稿 L64/L67】）→ `dead_mark=true` 出现即应能在同轮 event 末尾看到 result 终态，不允许「死而未结算」穿透回合边界。
- `combo_state` 只做引用 + 结算钩子：本层不重定义清空规则，全部委托给 1c《派生》规则（【派生定稿 L51-59/L182-184】）；δ 增量仅记录于 `action_record[].combo_delta` 供审计。

## ② 命中/会心/格挡/乘区等对状态的影响（简述）

判定管线固定为：`命中 → 会心 → 格挡 → 双通道（物理/元素）→ 防御率 → 伤害拦截链 → 扣血`（【战斗定稿 L16】）。各环节对 `battle_state` 的**唯一写入通道是 ④行动记录 + ⑥combo_state**；对 `sides` 的写入口只有 `伤害拦截链→扣血`（【战斗定稿 L36】）与 `回合结束 tick 衰减`（【战斗定稿 L58】）。

| 环节 | 判定/公式（定稿） | 对 battle_state 的影响 |
|---|---|---|
| 命中 | 命中率 = clamp(专注/(专注+K_hit·对方敏捷), 10%, 95%)，K_hit=0.2（L21） | miss → `damage.final=0`，扣血 0，仍写 `action_record`（提示「未命中」L22）；**不触发击杀判定** |
| 会心 | P=√幸运÷2：r≤P 高级 / ≤P×3 中级 / 其余低级；倍率 2.2/1.7/1.3 + 0.05×超会心Lv（L23-24） | 写入 `rating.crit` 档位；倍率进入双通道乘区；**不直接改状态**，仅放大伤害 |
| 格挡 | min(40%, 专注/(专注+150))；成功 → 总伤害 ×0.5；魔攻击无视（L25） | 写入 `rating.blocked`；乘区 ×0.5 只在当次伤害生效，**不落持续状态** |
| 双通道/防御率 | 物理=攻击值×倍率×类型克制×会心×防御系数×怪物防御率（L26-30）；元素通道含元素弱点/元素减伤（L31-33）；总伤害×格挡×防御指令×乱数[0.9,1.1]（L34-35） | 通道末 floor（L38）→ `damage.ch_phys/ch_elem/final`；破防 `pierce`（L30/324）仅本段生效 |
| 类型加成 | 斩+5%会心 / 突+5%命中 / 打破防20% / 魔无视格挡（L88-95） | 写入 `rating.multi` 之外的影响已并入通道公式，**不新建状态字段** |
| 伤害拦截链 | 减伤→护盾→反弹→吸收→免疫→续行→扣血，顺序以效果系统 §3.4 为准（L36） | 唯一写血量通道：`sides[].hp/shields` 变更；**扣血后立即插入击杀判定**（L50）→ 可能置位 `dead_mark` / `result` |
| 派生累计乘区 | 加法叠乘 + ≤1.5× 封顶（【战斗定稿 L129/L228-229】） | 写入 `rating.multi` + `combo_state.derived_mult_total`；随连段推进更新 |

> 简述结论：**命中/会心/格挡/乘区均为「一次性判定 + 记录」，不产生持久化状态字段**；唯一持续状态写入路径是拦截链扣血 / tick 衰减 / 死亡标记 / 连段结算。判定的全量中间结果落 `action_record.rating` 供伤害构成统计与审计（【战斗定稿 L314/L317-333】）。
