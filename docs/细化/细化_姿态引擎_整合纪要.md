## 四、关键设计裁定（三路共识）
1. **姿态修正 = 命中修正（非伤害倍率），不进十乘区**（M1-M10+O1 不变）——挂命中判定①，`final=clamp(base+stance_hit_mod+其他,10%,95%)`
2. **受伤害判定优先级**：①护盾（未破→不落地，全 tpl_shield 系）> ②重击（heavy 标记权威源，怪物对称）> ③其他
3. **击落 = 打断语义**（清 chain_queue/charge，armor 不防击落）；倒地强制起身占行动（跳过 L2-L7 防 AI 空转）
