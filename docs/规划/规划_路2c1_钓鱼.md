## 层 1 · 数据与配置（鱼种数据）

### T01 任务名：profession.json fishing 段配置骨架
- 定稿依据：§三（行 69-80）；§七 登记要求·profession.json（行 119）
- 实现要点：
  - 在 profession.json 落 `fishing` 段七键：`mode`（full/simple/off）、`bait_ids`（5 档饵引用炼金 recipe）、`crown_thresholds`（reverse=5 / silver=85 / gold=95）、`wait_sec`（min=300 / max=900）、`daily_limit`=20、`energy.enabled`=false、`king_event`（enabled=true / window_daily=2 / chance=0.3）。
  - 鱼种数据不在此段，独立放 fishing.json 内容文件（§三 行 81 注释）。
  - 加载器容错：未知键不破坏加载；default 与定稿一致。
- 验收标准：结构可按框架配置加载器读取且默认值与定稿逐键一致；非法枚举值触发 T03 硬错误而非静默。

### T02 任务名：fishing.json 鱼种数据（base/区间/稀有度/时段/钓点/饵偏好/文案）
- 定稿依据：§三 fishing.json 行（行 81-88）；§五 鱼种池 CSV 列（行 104）；§七 登记要求·fishing.json（行 123）
- 实现要点：
  - 每鱼种行字段：`id/name/rarity`（normal/rare/gold 等、与§四 70/25/5 稀有度体系同枚举）、`size_min/size_max/weight_min/weight_max`（百分位线性插值区间）、`seasons`（季节，空=全年）、`periods`（五时段，空=全天，时间天气定稿 §4.1 语义）、`hours`（现实钟点，3.6 语义保留兼容，默认 00:00-24:00）、钓点（关联 maps 采集点，时段+稀有度标记素材）、饵偏好（定向饵引用）、图鉴文案（含大小/重量单位 cm/kg）。
  - 单测夹具内置 1 条示例鱼种 `silver_carp 银鳞鲤`（§三 行 84）；CSV 双向导入导出（鱼种/大小区间/重量区间/稀有度/时段/钓点/饵偏好）。
- 验收标准：示例行字段完整；seasons/periods 空数组语义（不限）在时段匹配中生效；CSV 导出→导入与源数据一致。

### T03 任务名：配置校验器（4 行硬校验 + simple 黄提示）
- 定稿依据：§2.4（行 62-67）；§七 登记要求·校验器（行 122）
- 实现要点：
  - 硬校验：① 鱼种 `size_min ≤ size_max`、`weight_min ≤ weight_max`；② 冠级阈值合法 `0 < reverse < silver < gold < 100`（默认 5/85/95）；③ 定向饵引用鱼种存在；④ mode 为 full/simple/off 三态枚举（simple/off 下引用 full 专属字段如 king_event → 黄提示，非硬错，对齐附 K K.2）。
  - 校验在配置加载期执行并记录到日志/启动报告。
- 验收标准：4 项硬校验各有独立失败用例并能定位到具体字段；`mode=simple` 且配 `king_event` 时出现黄提示不阻断加载。

### T04 任务名：鱼饵体系（5 档通用饵 + 定向饵，炼金 recipe 引用）
- 定稿依据：§1 M2（行 16）；§三 `bait_ids`（行 74）；§2.4 定向饵引用校验（行 66）；§四 鱼饵消耗（行 96）
- 实现要点：
  - 5 档通用饵（饵_蚯蚓 / 饵_面团 / 饵_小鱼 / 饵_黄金虫 / 饵_龙涎）为炼金 recipe 产物（消耗品）。
  - 定向饵：对口饵稀有 +8% / 金 +2%（作用于 T09 收杆概率与 T10 结算）；无饵保底不卡死（可无饵抛竿，仅不吃加成）。
  - 消耗：抛竿 1 次 = 1 饵，进每日计数（T06）。
- 验收标准：对口饵+满力收杆时稀有度分布 54/37/9 复现（§四 行 94）；无饵可正常出鱼；bait_ids 指向的 recipe 均存在（T03 ③ 校验通过）。

## 层 2 · 流程指令（/钓鱼 · 抛竿 · 鱼讯 · /收杆）

### T05 任务名：/钓鱼 指令与当前地图钓点列举
- 定稿依据：§1 M1（行 15）；§6 玩家所见（行 110）；§五 生活系统页（行 103）
- 实现要点：
  - 垂钓点 = maps 采集点变体：挂时段偏好 + 稀有度标记（“时段+稀有度标记”）。
  - `/钓鱼` 列出当前地图可钓鱼点，并附鱼讯参考说明（微动=小鱼 / 拉扯=中鱼 / 猛烈=大鱼或鱼王）；无钓点地图给空态文案。
  - 与 T17 联动：simple 模式下 `/钓鱼` 直接出鱼（无等待/鱼讯/鱼王）；off 模式拒绝。
- 验收标准：钓点列表字段（名称/时段/稀有度）正确；空地图返回空态；simple 模式首条消息即出鱼。

### T06 任务名：抛竿流程（扣饵 + 等待懒计算 + 每日计数）
- 定稿依据：§1 M3（行 17）；§三 `wait_sec`/`daily_limit`（行 76-77）；§四 鱼饵消耗（行 96）
- 实现要点：
  - 复用 farming.harvest_sec 懒计算定时（无实时倒计时，跨会话可结算）；等待区间可配（默认 300-900 秒，0=即收）。
  - 抛竿即扣饵（1 次 1 饵，T04）；每日次数走 quest_daily 懒计算（默认 20，T01）。
  - 等待状态机：抛竿 → 等待中 → 鱼讯 → 收杆 → 结算。
- 验收标准：等待期内无实时计时器仍到期可收（懒计算）；wait_sec 配 0 立即可收；当日第 21 次抛竿被拦截。

### T07 任务名：鱼讯三类意图生成（微动 / 拉扯 / 猛烈）
- 定稿依据：§1 M4（行 18）；§6 鱼讯参考（行 110）
- 实现要点：
  - 等待期结束按鱼种大小生成意图预告：**微动**=小鱼 / **拉扯**=中鱼 / **猛烈**=大鱼或鱼王；复用怪物 AI 意图预告机制（零新增）。
  - 猛烈鱼讯在 T15 触发时携带“金闪”标记（鱼王预告）。
  - simple 模式不产生鱼讯（直出）。
- 验收标准：三类鱼讯均可出现且文案与意图对应；金闪标记仅随猛烈鱼讯出现；simple 模式无鱼讯实例。

### T08 任务名：/鱼讯 指令（状态查询；可并入 /钓鱼 流程）
- 定稿依据：§七 指令表（行 121，/鱼讯 或合并 /钓鱼 内）；§四 单次节奏（行 93）
- 实现要点：
  - 等待中可用 `/鱼讯` 查询当前钓局状态（钓点/已耗时/是否已触发鱼讯及类别）；实现上允许并入 `/钓鱼` 输出。
  - 节奏约束：抛竿→等待→鱼讯→收杆共 2-3 条消息/次（§四）。
- 验收标准：无进行中钓局时提示空态；等待中可返回鱼讯类别（未触发时返回“等待中”）；一轮消息数落在 2-3 条。

### T09 任务名：/收杆 三选一（满力 / 自动 / 止损）
- 定稿依据：§1 M5（行 19）；§三 mode 描述（行 73）；§四 概率（行 94）
- 实现要点：
  - **满力收杆**：升级 roll，+稀有度/冠级概率（配合对口饵达满配 54/37/9）。
  - **自动收杆**：基础概率（70/25/5）。
  - **止损收杆**：提前收，已计饵照常消耗（T06 已扣），不触发鱼讯收益。
  - 纯决策三选一，无任何判定小游戏（M5 蓄力小游戏用户拍板删除，行 6/19）。
- 验收标准：三选一各自产出结算结果；满配（对口饵+满力）54/37/9 与基础 70/25/5 均以种子 42/2026 可复现（§四 行 94）。

### T10 任务名：出鱼结算与奖励发放（图鉴点亮 + 熟练经验 + 奖励）
- 定稿依据：§1 M6（行 20）；§四 节奏/经济（行 93-97）
- 实现要点：
  - 结算链路：鱼种 × 大小 × 重量 × 冠级 → 图鉴点亮（T13/T14）+ 钓鱼熟练经验（T16）+ 奖励；走 reward 统一发放器。
  - 大小/重量数值由 T11 冠级生成同源供给；结算记录落日志含 size/weight/crown。
  - 经济锚点：普通饵单次期望 ≈22.8 金（净 +12.8），日 20 次 ≈256 金，对齐 50 级尖峰 3374 量级且低于战斗（防冲击）。
- 验收标准：结算记录三要素（size/weight/crown）齐全；图鉴条目与熟练经验同步入账；种子化对账日期望 ≈256 金。

## 层 3 · 冠级与图鉴

### T11 任务名：冠级百分位生成与六档判定（阈值可配，判定顺序写死）
- 定稿依据：§2.1-2.2（行 27-44）；§三 `crown_thresholds`（行 75）
- 实现要点：
  - 每条鱼获独立生成 size% 与 weight%（0-100 均匀分布，可配）；具体值 = 鱼种 base × 百分位映射（按 size_min/size_max/weight_min/weight_max 线性插值）。
  - 阈值从 `crown_thresholds` 读取（默认 5/85/95，可配）。
  - 判定顺序写死：**逆金冠 → 大金冠 → 金冠 → 大银冠 → 银冠 → 普通**；混合极端（size≥95 且 weight<5）按金冠档显示——逆金冠仅在两者都 <5% 时成立。
  - 六档（均匀分布概率）：普通 ~72.0 / 银冠 ~17.0（2×0.10×0.85）/ 大银冠 ~1.0（0.10²）/ 金冠 ~9.5（1−0.95²−0.00025）/ 大金冠 0.25（0.05²）/ 逆金冠 0.25（0.05²）。
- 验收标准：种子 42/2026 六档频率与定义分布吻合；档位边界用例（4.9% vs 5.0%、84.9% vs 85.0%、94.9% vs 95.0%）判定正确；混合极端（size 95+ / weight 5−）判为金冠。

### T12 任务名：冠级纯收藏约束（不参与任何数值）
- 定稿依据：§2.3（行 46-48）；§八 风险对策（行 132）
- 实现要点：
  - 冠级仅做图鉴记录与社交展示；不进入鱼获价值/经验/出售价计算（防数值倾斜）。
  - 大金冠/逆金冠全收集期望 ~400 竿/鱼（§四 行 99）为炫耀物提示，不设硬门槛。
- 验收标准：同鱼种、同大小重量、不同冠级时，价值/经验/售价完全一致（差分测试为 0）；展示层含冠级字样。

### T13 任务名：codex_state 鱼类条目冠级记录扩展（历史最佳）
- 定稿依据：§2.3（行 49-58）；§七 登记要求·codex_state（行 120）
- 实现要点：
  - 鱼条目扩展六键：`caught_count` / `best_crown` / `best_size` / `best_weight` / `min_size` / `min_weight` / `reverse_crown_count`（逆金冠单独记录次数与最值）。
  - 更新规则：best_crown 取玩家获取过的最优标志中**最大**者（大金冠 > 金冠 > 大银冠 > 银冠 > 普通）；best/min 尺寸重量按极值更新；逆金冠每次+1 并刷新最小记录。
- 验收标准：多次捕捞序列后 best/min/reverse 计数与手工推演一致；未捕获过的鱼种无条目。

### T14 任务名：图鉴点亮与冠级标注展示（codex type=fish）
- 定稿依据：§2.3 显示示例（行 59-60）；§6 玩家所见（行 112-113）；§七 登记要求·图鉴（行 126）
- 实现要点：
  - codex 增加 type=fish 枚举；首获即点亮，捕获计数随 T10 更新。
  - 鱼条目展示：最大记录 + 最优冠级标注 + 逆金冠×N；示例格式 `鲤鱼 Lv3 · 最大 45.2cm/3.8kg · 金冠 · 逆金冠×1`。
  - 冠级规则由图鉴标注自然揭示，**不写判定公式、不教攻略**（行 113）。
- 验收标准：示例格式逐字段一致；逆金冠独立标注（不是等级）；图鉴界面检索不到判定公式文本。

### T15 任务名：鱼王事件（金闪鱼讯 → 鱼王 BOSS 战）
- 定稿依据：§1 M7（行 21）；§三 `king_event`（行 79）；§四 钓鱼王（行 98）；§八 风险对策（行 134）
- 实现要点：
  - 猛烈鱼讯金闪时触发鱼王讨伐：enemies 引用鱼王 BOSS，复用怪物/BOSS 引擎。
  - 触发控制：`enabled=true`、每日窗口 `window_daily=2`、单次概率 `chance=0.3`（均来自 T01 可配）。
  - 讨伐胜利计 1 次鱼王事件次数，参与图鉴全亮条件（钓鱼王称号须含鱼王事件 2 次，T16）。
  - simple 模式无鱼王（T17 拦截）。
- 验收标准：种子 2026 左右 30% 触发率可复现；每日第 3 次触发被窗口拦截；simple 模式鱼王路径不可达。

### T17 任务名：mode 三态开关路由（full / simple / off）

### T18 任务名：经济四出口闭环（商店 / 委托 / 品评 / 炼金）

- 验收标准：四出口各自可消费/变现鱼获且数据回写正确；种子化对账日经济 ≈256 金。
