## 二、M12 核心内容

### 2.1 5a 编辑器壳（六页 CRUD · 15 端点 · 认证 · 热重载）
- **元数据驱动**：字段元数据表（field_meta 正式表）是唯一数据源——编辑器表单/CSV 列头/JSON Schema/校验规则四处共用（P-07）
- **页面结构**：左侧列表 + 右侧卡片；顶栏（游戏名/数据包信息/保存/试玩）+ 侧边栏（总览/职业/技能/部位/装备物品/怪物/掉落/地图/公式数值 + 运营/数据包管理）
- **控件 7 类**：C-01 text / C-02 number / C-03 select / C-04 range 滑条 / C-05 引用芯片+底部抽屉 / C-06 list 子表 / C-07 formula 公式输入框（含变量大全面板）
- **保存链路 SV-01~08**：实时校验（标红/黄）→ 从不阻断保存 → 红拦 5 类（类型错误/负数/非数字/引用不存在/结构错误）→ 原子写盘（temp+rename）→ 全部写完统一重载 → 快照回退（校验失败回退旧 registry）→ 旧快照续战
- **认证 AU-01~06**：首次强制设密（≥8 位含字母数字）→ 随机 token+过期+单设备互踢 → 5 次失败锁 15 分钟 → 公网默认关（仅 localhost）→ 机主/GM 权限
- **API 15 端点**（§6）：统一包络 `{ok, data}` / `{ok, false, errors[]}`；写端点全走原子写盘+触发热重载；>50ms 操作 asyncio.to_thread

### 2.3 5b GM 指令与权限（14 条 · 34 TC）
- **权限三级**：机主 > GM > 普通玩家；GM 默认授予集（重载/备份/恢复/日志/编辑/封禁/解封/封禁列表）；机主专属可下授（存档导出/调试/测试/广播/玩家查询/设置）
- **admin_users 表**（5b §1.2）：权限唯一事实来源；玩家存档不含权限字段（防拷贝伪造）
- **静默语义**：无权限发 GM 指令 → 直接无视（不报错不提示不写审计）；被封玩家发游玩指令 → 人话提示
- **GM 禁绑**：GM 指令不可快捷绑定/不可别名化/强制 / 前缀（防权限绕过四攻击面核对）
- **审计 audit_log**（§4）：追加写不可删/成败皆写/无权限不写/轮转/权限 600/700；事件类 E1-E6
- **14 条指令** G1-G14（见 §2.1 已实现 5 条 + 待接线 9 条）
