## 〇、时间标准：1000 行动条 = 1「回合」

1. 战斗机制层时间单位统一为**行动条**（CTB `battle_time`）。
2. **换算标准：1000 行动条 = 1「回合」**。设计文本 / 内容中的「N 回合」时长 = **N × 1000 行动条**。
   - 示例：获得「5 回合」的攻击提升 → 接下来 **5000 行动条**内有效。
3. 现状衔接：现行内容以「次行动 / turns 计数」承载的持续（如 腾空姿态 3 次行动），实装时按本标准复核换算（见 §四）。
4. 【推定】新设计的效果时长一律以行动条为单位表达；内容层字段形式（沿用 `turns` 语义 vs 新增行动条字段）留实装批次定。

## 一、行动时间（技能使用时间）

1. 新增概念：**行动时间** = 技能发动后、其生效窗口占用的行动条时长（「使用这个技能的时间」）。
2. 触发规则：反应类技能在**行动时间窗口内**监听敌方行动——窗口内出现符合条件的敌方攻击 → 触发反应效果。
   - 标准示例（本批拍板）：**闪反技能的行动时间 = 400 行动条**。发动后 400 行动条内，怪物出现「可闪反」的攻击行动 → 闪反触发（免伤 + 反击）。
3. 口径变更：现行「姿态窗口 = 自写入起至持有者再次行动止」（R10，`_stance_owner_seq` 计数口径）**改写为时间口径**——窗口 = 行动时间时长，到期即结束。
4. 【推定】边界（实装前核对）：
   - 窗口内未出现可反应行动 → 到期自然结束（无补偿）；
   - 窗口内多次出现符合条件的敌方行动 → 按技能自身触发上限约束（现行反制技 `trigger_limit.per_round=1`）；
   - 持有者提前再次行动不提前关闭窗口（以时间到期为准；原「至持有者再次行动止」不再作为上界）。
5. 命名核对项：战报批次行已有「（行动时间 {start} → {end}）」时间段显示（`battle_ctb_batch_head`）——技能「行动时间」为独立概念，二者可共存；如审阅认为易混，实装批调整显示词。

## 二、术语：未命中（废「够不着」）

1. 因方位覆盖不足导致的攻击落空（position miss）→ 统一称**未命中**。废弃「够不着」表述。
2. 语义不变：未命中 = 完整行动（照常消耗、不产生伤害/破坏力/效果，不拒绝施放）。
3. 战报文案（已落地）：`✅ 未命中：{name}的攻击未能命中{pos}的你（HP {hp}/{max_hp}）`。
4. 落地范围（`b061ef0`）：战报模板 `battle_enemy_position_miss`、引擎兜底消息、代码注释、内容包描述（御剑·腾空）、测试断言、现行设计文档（方位草案 / 开工提示词）——11 文件 32 处；历史记录 / 审查档案不改。

## 三、怪物自动转向与仇恨值

1. **仇恨值（隐藏）**：玩家对每只怪持有仇恨值；**玩家不可见**（内部数据，不做面板展示）。
2. **自动转向**：怪物优先转向**仇恨值最高**的玩家；**转向消耗行动条**（时间成本）。
3. **远程抑制**：远程武器产生的仇恨值**低于**近战武器——设计意图：避免「脆皮」远程被怪物锁着杀。
4. 适用范围：多玩家共斗场景（框架现行 1v1；方位原语已按多玩家可扩展设计，组队为独立里程碑）。1v1 下等价表现：玩家绕背/侧移后，怪按行动条成本转回面向（现行「玩家行动前自动回正面」的延伸）。
5. 【推定】待细化项（实装批）：仇恨值来源清单（造成伤害 / 成功反制 / 嘲讽类技能…）与衰减（受击 / 时间）；远程仇恨系数档位；每次转向的行动条成本。

## 四、跃空维持时间

1. 跃空状态默认维持 **2000 行动条**。
2. 跃空期间使用**攻击 / 技能** → **少量延长**维持时间；**部分技能大幅延长**（技能自带延长值）。
3. 到期自动落地（保留现行 `_settle_air_landing` 兜底语义）；空中既有规则（地面技未命中、背壳仅在空可达等）不变。
4. 实装换算：`sw_vault_air`（现 3 次行动）→ 行动条制（默认 2000）；`vs_air_window` / `va_air_window` 等关联状态同步审计。
5. 【推定】延长档位量化（普攻 / 技能小幅 vs 专用技大幅）实装批给数值。

## 五、会心

1. 会心 = **概率效果**（等价于其他游戏的「暴击」）；**允许满会心（100%）**——满会心时必定触发会心。
2. 现状对照（已实现）：会心率 = min(cap, √幸运×系数 + crit_bonus + slash_crit)；**cap 默认 95%（可配，0=不限）**；三档倍率（2.2 / 1.7 / 1.3）+ 超会心 Lv1-3（+0.05/档）；斩击类型 +5%。
3. **冲突点**：现行 cap 95% 封顶与「允许满会心」冲突 → 实装批次放开（cap=100 或 0=不限，方式实装批定）。
4. 【建议】同步扩充会心来源（装备 / 技能 / 效果的 `crit_bonus`），使满会心成为可达成的养成目标。

## 附、推定项汇总（审阅用）

1. 行动时间窗口：到期自然结束、无补偿；多次触发按技能触发上限。
2. 持有者提前再行动不提前关闭窗口（以时间到期为准）。
3. 仇恨：来源 / 衰减清单；远程系数档位；转向行动条成本。
4. 跃空延长档位量化。
5. 会心 cap 放开方式（100 vs 不限）。
