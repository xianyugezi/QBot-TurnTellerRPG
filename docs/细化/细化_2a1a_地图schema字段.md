# 细化规划 · 2a1a：maps.json 地图 Schema（字段级）

> 仓库：QBot-TurnTellerRPG（新仓库）｜阶段：2a1a 细化规划｜范围：maps.json 完整字段级 schema
> 依据（严格引用）：《副本系统设计定稿.md》（下称【副本】）+《怪物模块设计定稿.md》（下称【怪物】）
> 定位：副本=网状多地图（节点+边、方向制），玩家 `/进入 <方向>` 走通道追击换区 BOSS（【副本】L12/L46-51/L75-77；【怪物】L13/L95）

---

## 0. 结构总览（字段树）

```
maps.json                        // 文件根
└── [地图节点] ×N                 // key = 地图 ID（【副本】L191/L207/L229-231 共用同一组 ID）
    ├── id        : string        ◆ 必需
    ├── name      : string        ◆ 必需
    ├── desc      : string        ▲ 建议
    ├── spawns    : Spawn[]       ○ 可有（BOSS 房可空）
    │     └── { enemy, rank, chance? }
    ├── exits     : Exit[]        ○ 每图编辑 4 方向（上/下/左/右），双向/单向
    │     └── { direction, target, mode, shortcut?, hidden?, lore? }
    ├── mechanics : Mechanic[]    ○【副本】L232/L157/L270 场地效果（可选扩展）
    └── gate_guard: string        ○ 守门怪 ID（可选扩展；【副本】L231/L270）
```

字段数：节点级 **7** ＋ spawns 条目 **3** ＋ exits 条目 **6** ＝ **16 字段**。

---

## 1. 地图节点（maps.json 根级条目；key = 地图 ID）

### 1.1 id —— 地图唯一标识（引用 key）
- 类型：`string`｜必需
- 语义：地图唯一 ID，被 dungeon.json 的 `"maps": [...]` 引用（【副本】L191「"maps": ["molten_entrance", "molten_corridor", "molten_core"]」；L207 同上）
- 约束：**两组副本（探索/BOSS）引用同一组地图 ID**，地图配置共用、不复制（【副本】L229「两组副本引用【同一组地图 ID】」、L230-232）
- 例：`molten_entrance` / `molten_corridor` / `molten_core` / `molten_boss_room`（【副本】L191/L207）

### 1.2 name —— 地图名称
- 类型：`string`｜必需
- 语义：玩家可见地图名；换区提示与候选区域即用此名（【副本】L57「提示『逃向了熔岩坑道』」、L144「targets: [『熔岩坑道』,『矿洞』]」）
- 例：`熔岩坑道` / `龙王巢穴`（【副本】L43/L57）

### 1.3 desc —— 地图介绍文本（含机制/预告）
- 类型：`string`｜建议
- 语义：地图熟悉性信息——地形、通道、机制、宝箱/采集点、BOSS 房机制预告（【副本】L156「地形/通道/捷径（哪里能走哪里不能走）」、L159「宝箱/采集点位置」、L160「提前学习：BOSS 房的机制预告（如『前方有灼热气息』）」）
- 切换视角：探索版/BOSS 版共用同一 maps（【副本】L230），文本应为两版通用介绍

### 1.4 spawns —— 怪物分布（引用 enemies.json）
- 类型：`Spawn[]`｜可有（BOSS 房/纯机关区可空）
- 语义：本图「哪里有什么怪」（【副本】L158「怪物分布（哪里有什么怪）」）；怪物配置在 enemies.json（【副本】L271「enemies.json：PV/行动表/…」）
- 组成见 §3

### 1.5 exits —— 出口/通道列表（网状核心）
- 类型：`Exit[]`｜可有
- 语义：本图可走通道，**每地图编辑 4 个方向（上/下/左/右）**（【副本】L47）；玩家承接 `/进入 <方向> <空格>` 追击 BOSS（【副本】L76「玩家 /进入 <方向> 走通道追击」、L12；【怪物】L95「玩家走地图通道去找（/进入 <方向>，框架通道系统）」、L13）
- 组成见 §2

### 1.6 mechanics（可选）—— 场地效果/地图机制
- 类型：`Mechanic[]`｜可选
- 语义：落石/陷阱/机关/场地效果——**探索副本先学会，BOSS 副本直接用（两副本共用）**（【副本】L232「地图机制（落石/场地效果）两副本共用」）；maps.json 是场地效果承载处（【副本】L270「maps.json：副地图链接 + 场地效果 + 守门怪」；L157「地图机制（落石/陷阱/机关/场地效果）」）
- 条目建议：`{ "id": "rockfall", "desc": "...", "on_step": {...} }`（类型以机制系统定稿为准，此处仅登记承载位置）

### 1.7 gate_guard（可选）—— 守门怪
- 类型：`string`｜可选
- 语义：BOSS 副本在入口/BOSS 房前配置的守门怪（【副本】L231「同一地图 + 额外 BOSS 房 + 守门怪配置」；L270「守门怪」）；值为 enemies.json 中怪物 ID（如 `rock_weasel`，【怪物】L19）

## 2. exits 出口结构（Exit，6 字段）

> 依据：【副本】L46-51「通道结构（用户拍板：4 方向编辑）」——方向/双向↔单向/捷径/隐藏通道 四项全出自此节

### 2.1 direction —— 方向
- 类型：`"up" | "down" | "left" | "right"`｜必需
- 语义：本通道在本图的方向之一；**每地图最多编辑 4 方向**（【副本】L47「每地图编辑 4 个方向（上/下/左/右）的通向地图」）；与 `/进入 <方向>` 空格指令一致（【副本】L12、L76；【怪物】L13）

### 2.2 target —— 目标地图 ID
- 类型：`string`｜必需
- 语义：此通道通向的地图 ID（【副本】L47-48「地图1↔地图2」）；指向 §1.1 其他节点
- 校验：**target 必须存在**（对应 maps 节点）；双向时两侧互为 target

### 2.3 mode —— 双向 / 单向
- 类型：`"bidirectional" | "one_way"`｜必需
- 语义：**双向 = 地图1↔地图2 互相有通道；单向 = 地图1→地图2 只有一边**（【副本】L48-49）
- 换区联动：无论双向/单向，追击都走通道方向判定（【副本】L76-77；L56-59「不熟悉→绕矿洞岔路（错过追击窗口/遇到精英）」——绕路性由 §2.4/§2.5 表达）

### 2.4 shortcut —— 捷径标记
- 类型：`boolean`｜可选（默认 `false`）
- 语义：**捷径 = 绕路连通**——地图1→地图2 单向，地图2→地图3→地图1 绕回（【副本】L50）；示例「熔岩坑道（捷径，单向门）」（【副本】L43）；熟悉地图者走捷径直追 BOSS（【副本】L58「走回廊→坑道捷径直追」）
- 约束：`shortcut: true` 时通常伴随 `mode: "one_way"`（【副本】L50）

### 2.5 hidden —— 隐藏通道条件
- 类型：`string | { condition, value? }`｜可选
- 语义：**隐藏通道 = 满足条件才显示/可走（可选）**（【副本】L51）；条件示例：到达某处/持有钥匙/机制触发
- 落地：由 dungeon.json 级条件或子任务解锁联动（映射【副本】L165 探索任务「到达指定区域」机制语义）；不配置=普通通道

### 2.6 lore —— 通道介绍文本
- 类型：`string`｜可选
- 语义：走到该通道/地图时给玩家的文字——「哪里能走哪里不能走」的地形通道信息（【副本】L156-157）；支持换区追击提示的对位（【副本】L57「逃向了熔岩坑道」、L76「BOSS 逃向了 XX 区域」）
- 例：`顺着灼热气流向下，通往熔岩坑道（捷径，单向）。`

## 3. spawns 条目结构（Spawn，3 字段）

### 3.1 enemy —— 怪物 ID
- 类型：`string`｜必需
- 语义：引用 enemies.json 的怪物（【副本】L271「enemies.json：PV/行动表/特殊行动/掉落三类」；【怪物】L19 `"id": "rock_weasel"`）
- 校验：enemy ID 引用必须存在（对齐【怪物】L295 校验器思路）

### 3.2 rank —— 怪物档位（普通/精英/守门）
- 类型：`"normal" | "elite" | "gate"`｜必需
- 语义：普通怪与精英遭遇——精英=升压段（【副本】L23「精英遭遇」、L33「升压（精英遭遇）」）；守门怪=BOSS 副本专属（【副本】L231）；档位数值与难度模板对齐（【怪物】L44-45 精英 HP×2.5/BOSS HP×10+）

### 3.3 chance —— 遭遇概率（可选）
- 类型：`number`（0-100）｜可选（默认按难度模板）
- 语义：本怪在本图遭遇权重；缺省走难度模板/编辑器数值（【怪物】L44「按难度模板自动补全」，L362 对齐内容包难度模板）；概率语义对齐概率归一化思路（【怪物】L145 weight 归一化）

## 4. 换区追击对该 schema 的消费（规划备注，非字段）

- 出口结构为 BOSS 换区「玩家凭地图知识追击」提供路径表（【副本】L57-59、L75-77）：`exits[].target` + `shortcut` 构成快/慢两条追击路径（回廊→坑道捷径 vs 矿洞岔路）
- 候选区域名单独立配置于 dungeon.json/enemies.json `zone_change.targets`（【副本】L144），maps 只保证该 ID 存在
- BOSS 房（如 molten_boss_room）无普通 spawns、可配 gate_guard（【副本】L43「龙王巢穴（BOSS）」、L231）

| 校验 | 依据 |
