## ① 怪物技能池字段扩展（schema + 默认推断规则 + 校验）

### 1.1 落点裁决

| 字段 | 落点 | 理由 | 依据 |
|---|---|---|---|
| `counter_tags` | **action.json**（行动数据库，技能池逐行动） | 行动可被多只怪复用；标签属于「招的攻防属性」而非「怪」 | 【底座】L92-94、【规范】L424 |
| `stance_change` | **action.json**（逐行动） | 同上；「飞扑/腾跃」是行动自身携带的形态副作用 | 【底座】L94、【规范】L424 |
| `initial_stance` | **enemies.json 顶层**（逐怪） | 「初始姿态」属于怪的面板（飞行怪 vs 地面怪是怪本身的差异）；不同怪可复用同一行动池但初始姿态不同 | 【规范】L425、底座拍板#5（【底座】L6/L135） |

### 1.2 action.json 扩展字段（2 字段，并入【6a】§2.3 怪物侧扩展字段表）

| # | 字段 | 类型 | 必填 | 默认值 | 约束 / 枚举 | 编辑器控件 | 来源 |
|---|---|---|---|---|---|---|---|
| C01 | `counter_tags` | string[] | 选填 | 按推断（见 1.3） | 元素 ∈ {`blockable` 可防反, `dodgeable` 可闪避}；去重；**空数组 `[]` = 不可反**（极端怪#1 载体）；双标签允许（防反/闪反皆可接） | 多选勾选（可反/可闪/无） | 【底座】L92-93、【规范】L424 |
| C02 | `stance_change` | string \| null | 选填 | `null` | ∈ {`airborne` 跃空, `ground` 落地}；使用后怪物姿态切到目标姿态（已在则无变化）；无「down」选项（怪物不自我倒地，倒地只由玩家击落驱动） | 下拉（无/跃空/落地） | 【底座】L94、【规范】L424 |

> **【细化定型】`counter_tags` 数组形态**：底座写「blockable / dodgeable」两枚可配（【底座】L93），本文档定型为数组（`["blockable"]`/`["dodgeable"]`/`["blockable","dodgeable"]`/`[]`），空数组显式表达「不可反」——否则无法表达「这招没法读招」（极端怪盲测 #1 硬需求，【规范】L428①）。

### 1.3 `counter_tags` 默认推断规则（【细化定型】· 只建议不限制，per-skill 可配覆盖）

推断目的：作者漏配时不落盘自动补默认，降低配置负担（对齐【6a】三铁律②「漏配=合理默认」【6a L23】）。

```
推断优先级（运行期只读，不写回配置）：
1. 显式优先：action.counter_tags 显式配置 → 权威使用（含 [] = 不可反），不做推断。
2. 按 attack_type（ActionCore 共用字段【6a §2.2】）推断：
   - slash 斩 / blunt 打 / pierce 突（近战三族）  → ["blockable"]（近战默认可防反）
   - magic 魔（远程魔法/弹道）                    → ["dodgeable"]（远程默认可闪避）
   - 其余 / 未配 attack_type                      → ["blockable"]（近战安全默认）+ 校验黄提示
3. 爆发类加权（细化定型，仅当 2 无法判定时参考）：intent=charge（蓄力）且 power 高于怪物档位常见上限（普通>120 / 精英>150 / BOSS>200，建议默认值可配）
   → ["dodgeable"]（爆发/蓄力技默认闪避，符合「远程/爆发→dodgeable」）
4. 非攻击类行动建议（黄提示不拦截）：intent ∈ {heal, buff, debuff, utility, control} 且配了非空 counter_tags
   → 黄提示「非攻击行动建议 counter_tags:[]（读招「可防反」用于非攻击招语义存疑）」
```

- **推断结果只读**：运行期生效，不写回 action.json（保持配置最小）；编辑器保存时可「确认并固化」将推断值落盘（黄提示）。
- **推断入口**：行动解析器（【1f】④ 行动表解析）读取行动时一次性求值，存入运行时行动条目；意图播报（③）消费运行时 `counter` 值。

### 1.4 enemies.json 顶层扩展字段（1 字段，并入【1e】§1.1 顶层字段表）

| # | 字段 | 类型 | 必填 | 默认值 | 约束 / 枚举 | 编辑器控件 | 来源 |
|---|---|---|---|---|---|---|---|
| C03 | `initial_stance` | enum | 选填 | `ground` | ∈ {`ground` 地面, `airborne` 跃空}；`airborne` = 飞行怪开局跃空；不支持 `down`（无怪开局倒地） | 下拉（地面/跃空） | 【规范】L425、底座拍板#5 |

### 1.5 校验器新增规则（并入【1e】§五，级别：拦截 / 黄提示）

| # | 规则 | 级别 | 判定细节 | 依据 |
|---|---|---|---|---|
| R-C1 | counter_tags 合法值 | 拦截 | 元素 ⊆ {blockable, dodgeable}；类型为 string[]；重复项去重提示 | 本文件 1.2 |
| R-C2 | stance_change 合法值 | 拦截 | ∈ {airborne, ground} 或 null/缺省 | 本文件 1.2 |

## ② 怪物姿态行为（AI 决策中 stance 的影响 / 起身 / 被击落）

> 状态机本体（stance 字段、转换表、命中修正、倒地减防 30%、倒地免疫）由**子系统 A（JD-F1/2/5/6）**承接（【底座】L39-87）；本节只定义**怪物侧如何进入/离开姿态**与 **AI 决策管线中 stance 的消费**。

### 2.1 怪物姿态进入/离开（怪物侧转换表·细化定型）

| 时机 | 事件 | 结果 | 依据 |
|---|---|---|---|
| 战斗开始 | initial_stance（默认 ground） | 按字段初始化；airborne=开局跃空 | 【规范】L425 |
| 行动结算 | 行动带 `stance_change: airborne` | 结算后 → 跃空（技能确定性副作用，**套内生效**，不经过条件评估管线） | 【底座】L94、核心规则1（【AI 定稿】L15） |
| 行动结算 | 行动带 `stance_change: ground` | 结算后 → 落地 | 同上 |
| 受击 | 跃空中受玩家**重击**命中（破盾后） | → **倒地** down | 【底座】L57 |
| 受击 | 跃空中受玩家**非重击**伤害 | → **落地** ground | 【底座】L57 |
| 受击 | 跃空中带护盾且护盾未被打破 | **不落地**（保持跃空） | 【底座】L58/L63-70（盾不破不落地，对所有 tpl_shield 系） |
| 倒地 | 玩家跃空重击命中（陨星落） | 起身被打断，保持倒地 | 【底座】L77/L85 |
| 倒地 | 本回合行动 | = **起身**（回 ground，占行动，免费，技能不结算） | 【底座】L84、L49 |

- **套内确定性**：`stance_change` 是行动自带的确定性副作用，与 damage 等效果同回合结算，**不触发条件评估**（核心规则1 的「套内不评估」不禁止行动自身副作用）——套内后续链节点按新姿态结算。
- **被击落 = 打断语义**：怪物被击倒按「打断 = 套完结」（核心规则3，【AI 定稿】L24-25）处理——**在途链完结（chain_queue 清空）、蓄力被打断（charge 清空）**；起身后下一回合进入随机流程。
- **armor 不防击落**（【细化定型】）：armor=true 只免疫「玩家打断技对连招/蓄力的打断」语义（核心规则7，【AI 定稿】L29）；**击落由命中结果驱动，不属打断技判定**——霸体怪跃空同样可被重击击落。

### 2.2 怪物倒地行动（起身占行动 · 对齐【1f】执行态 downed）

1. **倒地回合**：怪物执行态 = downed（【1f】① 表 downed，L42）；本回合行动**强制 = 起身**，回 ground，占行动、免费、不耗 MP/冷却、技能不结算（【底座】L84、L49）。
2. **不进入 L2-L7**：倒地回合跳过套间评估（强制队列/条件行动/连锁队列/状态专属/随机表/兜底全部跳过）——避免倒地回合条件行动（如 pv_broken）与起身行动冲突（防 AI 空转双轨）。
3. **起身后**：下一回合正常套间评估（L1-L7）；可触发 `get_up` 条件行动（触发类型 ③，下一回合，【AI 定稿】L64、【怪定】L180）——如起身咆哮反扑。
4. **起身可被打断 + 倒地免疫**：玩家跃空重击命中倒地怪 → 起身打断保持倒地；连续断起身达 N 次（默认 3，`down_break_immunity_after`）→ 倒地免疫窗口（默认 2 回合，`down_break_immunity_turns`），期间不被击倒/断起身（【底座】L86、v1.1 拍板）——怪物侧同样生效（连控受控）。

### 2.3 AI 决策中 stance 的影响（细化定型 · 消费接口登记）

姿态对怪物 AI 的三处影响：

| 影响面 | 内容 | 落点 | 依据 |
|---|---|---|---|
| 命中修正（结算层） | 跃空怪被打 -1/3 命中；怪打地面 +1/3；重击击空→倒地 | 子系统 A JD-F2 承接（乘区），本文件只声明怪物侧同样适用 | 【底座】L72-80 |
| 条件键（配置层） | **新增怪物侧条件键 `[怪物姿态]`**（target.stance，注入中文：地面/跃空/倒地）：供 `special_actions.trigger`（x_ 前缀扩展）、`ai.states.transitions` 条件表达式、`actions[].condition` 权重修正引用——如「跃空中才用某招」「倒地后换防御权重」 | 条件引擎（【AI 定稿】§二/§三、【1f】L1-L7） | 【细化定型】（对齐 [怪物意图] 键机制，见 ③） |
| 公式键（消费层） | 玩家侧公式新增 `[对方姿态]`（target.stance）/`[我方姿态]`（attacker.stance）——字符串注入（地面/跃空/倒地），仅供公式可用、不进玩家派生条件下拉（对齐【实现层规划文档】L206 裁决） | formula_engine（承接 JD-F1 stance 字段） | 【细化定型】 |

> **只建议不限制**：上述条件/公式键为**可选消费接口**，作者不用则不生效；怪物默认行为（无姿态条件时）不受影响。

## ③ 意图播报机制（JD-F15 · 数据结构 + 播报模板 + [怪物意图] 键绑定）

### 3.1 数据源链（意图标签的产生与消费）

```
AI 决策管线（【1f】L0-L7）选定行动
   → 取 action.intent（G03 配置字段，权威枚举 9 值 + gather，【6a】G03）
   → 运行时求值：action.counter_tags（推断后运行值，本文件 1.3）
   → 写 ai_state.intent 结构化对象（扩展【1f】§3.1）
   → 意图播报器渲染读招播报块（3.3）+ 写入 target.intent 字符串视图（3.4）
   → 玩家公式 [怪物意图] 消费（formula_engine 既有映射）
```

### 3.2 运行时意图数据结构（扩展【1f】§3.1 intent，新增 2 字段）

```json
"intent": {
  "level": 1,                    // 预告分级 L1/L2/L3【AI 定稿 L149-154】
  "category": "attack",          // L1 播报类别（机器键，映射见 3.4 表）
  "action_id": "heavy_claw",
  "name_revealed": false,        // 图鉴解锁后 true【AI 定稿 L152】
  "chain_preview": ["tail_sweep"],  // L3 连锁预演（图鉴解锁后显示）【AI 定稿 L153】
  "progress": "1/2",             // 蓄力进度【AI 定稿 L161】
  "stance_after": "airborne",    // 【扩展】意图行动结算后怪物姿态（= action.stance_change 的运行时值，null=无变化）
  "counter": ["blockable"]       // 【扩展】意图行动 counter_tags 运行时值（推断后，[] = 不可反）
}
```

- 落点：快照 `ai_state.intent`（【AI 定稿】L275 A.5，快照持久化 → 中断恢复可续，对齐【1f】TC-12）。
- 求值时机：**玩家行动评估前的回合间隙**（怪物意图已由管线预选，预告先于玩家行动展示——「打完一套再变」套间评估产出【AI 定稿】L17）。

### 3.3 播报模板（读招播报块 · 对齐【5e】D-5E 统一句式精神）

> 在【5e】BREP-12 固定句式（D-5E，`{怪物} 蓄力中（下回合发动「{招名}」）`，【5e】L47/L103）基础上扩展为**读招完整句式**——新增 3 条模板（登记建议并入【5e】注册表，本子系统为提出方）：

| ID | 类别 | 模板 / 输出 | 说明 |
|---|---|---|---|
| BREP-26 | 怪物-读招播报（意图预告） | `{怪物} 意图：{L1类别}「{招名|？？？}」·{可反标记}·{姿态}·{连段 N/M}` | 意图预告置顶行（【AI 定稿】L160 消息模板对齐）；**不计入怪物回合行动行数**（预告不是行动，对齐【5e】L195） |
| BREP-27 | 怪物-姿态转换播报 | `{怪物} 跃空/落地/倒地了` | 姿态变化时输出一行（状态行同步更新）；击落行 `❌ {怪物} 被击落（倒地）` 复用【5e】BREP-13 变体风格 |
| BREP-28 | 怪物-倒地起身播报 | 起身：`{怪物} 正在起身…（起身占用行动）`；被打断：`{怪物} 起身被打断，保持倒地！` | 起身/断起身可读（C3/RL1） |

## ④ 极端怪 5 类盲测样本定义（RL3 · 【规范】L428）

> 每类：样本要点（enemies.json）+ 姿态相关定义 + 盲测判据（P5 必做：模拟对局无死局自证，【规范】L428）。数值为**建议默认基准（可配）**，只建议不限制。

### 4.1 ① 全远程不可反怪（双不可反技能）
- **要点**：行动表 2 招**均** `counter_tags: []`（不可反）+ 远程（attack_type=magic，默认推断 dodgeable 被显式 [] 覆盖）；intent 可配 charge 蓄力大招。
- **姿态定义**：可选 `initial_stance: airborne`（飞行弓手）→ 玩家先手重击可击落（战术口子，见 ⑤-1）。
- **盲测判据**：玩家无法读招防御（无可反标记）；仍有应对面——打断（蓄力可打断）、减伤/护盾/吸血（生存）、破防（PV）→ **无死局自证**（MI9 破盾门禁【规范】L427）。

### 4.2 ② 高防盾怪（破盾考验）
- **要点**：PV 高（按档上限）+ `pv_half_ratio` 减半 debuff + 护盾 tpl_shield（盾不破不落地联动）+ 高防（monster_def_rate，contract_deviations R-09）+ 防御性 intent。
- **姿态定义**：地面为主；若配跃空技能 → 玩家需先破盾才能击落（盾不破不落地，【底座】L58/L63-70）。
- **盲测判据**：破防/贯穿/重击路径是否可稳定破 PV → 破防后 debuff 引爆窗口（【怪定】L73-89）；无破盾手段的职业靠替代（装备破防特效）→ 无死局。

### 4.3 ③ 持续净化怪（印记职业克星）
- **要点**：每回合/低冷却 `mark_remove` 清玩家印记（effects mark_remove）+ 清自身 debuff（player_status 触发）。
- **姿态定义**：地面；可配防御姿态权重（净化回合防御倾向）。
- **盲测判据**：印记职业（咒印师/处刑人）在印记被清的劣势下仍有伤害路径（直伤/连段），不依赖单一印记爆发 → 无死局。

### 4.4 ④ 反伤怪（reflect）
- **要点**：反弹效果（effects reflect，按 % 减伤并反弹，contract_deviations G3 已接线）+ 自身减伤（tpl_mitigation）+ 中低 HP。
- **姿态定义**：地面 + 防御姿态（防御回合反弹强化可选）。
- **盲测判据**：玩家自伤管理（换血 vs 吸血/减伤/护盾）；反伤互杀按平局裁决（contract_deviations D5 拍板）→ 玩家可算清斩杀线 → 无死局。

### 4.5 ⑤ 高爆发连段怪（生存考验）
- **要点**：顶层 chains 连招链（起手→锚点→收尾，【AI 定稿】L178-185）+ 高 power 蓄力大招（可打断，armor 可选）+ 阶段机制（phases）。
- **姿态定义**：连招链中某节点 `stance_change: airborne`（如「腾跃→俯冲」）制造命中修正/可击落窗口——姿态成为连招的一部分。
- **盲测判据**：生存三选一（回复/减伤/护盾，【规范】HC-6）+ 读招打断（蓄力断招）+ 读招四选一（防御/打断/霸体/硬吃，【AI 定稿】L224）→ 精英攻×1.2 高压 10-15 回合存活 → 无死局。

### 4.6 盲测运行要求
- 5 类均需**模拟对局**自证无死局（【规范】L428「5 类均需模拟对局无死局自证」）；验收 TC 见 ⑥ D 组。
