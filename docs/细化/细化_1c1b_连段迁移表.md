# 细化规划：1c1b 连段状态机迁移表

> 依据：`/root/docs_archive/RPG框架项目/技能派生系统设计定稿.md`（行号引用格式：L{n}）
> 作用域：1c1b = 单活跃链（1 chain）× 单战斗（1 battle）；多链并存（L189–191）不展开，跨战斗蓄力默认关（L213）

## 一、状态定义

| 状态 | 含义 | 依据 |
|---|---|---|
| **S0** | 无活跃链，count=0 | L45（无标签=无连段基线）、L59（战斗内资源） |
| **Sn** | 活跃链 C 上 count=n（1≤n<max_combo） | L42、L152–153（max_combo 链级属性） |
| **Smax** | count=max_combo（到顶） | L154–157（到顶行为分派点） |
| **H** | hold 到顶保持态（combo==max 时的被动态，仅此时免疫打断） | L156–157、L163 |

状态变量：`combo_state = {chain_id, chain_name, count, hold, step_index}`（L334–341）。
