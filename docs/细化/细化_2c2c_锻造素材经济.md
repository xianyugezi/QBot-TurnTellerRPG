## 一、素材来源全景（五来源 × 锻造衔接）

> 依据：【锻造】§5.2 L151-158（挖掘/采集/垂钓/怪物掉落/商店五路）、§五 L144-148（两档+来源提示+怪物素材对应）、【炼金】L129（六路材料来源）与 §11.2/11.4（种植/温室、代工助手）、【怪物】§八 L189-213（三类掉落）。编号 SOUR-01 ~ SOUR-05。

| # | 来源通道 | 产出内容 | 与锻造衔接（落点） | 引用 |
|---|---|---|---|---|
| SOUR-01 | **怪物掉落**（核心来源） | 核心素材：皮/爪/宝玉，**每怪 2-3 种**，素材需求驱动打怪；战斗/特殊/死亡三类掉落 | forge 节点素材行 `materials[].item` 直接引用 loot.json 素材 id；`monster_source`（forge N-13）登记主来源怪；**稀有素材保底机制复用 loot.json**；缺件提示"来源：火龙掉落" | 【锻造】L148 / L156 / L266；【怪物】L189-213 / L212 |
| SOUR-02 | **采集类**（基础/特殊来源） | ① 挖掘 → 矿石系（武器/防具基础材料）② 采集 → 草药/植物系（调和用途多，锻造少量）③ 垂钓 → 鱼/特殊素材（高级装备材料） | 挖矿/采集/垂钓点产出的素材 id 与 forge `materials[].item` 同物品表（items.json 材料类）；缺件提示"需 采集 冰晶"式分支引导；垂钓细化见 2c1a/2c1b | 【锻造】L153-155 / L144；L104-105 |
| SOUR-03 | **种植**（长线产能） | /种植 <种子> 定时收获（默认 4 小时），种子继承特性、收获品质 ≥ 种子；温室（大师）可复制一种素材 | 种子收获表产出 id 可为 forge 素材；锻造素材可作种植目标物（长线囤积，缓解稀有素材缺口）；碎片化友好"种→等→收" | 【炼金】L440-447 / L340；L446 |
| SOUR-04 | **代工**（减负阀） | /雇工 <助手> 持续"代采 X / 代调 Y"，消耗能源道具，后台定时产出 → /收取 | 代采目标 X 可直接指定 forge 素材 id；收取入包后参与锻造原子判定；等级提升→采集品质更高 | 【炼金】L458-465 / L341 |
| SOUR-05 | **商店**（金币回收口） | 基础素材可买（金币回收口）；炼金口径：商店限购（shop.json） | shop.json 基础素材条目与 forge 素材 id 对齐；限购量不影响锻造原子判定（判定只看背包持有）；金币→素材 回收口 | 【锻造】L157；【炼金】L129 |

> **来源提示元数据（SOUR-00 总则）**：每条素材必须标注来源（采集点/怪物/商店），【锻造】L147；落点 = items.json 材料类"来源标签"字段（2c2a 登记建议），forge 素材行可 `source_override`（M-04）覆写显示文本。素材需求行（M-01/M-02，forge 定稿 L260-263）+ 来源标签共同支撑缺件报错与 /图纸 全链（PROG-02/PROG-05）。

> **衔接总则**：五个来源的输出都是 **items.json 材料类物品 id**，forge 素材需求行引用同一 id 空间（N-10/M-01，见 2c2a §1.2.1）——来源侧（loot/采集/种植/代工/商店）只需产出"材料类 id 入包"，锻造侧只需按 id 查持有量，**两侧不引入第二套素材标识**（校验器 V10 强制材料类）。

### 2.2 3:1 合成扩展（普通 → 稀有 升档通道，P1 扩展）

| # | 规则 | 行为 | 引用 |
|---|---|---|---|
| CMB-01 | 合成规则 | **3 个普通素材 → 1 个稀有素材**；炼金/锻造工房均可 = **合成引擎 `kind=combine` 配置实例**（N 素材→1 高级素材，框架 4.1 recipe.json 统一 schema 登记；**原数值不变**） | 【锻造】L146 |
| CMB-02 | 映射配置 | 作者在 recipe.json 配置 combine 实例：`inputs=[同种/同系普通素材×3] → output=对应稀有素材`（合成映射表 `comb_synth_map` 登记：普通 id → 稀有 id），产出素材数值 = items.json 原值（不打折） | 【锻造】L146 / L354 |
| CMB-03 | 开关 | `synth_ratio_3to1`（forge settings S-02，默认 true）＝该 combine 实例开关；false=无升档渠道，校验器 W 级提示素材死锁风险 | 【锻造】L354 / L387 |
| CMB-04 | SP 解锁 | 3:1 合成是铸造职业 SP 面板可解锁项（自选解锁，非等级自动给） | 【锻造】L216 |

> 3:1 合成 = 稀有素材的**第二来源保底**（DEAD-02 三通道之一）：即使某个稀有素材的掉落怪当前不可刷（地图关/时段外），玩家仍可用普通素材升档获得，避免单点卡死（DEAD-06 衔接）。

## 四、材料闭环防死锁（多来源保底）

> 依据：【锻造】L387（素材死锁对策：3:1 合成 + 商店基础材料 + 分解回收）、L356（decompose_rate 复用炼金分解规则）、L235（/分解）、【炼金】L467-474（材料经济闭环五环节）、L169/L508（分解限炼金产出防套现）、L440-465（种植/温室/代工长线产能）。

| # | 规则 | 行为 | 引用 |
|---|---|---|---|
| DEAD-01 | **主副来源保底** | 每个被 forge 节点引用的素材 id，必须可回溯 ≥1 主来源（掉落/采集点/垂钓）+ ≥1 副来源（商店/种植/代工/3:1 合成/另一掉落怪）；校验器按素材 id 汇总途径数 | 【锻造】L147（来源标注）/ L156（掉落）/ L157（商店） |
| DEAD-02 | **三通道对策** | 素材死锁对策 = **3:1 合成 + 商店基础材料 + 分解回收**（三通道任一关闭其余仍保底）；与炼金 §11.5"合成保底通道 + 分解回收 + 商店可买基础材料"同构 | 【锻造】L387；【炼金】L473 / L507 |
| DEAD-03 | **分解回收** | /分解 旧装备回收素材（P1，复用炼金分解规则）：回收率 `decompose_rate` 40%→65%（称号档跳变，可配）；防御性限制复用炼金口径——分解范围及返还规则按炼金 §4.5 对齐（防商店套宝石类漏洞） | 【锻造】L235 / L356；【炼金】L169 / L418 / L508 |
| DEAD-04 | **分级保底下限** | 普通素材 ≥3 途径（采集/挖掘/垂钓/商店/种植/掉落任 3）；稀有素材 ≥2 途径（掉落主来源 + 3:1 合成/特殊垂钓/种植/代工任 1）；不满足 → 校验器 W 级死锁风险提示（不拦截，对齐 2c2a W4） | 【锻造】L144-145 / L387 |
| DEAD-05 | **长线产能** | 种植/温室（种子可复制素材）+ 代工助手（代采指定素材）= 锻造素材的挂机/长线补充，防"只能肝掉落"单一化 | 【炼金】L440-447 / L458-465 |
| DEAD-06 | **时间窗口兜底** | 出没时段稀有素材（炼金 L129）缺口时，缺件提示必须给出**替代途径**（3:1 合成或商店或另一掉落怪），禁只写单一来源 | 【锻造】L147 / L240；【炼金】L129 |
| DEAD-07 | **死锁扫描报告** | 校验器加载 forge.json + loot.json + shop.json + 种植/代工表后，生成"素材死锁风险报告"：素材 id → 途径数 → 缺口建议（补掉落/补商店/开 3:1）；W 级不阻断，启动日志输出 | 【锻造】L387 / L369（校验器清单）；【炼金】L467-474 |

> **闭环总览（读法）**：获取（掉落/采集/种植/代工/商店）→ 生产（锻造 100% 确定性消费；炼金合成/炼金是素材的平行消费方，共用同一 items 材料 id 空间）→ 消耗（装备树形态推进 = 素材的主要消耗出口）→ 回收（/分解 40-65% + 3:1 降级返还）→ 防死锁（DEAD-01~07）。锻造侧素材只进不出（装备化后经/分解回炉），炼金侧另有宝石经济平行回环（【炼金】L467-474）。
