## 二、M11 核心内容（4c + 4d + 4e）

### 2.1 4c 成就系统（细化_4c_成就系统契约.md · 22 TC）

- **achievements.json 数据模型**：顶层 8 字段 + hidden 3 key（11 叶子字段）；conditions 数组（全与 AND）；trigger=check；once/repeat；reward 四型（数值/物品/称号/组合）；hidden mode（locked 默认/hide）
- **解锁条件四类**（全部复用统一条件引擎）：图鉴完成度（var:codex 总册/param 分册）/ 事件计数 / 物品收集（累计 gain_count / 当前背包 item_count）/ 等级
- **奖励**：统一 reward 解析器（exp/coins/gem/物品/称号）+ 称号联动（/称号 查看 /称号 佩戴 <N>，1 个佩戴槽替换式 + 消息前缀 [称号]）
- **状态持久化**：achievement_state 存档（只增不减 + message_id 幂等 + 热重载降级「配置已移除」）
- **隐藏成就**：锁定行「？？？」占序号 / hide 完全隐藏；达成瞬间一次性揭示卡片 + reveal_text；不提供 /秘密
- **指令**：/成就 [页数]（5 条/页）· /成就信息 <N> · /称号 查看 · /称号 佩戴 <N>
- **校验器**：ACH-01~13（默认值兜底/别名/枚举/引用/可达性）

### 2.2 4d 图鉴聚合四册（细化_4d_图鉴聚合契约.md · 25 TC）

- **四册**：monster / fish / item / craft（craft=可由 forge 树节点或炼金 recipe 产出的物品；item=无制造路径；D-04 数据驱动判定）
- **现状**：codex.py 已有 monster/weapon/item/alchemy/fish 五分类（M7+M10），但**无 craft 册、无加权、无 lore 情报解锁**——M11 收敛为四册（weapon→craft 归属判定）+ 加权完成度
- **加权完成度**：权重配置（默认等权）+ 公式 T = Σ(wi×Vi)/Σwi + 运算口径（COD-08 展示取整/条件未取整）
- **里程碑阶梯**：25/50/75/90/100 五档 + 90% desc 软锚「全收集还有更深处」+ 分册称号（怪物博士/鱼类大师等）+ 100% 三件套（收藏家称号 + 世界之书 + 隐藏神龛解锁）
- **图鉴展示**：/图鉴 总览（总完成度 + 四册进度条 + 下一档提示）+ 分册列表（5 条/页 + 「？？？」占位）+ 鱼条目冠级标注 + 隐藏要素条目占位
- **情报解锁**：lore.unlock 阈值（1-100）→ 完成度 ≥ unlock 解锁该行；跨档跳升逐档授予
- **隐藏要素**：隐藏 BOSS→monster 册、鱼王→fish 册、彩蛋物品→item 册、隐藏配方→craft 册

### 2.3 4e PVP 玩家互斗（细化_4e_PVP决斗契约.md · 用户拍板 2026-08-28 + 2026-09-01 语义纠正）

- **决斗四指令（/决斗 + 接受/拒绝/信息）已拍板删除，不实现**（CMD-01~04 作废保留追溯）
- **PVP 概念 = 「其他玩家 = 野怪实例」**（定稿 §3.19 L345-354）：**目标 = 真实玩家，不是镜像战斗**——你锁定的是活人玩家的档案，攻击他直接与他的真实状态结算
- **指令双原语**：
  - `/锁定玩家 <QQ号>`：指定目标（显示对方状态：等级/职业/血量/装备摘要）
  - `/攻击玩家 <技能序号>`：对锁定玩家攻击（技能序号解析同 /攻击，不加 `*`）
- **偷袭语义（用户 2026-09-01 纠正）**：**目标玩家正在与怪物战斗时，你可以锁定并攻击他——偷袭**。框架已支持「战斗期间怪物被其他人杀死 → 玩家操作时提示『怪物丢失』」（定稿 L100），PVP 切入同理：目标在战斗会话中时，攻击玩家可插入其战斗（复用会话互斥/战斗干预机制）
- **战斗复用**：1v1 战斗引擎（定稿 L349「其他玩家=野怪实例，复用 1v1 战斗引擎，无新机制」）——目标玩家档案 → Battle 引擎敌方侧，非「造一个镜像打副本」
- **胜负结算**：统一 reward 管线 + 防刷（每日上限/等级差/对数上限/幂等）
- **PVP 配置**（编辑器通用设置 → PVP 卡片）：开关 / 回合制或非回合制 / 等级门槛 / 战斗掉落（无/货币/物品）/ 击杀惩罚（无/回城）
- **目标在线判定**：发起时目标需在线（离线=防御仅指战斗中掉线）
- 状态机 ST-S1~S4 仅保留战斗态（IDLE→BATTLE→结算）
