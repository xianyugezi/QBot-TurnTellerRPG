## 4. 工作清单（顺序执行）
1. 读 worktree 里本模块的相关代码，逐键核对占位符/触发场景。
2. **设计新文案 → 立即写 fragment**：`/tmp/tpl_b3i/docs/消息模板重构/_fragments/b3i.json`
   格式：`{"rail":"b3i","templates":{...},"prose_keys":{},"notes":{"key":"重做|维持＋一句理由"}}`（**先落盘！**）
3. 合入 worktree 表：python 脚本读 fragment 写 `qbot_rpg/core/templates/template_table.json`（indent=2、ensure_ascii=False；只加你的 key）。
4. 从 forge_tpl.py 删除这 33 键（DEFAULT_TEMPLATES 与 PLACEHOLDER_WHITELIST 两处）；死键候选复核后清除并记录。
5. 自校验：`-m python scripts/check_template_width.py`（0 FAIL）；`-m pytest tests/unit/test_template_table.py tests/unit/test_emoji_discipline.py -q`。
6. 修测试：本模块测试文件 + 全仓 grep 本模块旧文案断言（含 scripts/ 内嵌冒烟）；`content/test_demo/templates.json` 最小同步（本批 key 且值有差异者→新文本；veinborn 若有本模块覆盖则同法）。
7. 硬编码扫描：本模块命令/核心文件中玩家可见中文字面量（除已迁移键）→ 报告清单（迁入表 或 豁免+理由）。
8. 全量 tests/unit 一次 → 提交 → 按 §6 报告。
