## P1（1 项)

### P1-1｜等级编号口径内部冲突：TC-01「0 级=见习」与 5.3 存档样例「level 4 / exp 850」互相矛盾

- **位置**：TC-01（L270）+ §5.3 存档样例（L206-208）+ LVL-05 默认阈值（L46/162）+ SP-01（L96）
- **细化原文**：TC-01「新玩家炼金职业 **0 级** → 面板显示「见习」」；5.3 样例 `"alchemy": { "level": 4, "exp": 850, "sp_earned": 4, "sp_used": 2, ... }`
- **冲突演算**（按 LVL-05 补白阈值 `[0,100,300,700,1500,3000,6000]`）：
  - 0 基编号（见习=0，TC-01 的口径）：exp 850 已跨 100/300/700 三阈值 → 应达 **level 3（专家）**，且升级次数=3 → **sp_earned 应为 3**；样例写 level 4 / sp_earned 4（=大师，需 exp≥1500）。
  - 1 基编号（见习=1）：TC-01 的「0 级」不存在，且升到 level 4 仍只升 3 级 → sp_earned 仍应为 3。
  - **结论：无论取哪种编号，level=4、exp=850、sp_earned=4 三者不可能同时成立**；且 TC-01 与样例采用不同编号口径，实现时会产生 off-by-one（等级显示/升级次数/SP 发放错误）。
- **判定**：非定稿幻觉（定稿未定义等级编号与阈值数值，阈值已标补白），但属**同一文档内规范性内容（TC 与 schema）数值口径冲突**，实施影响大。
- **建议修复**：统一为 0 基（见习=0），样例改为 `level: 3, exp: 850, sp_earned: 3`；或把样例 exp 改到 ≥1500 并保持 level 4。
