## 系统 1：装备强化（指令 4 · 引擎新建 · 契约最全）

### 指令与功能
| 指令 | 语法 | 功能 | 出处 |
|---|---|---|---|
| 强化 | `强化 <装备名>[+N]` | 强化当前装备到 +N 档（原子一条消息出结果；材料照扣/失败分级惩罚/禁批量 `*`） | 细化_2c3b 一、GU-01~05 |
| 强化信息 | `强化信息 <装备名>` | 查询：当前 +N / 成功率 / 上限 / 消耗预览（材料+货币） | 细化_2c3b 二、2.2 |
| 强化保护 | `强化保护 <装备名>[+N]` | 带保护石强化（失败扣 1 石免掉级；保护石消耗时机=判定失败且掉级时） | 细化_2c3b 三、3.1~3.2 |
| 强化转移 | `强化转移 <源装备> <目标装备>` | 把源装备强化等级转移到目标装备（源销毁或降级——定稿未定义，实施按「只建议不限制」补白定型） | 定稿 L1368（建议指令名） |

### 变量/可配置项（内容包 enhance.json——schema 在细化_2c3a）
| 配置键 | 功能 | 出处 |
|---|---|---|
| `enhance.json.curves[]` | 成功率曲线（按品质×档位→成功率；单调不增） | 2c3a §7 校验 |
| `enhance.json.materials` | 各档位消耗材料表（材料 id × 数量） | 2c3b 1.3 |
| `enhance.json.max_by_quality` | 上限键（items.json 四档品质枚举 → 最大 +N） | 2c3a |
| `enhance.json.fail_penalty` | 失败惩罚分级（掉级/归零/爆装；保护石免掉级） | 2c3b 1.4 |
| `settings.json.enhance_enabled` | 系统总开关（false → 强化 提示未启用） | 2c3b GU-01 |
| 装备条目 `enhance_slots` | 可强化装备标记（equipment.json 字段） | 2c3b |

### 事件（内部结算事件，无跨系统广播）
| 事件 | 功能 | 出处 |
|---|---|---|
| `enhance_success` | 强化成功 → 更新装备档位/属性 → 回执 | 2c3b 1.3 |
| `enhance_fail_penalty` | 失败 → 按惩罚扣材料/掉级（保护石豁免） | 2c3b 1.4 |
| `enhance_reach_max` | 达顶 → 提示已满（+N=上限，禁再强） | 2c3b 2.3 |

### 关键实现点
- 原子防双扣：SQLite 事务 + message_id 幂等 + 热重载免疫（2c3b 四、F-01~07 已定义）
- 注册门槛：/注册 后可用；模板 enhance_tpl.py（内容包可覆盖）
- stub 移除：router_setup「强化」stub 删除

## 实施顺序建议（新对话分批）
1. **批 1（三路并行）**：
   - 路 1：强化系（契约最全 2c3b/2c3a——4 指令 + 引擎 + 模板 + 测试）
   - 路 2：木桩训练（最简——2 指令 + dummy.json）
   - 路 3：查看目标（壳层——战斗会话只读面板）
2. **批 2（三路并行）**：
   - 路 1：赠送（新交易引擎——玩家寻址 + 原子转移）
   - 路 2：种植温室核心（温室/种植/收获——crops 表 + 生长计时）
   - 路 3：委托板 + 声望（board.quests + 声望等级）
3. **批 3（两路并行）**：
   - 路 1：雇工/收取（代工助手后台产出）
   - 路 2：投稿 + 排行榜（品评会周赛）

每批门禁：对应细化契约测试用例全过 → 模拟器实测 → 全仓 pytest 无新增红（基线 10 failed）→ commit。
