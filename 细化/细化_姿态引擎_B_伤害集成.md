## 1. ① 命中修正（姿态修正乘区 · JD-F2）

### 1.1 定义与公式

**基础命中率**（【数值层】L21-22 / L188-190，唯一数据源）：

```
base_hit_rate = clamp( 专注 / (专注 + K_hit × 对方敏捷), cap_min=10%, cap_max=95% )
   K_hit = formula.hit.k（默认 0.2，可配）
```

**姿态命中修正**（【底座】L72-80 /【规范】L233 / contract_deviations JD-F2 L165）：

```
final_hit_rate = clamp( base_hit_rate + stance_hit_mod + other_hit_mods, hit.cap_min, hit.cap_max )
   stance_hit_mod ∈ { -0.33, 0, +0.33 }（默认建议值；per-职业可覆盖，非硬编码）
```

- **语义**：姿态修正是**命中率百分点加算**（additive percentage points），不是伤害倍率。±1/3 = ±33 个百分点（【底座】L80：±33%（±1/3）为默认建议值）。
- **clamp 复用**：clamp 上下限不另立字段，直接引用 `formula.hit.cap_min`(10) / `hit.cap_max`(95)（【数值层】L188-190；引用不复制数值，L252-258）。
- **收益边界自洽**：空打地 +33pp 命中在命中区间 75-95% 内 → 命中期望提升 ≈ ×1.4（90%→95% 为 ×1.06，75%→95% 为 ×1.27，叠加倒地减防/陨星落派生构成击落链收益）；地打空 -33pp 是身位劣势的主要惩罚。收益由「命中期望」体现，**不另设伤害乘区**（理由见 §3.2）。

### 1.2 命中修正表（姿态组合查表，互斥）

| 攻击方姿态 | 目标姿态 | stance_hit_mod（默认） | 备注 |
|---|---|---|---|
| 地面 ground | 跃空 airborne | **-0.33** | 地打空劣势（【底座】L76） |
| 跃空 airborne | 地面 ground | **+0.33** | 空打地优势（【底座】L77） |
| 跃空 airborne | 倒地 down | **+0.33** | 空打倒地同空打地（【底座】L77「地面/倒地」） |
| 地面 ground | 地面 ground | 0 | 无身位差（【底座】L78） |
| 跃空 airborne | 跃空 airborne | **0**（细化裁定 ⚑） | 双跃空 = 平视，无身位差；底座未定义 → 0 |
| 倒地 down | 任意 | 不适用 | 倒地非闪反行动=起身，技能不结算（【底座】L49/L60），无「倒地攻击方伤害」场景；特殊标注可攻击的倒地单位按地面攻击方（0）降级兜底 ⚑ |

> ⚑ 标注为细化裁定（定稿未逐字写明，属实现裁决，已诚实标注）。

### 1.3 叠加规则

1. **姿态修正互斥**：同一 (攻击方姿态, 目标姿态) 组合**只取一个查表值**（1.2 表），不同姿态组合不互相叠加。
2. **与其他命中修正加法叠加**：与 `type_affinity.thrust_hit`（突击 +5%，【数值层】L90-94/L216）加法叠加后再统一 clamp。例：突击·地打空 = -0.33 + 0.05 = -0.28。
3. **必中标记（F-6）覆盖**：倒地闪反成功 → 下回合必中（【底座】L59/L109，contract_deviations JD-F6）——必中时**跳过命中 roll**（final=100%，不经 clamp），姿态修正不参与；仅影响命中判定，不跳过伤害管线（仍走会心/格挡/通道/拦截链）。此为衔接 F-6（子系统 C），本子系统只声明消费。
4. **miss → 0 伤害**：姿态修正只改变命中率，不保证命中；miss 时伤害 0 且**不触发任何姿态转换**（击落/落地/陨星落均以「命中」为前提，§2.5）。
5. **clamp 次序**：全部命中修正（姿态 + 突击 + 其他）加算**后**统一 clamp [10%, 95%]，不允许中间态越界。

### 1.4 配置落点（formula.json 全局默认 + per-职业 / per-怪物覆盖）

```json
// formula.json · stance 段（框架默认，可配；clamp 复用 hit.cap_min/cap_max 不复制）
{
  "stance": {
    "hit_mod": {
      "ground_to_air": -0.33,   // 默认建议值，非硬编码
      "air_to_ground": 0.33,
      "air_to_down": 0.33,
      "same": 0.0
    }
  }
}
```

- **覆盖优先级（低→高）**：`formula.json stance.hit_mod`（框架默认）< `jobs.json` per-职业 `stance_hit_mod`（可选覆盖，【规范】HC-4 L126「per-职业可覆盖」）< `enemies.json` per-怪物 `stance_hit_mod`（可选覆盖，怪物侧同规则）。
- 覆盖粒度：按 (姿态组合) 键逐项覆盖，未覆盖项回退全局默认。
- **HC-4/只建议不限制**：覆盖值为任意合法浮点，校验器只拦非法类型/越界（见 1.5），不拦数值强度（【规范】HC-3 L125）。

### 1.5 校验器（细化建议）

| # | 规则 | 类型 |
|---|---|---|
| V-1 | `stance.hit_mod` 各键为数值（float），值域建议 [-0.9, 0.9]（超范围黄提示「姿态修正过强，注意 RL12 概率失衡」） | 提示不拦截（HC-3） |
| V-2 | 必选键检查：`ground_to_air/air_to_ground/air_to_down/same` 缺省时按默认值回退（0 修正），不报错（旧配置零改动可跑） | 兼容兜底 |
| V-3 | per-职业 `stance_hit_mod` 键必须 ⊆ 1.2 表键集（未注册键黄提示，不拦截） | 提示不拦截 |
| V-4 | 怪物 `initial_stance=airborne` 时校验器提示「该怪开局跃空，玩家地打空命中 -33pp」（可读性辅助，MI3/MI4） | 提示 |

## 2. ② 击落 / 落地 / 陨星落结算（JD-F5 + skill_chain 衔接）

### 2.1 跃空受伤害判定（【底座】§2.3 L62-70 全量 → 管线化）

目标为**跃空**时，受伤害按此顺序判定（挂载点 P2，在拦截链②护盾吸收结算后）：

```
受伤害 → 拦截链 ①减伤 ②护盾先扣（吸收量结算）
  ├─ 护盾未破（盾值结算后 > 0）→ 不落地，保持跃空（盾=空中保护层）【底座 L58/L65】
  └─ 无盾 或 护盾被本次伤害打破（盾值归 0）→ 破盾后判定：
       ├─ 伤害来源为【重击】→ 目标倒地（击落）【底座 L57/L67】
       └─ 其他伤害 → 目标落地（回地面，不倒地）【底座 L57/L68】
```

- **「护盾未破」定义**：本次伤害结算后盾值仍 > 0（含盾值被消耗但未归零）。**护盾破一半（消耗部分、剩余>0）→ 视为未破 → 不落地**（边界见 §4-3）。
- **「重击」定义（细化裁定 ⚑）**：技能 `tag` 含新增枚举 **`heavy`**（破防/击落标签）为**权威判定源**。默认建议：六功能位「破防/击落」位技能（重击，damage+pierce+combo+1，【底座】L18/【规范】L171）标注 `heavy`。校验器软提示：含 pierce 修正器但未标 heavy 的技能黄提示「是否为重击/击落技？」。**怪物技能池同样可标 heavy**（怪物跃空重击可击落玩家，对称性）。
- **状态变更时机**：倒地/落地状态变更在拦截链 **⑦扣血结算完成后**落位（不早于扣血），保证①本次伤害按当前姿态结算（倒地减防对本次不生效）②被击杀目标不落位姿态转换（死亡优先，§4-7）。

### 2.2 击落触发条件汇总（全部须同时满足）

| 条件 | 依据 |
|---|---|
| 攻击方技能为【重击】（tag=heavy） | 【底座】L57 |
| 目标为**跃空** | 【底座】L57 |
| 目标**无盾 或 盾被本次重击打破**（破盾后） | 【底座】L58/L65-68 |
| 重击**命中**（姿态修正参与命中 roll；miss 不触发） | §1.3-4 /【数值层】L22 |
| 不在**倒地免疫窗口**内（免疫窗口拦截倒地，§2.4） | 【规范】L231-232 |

→ 击落 = 破盾后 + 重击命中 + 跃空目标 → 目标 **倒地**。
非重击命中跃空目标 → 目标 **落地**（回地面，不倒地）——「重击是唯一击落手段」推论（【底座】L70）。

### 2.3 陨星落特殊派生（跃空重击打倒地 · skill_chain 独立实体）

**触发条件**：攻击方**跃空** + 技能为**重击**（tag=heavy）+ 目标**倒地** + 重击命中 + 不在倒地免疫窗口（断起身部分）。

**效果**（任务给定权威数值）：**160% 伤害 + 破防 30%（pierce）+ 断起身（目标保持倒地）**。

**与 skill_chain 衔接**（【底座】§一 派生独立实体规则 L30-35 /【规范】4.3 L186-191 /【派生】§9.1）：

- 陨星落 = **独立技能实体**（独立技能卡/ID/数值），主技能（重击）描述只做指向（「可派生成：陨星落（跃空重击倒地目标）」）。
- skill_chains.json 示例（to 为独立技能 ID；条件键 `self_stance`/`target_stance` 为**新增注册条件键**，随姿态引擎注册进条件引擎【派生】§9.3 L319-330）：

```json
{
  "id": "chain_heavy_air_down",
  "trigger_skill": "heavy_smash",
  "max_combo": 1,
  "max_combo_behavior": "reset",
  "steps": [{
    "from": "heavy_smash",
    "to": "yunxingluo",
    "tag": "heavy",
    "condition": { "self_stance": "airborne", "target_stance": "down" },
    "priority": 1,
    "mode": "replace",
    "armor": false,
    "consume": 0,
    "variant_override": { "dmg_mult": 1.6 }
  }]
}
```

- 陨星落技能卡 L0 构成（【规范】4.5 /【效果】§7.1）：`damage(power=160%)` + `pierce(30%, pct)` + `status_apply(down_break / 断起身)`。破防 30% 走 **pierce 模板**（【效果】L325：`type=pierce · value=30 · pct=true`），并入 M6 有效体质（§3.3-P3）。
- **倍率封顶边界**：陨星落 160%（1.6）为**技能自身基准倍率**（小技带 150-200%，【数值层】L127），**不触发** `derived.max_total_mult`（≤1.5×）累计封顶——封顶只约束**派生加成累加**（【派生】§6.3 L194-199 / 细化_1a T32），不约束技能基准。⚑ 此边界需校验器文案注明，防内容包作者误判。
- **无派生配置兜底**：跃空重击命中倒地目标但无陨星落链 → 按普通重击结算 + **断起身固有判定仍生效**（断起身是「重击命中倒地目标」的固有效果【底座】L77/L85，非陨星落专属）；160%+破防30% 不生效。派生被拒（MP/冷却/条件不足）→ 整体被拒/降级语义同【派生】§6.4。

### 2.4 断起身与倒地免疫窗口（【底座】§2.5 /【规范】§5.1）

- **断起身**：跃空重击（含陨星落）命中倒地目标 → 目标起身被打断，**保持倒地**（控制链）【底座】L85。
- **起身动作替换**：倒地时非闪反行动 = 起身（回地面，占行动，免费，不耗 MP/冷却，技能不结算）【底座】L49/L60/L84。
- **倒地免疫窗口（参数化，JD-F1 字段，本子系统消费）**：
  - 连续被打断起身达 **N 次（`down_break_immunity_after`，默认 3，可配）** → 进入**倒地免疫窗口**（`down_break_immunity_turns`，默认 2 回合，可配），期间**不被击倒/断起身**【规范】L232。
  - 免疫窗口内：
    - 重击命中跃空目标 → **不倒地**，**降级为落地**（回地面）⚑（裁定：免疫只防「倒地控制链」，不防「身位压制」——保留重击把目标打下空的最小收益，避免免疫窗口=无限滞空保护）。
    - 陨星落命中倒地目标 → **断起身不生效**（目标起身不被延迟，可正常起身），但 **160% 伤害与破防 30% 照常结算**。
    - 命中修正本身不受免疫影响（免疫仅免疫 倒地/断起身 两个状态结果，不免疫命中修正与伤害）。

### 2.5 与 damage 管线交互时序（精确挂载点）

```
技能施放（重击/陨星落，tag=heavy）
  → [P4 派生引擎] 回合时序·玩家行动阶段条件评估（self_stance/target_stance）→ 陨星落替换 or 普通重击
  → [P1 命中] final_hit_rate = clamp(base + stance_hit_mod + 其他, 10%, 95%)；必中则跳过
        ├─ miss → 伤害 0，无姿态转换（§1.3-4）
        └─ hit → 继续
  → [M5 会心] → [M7 格挡] → [双通道 M1-M6/M10/O1] → [⑥ 总伤害 M8/M9]
  → [P2 拦截链] ①减伤 ②护盾吸收（盾破判定）→ ③反弹 ④吸收 ⑤免疫 ⑥续行 ⑦扣血
        └─ ⑦后：目标跃空且本次受伤害 → 击落/落地判定（§2.1）→ 状态变更
             └─ 断起身判定（目标倒地 & 重击命中 & 非免疫窗口）→ 保持倒地 or 允许起身
  → ⑧死亡判定（死亡优先于姿态转换落位）
```

## 3. ③ 十乘区集成点（姿态修正插在乘区顺序哪一位 + 理由）

### 3.1 判定顺序定位

姿态命中修正挂在**判定顺序 ①命中**（【数值层】L16），位于 **M5 会心频率之前、全部伤害乘区（M1-M10）之前**：命中是整条 damage 管线的第一道门（miss → 0 伤害，【数值层】L22），命中 roll 先于会心（②）与双通道（④⑤）。

### 3.2 姿态修正不进十乘区（不占第 11 号乘区）—— 裁定与理由 ⚑

**裁定：姿态修正 = 命中修正（命中率百分点加算），不是伤害倍率；十乘区保持 M1-M10 + O1 不变。**

| 理由 | 依据 |
|---|---|
| ① 权威语义：底座/规范将其定义为「**形态命中修正**」，跃空优势 = 「打地面 +1/3 **命中**」（非 +1/3 伤害） | 【底座】L48/L72-80 /【规范】L233 |
