## 一、防具套装（forge_sets，P1 扩展，默认开、内容包可关）

> 依据：【锻造】§六 L162-170（五部位 L165 / 2-3-5 件激活技能等级 1/2/3 L166 / αβ 双版 L167 / 套装图鉴 L168 / 混搭取舍 L169）、§12.2 数据样例 L309-322、指令表 /套装 L236、编辑器-套装页 L366、CSV 套装表 L368、新手引导升大师公告 L378、风险·套装数值膨胀 L389。
> 结构：forge.json 顶层 `sets` 段（2c2a D-03 登记点，本细化做字段展开）；每套 = 一条 forge_sets 记录 = 一个 variant（α 或 β），同一套装族由同 `id` 的 α/β 两条记录表达（VAR-01）。

### 1.1 forge_sets 条目 JSON 样例（对齐定稿 §12.2 L311-321）

```json
{
  "id": "set_dragon_knight",        // 套装族 id（α/β 两 variant 共用；set_tracker/set_tag 统计键）
  "name": "龙骑士套装",
  "variant": "alpha",               // alpha/beta 双版
  "pieces": ["node_dk_head_a", "node_dk_body_a", "node_dk_hand_a", "node_dk_leg_a", "node_dk_foot_a"],
  "skills": [
    { "piece_count": 2, "skill": "dragon_guard", "level": 1 },
    { "piece_count": 3, "skill": "dragon_guard", "level": 2 },
    { "piece_count": 5, "skill": "dragon_guard", "level": 3 }
  ],
  "desc": "龙之加护寄宿的勇者之铠",
  "enabled": true,
  "codex_group": "set_dragon_knight"
}
```

> 同族 β 记录：`{ "id": "set_dragon_knight", "variant": "beta", "pieces": [..._b 节点...], "skills": 同 α（共享档位）}`——α/β 的孔位/属性差异全部落在各自 pieces 引用的锻造节点上（2c2a N-08 stats / N-09 slots），数据不重复维护。

### 1.2 forge_sets 字段表（SET-01 ~ SET-08）

> 依据：【锻造】L309-322（id/name/pieces/skills/variant 六字段原文）、L165（五部位 slots.json）、L166（2/3/5 激活）、L167（αβ 语义）、L168（图鉴）、L162（开关）。`id` 语义【工程补白】：定稿样例单条携带 variant（L311-321），α/β 双版需两条记录共用族 id，故 id = 族键（收集/统计键，对齐 4b EQP-03 键名）。

| # | 字段 | 类型 | 必填 | 默认 | 语义 | 引用 |
|---|---|---|---|---|---|---|
| SET-01 | `id` | string | 是 | — | 套装**族 id**（如 `set_dragon_knight`）；α/β 两条记录共用；`set_tracker`/`set_tag` 件数统计键（4b EQP-03/INS-07）；族级唯一（V1） | 【锻造】L312 / 4b EQP-03 |
| SET-02 | `name` | string | 是 | — | 中文名（如 龙骑士套装）；/套装 指令参数匹配名（L236）；α/β 显示名可带后缀（α/β） | L313 / L236 |
| SET-03 | `variant` | enum | 是 | — | `alpha` / `beta` 双版（可配）；(id, variant) 组合唯一（V1）；α=技能多孔少、β=技能少孔多（配珠自由度取舍，L167） | L320 / L167 |
| SET-04 | `pieces` | array\<string\> | 是 | — | 套装件 = forge 树**节点 id** 列表（2c2a N-01，定稿样例 L314）；≤5 项；每项 type ∈ 防具五部位之一（armor_head/armor_body/armor_hand/armor_leg/armor_foot）且部位不重复（V2）；件数为激活判定输入 | L314 / L165 |
| SET-05 | `skills` | array\<SetSkill\> | 是（≥1） | — | 套装技能档位（样例 L315-319）；子结构见 SK-01~SK-04；同套装可配多条技能 | L315-319 / L166 |
| SET-06 | `desc` | string | 否 | `""` | 套装介绍/收集描述（套装图鉴条目文本，L168） | L168 |
| SET-07 | `enabled` | bool | 否 | `true` | 套装模块开关（默认开、内容包可关，L162）；联动 2c2a W3：settings 关闭时数据可存在但黄提示不生效 | L162 / 2c2a W3 |
| SET-08 | `codex_group` | string | 否 | =`id` | 套装图鉴聚合分组（4d craft 册套装条目引用键；收集控目标 L168；补白登记字段） | L168 / 4d §1.5 |

#### 1.2.1 SetSkill 子字段（SK-01 ~ SK-04）

> 依据：【锻造】L166（穿 2/3/5 件 → 激活套装技能（技能等级 1/2/3））、L315-319（piece_count/skill/level 三键样例）、L389（技能等级默认封顶 3 级可配）、L30（效果类模板走效果系统）、6a 技能库契约。

| # | 字段 | 类型 | 必填 | 默认 | 语义 | 引用 |
|---|---|---|---|---|---|---|
| SK-01 | `piece_count` | int | 是 | — | 激活件数；**∈ {2, 3, 5}**（L166）；同一 `skill` 的档位按 2 < 3 < 5 **递增连续**（允许缺档？→ 硬校验禁止跳档，V3） | 【锻造】L166 / L316-318 |
| SK-02 | `skill` | string | 是 | — | 套装技能 id（对齐 6a 技能库契约；激活后按 `level` 生效，效果接线登记 SK-04） | L316-318（skill 键） |
| SK-03 | `level` | int | 是 | — | 技能等级；**∈ {1, 2, 3}**（L166 技能等级 1/2/3）；内容包可配更高级别、默认封顶 3 级（L389 套装技能等级默认封顶 3 级） | L166 / L389 |
| SK-04 | `effect_ref` | string | 否 | `""` | 效果接线登记【补白】：套装技能效果 = 技能库定义（6a）或效果系统模板（L30「效果类模板走效果系统」）；空=仅登记占位（占位技能只显示不结算） | L30 / 6a |

> 注：定稿样例（L315-319）为单技能三档；多技能并存（不同 skill 各带 2/3/5 档）时各技能独立按件数判定（ACT-04）。

### 1.3 套装激活规则（ACT-01 ~ ACT-06）

> 依据：【锻造】L165-169（五部位/2-3-5 激活/αβ/图鉴/混搭）、L389（数值膨胀对策）；4b EQP-03（set_tracker 件数统计字段）、INS-07（set_tag 套装标记）、EQP-R06（战斗内不可穿脱）。

| # | 规则 | 行为 | 引用 |
|---|---|---|---|
| ACT-01 | **件数统计口径** | 穿戴着装时按实例 `set_tag`（4b INS-07，值为 `族id:variant`）归族，聚合件数写 `set_tracker[族id]`（4b EQP-03，键=族 id）；**α/β 混穿合并计数**（VAR-03）；穿戴/脱卸实时增减 | 【锻造】L166 / 4b INS-07、EQP-03 |
| ACT-02 | **2/3/5 档位判定** | 设当前件数 N：取该 `skill` 全部档位中 `piece_count ≤ N` 的最大档 → 激活对应 `level`（2 件→Lv1 / 3 件→Lv2 / 5 件→Lv3）；N < 2 → 不激活 | L166 |
| ACT-03 | **无 4 档** | 穿 4 件 = 3 件档（技能等级 2），**无 4 件档位**（定稿只定义 2/3/5 三档）；穿 1/0 件 = 无技能 | L166 |
| ACT-04 | **多技能并行 / 同级取高** | 同套装多条技能各自按 ACT-02 判定、并行生效；同一条技能多档命中只取最高档（不叠加） | L166 / L389 |
| ACT-05 | **动态重算与战斗边界** | 穿/脱/换装 → 重算 set_tracker → 技能等级即时更新；**战斗内不可穿脱**（4b EQP-R06）→ 战斗内套装状态冻结（战前配装，与珠「战前准备」同构） | 4b EQP-R06 / L167（配珠取舍战前决策） |
| ACT-06 | **套装 × 散件混搭** | 套装件 + 散件并存：散件属性照常生效（进 4b EQP-02 equip_snapshot），套装技能按已穿套装件数判定——凑技能 vs 堆孔位的取舍深度（L169）；不设「混搭惩罚」 | L169 |

### 1.4 α/β 双版规则（VAR-01 ~ VAR-03）

> 依据：【锻造】L167（α=技能多孔少 / β=技能少孔多，配珠自由度取舍）、L389（α/β 取舍为套装数值膨胀对策之一）、数据结构样例 L320（variant 字段）。

| # | 规则 | 行为 | 引用 |
|---|---|---|---|
| VAR-01 | **一记录一 variant** | 每条 forge_sets 记录 = 一个 variant（α 或 β）；同一套装族 = 同 `id` 的两条记录（(id, variant) 唯一）；两条记录 `skills` 档位默认共享（α/β 只差孔位/单件数值，不差套装激活档位） | 【锻造】L311-321 / L167 |
| VAR-02 | **差异落点在节点** | α/β 的「技能多孔少 / 技能少孔多」差异落在各自 pieces 引用的锻造节点：α 节点 = 技能属性高（stats 技能相关键多）+ 孔位少（slots 少）；β 节点 = 技能属性低 + 孔位多——数据不重复维护（双源仲裁 2c2a AR-1/AR-2 自然承载）；校验器对比同族两版孔位总数 α ≤ β 给 W1 黄提示 | L167 / 2c2a N-08、N-09 |
| VAR-03 | **α/β 混穿归族计数** | α 头 + β 身 同族 → set_tracker[族id] = 2 → 激活 ACT-02（混穿不拆族；「同套装」= 同族 id，L166） | L166 / 4b EQP-03 |

### 1.5 /套装 <套装名> 指令（P1，无门槛）

> 依据：【锻造】指令表 L236（`/套装 <套装名>` 查看套装技能/需求（P1），门槛=无）、L58/L99-107（素材即进度/图纸全链精神、持有进度行）、L169（混搭取舍展示）、L12（指令分隔规范：单参数、无 `,`/`*` 多项目）。
> 流程：**零会话查询**（L239 锻造全部原子指令）；无铸造等级门槛 → 0 级玩家可用（L236「无」）；未命中套装名（精确→唯一前缀→歧义列表，对齐 2c2b §5.2 匹配算法）→ `未找到「<套装名>」相关套装 → /锻造树 查看可锻装备`。

```
📖 龙骑士套装（α）｜技能 多 · 孔 少
部位：头·龙骑盔 / 身·龙骑铠 / 手·龙骑腕 / 腿·龙骑腿 / 脚·龙骑靴
套装技能：龙之加护 Lv1（2件）/ Lv2（3件）/ Lv3（5件）
当前穿戴：2/5（头 ✓ · 身 ✓）→ 龙之加护 Lv1 生效中
缺件：手（可锻造：龙骑腕 ← 龙骑身 + 秘银×5）｜脚（可锻造：…）
α/β 对照：β 版孔位 3 > α 版孔位 1（配珠取舍）
```

逐字段接线：`套装技能` 行 = SET-05 skills 渲染（激活档位与等级）；`当前穿戴 N/5` = set_tracker 实时值 + 逐件 ✓（已穿/已拥有，对齐 /图纸 ✓ 规则 2c2b §2.3）；`缺件` 行 = 未穿部位的锻造入口（节点 + 素材需求，消费 2c2a N-06/N-10，素材即进度 L58）；`α/β 对照` 行 = 同族双记录孔位对比（VAR-02 数据，缺 β 记录则不渲染）。
