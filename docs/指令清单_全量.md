## 备注与边界

1. **定稿 7.1 注记**：明确【无 /探索】（玩家直接锁定/采集）；会话式指令 /投料 /继承 /确认 由会话管理器路由；/合成 /炼金 /锻造 等由内容包声明注册。
2. **GM 指令**：无 GM 权限玩家使用→直接无视不提示；GM 指令强制 `/` 前缀、永不快捷、快捷禁绑。
3. **分隔符规范**（指令分隔符统一规范 v1.1 / 细化_3c）：空格分参数、`*` 连数量、`,` 列列表、`=` 键值、`+` 标等级、`-` 表连招/区间、`>` 指路径；位置参数 ≤2（背包筛选豁免）。
4. **实现状态判定基于**：qbot_rpg/assembly/router_setup.py 装配清单 + 各 register_* 函数实际 CommandSpec 注册 + parsers.py DEFAULT_WHITELIST/DEFAULT_PREFIX_REQUIRED。装配层（M7）为「批次7 待接线」到「已接线」状态；GM 壳待 M12 后端。
5. **白名单已登记未接线**（解析层含、无注册 handler）：锁定怪物、采集、地图、怪物、使用、合成、炼金、锻造、强化、调合、镶嵌、拆珠、投料、雇工、继承。
