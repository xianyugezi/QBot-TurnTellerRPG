## 一、脊剑士派生树（大剑式）

```

├─ 蓄力流（核心，押注高伤）
│  蓄力(1层) ──► 蓄力(2层) ──► 蓄力(3层) ──► ⛔ 真蓄斩（300% 超高单发）
│     │            │            │                （大硬直，本回结束）
│     │            │            └─ 中途可取消 ──► 猛进斩（突进 SA，消耗蓄力）
│     │            └─ 中途可取消 ──► 猛进斩
│     └─ 中途可取消 ──► 猛进斩
│
├─ 轻击流（回精力，安全输出）
│  脊斩 ──► 横扫 ──► 上撩（循环，回精力 1/1/2）
│
├─ 防御流（防反）
│  脊挡 ──►（怪物攻击被挡）──► 盾返（反击+挂破绽）

├─ 机动流（位移/回避）

   （蓄力流真蓄斩打脉核）──► 破脉核（破坏+倒地）
```

## 三、蓄力机制设计（纯配置表达）

蓄力 = 印记层数（复用 marks，纯配置）：
- `蓄力印记`（charge_mark）：max_stack 3
- 蓄力斩（rb_form_strike 复用名改）：效果 mark_add charge +1（每回合 1 次）
- 真蓄斩：chain 条件 charge_mark ≥3 → replace 不竭·终（超高伤）
- 猛进斩：消耗蓄力（consume charge）→ 突进攻击 + SA
- 蓄力中断：被打断/换招 → 蓄力保留还是清零（设计决策）

**回合制适配**：怪猎的「蓄力押注」= 玩家连续 N 回合选蓄力，怪在打你（被打断风险=你掉血），第 3 回合释放真蓄（高回报）。这保留了「押注」张力。
