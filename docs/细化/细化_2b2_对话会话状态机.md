## 一、/对话 指令参数解析

### 1.0 定位

玩家只记一个主指令 `/对话`（L30、L31「记住最少」），高频可快捷绑定/免前缀（L51）；指令别名由内容包世界观定制（L52）。本段定义 `/对话` 的三个参数形态与解析顺序。

### 1.1 参数形态表

| 形态 | 语法 | 语义 | 定稿引用 |
|---|---|---|---|
| 无参列表 | `/对话` | 查看当前地图 NPC 列表（**序号 + 名字 + 类型图标**） | L40–41 |
| 序号快捷 | `/对话 N` | 序号快捷对话——直接进入该 NPC 交互菜单 | L42、L117 |
| 名称对话 | `/对话 名字` | 名称对话——直接进入该 NPC 交互菜单 | L43、L117 |

无参示例输出（对齐 L41 文案）：

```
这里的人：
1.🔨铁匠·老周　2.🧺杂货商人·林　3.📖学者·杜
```

### 1.2 参数解析步骤（非空参时，顺序写死）

1. **预处理**：去首尾空白；对参数做**整体 trim 后单串判定**（QQ 文本直接拼接，不二次分词）。
2. **名称优先**：先将整串按 NPC 名做**精确匹配**（L42「名称优先」）——命中即走该 NPC（L42、L43）。
3. **序号兜底**：名称未命中，若整串为**纯数字**（`^\d+$`）→ 按序号解析（L42「失败按序号」）：`1 ≤ N ≤ 当前地图 NPC 总数` → 取第 N 个；超界 → 失败提示，回列表（L42）。
4. **未命中**：既非名称也非合法序号 → 提示「没找到这个人」，不建会话。

### 1.3 名称匹配约束（命名铁律）

- **禁空格**：NPC 名禁空格（防解析歧义）→ 名称匹配即整串匹配；**含空格的参数必然无法命中任何名称**，走 1.2 步骤 3/4（L49）。【工程补白】含空格参数若首字符为数字，按数字段尝试序号；否则整串尝试后未命中 → 提示。
- **允许 `·` / `Ⅱ`**：名称中允许间隔号 `·` 与罗马数字 `Ⅱ`（如 `铁匠·老周`、`学者·杜Ⅱ`），匹配按普通字符处理，不做分词（L49）。
- **名称唯一**：NPC id/name 必填且名称唯一（L386）——名称精确匹配无二义。

### 1.4 NPC 来源

列表/序号/名称的候选集合 = **当前地图挂点 NPC**：`npc.map` 挂点（L360、L387）+ `maps.json npcs` 引用数组（L427、L360）。仅 `visible=true` 的纳入（L363、L390）。

## 二、对话会话状态机（7 态 / 15 条迁移）

### 2.0 状态集总览

`对话会话` 随对谈持续期持有（快照随 2.4 落盘，L94–102；会话快照 30 天回收，L88），收到结束词/自然结束即清理回收。状态变量：`{ state, npc_id, page_index, 已听集合, current_shop_ref, 恢复简报 }`。

| 状态枚举 | 名称 | 语义 | 定稿引用 |
|---|---|---|---|
| S0 `IDLE` | 未会话 | 无对话上下文；地图无 NPC 时 /对话 仅提示不建会话 | L50 |
| S1 `LIST` | 菜单列表 | /对话 无参后展示当前地图 NPC 列表（序号+名字+图标），等待选 NPC | L40–41 |
| S2 `NPCSEL` | 选 NPC | 序号/名称解析落地：确定目标 NPC，渲染交互菜单 | L42–43、L117 |
| S3 `MENU` | 交互选择 | NPC 交互菜单显示，`选择 N` 选交互功能 | L46、L117–119 |
| S4 `EXEC` | 交互执行 | 执行已选交互动作；长叙述内 `继续` 翻下一段 | L46–47、L119–120、L101 |
| S5 `SUBUI` | 子界面层 | 确认页挂起（heal 确认/任务交付确认/领取中）——**商店选购不在此层**（定稿 L80「无需子界面快照」，走 2b3 当前商店机制地图级状态兜底；幻觉审查_2b2 修正） | L76–79、L99–100 |
| S6 `END` | 会话结束 | 结束词/自然收尾；快照清理，回未会话 | L62–63、L98 |

> **宏链**：`S0 未会话 →/对话/ S1 列表 →选NPC/ S2 选NPC →解析/ S3 交互选择 →选择N/ S4 执行 →单轮/ S3 回菜单 →N.离开/ S6 结束`（对齐任务要求「未会话→菜单列表→选 NPC→交互选择→执行→结束」）。
> **中断不占态**：任何时刻中断 = 落快照即回，不迁移状态（L32「断了能续」、L94–102），见 2.3。

## 三、会话路由（对话激活时的输入分派）

### 3.0 原则（写死，不可配）

对话会话激活时，解析路由按**固定优先级**判定（L58–63）。**结论先摆**：路由冲突天然不存在——「对话中 1 = 选选项」「战斗中 1 = 快捷绑定」「使用1/攻击1 = 带指令词永远正常解析」（L67–70）。

### 3.1 路由判定表（R1–R5）

| # | 输入样例 | 判定 | 去向 | 定稿引用 |
|---|---|---|---|---|
| **R1 会话子词送状态机** | `1` / `2` / `3`（纯数字）、`继续`、`离开`/`再见`/`退出`、`选择 N` | 送对话状态机（选交互/翻页/结束） | 按当前状态消费（T03/T07/T09/T11/T13/T14） | L58 |
| **R2 带指令词正常解析** | `攻击1`、`使用1`、`背包2` | 带指令词 → 正常指令解析（不冲突） | 走对应指令系统（玩家对话中也能「使用1」吃药再「继续」，L70） | L59、L69–70 |
| **R3 会话优先于快捷** | 已绑定「快捷 1=攻击」，会话激活中发 `1` | 会话路由优先——选选项，**不触发攻击** | R1 送状态机 | L60 |
| **R4 快捷仅无会话生效** | 无对话会话时发 `1` | 跳过状态机纯数字匹配，走快捷表/其他指令 | 快捷表生效（如战斗选技能） | L61 |
| **R5 菜单底固定离开钮** | N = 选项数 + 1 | 菜单末尾**固定**「N. 离开」，与路由词严格一致 | R1 结束路径（T09） | L63 |

### 3.2 路由优先级总表（实现顺序）

```
对话会话激活中：
  ① 输入 ∈ {纯数字, 继续, 离开/再见/退出, 选择 N}  → 送对话状态机（R1，含会话优先 R3）
  ② 输入带指令词（攻击/使用/背包/查看/送礼/商店/…）→ 正常指令解析（R2）
  ③ 无会话上下文（未激活）                           → 快捷表/常规指令（R4）
```

> 路由判定的前置 = 是否「对话会话激活」。会话激活区间 = 建会话（T01/T02）→ 会话收尾（T15），与 `2.4 会话快照` 生命周期一致（L94–102）。【工程补白】「选择 N」中的 N 与纯数字 N 等价映射；`选择` 为前缀保留词，仅在会话激活时具语义（L46、L58）。

## 四、菜单 ≤6 选项折叠

> 约束对象 = **NPC 交互菜单**（S3 `MENU`，非 NPC 列表），对齐 3.0（L108–113）。

1. **上限 6**：交互菜单最多显示 6 个选项 + **固定「N. 离开」**（N = 选项数 + 1，L110、L63）。
2. **折叠**：超过 6 个 → 折叠为「7.更多…」二级菜单（L111）。
3. **条件提示一行**：条件不满足选项给一行提示「需要：等级 ≥10」，不展开长文本（L112、L121）。
4. **一次一物对齐**：信息类已交付置灰「已听」（我在表 1.2/T10 已接线）（L86–89）；功能类不置灰（L90）。
5. **长叙述分页**：叙述多段用 `继续` 翻页 + `page_index` 快照，与菜单折叠正交（L47、L101）。

【工程补白】NPC 列表（S1 `LIST`，L40–41）定稿未设 ≤6 上限，按消息行数自然换行；若行数超 QQ 单消息上限沿「上下页」翻动，复用 `page_index` 机制。交互菜单 ≤6 为硬上限（L110）。

## 五、无 NPC 地图提示

1. **玩家侧（运行时）**：无 NPC 地图 `/对话` → **「当前地图没有可对话的人」**，不建会话（留在 S0 `IDLE`，非列表态）（L50）。
2. **工具侧（编辑器/校验器）**：地图无 NPC → 黄提示「这个世界有点空？」（只建议不限制，不硬拦）（L447）。
3. **挂点一致性**：列表候选 = `maps.json npcs` 引用数组 ∩ `npc.map` 挂点且 `visible=true`（L360、L387、L427）；引用不存在由校验器硬拦（L446）。

## 七、状态机不变量（实现期强制约束）

1. **路由写死不可配**：R1–R5 优先级固定（L58–63）；结束后词统一 离开/再见/退出 三词同义（L62）。
2. **菜单末项 = N.离开 恒定**：N = 选项数 + 1，与路由结束词严格一致（L63），实现不得改动末项。
3. **名称禁空格约束贯穿**：解析层（1.2）、命名铁律（L49）、列表展示三层一致；`·`/`Ⅱ` 允许。
4. **单轮交付回菜单**：信息类交付后必须置灰「已听」并持久化落**玩家存档**（不落会话快照，30 天回收不丢标记）（L88）；功能类不置灰（L90）。
5. **中断不迁移状态**：只落快照；恢复 = 原状态重入（菜单层重显 L98 / 子界面简报 L99–100 / 长叙述 page 续 L101）。
6. **结束路径单点收尾**：统一走 S6 `END` →（T15）打 `[事件:NPC对话:ID]` + 清理快照 → S0（L289、L98）。
