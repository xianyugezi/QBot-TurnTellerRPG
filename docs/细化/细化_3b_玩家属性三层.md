### 0.2 一句话契约

> 玩家属性 = **三层（白值 → 加成 → 临时）写死管线**：`白值 + 加成flat → 基础合计 → ×(1+加成pct) → 加成后属性 → ×(1+临时pct) + 临时flat + 条件加成 → 最终属性`；
> 百分比**只乘一次**（加成 pct 只乘基础合计、临时 pct 只乘加成后属性，均不递归）；
> 条件加成**只按基础合计（白值+数值加成）触发**，自身永不进入任何后续乘算基准 → 防无限叠乘；
> stats.json 定义 9 项预置属性（注册制支持自定义键），派生属性统一按最终属性计算。

## 一、三层结构定义（白值 / 加成 / 临时）

> 【属性定稿】L141-146（§五 三层数据结构，用户核心设计）：
> ```
> 玩家属性 = 三层：
> ① 白值——永久（基础 + 职业成长）
> ② 加成层——非战斗也存在（装备永久 + 药剂有时效）
>    数值层 flat：固定值（+5 力量）
>    百分比层 pct：百分比（+10%）
> ③ 临时层——战斗 buff（战斗内，结束清除）
> ```
> （对应 L142 / L143-145 / L146）

### 1.1 各层来源与属性

| 层 | 名称 | 持久性 | 来源 | 形态 | 依据 |
|---|---|---|---|---|---|
| ① | 白值层 | **永久**（一次计算，常驻） | 基础 `base` + 职业成长 `growth×等级`（jobs.json 可配）+ 自由加点（加点 = 白值层）；换职业**不重算** | 固定值 | L142 / L173 / L179 / L174-178 |
| ② | 加成层·数值 flat | 非战斗也存在；装备**永久**、药剂**有时效**（到期自动移除重算） | 装备 `stats_bonus`（如 `{"ele_atk_fire": 8}`）；战斗外服用药剂；元素攻击力 `ele_atk_*`（白值 0）；元素抗性 `elem_res`（默认 0） | 固定值（+5 力量） | L143-145 / L116-117 / L132 / L161 |
| ② | 加成层·百分比 pct | 同上一行 | 装备百分比词条；战斗外服用百分比药剂；内容包注册的百分比来源 | 百分比（+10%） | L145 / L152 |
| ③ | 临时层 | **战斗内**，回合/战斗结束清除 | 战斗 buff（效果系统产出）；战斗内服用药剂（回合计时，入战斗快照，中断恢复）；超会心 Lv1-3 / crit_bonus 由效果系统在此层挂载 | 百分比为主（L155 公式），flat 扩展见 ADR-01 | L146 / L162-163 / L193 |

### 1.2 层优先级与覆盖规则

- **计算优先级（写死）**：白值 → 加成 flat → 加成 pct → 临时 pct → 临时 flat + 条件加成。后层永远基于前层已算出的值，**不允许跳层、不允许回写前层**（L151-155）。
- **相同优先级内聚合**：同层同属性多来源**求和**聚合（多件装备 flat 相加、多个 pct 相加后再乘），聚合后再进入下一层——这是\"百分比只乘一次\"的物理前提。
- **替换规则**：同类药剂不叠加，新覆盖旧（L164）；同层同槽位（装备）后装备覆盖先装备。
- **生命周期边界**：加成层药剂按**现实时间**计时，到期自动移除并重算（L161）；临时层按**回合**计时，回合结束 tick 扣减，战斗结束清除，快照只落回合边界（L162-163，对齐细化_1g3 快照规则）。

## 二、计算管线（写死顺序，防无限叠乘）

> 【属性定稿】L151-155（§五 计算模型）原文：
> ```
> ① 基础合计 = 白值 + 加成层数值（装备固定 + 药剂固定）
> ② 加成后属性 = 基础合计 × (1 + 加成层百分比)（装备% + 药剂%）
> ③ 条件加成 = 基于【基础合计】触发（每点力量+1智力——防循环）
> ④ 战斗临时 = 基于【加成后属性】计算（战斗 buff 吃到装备+药剂百分比）
> 最终属性 = 加成后属性 × (1 + 战斗临时%) + 条件加成
> ```
> （对应 L151 / L152 / L153 / L154 / L155）

### 2.1 管线五步（实现级伪代码）

```
def calc_final_attr(attr_id, base, flat_bonus, pct_bonus, temp_flat, temp_pct, cond_rule, lv, free_points):
    # 第 0 步：白值层（L142/L173）——永久
    white  = base + growth × (lv - 1) + free_points
    # 第 1 步：① 基础合计 = 白值 + 加成层数值（L151）
    base_total = white + flat_bonus                     # 元素攻击力白值=0 时即 0 + flat（L117）
    # 第 2 步：② 加成后属性 = 基础合计 × (1 + 加成层百分比)（L152）——百分比【只乘一次】，不乘自身
    boosted = base_total × (1 + pct_bonus / 100)
    # 第 3 步：④ 战斗临时 = 基于【加成后属性】计算（L154）
    temp_term = boosted × (1 + temp_pct / 100)
    # 第 4 步：③ 条件加成 + 临时 flat → 最终属性（L155 + ADR-01）
    final = temp_term + cond_rule(base_total) + temp_flat
    return floor(final)                                 # 出口唯一取整（ADR-04）
```

- **管线顺序写死、不可配**（定稿 L149「计算模型」+ L226「计算管线写死」）。
- **百分比只乘一次的两种含义**（强制约束，任何配置不得破坏）：
  1. 加成层 pct 的乘数 = **基础合计**（白值+flat）；pct 值本身、条件加成、临时值**都不进入该乘算**。
  2. 临时层 pct 的乘数 = **加成后属性**；临时自身结果、条件加成不再被任何 pct 乘。
- **禁止递归**：管线内任何节点产物不得重新作为自身公式的输入（前置因子只读取，不回写）；条件加成只读基础合计（L153）。
- **元素攻击力管线对齐**：`白值 0 → 加成 flat → ×(1+临时%)`（L117 原文），即元素攻击力以 flat 形态走完 ②→③ 两步，顶层 pct 关节照常生效。

### 2.2 药剂计时双轨（占用哪一层）

> 【属性定稿】L160-165：
> - 药剂定义在 items.json（带 duration）（L160）
> - 【战斗外服用】→ 加成层（现实时间计时，带到期时间，到期自动移除重算）（L161）
> - 【战斗内服用】→ 临时层（回合计时，战斗结束清除；回合结束 tick 扣减，入战斗快照中断恢复）（L162-163）
> - 同类药剂不叠加（新覆盖旧）（L164）；与 3.14 药剂冷却共用规则（L165）

| 使用场景 | 落层 | 计时 | 过期行为 | 依据 |
|---|---|---|---|---|
| 战斗外服用 | 加成层（flat 按值型 / pct 按百分比型） | 现实时间（挂到期时间戳） | 到期自动移除 + 全量重算 | L161 |
| 战斗内服用 | 临时层（pct 主形态；固定值见 ADR-01） | 回合制（回合结束 tick 扣减） | 战斗结束清除；快照记录以便中断恢复 | L162-163 |
| 同类药剂 | — | 覆盖（新覆盖旧），不叠加 | — | L164 |

## 三、条件加成（每点 X → Y · 触发基准 = 白值+数值 · 防无限叠乘）

> 【属性定稿】L153：`③ 条件加成 = 基于【基础合计】触发（每点力量+1智力——防循环）`
> 【属性定稿】L155：`最终属性 = 加成后属性 × (1 + 战斗临时%) + 条件加成`

### 3.1 定义与触发基准

- **形态**：条件规则 = `每点 X → Y`（如每点力量 +1 智力）。产出为 flat 数值，最终阶段一次性平加（L155 末项）。
- **触发基准（写死）**：只读**基础合计** = 白值 + 加成层数值 flat（L151 + L153）。**百分比层（加成 pct）、临时层、其他条件加成自身均不计入基准**。
- **防无限叠乘机制（三重锁）**：
  1. **基准锁**：基准固定为基础合计，条件加成的产出不会改变基准；
  2. **自引用锁**：条件规则禁止以自身产出为输入的循环定义（X 与 Y 不能互相以对方为条件构成环），注册校验时做依赖图检测（见 TC-05）；
  3. **终值锁**：条件加成在管线**最后一步**以纯加法进入最终属性（L155），之后不再进入任何乘算节点。

### 3.2 规则配置（join.json / 属性联动配置 · 字段级）

```json
{
  "conditional": [
    { "id": "cond_str_int", "source": "str", "target": "int", "per_point": 1, "note": "每点力量+1智力（L153 示例语义）" }
  ]
}
```

| 字段 | 类型 | 说明 | 可配 | 依据 |
|---|---|---|---|---|
| `id` | string | 规则唯一 ID | 是 | 注册表约束（L225） |
| `source` | string | 触发属性 X（基准取该属性的基础合计） | 是 | L153 |
| `target` | string | 产出属性 Y（flat 加算到最终属性） | 是 | L153 |
| `per_point` | number | 每点 X 产出 Y 的量 | 是 | L153 |
| `note` | string | 说明（可选） | 是 | L209 模板风格 |

- 校验器：source/target 必须 ∈ 属性注册表（L225）；**source==target（自环）→ 红色拦截**（防无限叠乘首要原则，L153 原文「每点力量+1智力——防循环」；3b §3.2 与 TC-05 口径冲突已按 2026-08-18 仲裁 C-1 统一为红拦）；依赖图环（A→B→A）→ **红色拦截拒绝加载**（ADR-05 + L225 引用存在性校验）。
- 【2026-08-18 仲裁 C-1】source==target：原写「黄提示（自身增益合法）」与 TC-05「自环红拦」矛盾；对照定稿 L153「防循环」意图裁**红拦**（规约=自引用即失稳源，一律拒绝）。

### 4.1 键空间（stats.json 顶层）

```
stats.json
├── <attr_id>              # 顶层键 = 属性 ID（九预置 + 自定义注册键）
│   ├── name / type / base / growth / role     # 必填（L203-211）
│   ├── mh_map / note                          # 可选（L203-211）
└── （无其他顶层字段——每键即一属性定义）
```

- **九预置键**（写死默认模板，可改数值不可删九项本身？——不：九项为默认模板，内容包可整体替换注册表，见 L225「9 项为默认模板；自定义属性注册制」；但预置九项的角色语义 role 由定稿绑定，替换需内容包显式声明）。
- **自定义键**：新增属性 ID 必须注册（ADR-05），供内容包扩展（L115）。

## 五、会心 / 命中 / 格挡等派生属性计算

> 派生属性统一以**最终属性**为输入（ADR-03，与 L41「√最终幸运」口径对齐）；派生属性为只读计算、不进入三层管线、永不回写属性层。

### 5.1 会心体系（§二 会心体系，用户拍板 A+B 结合）

**会心率（频率）** — 【属性定稿】L41-45：
```
会心率 = min(95%, √最终幸运 × 0.5% + crit_bonus)
- √幸运×0.5%：属性驱动基础（借绮谭必杀率口径）
- crit_bonus：装备/技能/效果提供的会心加成（怪猎原味）
- 双通道共用一次会心判定（物理+元素同判，L44）
- cap 默认 95%，可配 0=不限（L222）
```

**会心倍率（质量）** — 【属性定稿】L52-58：
```
P = √最终幸运 ÷ 2
随机数 r = 1~100
r ≤ P     → 高级会心：2.2 + 0.05×超会心等级
r ≤ P×3   → 中级会心：1.7 + 0.05×超会心等级
r > P×3   → 低级会心：1.3 + 0.05×超会心等级
超会心 Lv1-3：三档各 +0.05×等级（效果系统 crit_mult_up 提供）
```
- 判定执行顺序：先判高级（r ≤ P），再判中级（r ≤ 3P），其余低级——严格按此顺序，避免区间重叠歧义（L55-57 原文区间嵌套）。
- 倍率矩阵（L62-66）：基础 1.3/1.7/2.2；超会心 Lv1 1.35/1.75/2.25；Lv2 1.4/1.8/2.3；Lv3 1.45/1.85/2.35。
- 示例校验（L69）：幸运 100 → P=5 → 高级 5% / 中级 10% / 低级 85%。
- 负会心 ×0.75：可选，怪物配置（L70）。
- 幸运职责总成（L75）：会心率 + 会心三级 + 概率修正（强化成功率/异常赋予/特效触发，√体系；L188 √我方−√对方、L189 √幸运）。

### 5.2 命中率 — 【属性定稿】L85-90

```
命中率 = clamp(最终专注 / (最终专注 + K × 最终对方敏捷), 10%, 95%)
```
| 边界 | 规则 | 依据 |
|---|---|---|
| K | 可配，默认 1 | L86 |
| 对方敏捷 = 0 | → 100% 命中 | L86 |
| 双方都 0 | → 100% 命中（0/0 兜底） | L88 |
| 怪物敏捷缺省 | 按等级换算兜底 | L89 |
| 战斗提示 | 显示当前命中率（\"命中率 72%\"） | L90 |

> 注：L86「对方敏捷 0 → 100%」先于 clamp 判定；仅当分母 > 0 时进入 clamp(10%, 95%)。

### 5.3 格挡率 — 【属性定稿】L95-100

```
格挡率 = min(40%, 最终专注 / (最终专注 + 150))
- 格挡 = 会心后最终伤害减半（与 /防御 指令乘算，L96）
- 判定串行：命中 → 会心 → 格挡（L100）
- 格挡减半特色（L97-99）：
  · 每次触发格挡后，当回合格挡率减半，下回合恢复
  · 1v1 一轮单次攻击：触发格挡后本回合无二段攻击，减半规则不消费
  · 组队/多段攻击场景减半规则生效（防无限格挡坦克，L99 预留）
- 快照记录当回合格挡状态（L223）
```

### 5.4 减伤与其余派生

| 派生项 | 公式 | 输入口径 | 依据 |
|---|---|---|---|
| 物理减伤 | 最终体质 / (最终体质 + K)，K=100 可配（无悬崖无封顶） | 双轨防御侧 | L20 / L31-32 |
| 魔法减伤 | 最终精神 同构除算 | 双轨防御侧 | L21 / L31 |
| 元素减伤率 | elem_res / (elem_res + 100)（elem_res 来自装备词条，最终加成层 flat 口径） | 加成层 | L131-132 |
| 闪避（敌方命中公式输入） | 对方敏捷置入命中率分母（§5.2） | 最终敏捷 | L23 / L85 |
| 逃跑成功率 | 最终敏捷 / (最终敏捷 + 敌敏捷) | 最终敏捷 | L190 |
| 元素攻击力 | 装备 ele_atk_*（flat）→ 元素通道：floor(装备元素攻击 × 元素动作倍率 × 会心 × 元素弱点 × 元素减伤) | 加成层 flat | L116-117 / L123 |
| 双通道合计 | 总伤害 = floor(物理通道) + floor(元素通道)（独立取整后相加） | —— | L124 |

### 5.5 判定顺序（写死，不可配）

> 【属性定稿】L105：`命中 → 会心 → 格挡 → 双通道伤害（各自取整后相加）→ 防御率 → 伤害拦截链 → 扣血`
> 对齐《细化_1a_伤害公式数值》§0.1（同一原文）。

## 六、验收测试用例（TC-01 ~ TC-18）

### 6.1 三层叠加与管线顺序

| 编号 | 用例 | 输入（层） | 期望断言 | 覆盖定稿行 |
|---|---|---|---|---|
| TC-01 | 三层完整叠加 | 白 15 + flat 5 + pct 10% + 临时 pct 20% | 基础合计=20；加成后=20×1.10=22；最终=22×1.20=26.4 → floor 26（无临时 flat/条件时） | L151-155 / ADR-04 |

| TC-03 | 临时 pct 基于加成后属性（吃到装备+药剂百分比） | 白 15 + flat 5 + pct 10% + 临时 pct 20% + 临时 flat 3 | 加成后 22 → 22×1.2=26.4 + 3 = 29.4 → floor 29（临时 flat 生效，ADR-01） | L154 / L155 / ADR-01 |
| TC-04 | 加成 pct 不改变条件触发的基准 | 白 15 + pct 100%（加成后=30）+ 每点 str→int+1 | 条件基准=基础合计 15（非 30）：条件产出 int +15；最终 int=30+15=45；**不得** 按 30 触发 | L153 / L155 |
| TC-05 | 条件加成自引用/循环依赖拒绝 | 配置 A→B 且 B→A（或 X→X 自环） | 依赖图检测 → 红色拦截，该内容包不加载 | L153 / L225 / ADR-05 / §3.2 |
| TC-06 | 白值=基础+成长+加点；换职业保留 | lv=50，str 白值=15+1.5×49=88.5（base 15 / growth 1.5，定稿 L205；成长按 ×(lv−1)，见 §2.1）+ 加点 10 | str 白值=98.5；换职业后白值不变（加点/成长不重算） | L142 / L173 / L179 / L205 |

|---|---|---|---|---|
