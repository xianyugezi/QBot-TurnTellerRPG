## 一、投料机制（链式投料 FEED · 一键投料 AUTO · 单批量 BATCH）

> 依据：【炼金】§4.2 L131-143（流程示例）、§4.3#5 L153（链式投料/连锁段数）、#7 L155（一键投料）、#8 L156（单件/批量）、§2.3 L81（见习解锁投料/品质/一键投料/单批量）、§4.4 L162（反馈附特性清单）、L163（悬念分级）、§4.6 L175/L179（无会话模板/确认全量复核）、§5.2#20 L218（全物入料）、§九 L322、【分隔符】L29-44 / L46-51 / L65-74

### 1.1 链式投料（FEED）

- **【FEED-01 参数解析】** `/投料 <材料1>,<材料2>,… [追加]`：位置参数 1 = 材料列表（`,` 分隔，全角/半角等价、不空格，L12 + 【分隔符】L17/L39-44）；单项可带数量 `材料*N`（【分隔符】L32）；位置参数 2 = 固定子词 `追加`（/投料 追加 龙牙，L139 + 【分隔符】L71）；解析顺序固定：先按 `,` 拆列表 → 再按 `*` 拆数量 → 再按 `=` 拆键值（【分隔符】L69）。
- **【FEED-02 会话前置】** 调合会话中（含深度会话，L322）；无会话 → 「当前没有调合会话，先 /炼金 <配方> 开始」（L175）。
- **【FEED-03 战斗拦截】** 战斗中收到 /投料 → 「战斗中使用 /即时调合 <配方>（不进入调合会话）」（L295）。
- **【FEED-04 槽位上限】** 投料不超配方槽位（错误模板「投料超槽位」L344；深度层 6 槽/核心槽示例 L235）。
- **【FEED-05 材料持有】** 所投材料在背包且数量足够（逐项校验；数量不足全拒并提示差异，对齐原子口径 L115）。
- **【FEED-06 连锁段数】** 段数 = 相邻同属性对数（连续 n 个 = n-1 段）；同属性判定 = 材料**当前**属性（触媒改变后按新属性，L153）；段数 → 效果等级映射 `chain_map`（1 段=1 级…6 段=6 级，可配，L153/L413）。
- **【FEED-07 属性刻度】** 累计材料属性对照 `element_req` 阈值（L152）；未达标 = 品质降级（差一档降一档，最低普通，绝不吞材料，L152/L167）；悬念分级：第 2 层引导语（"火系还差一点…"）、大师级显示精确阈值（"火 42/45"，L163）。
- **【FEED-08 反馈】** 投料反馈附可继承特性清单（L162）；稀有金色素材 → 金色超特性候选（第 4 位独占，L201）；✨觉醒素材 → 隐藏效果候选（L204）；连锁 ≥3 段触发连锁奖励候选（L199）。
- **【FEED-09 全物入料】** 专家级起：成品/装备可入料（L218）；入料物品按 items.json 元素/特性/品质折算材料属性。
- **【FEED-10 确认全量复核】** /确认 时全量校验材料（含追加链）仍在背包，不足拒绝并提示差异（L179）——防过期快照。

### 1.2 一键投料（AUTO）

- **【AUTO-01 触发】** `/炼金 <配方> 自动`：位置参数 2 = 固定子词 `自动`（L155 + 【分隔符】L48/L71）；自动 = 一键投料。
- **【AUTO-02 自动配平】** 机器人按配方 materials 清单 + 背包持有自动配平入料（小白兜底，L155）：优先匹配 `element_req` 达标组合，其次按配方基础材料；配平结果照常进入连锁/刻度/特性候选计算（复用 FEED-06/07/08）。
- **【AUTO-03 配平失败原子拒绝】** 背包无法配平任一材料 → 全拒并提示差异（缺 水结晶×5 + 金币 30 同款口径，L115）；不部分入料。

### 1.3 单批量（BATCH）

> 定稿仅对比两种模式（L156「逐项调合（继承特性）vs 批量（平均品质、丢特性）」），未给批量流程细节——以下为实现层细化（括号标注）。

- **【BATCH-01 触发与语法】** `/炼金 <配方>*<N>`：数量 `*` 即"数量开关"（【分隔符】L29-37/L36）；N=1 默认逐项调合（交互会话、继承特性，L156）；N≥2 = 单批量调合（一步出结果、无投料/继承/确认链，L156）。（实现层细化：定稿未给批量触发语法，取数量 `*` 对齐【分隔符】L32 同款语法。）
- **【BATCH-02 品质与特性】** 批量产出 = 平均品质、丢特性（L156）：品质取材料品质均值入档（items.json 四档，L150/L411）；无特性/无连锁奖励/无刻度效果；熟练经验按每个成品 = 配方等级 ×1（L116/L420）。（实现层细化：批量逐份结算品质均值。）
- **【BATCH-03 能量按次】** 批量 N 次 = 扣调合能量 N 格（每次炼金消耗 1 格，L93）；指令执行时一次性原子扣减（不足全拒，见 BATCH-05）。
- **【BATCH-04 数量上限（拍板⑤）】** 数量上限默认 **2147483647（int32 max）**、可配（覆盖【分隔符】L33 的 ≤99 默认）；超限提示「最多一次使用 N 个」（N=配置上限）不拦截，仅提示（对齐【分隔符】L73 只提示不拦截口径）。
- **【BATCH-05 原子性】** 材料 ×N + 能量 N 格 + 金币全量满足才执行，否则全拒并提示差异（对齐原子口径 L115）；单事务提交，任一步失败 ROLLBACK 零副作用（对齐 2c4d ATO-02）。

## 二、触媒机制（CAT）

> 依据：【炼金】§4.3#6 L154（同材料+不同触媒=不同方向/注册制）、§2.3 L84（专家解锁触媒）、§4.2 L136（触媒=爆裂壶 指定）、§4.4 L164（触媒=决定方向的调料）、§4.6 L179（确认全量复核）、§10.1 L356（recipe.json catalyst[]）、§10.3 L380（items type）、§13 L492/L494（编辑器触媒下拉/存在性校验）、§九 L344（触媒无效模板）、【分隔符】L49（键值 `=`）

- **【CAT-01 解锁等级（已按细化_0 R-07 定案）】** 定稿两处口径不一：§2.3 每级解锁明细表「专家 | …；触媒；…」（L84）vs §4.3#6「（精通解锁）」（L154）。**已按细化_0 R-07 采纳 = 专家**（第 5 级：L84 为解锁专项表，权威性高于行内提及，保守解锁防过早开放复杂机制）；落点 `settings alchemy.catalyst_unlock_tier: "expert"`（默认 expert，可配）。未达门槛 → 错误模板「等级不足」（L344）。
- **【CAT-02 作用】** 同材料 + 不同触媒 = 不同方向（L154）：触媒改变材料属性判定（连锁同属性判定按触媒改变后的新属性，L153）与成品效果方向（术语人话化：触媒 = 决定方向的调料，L164）。
- **【CAT-03 注册制】** 触媒注册制：未注册的触媒 → 仅提示（不阻断，L154）；指定语法 `/炼金 <配方> 触媒=<触媒名>`（键值 `=`，L136/L12 + 【分隔符】L49）。
- **【CAT-04 消耗（实现层默认，可配）】** 定稿未明示触媒是否消耗（仅定义指定方式 L136 与类型 L356）——**实现默认：每次调合确认结算消耗触媒 1 个**（与材料同事务扣减，纳入 /确认 全量复核 L179）；落点 `settings alchemy.catalyst_consume: true`（可配 false = 触媒不消耗仅作方向修饰）。
- **【CAT-05 类型与校验】** 触媒必须是 items.json `type=触媒` 的物品（L356/L380）；指定非触媒类型物品 → 「触媒无效」（L344）；编辑器配置页触媒下拉按 `type=触媒` 过滤（L492）+ 校验器触媒存在性（L494）。
- **【CAT-06 面板展示（实现层细化）】** 定稿面板示例（L134-135）不含触媒项、未定义面板触媒项展示——**若实现展示触媒项，属实现层细化（证据缺口：定稿未定义）**；触媒指定走语法 `触媒=<触媒名>`（键值 `=`，L136，2/3 层通用）。

## 三、调合能量条（ENG）

> 依据：【炼金】§2.4 L91-98（A8 软节奏）、§2.3 L81（见习解锁）、§九 L321/L325/L336（/炼金 /深度炼金 /即时调合 门槛=能量）、§九 L344（能量不足模板）、§10.5 L400（能量条当前值入存档）、§10.6 L416（energy_max 表）/ L417（energy_regen_sec）/ L410（mode simple 无能量条）、【规划】L156/L286/L560（可选默认关）、【总纲】L56（默认关口径）

- **【ENG-01 默认关（开关口径）】** 能量条 = 可选模块，**默认关**（【规划】L286「能量条（可选默认关）」/ L560「能量条（默认关）」；【总纲】L56「默认不干预，作者显式开启」）。落点：`settings alchemy.energy_enabled: false`（默认）；内容包显式开启后 §2.4 全部规则生效。关闭时：/炼金 /深度炼金 /即时调合 不扣能量、不显示能量上限、无「能量不足」模板（不干预炼金节奏）。`mode: "simple"`（仅合成层）本就无炼金层/能量条（L410）。
- **【ENG-02 解锁】** 见习解锁能量条（L81）；上限随职业等级（L94）。
- **【ENG-03 上限】** `energy_max: {见习:5, 正式:8, 精通:10, 专家:12, 大师:15, 宗师:18, 王:20}`（L416，可配）；显示格式「能量 0/10」（L344 模板同款）。
- **【ENG-04 每炼金消耗 1 格】** 每次炼金/深度炼金消耗 1 格（L93）：/炼金 开会话扣 1 格（对齐 2c4d F-02 同口径）；/深度炼金 扣 1 格（L93/L325）；批量 N 次扣 N 格（BATCH-03）；即时调合扣 1 格（L283/L336，结算时扣）；能量不足 → 拒绝并提示「能量 0/10，等 30 分钟回 1 格，或 /合成 保底」（L344）。
- **【ENG-05 恢复 30 分钟 1 格】** 每 30 分钟回 1 格（现实时间，碎片化友好，L95）；`energy_regen_sec: 1800`（L417，可配）；实现采用**懒计算**：存档 `energy_last_regen_ts`，查询/消耗时按 `(now - last_regen_ts) / energy_regen_sec` 补格、上限封顶（对齐【规划】L265 三周期懒计算同款口径；能量条当前值+时间戳入存档 L400）。
- **【ENG-06 安全区加速（实现层细化）】** 定稿仅要求「休整/安全区可加速」（L95）未给数值——**实现默认：安全区/休整状态恢复间隔减半（2 倍速）**，落点新增字段 `energy_regen_sec_safe: 900`（可配）；判定：玩家当前所在场景为安全区（城镇/休整态，场景配置标记）时按 safe 间隔补格，离开后恢复 1800 基准。
- **【ENG-07 合成豁免】** 合成不消耗能量（L97）——保底通道永可用；/合成 指令不检查能量（L320 门槛=生活职业达标+synth_allowed，无能量）。
- **【ENG-08 保底与定位】** 能量空 = 软节奏控制（防无限刷），不卡死体验（L96）：能量 0 时 /合成 仍可用（L97/L344 模板末句「或 /合成 保底」）；消息频率控制 + 能量条软限流（L506）。
- **【ENG-09 存档】** 能量条当前值（+last_regen_ts）入玩家存档（L400）；与熟练度/图鉴/SP 点同层（L399-400）；热重载不丢（对齐 L509 旧快照结算口径）。
- **【ENG-10 门槛挂载】** /炼金（L321）、/深度炼金（L325）、/即时调合（L336）三个指令在 `energy_enabled=true` 时统一走能量前置守卫（ENG-04），关闭时守卫直通。

## 四、即时调合（战斗内子流程，INST）

> 依据：【炼金】v2.3 D1 L8、§5.2#18 L216（大师解锁/素材+能量/限 1 次/场/吃冷却/会话互斥=战斗内子流程）、§七 L279-300（写死：L293 战斗内子流程 / L294 3.18 衔接 / L295 战斗内调合指令拦截 / L296-298 产出处理 auto_use / L299 限次落点 battle_alchemy_used / L300 settings）、§九 L336（/即时调合 指令行）、§10.5 L398（battle_alchemy_used 入战斗快照）、§10.6 L423（settings 战斗即时调合）、L510（战斗失衡对策）

- **【INST-01 战斗内子流程（写死）】** /即时调合 <配方> 在战斗会话内执行：不产生独立调合会话、不进入 §4.6 状态机、战斗不挂起；借用战斗会话上下文，一步出结果（无 投料/继承/确认 链）（L8/L293）；消息一行渲染「🔥 火焰弹！造成 58 伤害」（L287）。
- **【INST-02 豁免互斥（写死）】** 战斗会话已占用唯一会话槽，即时调合**不申请新会话槽、不触发** §4.6「单玩家同一时间只允许 1 个调合会话」互斥判定（该互斥只约束战斗外调合，L294）；§4.6 状态机「挂起(战斗)」仅用于战斗外调合被战斗打断，与即时调合无关（L294）。
- **【INST-03 限 1 次/场（写死落点）】** 计数存战斗快照（3.18/A.5）独立字段 `battle_alchemy_used`（与 ai_state/combo_state 同层，L299/L398）；中断恢复**不清零**（对齐 potion_use_counts 口径，L299）；「按场计」= 战斗会话生命周期，战斗结束清零（L299）；第 2 次 → 拒绝（per_battle_limit=1，L423）。
- **【INST-04 产出处理（可配，默认自动使用）】** `auto_use: true`（默认）：当场自动使用——消耗品效果立即结算（伤害/回血等，L297）；`auto_use: false`：产出入背包（战斗结束后可用，本场不可再用该产出，L298）；settings 落点 `战斗即时调合: {auto_use: true, per_battle_limit: 1}`（L300/L423）。
- **【INST-05 门槛与消耗】** 大师解锁（L216/L336）；消耗携带素材 + 能量 1 格（L283/L216；能量扣减同 ENG-04）；吃冷却（L283：炸弹 3 回合冷却同款，L282）；素材/能量不足 → 拒绝并提示差异（L115 原子口径）。
- **【INST-06 战斗中调合指令拦截】** 战斗中收到 /投料 /继承 /确认 等调合会话指令 → 「战斗中使用 /即时调合 <配方>（不进入调合会话）」（L295）——覆盖 FEED-03 / 2c4d MUT-04 同款。
