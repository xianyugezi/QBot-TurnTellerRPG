## 任务 1：7 级职业等级门槛（见习→王）与炼金层解锁关系

- 【任务名】7 级职业等级门槛与炼金层解锁关系
- 【定稿章节】§1.1 三层漏斗结构；§2.1 等级与熟练度；§2.3 每级解锁机制明细表；§2.4 调合能量条；§9 指令总表（门槛列）；§10.6 settings alchemy 段（energy_max / job_tier_map）
- 【实现要点】
  - 等级链：见习 → 正式 → 精通 → 专家 → 大师 → 宗师 → 王；职业等级与角色等级完全独立（§2.1）。
  - settings.json 落 `job_tier_map`：称号→配方等级区间 = 见习 1-5 / 正式 6-10 / 精通 11-20 / 专家 21-30 / 大师 31-40 / 宗师 41-50 / 王 51+（§2.1）。
  - 逐级解锁（§2.3 明细表，逐条对齐）：
    - 见习：合成可用；炼金层基础（投料/品质/一键投料/单批量）；调合能量条解锁。
    - 正式：特性继承 1 项；配方发想；种植解锁。
    - 精通：特性继承 2 项；属性刻度效果显现；代工助手解锁。
    - 专家：特性继承 3 项；触媒；配方合成；委托任务板高级委托。
    - 大师：⭐ 深度炼金 = 连锁奖励 + 核心镶嵌 + 分解回炉 + 量贩复制 + 图鉴成长 + 战斗即时调合。
    - 宗师：配方进化线 + 金色超特性 + 成品合成 + 觉醒 + 潜力 + 加成道具 + 特性合成。
    - 王：终极称号（炼金王）— 条件 = 该职业图鉴全点亮；奖励 = 专属配方 + 称号加成（全属性+X% 可配）+ 群内称号展示；品评会冠军专属；不唯一、按职业独立授予（§2.3 注）。
  - 能量条软门槛（§2.4）：每次炼金/深度炼金消耗 1 格；上限随等级 `energy_max = {见习:5, 正式:8, 精通:10, 专家:12, 大师:15, 宗师:18, 王:20}`（可配）；每 30 分钟回 1 格；合成不耗能量（保底通道永可用）。
  - 指令门槛（§9）：/炼金 = 炼金职业+能量；/深度炼金 = 大师+能量；/进化 = 宗师+炼金产出 N 次；/镶核心 /加成 = 大师/宗师；/成品合成 /特性合成 = 宗师+宝石；/配方合成 = 专家+宝石；/即时调合 = 大师+能量（限 1 次/场）。
  - 解锁反馈（§5.1/§十二）：升大师公告 + 深度炼金 6 新机制一句话预览；新机制首次触发逐条教学（/教学 回看）。
  - 错误模板（§9 注）：等级不足 / 深度未解锁 / 能量不足（"能量 0/10，等 30 分钟回 1 格，或 /合成 保底"）。
- 【验收标准】
  1. 7 级等级链与 §2.3 解锁明细逐条一致，大师前访问任何深度机制均被拒并提示"深度未解锁"。
  2. job_tier_map 配方区间、energy_max 数值与 §10.6 默认值一致，且全部可配。
  3. 王称号按职业独立授予、可多职业并存、条件=图鉴全点亮，非全图鉴不可获得。
  4. 能量空时 /炼金 拒绝且提示能量模板，/合成 始终可用。
  5. 升大师触发解锁公告，新机制首次触发出教学提示。

## 任务 2：SP 面板自选解锁（消耗 SP 点解锁配方/机制）

- 【任务名】SP 技能面板自选解锁
- 【定稿章节】§2.2 SP 技能面板（A4 技能树，v2.2 新增）；§10.6 settings（sp_per_level: 1）；§9 指令总表（/技能面板）；§10.5 存档（SP 点）
- 【实现要点】
  - 每升 1 级职业等级 → 获得 1 点 SP，可累积（§2.2；数值落 settings `sp_per_level: 1` 可配）。
  - /技能面板 查看：分支自选解锁——"等级到了自己选"，不是等级自动给（§2.2 核心语义）。
  - 解锁项（内容包可配，§2.2 列表）：
    - 品质上限 +10（可多次）
    - 投入次数 +1（可多次）
    - 特性位 +1（默认上限 3 普通，可配 1-6）
    - 解锁 复制 / 进化 / 挑战（作为等级硬门槛的替代或前置）
    - 采集量 +1
    - 连锁上限 +1
  - 与等级门槛的关系：SP 项只替代/前置「复制/进化/挑战」三类机制门槛；其余机制仍按 §2.3 等级硬门槛解锁（不冲突、不覆盖）。
  - 存档：SP 点数入存档（§10.5）；换包时复用框架 3.7 同 ID 保留/红名/一键清除规则。
  - 配置缺省兜底：内容包未配解锁项时，使用 §2.2 默认项与默认值。
- 【验收标准】
  1. 每升 1 级职业等级 SP +1 且可跨级累积，不升级不增加。
  2. /技能面板 展示全部分支、当前 SP、已解锁项及多次项次数。
  3. 未消耗 SP 时任何自选分支不自动生效（验证"不是等级自动给"）。
  4. 品质上限 +10、投入次数 +1 等多次项按次数叠加生效；特性位受默认上限 3（可配 1-6）封顶。
  5. SP 消耗与解锁状态持久化，换包同 ID 保留；配置缺省走默认值。

## 任务 3：proficiency.json 承载（等级名/曲线/SP）

- 【任务名】proficiency.json 承载职业等级（等级名/成长曲线/SP 联动）
- 【定稿章节】§2.1 等级与熟练度（承载定义）；§2.3 注（王级称号按职业命名）；§10.5 存档（熟练度 proficiency 按职业）；§10.6 settings（synth_exp / sp_per_level / energy_max）
- 【实现要点】
  - 框架新增 `proficiency.json`（§2.1 承载）：7 级默认名（见习/正式/精通/专家/大师/宗师/王）+ 内容包可改名 + 每职业熟练值 + 成长曲线。
  - 王级称号按职业命名可配（§2.3 注 / §2.1 示意）：炼金王/铸造王/钓鱼王/收集王…，默认名兜底。
  - 每职业熟练值：按职业独立存储（§10.5 "熟练度：proficiency 按职业"）；职业等级与角色等级独立（§2.1）。
  - 熟练经验来源（§2.1）：制作（合成/炼金/锻造）+ 采集 + 战斗；合成经验 = 配方等级 ×1（§3.2，settings `synth_exp` 可配）。
  - 成长曲线：每级所需熟练值由 proficiency.json 定义、内容包可改；等级升迁结果联动 job_tier_map（§2.1）与 SP 发放（§2.2 sp_per_level）。
  - 与 §10.6 的关系：proficiency.json 管「等级名/熟练值/曲线」，settings alchemy 段管「区间映射/SP 发放/能量上限」数值，二者不重复定义、互相引用。
- 【验收标准】
  1. proficiency.json 含 7 级默认名、每职业熟练值、成长曲线三项字段，缺省即可跑通完整 7 级。
  2. 内容包可改名（含王级按职业命名），改名缺失时回退默认名。
  3. 熟练值按职业独立累计，制作/采集/战斗三类来源均计入；合成按 配方等级×1 计。
  4. 升级时正确联动：job_tier_map 区间生效 + SP +1（settings sp_per_level）+ 能量上限按 energy_max 提升。
  5. 存档按职业读写熟练度，与角色等级互不影响。

## 任务 4：与其他制造职业共享熟练度体系

- 【任务名】跨制造职业共享熟练度与合成层门槛
- 【定稿章节】§1.1 三层漏斗（合成解锁：任一制造职业/资源技能达到配方等级）；§2.1 每职业熟练值（共享承载）；§3.1 合成解锁（任一制造职业或资源技能达标即可合成；例：钓鱼大师 → 可合成大师级普通配方，深度配方不可）；§10.1 recipe.json（synth_allowed / master_only）；§8 与锻造/强化分工（forge.json 占位 P1）
- 【实现要点】
  - 同一 proficiency.json 承载全部制造职业（炼金/锻造/钓鱼等）与资源技能的熟练度：等级名/曲线共用一份，熟练值按职业分列（§2.1 每职业熟练值）。
  - 合成层跨职业门槛（§3.1）：任一制造职业或资源技能等级 ≥ 配方等级 → 可合成该等级配方；不要求是炼金本身。
  - 深度层防绕过（§1.3/§3.1/§10.1）：`synth_allowed` 控制配方可否被合成（深度层默认 false）；`master_only: true` 的深度配方不因其他职业等级达标而可合成；若开启合成仅提示"此深度配方可被合成，将绕过深度炼金玩法"。
  - 王称号跨职业并存（§2.3 注）：各职业图鉴独立点亮、独立授予（炼金王/铸造王/钓鱼王…），互不冲突。
  - 与锻造分工（§8）：锻造 = 装备本体（forge.json，框架补占位 P1），复用同套职业等级与熟练度规则；强化（enhance.json）不占职业等级。
  - 经验来源共享（§2.1）：制作（合成/炼金/锻造）+ 采集 + 战斗对各自所属职业熟练度计值。
- 【验收标准】
  1. 所有制造职业读取同一 proficiency.json，熟练值按职业独立累计、互不覆盖。
  2. 钓鱼大师（或任一制造职业/资源技能大师）可合成大师级普通配方（synth_allowed=true）。
  3. master_only 深度配方对非炼金职业不可合成，且合成仅提示不绕过（或按配置拒绝）。
  4. 炼金/锻造/钓鱼可同时持有王称号（各自图鉴全点亮），等级互不影响。
  5. 合成产出熟练值正确计入来源职业的熟练度（配方等级×1）。
