# veinborn 装备体系规划 v2（拆分版：武器独立 / 防具套装 5 件核心 / 饰玉选配）

> 2026-09-05 ｜ 依据：数值模型 v2（上拉版锚点）+ 区域风味设计（怪名定稿）+ 用户拍板 v1 审阅意见 6-9
> v2 变更：① 武器系统单独规划（职业扩充预留）② 防具套 = 5 核心件（头身手脚足）③ 饰品/脉玉按怪风味选配 ④ 蚀晶/渊脉=润滑定位（比同级强比下档弱）

## 一、系统拆分

| 系统 | 内容 | 说明 |
|---|---|---|
| **武器系统** | 打造系武器 + 王骸武器 + 商店武器 + 新手武器 | 独立，后续按职业扩充形态 |
| **防具系统** | 各套核心 5 件（头/身/手/腿/足） | 新手/商店/基础/王骸/进阶散件 |
| **饰玉系统** | 饰品 + 脉玉 | 额外提升，按怪风味选配（可有可无） |

## 六、数值原则
- 同档基准：打造系 = 100%，王骸 = ~105-110%，商店 = ~80%，进阶散件 = 同级 95%~下档 110%（润滑）
- 系别差异走词条不走数值碾压（±10% 内）
- 防具 dfn 按 5 槽占比拆分；hp/词条按怪风味附加
