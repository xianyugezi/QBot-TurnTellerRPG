3. 合入 worktree 表（python 脚本；indent=2、ensure_ascii=False；只加你的 key）。
4. 从 alchemy_tpl.py 删除这 30 键（DEFAULT_TEMPLATES + PLACEHOLDER_WHITELIST）；死键复核后清除并记录。
5. 自校验：`-m python scripts/check_template_width.py`（0 FAIL）；`-m pytest tests/unit/test_template_table.py tests/unit/test_emoji_discipline.py -q`。
6. 修测试：本模块测试文件 + 全仓 grep 旧文案断言（含 scripts/ 内嵌冒烟）；`content/test_demo/templates.json` 最小同步（值有差异者）。
7. 硬编码扫描：本模块玩家可见中文字面量（除已迁移键）→ 报告清单（迁表 or 豁免+理由）。
8. 全量 tests/unit 一次 → 提交 → 按 §6 报告。
