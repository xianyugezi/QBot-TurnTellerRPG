# 指令分隔符统一规范 v1.1（全系统公共规范）

> 版本：v1.1 · 2026-08-15
> v1.1 变更：快捷指令模式（6.1-6.5）/ 快捷指令绑定（6.6）/ 指令别名 keep_original（6.7）/ 解析顺序含别名层
> 适用范围：RPG 框架全部指令（冒险/战斗/成长/制造/生活/会话式/GM/内容包自定义）
> 一句话：**空格分参数，`*` 连数量，`,` 列列表，`=` 键值，`+` 标等级，`-` 表连招，`>` 指路径**
> 用户拍板：不要什么都用空格，长指令漏了哪个参数都不清楚；数量用 `*`（使用1*10 / 使用经验药水*10）

---

## 一、分隔符总表

| 符号 | 名称 | 职责 | 示例 | 禁止用法 |
|---|---|---|---|---|
| 空格 | 参数分隔符 | 分隔指令名与参数、参数与参数（唯一） | /攻击 2 · /镶嵌 火珠 铁剑 | 不用空格表达数量 |
| `*` | 数量连接符 | 物品/材料/目标 与 份数 绑成一个参数 | /使用 经验药水*10 · /购买 药水*5 | 不用于分隔参数 |
| `,` | 列表分隔符 | 材料/特性/多目标列表（全角半角等价，不空格） | /投料 赤铁矿,火药,硫磺粉 | 不用于数量 |
| `=` | 键值修饰 | 参数修饰（触媒/代采等） | 触媒=爆裂壶 · 代采=矿石*5 | 不用于分隔 |
| `+` | 等级/数值标记 | 装备强化等级、词条数值 | /强化 铁剑+5 · 攻击+3 | 不用于数量 |
| `-` | 连招/序列符 | 连招序列、序号区间 | /攻击 1-2-3 · /背包 1-3 | 不用于数量 |
| `>` | 路径/派生符 | 派生链路径、连续移动 | /锻造 铁剑>铁剑Ⅱ · /进入 1>2 | 不用于数量 |

**记忆口诀**：空格是"切"，`*` 是"乘"（数量），`,` 是"列"，`=` 是"定"，`+ - >` 是"状态"（等级/连招/路径）。

## 二、三条铁律

### 铁律 1：数量 = `*`（半角星号，紧贴对象名后）
```
语法：对象*数量（* 后必须为纯数字）
/使用 经验药水*10 ｜ /合成 魔力药水*10 ｜ /投料 火晶石*2 ｜ /出售 铁矿*20
- 数量上限沿用各系统配置（默认 ≤99，可配）
- /强化 禁止 *（成功率随机，批量=连点爆装风险）；+N 是等级标记不是数量
- 序号（选择）不带 *：/攻击 2 = 2 号技能；/进入 2 = 2 号地图
- 判定：参数含 * → 数量；不含 * → 序号/名称。* 是"数量开关"，有无即区分
```

### 铁律 2：列表 = `,`（逗号，全角/半角等价，不空格）
```
材料/特性/多目标统一逗号：
/投料 赤铁矿,火药,硫磺粉 ｜ /继承 灼烧强化,回复量+5% ｜ /镶嵌 火焰之珠,炎剑Ⅱ
旧格式中"空格列表/+ 分隔/×2"写法全部废除，只保留 , 与 *
```

### 铁律 3：位置参数 ≤2 个（空格分隔）；键值修饰 = `=`
```
- 短指令保留空格：/锻造 炎剑Ⅱ 预览、/炼金 火焰弹 自动（第二位置参数限固定词表）
- 键值修饰：触媒=爆裂壶；键值列表：/雇工 助手名 代采=矿石*5,代调=药剂*2
- 第 3 个参数起强制走列表/键值解析
```

## 三、命名铁律（前置防歧义）

```
- 物品/配方/装备/特性/珠/套装/技能/行动名：禁止空格、禁止 * , = + /（保留字符）
- 允许：·、Ⅱ、-、数字（炎剑Ⅱ、炼狱爆弹·改）
- 解析器按"保留字符检查"黄色提示（不拦截，只建议不限制）
```

---

## 四、解析管线（实现要点）

```
统一解析：/指令名 [位置参数1] [位置参数2|固定子词] [键值列表]
参数内解析顺序固定：先按 , 拆列表 → 再按 * 拆数量 → 再按 = 拆键值
- 名称优先：* 左侧先精确匹配名称，失败再按序号解析
- 固定子词表（追加/预览/自动/查看/确认/放弃/续）为解析器内置常量，优先于物品匹配
- 错误模板统一 4 类：缺参/超参/未知分隔符/保留字符违规
- 数量超限提示"最多一次使用 99 个"（不拦截，仅提示）
```

---

## 五、内容包自定义指令

```
- 内容包注册指令时声明参数位：{pos, 名, 类型: target/qty/seq/level/path/keyword, 可选}
- 解析器按规范自动路由：qty → *、seq → -、level → +、path → >、其余 → 空格
- 新指令零特判：按"空格切参数 + 数量位 *"声明，语法自动统一
```

## 六、快捷指令模式（手机通勤玩家优先，用户拍板）

### 6.1 三种前缀模式（settings.json 用户/机主可配）
```
① prefix_only      需要前缀：全部指令必须 / 开头（/攻击 2）
② combat_shortcut  战斗内免前缀：战斗中直接发"攻击2"；战斗外保持 / 前缀
③ global_shortcut  全局免前缀：任何指令可直接发"攻击2"（我们默认用这个）

→ settings.json: command_mode: "global_shortcut"（默认全局，可改）
→ 不同群/机主可各自设置（机主 /设置 切换）
```

### 6.2 @机器人 触发勾选（独立开关）
```
- 是否启用 @机器人 触发（@机器人 攻击2）→ 勾选，默认关
- 我们不用（直接发"攻击2"即可）
- settings.json: require_at: false
```

### 6.3 紧凑 + 空格双认（解析器）
```
- 紧凑：攻击2 / 道具3 / 使用经验药水*10 / 进入上 / 进入2
- 空格：攻击 2 / 道具 3 / 使用 经验药水*10 / 进入 上
- 解析器两种都认；提示时展示紧凑格式（"下次可以这样写：攻击2"）
- 判定：指令名后紧跟数字=序号；含 * = 数量；汉字=方向/名称
```

### 6.4 快捷指令适用清单
```
✅ 高频可快捷：攻击 / 防御 / 逃跑 / 道具 / 使用 / 进入 / 锁定怪物 / 采集
✅ 制造可快捷（全局模式下）：合成 / 炼金 / 锻造 / 强化 / 调合 / 镶嵌 / 拆珠
✅ 状态查询：状态 / 背包 / 怪物 / 地图
⚠️ 保留前缀推荐：开始 / 重载 / 封禁 / 编辑（创建/GM 类低频指令）
- 白名单可配（command_shortcut_whitelist，默认以上清单；GM 指令永不快捷）
```

### 6.5 防误触（全局模式下）
```
- 非指令消息不响应（只匹配白名单指令名开头）
- 群聊中随机文本不会误触（无白名单匹配=忽略）
- GM 指令（重载/封禁/日志/编辑）永不快捷（强制 / 前缀）
- 频率控制照常（防刷屏）
```

### 6.6 快捷指令绑定（自定义别名，用户拍板）

**指令**：
```
快捷绑定 <自定义快捷名> <对应指令>
  例：快捷绑定 1 攻击 → 玩家发送"1"视为发送"攻击"
  例：快捷绑定 火球 攻击3 → 发送"火球"视为"攻击3"（可绑带参指令）
  例：快捷绑定 奶 使用治疗药水*2 → 完整指令串
快捷解绑 <自定义快捷名>
  例：快捷解绑 1 → 删除绑定
快捷列表 → 查看我的全部快捷绑定
```

**存储**：玩家存档快捷表 `{快捷名: 完整指令串}`（每玩家独立，随存档持久化）

**触发解析顺序（写死，含别名层）**：
```
玩家消息 → ① 查快捷表（完整消息精确匹配快捷名）→ 命中=执行对应指令
        → ② 查指令别名（全局配置，见 6.7）→ 命中=执行原指令
        → ③ 查指令白名单（指令名开头匹配）→ 命中=正常指令解析
        → ④ 忽略（非指令消息）
例：绑定 1=攻击 后，发"1"→攻击；发"攻击2"→正常攻击指令（不被快捷影响）
```

**指令冲突检测**（绑定时校验）：
```
- 绑定名 ∈ 现有指令名（动态指令注册表：框架指令 + 内容包注册指令 + 固定子词）
  → 提示冲突不可绑："『攻击』已经是现有指令，换个快捷名吧（如 a/1/火球）"
- 【GM 指令不可绑】：绑定目标指令为 GM 指令（重载/封禁/日志/编辑/设置）→ 拒绝
  "『重载』是 GM 指令，不可绑定为快捷"（防权限绕过）
- 绑定名含空格/保留字符 → 提示（快捷名建议 1-4 字符：数字/字母/汉字）
- 解绑不存在的快捷名 → 提示"没有绑定『xx』"
- 覆盖绑定：直接覆盖 + 提示"『1』已重新绑定为『防御』（原为『攻击』）"（无需二次确认）
```

**快捷执行铁律**：
```
- 快捷只是别名：执行对应指令时走【完整指令管线】
  （物品校验/冷却/MP/权限/频率控制/会话路由全部照常，不绕过任何校验）
- GM 指令即使被意外绑定也不执行（绑定层已拦截 + 执行层权限二次检查）
- 快捷表上限：每玩家默认 20 条（可配 0=不限），超出提示"快捷已满 20 条，先解绑再绑"
```

**前缀模式联动**：
```
- 快捷名跟随前缀模式：全局模式发"1"；prefix_only 发"/1"；combat_shortcut 战斗内发"1"、战斗外发"/1"
- @机器人 勾选开启时：快捷名也要 @机器人（@机器人 1）
```

**快捷名格式建议**：
```
- 纯数字（1/2/3...）：战斗快捷（发"1"=攻击）——注意与序号区分：完整消息匹配快捷名，攻击2 不受影响
- 字母（q/w/e...）：技能快捷
- 汉字（奶/盾/跑...）：动作快捷
- 长度 ≤4 字符（解析效率 + 防误触）
```

### 6.7 指令别名（内容包级世界观定制，用户拍板）

**用途**：修仙/武侠等世界观下，"炼金/转职/锻造"破坏代入感 → 作者配置别名（炼丹/突破/炼器）

**配置位置**（settings.json）：
```json
{
  "command_aliases": {
    "炼金": {"alias": "炼丹", "keep_original": false},  // 隐藏原指令（发"炼金"→引导提示）
    "转职": {"alias": "突破", "keep_original": false},
    "锻造": "炼器",                                     // 默认 keep_original: true（保留）
    "强化": "淬炼",
    "调合": "炼药"
  }
}
```

**规则**：
```
- 别名 = 作者配置的全局指令别名（世界观定制），区别于玩家快捷绑定（个人自定义）
- 玩家发别名 = 执行原指令：发"炼丹" = 炼金
- 【原指令保留可选（keep_original）】：
  · true（默认）= 原指令保留可用（发"炼金" 或 "炼丹" 都行）
  · false = 原指令隐藏禁用：发"炼金" → 提示"没有这个指令，试试『炼丹』？"（不尴尬）
- 【显示层替换】：/帮助 /角色 提示 技能卡 错误模板 全部用别名显示
  （代入感：提示"炼丹成功！" 而非 "炼金成功！"；keep_original:false 时帮助只显示别名）
- 别名作用于指令名层：带参指令别名同样生效（炼丹 火灵丹*3 = 炼金 火灵丹*3）
```

**冲突检测**（校验器，绑定时）：
```
- 别名 ∈ 现有指令名/其他别名/固定子词 → 黄色提示"『炼丹』与现有指令冲突，请换名"（不拦截）
- 别名含空格/保留字符 → 提示
- 别名表与快捷绑定互不干扰（别名=全局配置，快捷=玩家个人）
- 别名可配数量上限（默认 50 条，可配 0=不限）
```

**与快捷绑定的区别（明确）**：
```
指令别名（6.7）      = 内容包作者配置，全局生效，世界观定制（炼丹/突破）
快捷指令绑定（6.6）  = 玩家个人配置，每人独立，快捷操作（发"1"=攻击）
两者解析顺序：快捷表（个人）→ 指令别名（全局）→ 指令白名单 → 忽略
```

## 七、兼容策略（只建议不限制）

```
- 过渡期：解析器自动识别旧空格数量格式（物品 + 纯数字 → 按数量处理），
  并回显新格式提示"下次可以这样写：/合成 药水*10"
- 粘合写法（背包2）永久兼容（正则回退）
- 旧内容包零改动可跑，新格式逐步生效，不强制迁移
```
