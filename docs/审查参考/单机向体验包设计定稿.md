## 一、核心命题：零新机制 + 四功能联动

- **零新文件**：全部落在现有模块（maps/quest/achievements/longline_counters/事件注册表/NPC 对话树/商店限时）
- **零新引擎**：触发判定走统一条件引擎 + 事件注册表
- **零新存储**：冒险日志 = longline_counters 展示层 + 环境快照
- **零新指令**：/日志 权限分支改造（玩家=冒险日志，GM=系统日志）
- **四功能联动**：环境叙事（氛围暗示+事件计数）→ 隐藏要素（条件组合触发）→ 图鉴阶梯（反向要求挖秘密）→ 冒险日志（传记枢纽带环境快照，回溯规律）

## 二、F1 隐藏要素（纯配置 · 不提示原则）

### 2.1 三类隐藏要素

| 类型 | 载体（全复用） | 触发条件示例 |
|---|---|---|
| 隐藏 BOSS | maps.json 怪物行限定窗口 + enemies BOSS 档 + loot special | 秋·午夜·雷雨 + 图鉴≥60% → 蚀月之狼（replace/after/fixed 三触发模式） |
| 隐藏任务 | quest 不上任务板 + NPC 发任务条件（图鉴/事件/物品/时段组合） | 图鉴完成度≥50% + [事件:环境事件:雨夜] → NPC 主动对话发任务 |
| 彩蛋 | maps.json 已有 ☑隐藏地图 + 介绍文本 + lore condition | 特定地图 /调查 交互点文本彩蛋 |

### 2.2 三层线索漏斗（不直接告知）

1. **环境文本泛暗示**（地图介绍/天气演出文本暗写代号）
2. **图鉴 lore 定向线索**（怪物/鱼类图鉴补全后解锁传闻条目）
3. **玩家主动操作确认**（/调查 交互点/特定时段蹲点）

### 2.3 校验器可达性检查

- 隐藏要素条件永假（如引用了未注册事件/条件键）→ 黄提示"无发现路径=可能永不可发现"
- 每隐藏要素至少 1 条 lore 线索引用（硬提示，软拦）

## 三、F2 图鉴全收集阶梯（纯成就配置）

- **里程碑**：25% / 50% / 75% / 90% / 100% 五档，条件键 [图鉴完成度]（var:codex 已注册）
- **codex 分册结构（2026-08-16 仲裁定稿）**：codex_state 按四册组织——monster（怪物）/ fish（鱼类含冠级）/ item（物品）/ craft（制造品：装备/珠/料理）；总册完成度 = 四册加权（权重可配，默认等权）；条件键 [图鉴完成度] 支持 param 分册（[图鉴完成度:怪物]）；阶梯成就可配分册（每册 100% 各自专属称号：怪物博士/鱼类大师/物品收藏家/制造行家 + 总册 100% 收藏家）
- **100% 专属奖励**：「收藏家」称号（进 title_state 佩戴，钓鱼王先例推广到全图鉴维度）+ 世界之书唯一物品 + 隐藏神龛解锁（商店 event 类型）
- **desc 软锚**：软锚挂在里程碑条目 `milestone.items[i].desc_anchor`，跟随配置（默认模板在 90% 档设 desc_anchor："全收集还有更深处"）——不再是 90% 硬编码特殊分支，移动里程碑后软锚随配置
- **收集闭环**：100% 图鉴包含隐藏要素条目（隐藏 BOSS 击败/彩蛋发现后补全）→ 反向驱动探索

## 四、F3 冒险日志（longline 展示层 · 传记枢纽）

- **六类自动记录**（全挂事件注册表）：首杀 / 首钓冠级 / 剧情节点 / 隐藏发现 / 里程碑 / 图鉴新增
- **数据源**：longline_counters（3.7.1 ③ 只增不减）+ 事件计数
- **环境快照**：记录时附 [季节]/[时段]/[天气] 快照（供回溯规律——"上次金闪是雨夜"）
- **指令仲裁**：/日志 权限分支——玩家版 = 冒险日志（分组展示 5 条/页倒序，传记 50 段环形），GM 版 = 系统日志（保留最近事件）
- **容量**：300 条环形（可配）

## 五、F4 环境叙事（事件注册表扩展 · 氛围暗示）

- **窗口**：季节/时段/天气条件组合（[季节:X]+[时段:X]+[天气:X] 已有条件键）
- **事件注册**：[事件:环境事件:ID] 入事件注册表（NPC 4.3.2 预置口），可被任务/隐藏要素引用
- **效果引用现有系统**（零新机制）：
  - npc_appear：雨夜神秘 NPC 现身（NPC 发牌员条件）
  - quest_window：限时任务窗口（quest.timed + 条件键）
  - shop 限时：季节限定商品（**shop.open_condition 条目级条件键 [季节:X]，2026-08-16 仲裁**——限购周期 3.11 是现实时间层，季节条件走条目开放条件，两者正交不冲突）
  - monster_boost：环境出没加成（可选，默认关——环境不改数值原则）
- **懒触发不轰炸**：一次指令最多 1 条环境演出 + daily 配额 + 去重（时间天气懒检测同款）

## 六、仪式感揭示（发现即惊喜）★ A 版引入

- **一次性揭示卡片**：发现隐藏要素瞬间特殊格式（⛩️ 前缀 + 仪式感文本 + 状态翻转后不再出）
- **首见日志**：发现瞬间自动写入冒险日志（首见标记）
- **图鉴 lore 补全**：发现后图鉴对应条目解锁传闻段（奖励重读）
- **不提供 /秘密 列表指令**（探索感完整保留）

## 七、联动总表

```
环境事件发生（雨夜演出）→ 事件计数+1 → 满足隐藏 BOSS 条件（秋·午夜·雷雨+图鉴≥60%+雨夜≥3 次）
→ ⛩️ 一次性揭示 → 击败 → 图鉴条目补全 → 冒险日志记录（含环境快照）
→ 图鉴完成度 +1 → 阶梯里程碑推进 → 100% 收藏家称号 → 消息前缀 [称号] 展示
```

## 八、数值（可配，只建议不限制）

- 隐藏要素：18-28 个（BOSS 3-5 / 任务 5-8 / 彩蛋 10-15）；BOSS 条件满足 100% 蹲点必出 + 3 次保底、日限 1 次
- 环境事件：氛围 10-20%、特殊 2-5%
- 阶梯间隔：25/50/75/90/100%（可配）；desc_anchor 挂在对应里程碑条目（默认 90% 档模板示例）随配置移动
- 日志：300 条环形 / 传记 50 段

## 九、编辑器 / 校验器

- 隐藏要素页（条件组合表单 + 线索引用 + 可达性检查显示）
- 环境事件页（窗口条件 + 效果引用下拉）
- 阶梯模板一键插入（25/50/75/90/100 + 称号）
- 日志卡片（记录类型勾选 + 快照开关）
- 作者视角时间轴预览（玩家不可见——模拟作者配置的隐藏链能否被发现）
- 校验：V1-V7 硬 + W1-W7 黄提示（只建议不限制；条件永假黄提示）
