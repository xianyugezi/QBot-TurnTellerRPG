## 一、品质档位（QLT-01 ~ QLT-13）

> 依据：【炼金】§4.3#2 L150（品质机制）、§4.3#4 L152（属性刻度）、§10 L348-350（品质唯一注册表）、§10.6 L408-424（quality_tiers/quality_coef 落点）、§4.4 L160/L163（反馈与悬念分级）、§4.5 L167（失败与浪费）、§2.2 L68（SP 品质上限+10）、§5.2 L202/L206/L214（核心/加成/挑战品质联动）、§六 L257（珠等级=品质档）、§2.3 L83（精通刻度显现）。编号 QLT-01 ~ QLT-13。

### 1.1 基准品质系统（QLT-01 ~ QLT-05）

| # | 规则 | 行为 | 引用 |
|---|---|---|---|
| QLT-01 | 品质唯一注册表 | 品质档位只允许一套枚举：items.json 四档（普通/精良/史诗/传说 ↔ common/uncommon/rare/legendary）；炼金/强化/锻造跨系统引用同一注册表，**不重复定义、不另设档位**；品质数据落 items.json 实例 `quality` 字段 | 【炼金】L350 / L380 |
| QLT-02 | 品质分数口径 | 品质分 = 0-100 整数口径（计算用），档位 = 品质分区间映射；`quality_tiers: {common:0-39, uncommon:40-59, rare:60-79, legendary:80-100}`（可配）；**档位判定函数**：`score ∈ [lo, hi] → 档位`，例：80 分即传说、79 分仍史诗 | 【炼金】L411 |
| QLT-03 | 档位边界不可重叠 | 四档区间闭开边界固定（39/40、59/60、79/80 为跳档点），品质分四舍五入取整后落档；配置校验：档位区间必须单调覆盖 0-100 且不重叠（编辑器校验器）；**校验器对档位数/区间合法性只提示不拦截**（对齐定稿 L411） | 【炼金】L411 |
| QLT-04 | 品质系数 | 成品效果数值 = 基准效果 × 档位系数；`quality_coef: {common:0.8, uncommon:1.0, rare:1.2, legendary:1.5}`（可配，数值不变）——品质档位只放大效果数值，不改变效果结构 | 【炼金】L150 / L412 |
| QLT-05 | 珠等级=品质档 | 装饰珠等级直接取品质档位（默认模板四档 普通/精良/史诗/传说，档位数可配 3/5/7、0=不限制）；槽级→珠档映射：1 级=普通，2 级=精良及以下，3 级=全部——品质档同时是珠 build 的准入门槛 | 【炼金】L257-258 / L350 |

> 【旧名废弃】定稿 L150 品质机制段行文「普通 0-39/优秀 40-59/稀有 60-79/传说 80-100」中的"优秀/稀有"为早期旧档位名，已废弃（用户拍板②）；统一以定稿 L350/L411/L412 键集 **普通/精良/史诗/传说 ↔ common/uncommon/rare/legendary** 为准，旧名不再使用。

### 1.2 品质如何判定（QLT-06 ~ QLT-10）

| # | 规则 | 行为 | 引用 |
|---|---|---|---|
| QLT-06 | 材料品质→成品品质 | 成品品质分由投料材料品质聚合得出（**材料品质→成品品质**）；【工程补白】定稿未给聚合公式，实现层取最小必要推导：**成品品质分 = 全部投料材料品质分均值（四舍五入取整）**，再受 QLT-08/QLT-09 修正；基础调合 **100% 成功**，绝不吞材料 | 【炼金】L150 / L167 |
| QLT-07 | 批量=平均品质 | 批量调合按平均品质出货（QLT-06 均值口径）、**丢特性**；单件逐项调合才进入特性继承流程——批量是保底通道，单件是 build 通道 | 【炼金】L156 |
| QLT-08 | 品质上限提升 | 品质上限可被三处提升（互不冲突、可叠加）：① SP 面板「品质上限+10」（可多次，L68）；② 核心镶嵌「品质上限+X」（大师，L202）；③ 挑战调合成功「品质上限+10」（可配，L214）；上限提升只放宽品质分可达上限，**档位判定仍按 QLT-02 区间**，品质分 ≤100 | 【炼金】L68 / L202 / L214 |
| QLT-09 | 加成道具 | /加成 <道具>（宗师）：限 1 次/调合，大幅提品质/改属性（例：贤者之石 品质+30）；加成在品质均值结算后施加 | 【炼金】L206 / L245 |
| QLT-10 | 未达标=降级不失败 | 任何未达标情形（属性刻度未达标等）**不失败、不吞材料**：品质降级出货——差一档降一档，最低普通；即传说刻度全不达标 → 降至普通仍出货 | 【炼金】L152 / L167 |

### 1.3 属性刻度随品质变化规则（QLT-11 ~ QLT-13）

| # | 规则 | 行为 | 引用 |
|---|---|---|---|
| QLT-11 | 刻度机制定义 | 配方字段 `element_req: {元素: [{阈值, 效果}]}`；材料携带元素属性值（items.json `elements`，8 元素：地水火风雷晶月无）；**投料累计元素值 ≥ 阈值 → 该效果显现**（例：火焰弹「火≥6 显现"范围爆炸"」；深度例「火 30 ✓ 地狱火」）；刻度效果本身是效果系统原子动作 | 【炼金】L152 / L135 / L240 / L355 / L380 / L387 |
| QLT-12 | 刻度×品质双向联动 | ① 达标 → 刻度效果显现且品质不受影响；② **未达标 → 品质降级**（差一档降一档，最低普通，绝不吞材料，QLT-10）；③ 反馈分级：第 2 层引导语（"火系还差一点，试试多投火系材料？"）、大师级显示精确阈值（"火 42/45"）——品质与刻度在反馈上同屏呈现 | 【炼金】L152 / L163 |
| QLT-13 | 刻度显现门槛与连锁 | ① 刻度效果**显现**需炼金职业 ≥ 精通（精通前达标也不显现）；② 链式投料段数→效果等级（chain_map：1 段=1 级…6 段=6 级，可配）；③ 同属性判定=材料当前属性（触媒改变后按新属性） | 【炼金】L83 / L153 / L413 |

## 二、traits.json 字段级 schema（TSC-01 ~ TSC-18）

> 依据：【炼金】§10.2 L372-376（traits.json 进框架 4.1）、§10.4 L386（觉醒/潜力/核心表并入）、§4.3#3 L151（group/repeatable 语义）、§5.2#3 L201（金色超特性）、§5.2#17 L215/L366（特性合成=upgrade 实例）、§10.6 L414（pp_cost）、【效果】§1.3 L29（L0 原子动作）、§1.4 L35-39（六挂载点）、§七 L281-305（原子动作词汇表）。编号 TSC-01 ~ TSC-18。

### 2.1 表定位（TSC-01 ~ TSC-03）

| # | 规则 | 行为 | 引用 |
|---|---|---|---|
| TSC-01 | 唯一数据表 | traits.json 为特性唯一数据源（进框架 4.1）；**觉醒/潜力/核心表并入 traits.json 效果表（复用原子动作）**，不另立效果定义表 | 【炼金】L372 / L386 |
| TSC-02 | 效果系统挂载点 | traits.json 是效果系统六挂载点之一（skills/items/effects/statuses/traits/enemies）；特性 `effects` 字段引用效果系统 L0 原子动作词汇表（ID 引用，热重载自动迁移），特性自身不内联实现逻辑 | 【效果】L35-39 / L42 / L29 |
| TSC-03 | 两套词条分工 | `base_effects` = 固定基础效果（标准版/标准珠只有这个）；`traits` = 品质浮动 + 可继承（炼金/深度产出独有）——同一 items.json 实例两字段并存，标准版 traits 恒为空 | 【炼金】L265-267 / L117 |

### 2.2 字段级 schema（TSC-04 ~ TSC-10）

> 定稿字段原文（【炼金】L372-376）：`id | name | rarity(normal/super) | effects(原子动作) | group(互斥组，组内最多1) | repeatable(false) | source(素材/成品/金色素材)`。逐字段契约如下：

| 字段 | 类型/枚举 | 规则 | 引用 |
|---|---|---|---|
| `id` | string | 特性唯一标识；【工程补白】命名禁空格/禁保留字符 `* , = +`（对齐定稿 L12 指令分隔符规范——`*` 数量、`,` 列表、`=` 键值、`+` 等级标记）；被成品实例 `traits` 数组与调合会话快照引用；**快照/存档冗余存储 ID+名称**（热重载删配置降级不报错） | 【炼金】L372 / L12 / L511 / 【效果】L456 / L462 |
| `name` | string | 展示名（例：灼烧强化 / 攻击+15% / 回复量+5%）；投料反馈清单、成品消息、/继承 参数均用 name 匹配 | 【炼金】L138 / L142 / L140 |
| `rarity` | normal \| super | 特性稀有度；**super = 超特性（金色超特性）**，PP 消耗翻倍（pp_cost.super=2），普通 PP 消耗 1；rarity 是 PP 计价的唯一依据 | 【炼金】L373 / L414 |
| `effects` | L0 原子动作列表 | 特性"身体" = 效果系统 L0 原子动作列表（damage/heal/stat_modifier/dot/control/status_apply/dispel/shield/mark_add/mark_remove/clear_marks/summon/convert/interrupt/aoe；结算修正器 lifesteal/pierce/mitigation；触发容器 proc/element_modifier；允许 x_ 前缀自定义，框架级动作不走 x_ 通道）；编辑器校验效果 ID 引用存在性 | 【炼金】L374 / 【效果】L29 / L281-305 / L448 |
| `group` | string（互斥组） | **互斥组：组内最多 1 项**——同组特性在「继承选择」与「成品共存」两个层面互斥；组名为组内共享键；编辑器校验器做互斥组校验 | 【炼金】L375 / L151 / L492 |
| `repeatable` | boolean（默认 false） | 可否重复：false = 同一特性不可多次继承/成品上不重复出现；true = 允许重复（受效果系统叠加规则约束：同类互斥/同名递减等） | 【炼金】L375 / L151 |
| `source` | 素材 \| 成品 \| 金色素材 | 特性来源标签：决定投料后特性进入哪个可继承池——普通素材→普通池；金色素材→超特性池（第 4 位）；成品（全物入料）→按成品携带特性原样入池 | 【炼金】L376 / L201 / L218 |

> JSON 示例（schema 落点，字段即上表）：
> ```json
> {
>   "id": "trait_burn_boost",
>   "name": "灼烧强化",
>   "rarity": "normal",
>   "effects": [{"type": "element_modifier", "element": "fire", "value": 15}],
>   "group": "fire_boost",
>   "repeatable": false,
>   "source": "素材"
> }
> ```

### 2.3 超特性（TSC-11 ~ TSC-14）

| # | 规则 | 行为 | 引用 |
|---|---|---|---|
| TSC-11 | 定义与解锁 | `rarity=super` 的特性即超特性（金色超特性）；特性继承超特性需炼金职业 ≥ 宗师 | 【炼金】L373 / L86 |
| TSC-12 | 第 4 位独占 | 超特性占用第 4 特性位（普通位 3 个之外），默认独占（`gold_slot_exclusive: true`，可配关闭）；关闭后超特性与普通特性共用位池（仍受位上限约束） | 【炼金】L201 |
| TSC-13 | 触发来源 | 超特性的供给 = 稀有金色素材投料（采集点稀有/金色标记素材），素材继承——素材自身 `source=金色素材` 的特性才可进入超特性池；**无金色素材 → 超特性位空缺**，/继承超 无可选项 | 【炼金】L201 / L129 / L376 |
| TSC-14 | PP 消耗 | 继承超特性消耗 PP 2（`pp_cost.super`），普通特性 PP 1（`pp_cost.normal`）；PP 预算 = 配方卡 PP 上限（例：火焰弹 PP 5/5），会话内消耗、会话重置（pp_refresh: "会话重置"） | 【炼金】L414 / L415 / L135 |

### 2.4 进化特性（TSC-15 ~ TSC-18）

| # | 规则 | 行为 | 引用 |
|---|---|---|---|
| TSC-15 | 定义 | 进化特性 = /特性合成 产出的**更高位特性**：两同系特性融合升级（高品質Lv1×Lv2=更高级），是极限 build 天花板；解锁=宗师 | 【炼金】L215 / L86 |
| TSC-16 | 合成引擎映射 | 特性合成 = 合成引擎 `kind=upgrade` 配置实例：inputs=2 同系特性、cost=宝石 20 + 材料（可配，gem.特性合成）、output=更高位特性（数值不变口径下融合为更高位） | 【炼金】L366 / L229 / L332 / L215 |

## 三、特性继承规则（INH-01 ~ INH-16）

> 依据：【炼金】§4.3#3 L151（继承机制+冲突规则）、§2.3 L81-84（等级化解锁位）、§2.2 L70（SP 特性位+1）、§4.2 L138/L140（投料反馈/继承指令示例）、§4.4 L162（可继承特性清单）、§5.2#3 L201（超特性继承）、#17 L215（特性合成）、#19 L217（负面特性）、#6 L204（觉醒）、#20 L218（全物入料）、§11.2 L443（种子继承特性）、§11.4 L464（助手等级→特性更多）、§10.6 L414-415（pp_cost/pp_refresh）、§九 L344（错误模板全集）、§13 L492（校验器互斥组校验）。编号 INH-01 ~ INH-16。

### 3.1 来源（INH-01 ~ INH-04）

| # | 规则 | 行为 | 引用 |
