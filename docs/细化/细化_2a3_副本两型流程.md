## 0. 总览

### 0.1 一句话流程

```
【探索版（练习赛）】
进入探索副本(入口=安全区) → 平静探索（熟悉网状通道/机制/怪物分布）
  → 可选做子任务（探索/收集/清剿/机制学习/情报，奖励驱动、不做也能打 BOSS）
  → 精英遭遇可打可绕 → 无 BOSS → 任意子任务完成/自行离场
  → 非战斗状态离开副本 = 副本重置（下次满状态重打）

【BOSS 版（正式赛）】
进入讨伐副本(入口=安全区) → 平静探索推进 → 精英遭遇（升压）
  → 进入 BOSS 房 → 决战阶段机制（阶段1 常规 → 阶段2 狂暴 → 阶段3 绝境）
  → 换区条件命中 → BOSS 换区追击（随机候选区，玩家 /进入 <方向> 追击）
  → 追到续战（残血 + PV 半值 + 开场技）→ 击杀 = 通关结算（掉落/图鉴/首次奖励）
  → 死亡（BOSS 房或追击中）→ 复活点 + checkpoint 回退 + BOSS 状态保留（均可配）
  → 非战斗状态离开副本区域 = 副本重置
```

- 两型共用同一组地图 ID，同一张地图机制（落石/场地效果）两副本通用——探索版先学会，BOSS 版直接用（【副本】L229-233）。
- 全流程玩家状态全程延续（HP/MP/资源/印记不重置）（【副本】L24）。

## 1. 副本两型定义

### 1.1 探索版 = 练习赛（R1 / R3）

- **定义**：探索版（`dungeon_explore`，如「熔岩洞窟·探索」）= 同一地图的「练习赛」，**无 BOSS**（【副本】L28/L188-200）。
- **目的**：熟悉通道链接 / 捷径 / 单向门 / 陷阱机制 → 为正式「比赛」（BOSS 版）准备（【副本】L28-29）。
- **压力**：放空（松弛感），无 BOSS 威胁下自由的探索节奏（【副本】L34）。
- **玩法内容**：地形/通道/捷径、地图机制（落石/陷阱/机关/场地效果）、怪物分布、宝箱/采集点位置、BOSS 房机制预告的学习场（【副本】L155-160）。
- **赛制关系**：与 BOSS 版是**同一赛场两种赛制**——是整体体验的一部分，不是独立模块（【副本】L17/L30）。

### 1.2 BOSS 版 = 正式赛（R2 / R3）

- **定义**：BOSS 版（`dungeon_boss`，如「熔岩洞窟·讨伐」）= 正式比赛，**一场完整的战斗**（【副本】L22/L204-224）。
- **完整流程**：进入 → 探索推进 → 精英遭遇 → BOSS 换区（随机区域）→ 玩家凭地图知识追击 → 决战（【副本】L23）。
- **压力**：紧张（BOSS 战），高难（15 分钟+）（【副本】L34/L209）。
- **阶段机制**：BOSS 房含阶段机制（血量阈值联动行动表强化，§2.4）（【副本】L241-244）。

### 1.3 地图共用（R4 / R5 / R6 / R7）

- 两组副本引用【同一组地图 ID】（如 molten_entrance / molten_corridor / molten_core）（【副本】L229/L191/L207）。
- 探索副本：地图配置（怪物/采集/宝箱/机制）**完整保留**（【副本】L231）。
- BOSS 副本：同一地图 + **额外 BOSS 房** + 守门怪配置（【副本】L232；BOSS 房地图如 molten_boss_room 见 L207）。
- 地图机制两副本共用：探索版先学会 → BOSS 版直接用（【副本】L233）；这是「子任务先行学习」的底层保证。

### 1.4 入口区分与进度独立（R8–R12）

| 维度 | 探索版（dungeon_explore） | BOSS 版（dungeon_boss） | 依据 |
|---|---|---|---|
| 类型标识 | `type: "dungeon_explore"` | `type: "dungeon_boss"` | L190 / L206 |
| BOSS | `boss: null` | `boss: "magma_t_rex"` | L192 / L208 |
| 难度 | normal（练习赛） | high（15 分钟+ 正式赛） | L193 / L209 |
| 推荐等级 | 无（或可配更低） | recommended_level 30 | L210（推导） |
| 子任务 | subquests 可配置（示例 3 项） | 可配置（未显式列，沿用同机制） | L194-198/L272 |
| 入场 | entry_item: null（默认不限） | entry_item: 熔岩之钥 + entry_limit 可配 | L199/L211-212 |
| 安全区 | 入口区为安全区 | safe_zone 可配 + rest_per_dungeon/rest_auto | L213-215 |
| 死亡配置 | 无 BOSS 语义轻（低难可配无惩罚档） | checkpoints + death_policy 完整 | L216-221 |
| **进度独立性** | 探索进度独立（子任务完成态/离开重置自持） | BOSS 进度独立（残血/checkpoint/阶段独立） | L188/L204（推导） |

- **入口区分**：两副本是两个独立入口（可通过 type 或 id 路由）：探索版入口免道具（entry_item:null），BOSS 版入口消耗「熔岩之钥」并校验入场限制（L199/L211-212）。
- **进度独立**：探索版与 BOSS 版各自由独立副本状态承载（副本 id 唯一），互不牵涉——探索版练熟地图不影响 BOSS 版 BOSS 血量/checkpoint；BOSS 版死亡/重置也不清探索版子任务进度（两配置对象独立性推导，L188/L204）。
- **玩家状态跨副本共享**：无论哪一型，副本内玩家 HP/MP/资源/印记全程延续、不重置（L24/R13）——玩家状态是共享的，但副本实例进度是独立的。

## 2. 副本内流程（四阶段节奏）

### 2.1 节奏总览（R14）

副本游玩 = 一场战斗 / 一次小游戏，是整体体验（【副本】L16）；内部节奏四段（【副本】L33）：

```
平静（探索/熟悉）→ 升压（精英遭遇）→ 高潮（BOSS 换区追击）→ 决战（阶段机制）
  ↕ BOSS 版走完整四段；探索版止于平静→升压（无 BOSS，放空松弛感）（L34）
```

### 2.3 阶段细化

#### S1 平静探索（平静 → 缓坡）

- 内容：走通道熟悉网状结构（哪通哪/捷径/单向门），触发/观察地图机制（落石等），找宝箱/采集点，可接取子任务（【副本】L155-160/L33）。
- 子任务 = 这场体验的前菜（探索版先行熟悉）（【副本】L26），可选做（R24）。
- 放松态：无 BOSS 压力，节奏舒缓（L34）。

#### S2 升压精英（升压）

- 内容：当前图怪物分布含精英（副本地图配置，L231），遭遇进入精英战（衔接细化_1f 精英 AI）。
- 可选性：可打可绕——精英不是必打门槛，但图内精英属该图怪物分布（L231）；「不熟悉地图的玩家绕矿洞岔路会遇精英」（L59）是天然的升压提醒。
- 目的：把节奏从平静拉到紧张（L33），为 BOSS 战热身（验证配装/破防手感）。

#### S3 BOSS 换区追击（高潮）

- 内容：BOSS 残血/特定条件触发换区 → 「BOSS 逃向了 XX 区域」（随机候选）→ 玩家 /进入 <方向> 追击（【副本】L75-76，主路径已细化于细化_2a2）。
- 地图知识 = 追击资源：熟悉=走回廊→坑道捷径直追；不熟=绕矿洞岔路（错过窗口/遇精英）（【副本】L57-59/L77）。
- 追击期间玩家状态保留；BOSS 固定在目标区（细化_2a2 R22）。

#### S4 决战阶段机制（决战）

- BOSS 房设计（高难 15 分钟+，【副本】L237-240）：PV 200-500 + 行动表 4-6 招 + 特殊行动 2-4 个（阶段机制）。
- **阶段机制**（血量阈值，【副本】L241-244）：

| 阶段 | 血量区间 | 行为 | 定稿依据 |
|---|---|---|---|
| 阶段1 | 100-60% | 常规行动表 | L242 |
| 阶段2 | 60-30% | 狂暴：行动表强化 + 新招 + 换区 PV 恢复一半 | L243 |
| 阶段3 | 30-0% | 绝境：大招循环 + 印记反制 + 连招锚点加速 | L244 |

- **高难博弈**（【副本】L245-250）：PV 门禁先破防再 debuff 爆发（L247）｜锚点连招读招闪反（L248）｜印记反制叠/清印博弈（L249 已另细化于 1d）｜续航压力：副本内 HP/MP 不恢复，唯一例外=安全区 /休息（有限次数可配）（L249-250）｜换区 PV 恢复：阶段切换重新破防（L250）。
- **终结**：击杀 → 通关结算（BOSS 掉落三类 + 副本宝箱 + 首次通关奖励：专属素材/称号/图鉴）（【副本】L259）；或死亡 → §4。

### 2.4 快照与续玩（衔接细化_1g3）

- 副本整体为「战斗快照续玩」载休：战斗进行中退出/超时/锁屏 = 快照续玩，ai_state+combo_state 全保留，套内也可续（【副本】L80）。
- 非战斗状态（已离开副本区域）离开 = 副本重置（L81）——「战斗中断可续玩，离开副本将重置」在恢复入口明示（L82）。

## 4. 死亡处理与离开重置

> 死亡 ≠ 战斗中断：战斗中断（退出/超时/锁屏）= 快照续玩（L80）；副本内死亡 = 战斗结算败北（HP 归零/全灭）（【副本】L111）。本细化为死亡的主路径（death_policy 默认档）。

### 4.1 死亡结算流程（R27 / R28 / R29）

```
死亡（HP 归零/全灭）→ 判定：死亡发生在副本内 → 不离开副本（R31）
→ 复活点复活：默认退回副本入口；可配 death_policy.revive_point 指定区域（如 checkpoint 区）
→ 复活点 = 死亡后的安全区：可 /休息（按 §2.1 次数限制），虚弱结束后可继续推进
→ 进度处理（penalty 三档，death_policy 可配）：
   ① checkpoint（默认）：副本进度回退最近 checkpoint（已清区域/BOSS 血量回到记录状态），
     掉落/素材/已领奖励保留
   ② reset：整个副本进度重置（下次满状态重打，与离开=重置同口径）
   ③ none：仅复活，进度/BOSS 状态原样保留（低难探索副本适用）
   兜底：未配置 checkpoint 时 ①自动降级为 ②重置副本（不悬空）
```

- 依据：【副本】L114-121（死亡结算默认建议，全部可配）、L115-116（复活点=安全区）、L121（降级兜底）。

### 4.2 BOSS 状态处理（R30）

| 档位 | 值 | 语义 | 依据 |
|---|---|---|---|
| 保留（默认） | `boss_state: "keep"` | BOSS 血量/阶段保留——半血 BOSS 不重置，死亡重进继续打残血（配合 checkpoint 回退，挫败感最低） | L124 |
| 重置 | `boss_state: "reset"` | BOSS 满状态重打（与离开=重置统一，防反复试错磨血） | L125 |
| 判定 | 按 BOSS 独立可配 | 不同 BOSS 不同待遇 | L126 |

### 4.3 与「离开=重置」衔接（R31 / R32）

- **死亡 ≠ 离开副本**：玩家仍算在副本内，进度按 §4.1 处理，不自动触发重置（L129）。
- **死亡后主动离开副本 = 重置**（非战斗状态离开副本区域 → 副本重置）（L130/L81）。
- **死亡惩罚=重置副本**：等价于离开副本重置（下次进入满状态重打，入场限制正常结算）（L131）。
- **虚弱衔接（框架 3.12）**：复活后进入虚弱（默认 1 分钟可配）；期间可待在复活点/入口/安全区，**不可进入非安全区区域（含 BOSS 房）**——防立刻送死（L134）；虚弱期间副本进度/BOSS 状态不因虚弱额外重置（L135）。
- **安全区 /休息 ≠ 离开副本**：不改变位置、不退出副本、不触发重置；副本进度/BOSS 血量/快照（ai_state+combo_state）全程保留（L104-106/L83）。
- **配置落点**：dungeon.json（death_policy: {revive_point, penalty, boss_state} + checkpoints 列表，可配；缺省 = 入口复活 + checkpoint 回退 + BOSS 保留）（L136）。

### 4.4 探索版死亡（低难语境）

- 探索版难度 normal（R9/R10），可按 death_policy 配 `penalty: "none"`（仅复活，无惩罚，适合练习赛语境，L120「低难探索副本适用」）。
- 未配置 death_policy 时沿用缺省档；探索版基本无 BOSS 语义（boss_state 无意义，字段不启用）。
