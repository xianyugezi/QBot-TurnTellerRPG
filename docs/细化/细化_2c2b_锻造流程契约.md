### 1.2 成功路径（原子，一条指令出结果）

```
[玩家] /锻造 铁剑
[机器人] ✅ 铁剑锻造完成！
        攻击 12 | 部位：武器 | 槽位：无 | 品质：精良（固定）
```
—— 定稿原文 L76-79，逐字段接线：

1. **扣素材 / 扣金币**：按 2c2a N-10 `materials`（行 count）/ 2c2a N-11 `cost`（缺省按 settings `forge_fee`）扣减；**一次写完、无中间态**（原子写）。
2. **实例化并快照**：按「items 基础 + 节点改造」合并实例化（2c2a§1.3 AR-1/AR-2），属性快照入玩家存档（2c2a AR-5 / 【锻造】L278）——防热重载/后续删改回溯。
3. **发熟练经验**：+节点等级×2（可配，settings `exp_per_forge`）→ §四。
4. **成功行格式**（对齐 L78，字段来自合并后实例）：`攻击 N | 部位：X | 槽位：Y | 品质：Z（固定）`；带孔装备 `槽位` 显示孔位（如 `1 级槽 ×1`，2c2a N-09 / 【锻造】L190）；图片鉴/锻造树进度钩子一并更新（图鉴点亮）。
5. **新手指引钩子**（L375/L378）：首次 /锻造 引导「选一把铁剑→素材够直接锻」；装备带孔时附「炼金可做装饰珠镶嵌」转层提示。

- 多件：`/锻造 铁剑*2` → 按数量循环执行上述原子流程（素材扣 2 份、实例 2 件、经验按件计）【锻造】L12。
- **零会话**：完成后不建立任何会话/待确认上下文（明确不使用框架 3.18）【锻造】L239；同一次指令内也不产生随机判定或重 roll【锻造】L32。

### 1.3 失败路径（确定性错误模板，非随机）

| 场景 | 触发守卫 | 输出模板 | 引用 |
|---|---|---|---|

## 二、/图纸 <装备>（全链 + 分支 + 持有进度 + ✓ 标注 + 失效标注）

> 依据：【锻造】§3.4 L99-107、§2.1 #8 素材即进度 L58、指令表 L233（无门槛）、级联删除红名 L296、素材来源 L147。

### 2.1 触发与门槛

- `/图纸 <装备名>`；**无铸造等级门槛**（L233「无」）——0 级玩家即可看全链。
- 匹配目标：命中该装备所属派生树主干上的节点（含中间节点/分支节点），从该节点向两端展开全链。
- 未命中任何节点 → 空态：`未找到「<装备名>」相关锻造链`（附 /锻造树 查看可锻装备）。

### 2.2 输出结构（对齐定稿原文 L101-107）

```
📖 炎剑派生链：
铁剑 → 铁剑Ⅰ → 铁剑Ⅱ → 炎剑 → 炎剑Ⅱ → 炎剑Ⅲ → ■炎王剑（火）
├─ 分支：冰剑 ← 冰晶矿（需 采集 冰晶）
└─ 分支：雷剑 ← 雷兽牙（雷兽掉落）
当前持有：火龙鳞 1/3 | 矿石 5/5 | 铁剑Ⅰ ✓
```

逐段接线：

| 段 | 内容 | 数据源 | 引用 |
|---|---|---|---|
| 主链 | 根 → … → 目标节点 → … → ■最终强化（终结点前缀 ■ + 属性标注如（火）） | 2c2a §二 树拓扑（parent 正/反向遍历） | 【锻造】L103 / L117 |
| 分支 | 当前节点可转出的其他线：`├─ 分支：<名> ← <关键素材>（需 <动作/来源>）` | 2c2a N-07 `branch` + 该分支首段素材行 | L104-105 / L257 |
| 当前持有 | 目标节点各行素材：`<素材名> <持有>/<需求>`（持有取自背包实时） | 2c2a N-10 + 背包持有量 | L106 / L58 |
| ✓ 标注 | 已持有/已达成项打 `✓` | 见 §2.3 | L106 / L58 |

### 2.3 ✓ 标注规则（已锻＝✓ / 素材满额＝✓）

- **前置/父链节点**：玩家已锻造该节点 → 该节点名后 `✓`（如 `铁剑Ⅰ ✓`）。
- **素材**：背包持有数 ≥ 需求数 → `材质 ✓`（如 `矿石 5/5` 满额即 ✓ 态；`火龙鳞 1/3` 未满则不标 ✓，保持 x/y 进度）。
- **满链推进度**：当「前置全部 ✓ 且素材全部 ✓」时，目标节点显示 `可锻造`（/图纸 辅助行），等于把 GU-04+GU-05 的判定前置给玩家看（素材即进度，L58）。

### 2.4 失效标注（红名，级联删除①）

- 级联删除被引用 items 后节点标红（2c2a §五 TC-25）：/图纸 中该节点显示 **`已失效：物品已删除`** 标注，不参与 ✓/可锻造 判定；分支行若指向失效节点同样标注。【锻造】L296
- 整棵子树移除模式（级联删除②）：/图纸 不再渲染已移除节点，父节点 branch 引用已清（2c2a V15）。

## 三、锻造双流（直锻 vs 预览 + /确认）

> 依据：【锻造】§3.1 新手流 L74-79、§3.3 预览流 L89-97、§2.1 #7 L57、settings `straight_forge` L355、零会话 L239。

### 3.1 双流的开关与语义

| 流 | 触发 | 步骤 | 适用 | 引用 |
|---|---|---|---|---|
| **直锻**（默认开） | `/锻造 <节点>`（无 预览 参数） | 1 步：守卫全过即原子出结果 | 小白一步出结果（新手流） | 【锻造】L57 / L74-79 / L355 |
| **预览**（深度模式） | `/锻造 <节点> 预览` | 2 步：预览卡片 → `/确认` → 完成 | 深度玩家先看卡片再确认（预览流） | L57 / L89-97 |

- settings `straight_forge`（2c2a S-03，默认 `true`）：内容包关闭后**全部 /锻造 强制走预览**（前台无直锻入口），剩余行为一致。【锻造】L355 / 2c2a S-03
- 双流并存而非互斥：直锻开时玩家仍可显式带 `预览` 参数切深度流——`预览` 参数不依赖 `straight_forge` 开关（L57「深度玩家可关」指关直锻默认，并非禁预览）。

### 3.2 预览卡片（/锻造 <节点> 预览 输出）

```
📖 炎剑Ⅱ（火属性+8）
素材：铁剑Ⅰ + 火龙鳞×3 + 矿石×5 | 需求：铸造 精通 级
孔位：1 级槽 ×1 | 可继续锻造：炎剑Ⅲ → ■炎王剑
```
—— 定稿原文 L91-94，逐字段接线：

| 行 | 内容 | 数据源 | 引用 |
|---|---|---|---|
| 标题 | 节点名 +（属性摘要，如 火属性+8） | 2c2a N-02/N-08 | 【锻造】L92 |
| 素材行 | 前置节点名 + 各行素材 + 需求等级 | 2c2a N-06/N-10/N-05 | L93 |
| 孔位/后续 | 孔位（slots，空则略）+ 可继续锻造子链（child → ■终结） | 2c2a N-09/N-07 + 子树 | L94 |

### 3.3 确认窗（预览 → /确认）与会话边界

- 预览发出后，引擎登记**一次性待确认上下文**（单键：玩家 id + 目标节点，字段快照）：
  - ✅ `/确认` → 执行 §1.2 成功路径（重跑 GU-03~06 守卫，再扣素材发经验）→ `✅ 炎剑Ⅱ 锻造完成！`（L95-97）。
  - 未确认 / 超时（carry_sec 默认 90s，0=不限）→ 上下文作废，**无锻造、无扣款、无经验**（预览 0 副作用）。
  - 同一玩家同时仅 1 个待确认窗口；新 /锻造 或 /图纸 不覆盖既有窗口（保持可感知）。
- **边界**：本确认窗是**超短期一次性引导**（对齐新手指引节奏 L375-377），不是框架 3.18 会话——定稿明确「锻造全部原子指令、无会话状态（不使用框架 3.18）」【锻造】L239；窗口仅存在于单条指令→下一条指令之间，不持久化、不可跨指令续接（区别于炼金链式会话 L400）。

### 3.4 双流差异对照（验收锚点）

| 维度 | 直锻 | 预览+/确认 |
|---|---|---|
| 指令数 | 1 | 2 |
| 素材扣减时机 | 首条指令内 | /确认 时 |
| 失败副作用 | 零（§1.3） | 预览零副作用；/确认 失败同 §1.3 |
| 上下文 | 无 | 一次性待确认窗口（短，非 3.18 会话） |
| 成功输出 | 同一（✅ 锻造完成 + 属性行） | 同一 |

## 四、锻造熟练经验（节点等级×2 / SP 解锁 / 铸造王称号）

> 依据：【锻造】§十 L208-224（10.1 等级门槛 L211-217、10.2 铸造王 L219-223）、指令表 门槛列 L232-237、settings L355-357。完整职业表/SP 树归 2c2c，本文只落「指令侧契约」。

### 4.1 熟练经验计价（指令侧）

- **每件锻造成功 = 节点等级 ×2 熟练经验**（可配，settings `exp_per_forge`，默认 节点等级×2）【锻造】L214 / L357。
- 发放时点：§1.2 成功路径第 3 步（原子提交内）；**失败/预览不发放**（零副作用，§1.3/§3.3）。
- 多件（`*数量`）：按件累加（L12 语义）。
- 熟练面板呈现：`当前 <职业>（已 xx 熟练 / 还差 40 熟练）`，与等级不足报错模板 L240 同一数据源（`还差 N 熟练`）。

### 4.2 职业等级门槛（指令侧判定）

- **可锻造节点等级上限 = 铸造职业等级**【锻造】L213：GU-06 用节点 `level`（2c2a N-05）对比职业等级；越级锻造被拦 → L240 模板。
- 职业链：见习 → 正式 → 精通 → 专家 → 大师 → 宗师 → 王（铸造王）（L212）；等级阈值表归 2c2c。

### 4.3 SP 面板（解锁，指令侧接线）

- **每级 1 点 SP，自选解锁**（复用炼金 SP 设计）【锻造】L215；可解锁项含：**分支树 / 3:1 合成 / 开孔 / 套装 / 客制** 等【锻造】L216。
- 指令侧影响：未解锁 3:1 合成 → 无 combine 升档入口（2c2a S-02/§3.2）；未解锁 套装/客制 → /套装 /客制 指令拒绝；未解锁 分支树 → /图纸 分支段折叠（仅显示已解锁分支）。解锁状态为玩家存档字段，SP 树完整定义归 2c2c。

### 4.4 铸造王称号（图鉴全点亮）

- **条件**：装备图鉴全点亮（全部节点制作过）【锻造】L221——图鉴点亮即 §1.2 步骤 5 钩子回写；查询口径：派生树全部节点 ∈ 玩家已锻造集合。
- **奖励**【锻造】L222：专属锻造配方 + 称号加成（全属性+X% 可配）+ **群内称号展示**（与其他王称号并行：炼金王/钓鱼王/收集王，L223）。
- 触发：点亮最后一节点时即时结算称号；群公告走称号系统统一渠道（归 2c2c，本文登记触发条件与输入）。

## 五、指令参数解析（节点名禁空格 / 允许 · / Ⅱ / 序号）

### 5.1 词法规则（P-01 ~ P-06）

| # | 规则 | 行为 | 引用 |
|---|---|---|---|
| P-01 | **节点名禁空格** | /锻造 首个参数内**不允许空白字符**（`炎剑 Ⅱ` 视为参数错误，输出 `参数错误：节点名不含空格`） | 【锻造】L232（语法约束） |
| P-02 | 允许字符集 | 中文/大小写英文/数字/间隔号 `·`/罗马数字 `ⅠⅡⅢ`/方头括号 `【】`/短横 `-`（约定名法内允许） | L103-122（示例名） |
| P-03 | 罗马数字与序号 | `Ⅱ` 等罗马数字与阿拉伯数字序号均按**普通字符**参与匹配（`炎剑Ⅱ` ≠ `炎剑2` 除非配置别名）；节点名 `序号` 按 2c2a N-02 原样登记 | L103 / L252 |
| P-04 | 最终强化标志 `■` | 输入可省略（`/锻造 炎王剑` 命中 ■炎王剑）；含 `■` 时精确匹配 | L103（■ 为显示标记） |
| P-05 | 数量 `*` | `/锻造 <节点>*2`：`*` 后数字 ≥1 为批量锻造；与 预览 参数组合顺序 `预览 *N` | L12 |
| P-06 | 多项目 `,` | /锻造 单指令不允许多项目（锻造按节点+数量原子）；`,` 为 /客制 /分解 等列表指令保留 | L12（多项目用 `,`） |

### 5.2 匹配算法（精确 → 唯一前缀 → 歧义列表；零越权）

1. **精确匹配**：完整名（含符号/罗马数字/括号）精确命中 → 锻造之。
2. **唯一前缀**：无精确命中时，若存在唯一前缀匹配（如 `/锻造 炎剑` 恰一节点以「炎剑」开头）→ 命中；**不自动扩展**（`炎剑` 不吞 `炎剑Ⅱ`）。
3. **歧义**：多个候选 → 输出候选列表（每候选附 预览 1 行摘要）+ `/锻造树` 指引；**不默选、不自动锻造**（零会话不越权，L239）。
4. 未知节点：`未找到「<名>」→ /锻造树 查看可锻装备`（L234）。
