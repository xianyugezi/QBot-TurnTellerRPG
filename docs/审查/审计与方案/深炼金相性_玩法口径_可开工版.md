## 三、口径 A · 强度型（相性 → 效果强度 / 持续时长）

### 3.1 语义与映射（**先定「映射到哪条既有特效轴」**）

**不得**出现 `effect_mult` / `duration_mult` 这类新键。相性的「强度」直接**用一个既有特效轴名 + 百分点**表达：

| 药剂类别 | 唯一映射轴 | `doc_id` / 定义 | 语义对齐 |
|---|---|---|---|
| **治疗药剂**（veinborn 现有全部四种） | `healing_done_pct` | `data/gear_stats.py:222-231`（X16 施疗修正） | 「调整我造成的治疗」——玩家喝药 = 玩家施疗，语义精确 |
| **伤害药剂**（火焰弹类） | `damage_dealt_pct` | `data/gear_stats.py:246-256`（X01 造成伤害修正） | 「调整我造成的伤害」 |
| **施加状态的药剂** | `status_duration_pct` | `data/gear_stats.py:308-317`（X20 状态时长修正） | 「调整**我施加的**状态持续时长」 |
| **上状态的命中率** | `status_chance_pct` | `data/gear_stats.py:270-281`（X21） | 「调整施加状态的基础命中概率」 |
| 收到的治疗（**不用于药剂自身**） | `healing_received_pct` | `data/gear_stats.py:209-220`（X17） | 药剂是**输出**侧，用 X16 不用 X17；X17 留给「喝药时的受疗修正」运行时 buff |

> **键空间唯一源** = `data/gear_stats.py:423 GEAR_EFFECT_KEYS`（由 `EFFECT_AXIS_SPECS` 派生）。
> 内容包写错轴名 → 校验器红拦（§七）。

### 3.2 声明形状

```jsonc
// settings.alchemy.affinity_effects   —— 交给 resolve_affinity_effect() 取值
// 查表序：先 "主|副"（更具体优先）→ 再 "主" → 无 → None   （core/affinity.py:369-376）
{
  "炎火":        { "healing_done_pct": 20 },
  "炎火|雷":     { "healing_done_pct": 30, "status_duration_pct": 10 },
  "冰晶":        { "healing_done_pct": -10, "status_duration_pct": 25 },
  "月光|冰晶":   { "healing_done_pct": 15 }
}
```

* **内层键**：∈ `GEAR_EFFECT_KEYS`（否则红拦）。
* **内层值**：float，单位 = **百分点**（`20` = +20%）；允许负值/0。
* **有效区间**：**不由内容包自定**，读 `settings.effect_axes[<axis>]` 的 `min/max`，
  经 `data/gear_stats.normalize_effect_axes`（`:576`）取有效值；缺省表见 `:530-541`。
  （`healing_done_pct` 缺省 `-100~300`，`status_duration_pct` 缺省 `-80~300`。）

### 3.3 两个可开工子形状（**二选一，§九 Q7 裁决**）

#### A-α · T2「使用时复算」（**本报告推荐 · 改动最小 · 零迁移**）

**求值时点**：`/道具` 使用时。

```
inst.affinities（实例已带，data/item.py:69）
  → rank_affinities(inst.affinities, settings.affinities)      core/affinity.py:233
  → resolve_affinity_effect(settings.alchemy.affinity_effects, main, sub)  core/affinity.py:351
  → 取 healing_done_pct → 经 normalize_effect_axes 钳制
  → heal_total = round(heal_total × (1 + pct/100))             ← 与 core/effects.py:1861-1865 同式
```

| 项 | 落点 |
|---|---|
| 暂存 `ctx["settings"]`（已有惯例） | `commands/use_commands.py:_use_consumable:293`（入参加 `settings` 或就地 `ctx.get("settings")`） |
| 相性 → pct 复算 | **建议新建小模块 `qbot_rpg/core/alchemy_affinity.py`**，只放两个纯函数：`main_sub_of(aff_values, settings)` 与 `axis_pct(aff_values, settings, axis)`（内部即 `rank_affinities` + `resolve_affinity_effect` + `normalize_effect_axes`）。**不放进 `core/affinity.py`**——该模块铁律是「不做任何业务解释」（`core/affinity.py:362`），轴名→效果语义属炼金侧解释。`alchemy_settle`（口径 C）与 `use_commands`（口径 A）共用该模块 |
| pct 乘进回血 | `commands/use_commands.py:344-360`（`heal_total` 算出后、写 `player["hp"]` 前） |
| 文案（可选） | `:357-360` `use_ok` 占位符加 `{affinity_main}`（模板表 `use_ok` 需同步；不加以免动模板） |

**优点**：**不动 `ItemInstance`、不动存档、不动对拍**；G3 被「相性值已有承载位」自然消化。
