```
- 怪物使用与玩家相同的 9 属性：生命/魔法/力量/智力/体质/精神/专注/敏捷/幸运
```

## 三、② 双维弱点

```json
{
  "weakness": {
    "types": ["斩击", "打击"],       // 伤害类型弱点（斩打突魔，数量不设限）
    "elements": {"fire": 1.3, "water": 1.3}   // 元素弱点（8 元素，×1.3 默认）
  }
}
```
- 伤害类型弱点 + 元素弱点独立判定（两者都中=叠乘，参考伊甸 ×2×2 结构）
- 弱点数量倾向（待定，建议）：小怪 1 类 / 精英 2 类 / BOSS 2-3 类
- 校验器：每怪 ≥1 弱点（防白板怪，战斗数值层约束）
- 怪物攻击玩家时：怪物也可享受元素弱点加成（双向，但怪物攻击主要靠行为表驱动）

## 四、③ 防护值 PV（debuff 门禁，核心机制）

### 4.1 规则
```
- PV 不吸收伤害（与伤害同步下降）
- PV > 0：怪物受到的【负面效果减半】（效果值打折，层数照常积累！）——打折系数 = per-怪物可配字段 `pv_half_ratio`（默认 0.5，0=不启用），enemies.json 逐怪可调（配置落点见 §十二 `pv_half_ratio` 字段）
- PV = 0：提示"防护被击碎了！"→ 负面效果全量发挥
- 破防瞬间：攒了一身的 debuff 突然拉满（爆发爽感）
```

### 4.2 效果减半含义（用户确认）
```
- 层数保留：火伤 6 层还是 6 层
- 效果减半：每回合伤害减半（dot 减半）、概率减半（眩晕概率）、数值减半（降防）
- PV=0 瞬间：6 层完整生效——"预铺 debuff → 破防引爆"
```

### 4.3 行为引导价值
```
1. 破防前"预铺 debuff"（火伤/易伤攒起来），破防后引爆——防反流/控场流策略
2. 破防 = 奖励时刻（配合"防护崩溃"提示，战斗小高潮）
3. BOSS 战节奏：PV 高 → 前期 debuff 打折，破防后爆发——"持久战换爆发窗口"
```

### 4.4 PV 恢复（怪猎式换区，用户确认）
```
- 换区触发：怪物血量低于阈值（残血才会换区——不残血不会触发，逻辑闭环）
- 怪物逃跑换区 → 提示"逃到了 XX 地图"
- 玩家走地图通道去找（/进入 <方向>，框架通道系统）
- 换区后继续战斗：
  · 怪物【血量保持残血】（不重置——玩家打残血才换区，残血继续打）
  · 怪物 PV 恢复（默认一半）——恢复比例 = 配置键 `zone_change.pv_recover`（默认 0.5，0=不恢复，1=全恢复；内容包可调，归口怪物行动AI设计定稿 §八），取整默认向下取整——重新加压 debuff 门禁
  · 换区后第一回合：怪物开场技
- 玩家离开副本 → 副本重置（下次 BOSS 满状态重打）
- 怪物 PV 值：普通 0-20 / 精英 50-100 / BOSS 200-500（可配）
```

## 六、⑤ 行动表（概率驱动）

### 6.1 行动数据库（独立表）
```
- 怪物行动表 = 独立数据库（与玩家技能库对齐）
- 怪物引用行动 ID（不内嵌）——一个行动多只怪复用
action.json:
{
  "id": "fire_breath",
  "name": "火球",
  "intent": "蓄力",              // 意图预告（伤害/防御/蓄力/治疗）
  "type": "damage",
  "power": 120,                  // 倍率
  "element": "fire",
  "effects": [{"type": "mark_add", ...}],
  "chain": ["tail_sweep"],       // 连招衔接（历史写法：新配置连招一律走 enemies 顶层 chains 表，见 怪物行动AI定稿 §八【连招载体唯一化】）
  "probability": 1,              // 入池开关（0=锚点/1=入池，数值不参与概率计算——概率=weight 归一化，2026-08-16 统一）
  "cooldown": 2
}
```

### 6.2 概率驱动
```
- 怪物每回合按随机池行动表选行动（weight 归一化：普攻 50/重击 30/蓄力 20，probability=1 入池；probability=0 锚点只被链/条件/状态机触发——2026-08-16 统一语义）
- 意图预告配合概率趋势（玩家读"概率趋势"而非"固定套路"）
- 每次挑战行动顺序不同（差异性）
```

## 七、⑥ 特殊行动（锚点连招）

### 7.1 触发条件 13 类（2026-08-16 随怪物行动AI定稿扩展同步）
```
① 血量低于 xx%（当前回合）——狂暴/残血大招
② 防护崩溃后（下一回合）——破防反扑
③ 起身后（下一回合）——被击倒/控制恢复后
④ 进入战斗时（第一回合、换区后第一回合）——开场技
⑤ xx 行动后（下一回合）——固定连招锚点
```

### 7.2 "xx 行动后"的价值（随机+锚点结构）
```
随机行动表（差异性）→ 玩家每次挑战不同
    ↓
某行动触发"xx 行动后"→ 固定连招（可读性）
    ↓
玩家看到"火球"预判"尾扫"→ 配合意图预告形成博弈

例：熔岩霸王龙"火球"后 80% 跟"尾扫"——看到火球就知道下回合防尾扫（闪反窗口）
随机给新鲜感，锚点给可读性——"信息即资源"
```

```json
{
  "special_actions": [
    {"action": "rage", "trigger": {"type": "hp_below", "value": 30, "timing": "current_turn"}},
    {"action": "shield_bash", "trigger": {"type": "pv_broken", "timing": "next_turn"}},
    {"action": "roar", "trigger": {"type": "get_up", "timing": "next_turn"}},
    {"action": "opening", "trigger": {"type": "battle_start", "timing": "first_turn"}},
    {"action": "tail_sweep", "trigger": {"type": "after_action", "action": "fire_breath", "chance": 80, "timing": "next_turn"}}
  ]
}
```

## 八、⑦ 掉落表（三类）

```json
{
  "drops": {
    "battle": [   // 战斗掉落（战斗中触发）——条目 = 概率化 reward 条目（统一入账管线，见下方说明）
      {"item": "岩皮", "chance": 60, "count": [1, 3]}
    ],
    "special": [  // 特殊掉落（条件结算）
      {"item": "破防晶", "condition": "pv_broken", "chance": 100, "count": 1},
      {"item": "无伤勋章", "condition": "no_damage", "chance": 50}
    ],
    "death": [    // 死亡掉落（死亡时）
      {"item": "兽骨", "chance": 100, "count": [1, 2]},
      {"item": "稀有皮", "chance": 10, "count": 1}
    ]
  }
}
```
- 战斗掉落：战斗中触发（如行动后掉落）
- 特殊掉落：条件结算（破防掉落/无伤掉落/特定行动后）
- 死亡掉落：死亡时结算（普通/稀有+概率）
- 与掉落经济联动（战斗数值层 4.6：金币=等级×基准）
- 掉落条目 = **概率化 reward 条目（统一入账管线）**：item/count 键与统一 reward 条目 schema 同键（任务系统定稿 §2.1），chance（概率 0-100）/condition（触发条件）/count 区间 [min,max] 为掉落特有扩展；命中后经框架 reward 解析器统一入账（与任务/签到/NPC 同管线）——发放器唯一实现=框架 reward 解析器，怪物只配条目不另立发放逻辑

## 九、⑧ 图鉴情报

```json
{
  "lore": [
    {"unlock": 10, "desc": "岩皮鼬的皮肤由矿石构成，普通武器难以穿透。"},
    {"unlock": 50, "desc": "岩皮鼬在防护值被击破后会暴露柔软腹部，火系攻击效果翻倍。"},
    {"unlock": 100, "desc": "传说岩皮鼬的皮可以做成最坚硬的盾牌素材。"}
  ]
}
```
- 每条情报独立配置【解锁需求（1-100）+ 描述】——数量自由
- 玩家图鉴进度达到解锁需求显示对应情报（情报=策略提示：弱点/机制/掉落）
- 图鉴完成度 = 收集控目标（铸造王/炼金王等称号条件之一）
- **解锁进度落点 = 玩家存档 codex_state（框架 3.7 持久化语义总表，登记由批内另一 agent 同步）**：每怪 lore 条目的解锁状态（unlock 阈值 1-100 递增）+ 图鉴完成度（解锁条目/总数；条件键 [图鉴完成度] var:codex 读同一来源）统一存 codex_state——怪物模块只声明解锁需求与描述，不另立存储（重叠检查组2 F3 补登记）

## 十、难度分层 × 高难设计（联动战斗数值层）

```
- 普通怪：PV 0-20，行动表 1-2 招，斩杀 3-8 回合
- 精英怪：PV 50-100，行动表 2-4 招 + 1 个特殊行动，斩杀 10-15 回合
- BOSS：PV 200-500，行动表 4-6 招 + 2-4 个特殊行动（阶段机制），15 分钟+ 高难
  · BOSS 阶段机制：血量阈值触发（狂暴/换招表/印记反制）
  · 高难博弈：PV 门禁（先破防再爆发）+ 锚点连招（读招闪反）+ 印记反制
- 声明：上述斩杀回合带 / 难度分层区间 / 弱点倍率 ×1.3 / 难度模板乘数均为**建议默认基准（可配）**——归口 formula.json 经济基准键（可配），不构成引擎硬规则；实现层不得据此硬校验数值，校验器对超区间仅黄提示（§十三 4）
```

## 十一、与其他系统衔接

```
效果系统：PV 减半 = 效果系统伤害拦截链（减伤乘区，effects_link.intercept_order 扩展）
> 减益门禁管线顺序声明（2026-08-16，全量重叠检查组5 F7）：①免疫判定（immune 列表，施加前拦截——免疫状态不施加）→ ②抗性初始层数（resistance 门槛，施加时不足 N 层不生效/减效）→ ③PV 减半（PV>0 时负面效果数值打折——系数=per-怪物可配字段 `pv_half_ratio`，默认 0.5，0=不启用；层数照常积累，效果结算乘区）→ ④破防全量（PV=0 后无减半）。三者按序执行，一处在管线上、两处在施加判定。

行动数据库：action.json 独立模块（框架 4.1 新增，与 skills.json 对齐）
训练木桩：木桩 = enemies 特例（§十五），与普通战斗共用引擎；伤害构成统计落战斗数值层 §八
```

## 十三、校验器 / 编辑器

```
校验器：
1. 行动 ID 引用存在（action.json）
2. 特殊行动触发条件合法（13 类枚举：hp_below/phase_below/cooldown_ready/turn_elapsed/after_action/chain_complete/broken/revive/ally_dead/script/tag_trigger/enter_phase/delayed，x_ 前缀可扩展自定义触发；action 引用存在——枚举以怪物行动AI定稿为准）
3. 弱点允许 0（警告"该怪无弱点"）+ 元素 ID ∈ 注册表（引用检查）
4. PV 非负校验（<0 拦截）；难度档区间仅提示（"PV 超出该档常见区间，确认？"）
5. 掉落物品引用存在（条目结构对齐统一 reward 条目 schema，item/count 同键）+ 概率 0-100
6. 图鉴情报解锁需求 1-100 递增
7. 木桩（tier: training / type: dummy）：drops/lore/pv 若配置 → 黄提示"木桩忽略掉落/图鉴/PV"（不拦截）；防御/元素抗性基准非负

编辑器：
- 怪物页（基本信息/属性/弱点/PV/抗性/行动/特殊行动/掉落/图鉴 9 标签页；勾选木桩后折叠为 属性+木桩 表单——dummy 开关 + 多档防御/元素抗性基准，见 §十五）
- 行动数据库页（独立页，行动复用）
- 特殊行动条件表单（13 类触发下拉 + 参数，对齐怪物行动AI定稿）
- 掉落条件下拉（破防/无伤/特定行动）
```

## 十五、训练木桩（enemies.json 特例）

> 来源：新功能建议 #5（训练木桩与伤害构成统计）落地——木桩 = enemies.json 特例，不新增模块；伤害构成统计落战斗数值层 §八
> 用途：玩家侧配装试靶场——测试配装/连段/强化收益，伤害构成明细让"强化强在哪"可见

### 15.1 定位与标记（tier/type 至少其一，可配）

```json
{
  "id": "dummy_low",
  "name": "训练木桩·轻甲",
  "tier": "training",            // ① tier: "training"（normal/elite/boss 之外第四档，仅战斗外 /木桩 可进入）
  "type": "dummy",               // ② 或 type: "dummy"（标记式，tier 保持 normal 也可；至少其一）
  "stats": {"hp": 99999},        // HP 极大（≥ 目标斩杀回合总输出上限，防打死中断测量；可配）
  "def_base": 20,                // 防御基准（直读代入防御系数 K_def/(有效体质+K_def)；或映射 stats 体质，二选一，校验器提示一致性）
  "elem_res": {"fire": 0.2, "water": -0.2},   // 元素抗性基准（正=减伤/负=增伤；相对 formula.json 元素减伤系数）
  "weakness": {"types": ["打击"], "elements": {"fire": 1.3}}  // 可选：模拟目标怪弱点，测元素/类型配装
}
```

### 15.2 特例规则（不可反击写死，其余可配）

```
- 不可反击：木桩不行动——忽略 actions/special_actions/AI 状态机（配置了也忽略，黄提示）
- 无掉落：忽略 drops（配置了也忽略，黄提示）；无金币、无经验、不计击杀类任务进度
- 无 PV：pv 强制 0（防 debuff 门禁干扰伤害测量；想测 PV 破防节奏请用普通怪）
- 不入图鉴：无 lore 解锁，不占 codex_state 进度
- 战斗规则：与普通战斗共用引擎（命中/会心/格挡/双通道/拦截链全量生效）——
  木桩 = 特殊 enemies 引用（无掉落无经验）；玩家战败 → 无损退出（无死亡惩罚，可配 0=按普通战败处理）
- 可随时退出：战斗中 /撤退（=中断快照续玩，框架 3.17；指令表统一为 /逃跑 同义别名，2026-08-16 标注），碎片化友好
```

### 15.3 多档配置（模拟不同怪物）

```
- 档位 = 一只木桩（独立 id），作者按需建 N 只：低防脆皮（测尖峰）/ 高防重甲（测破防收益）/
  高元素抗（测元素穿透）/ 高敏捷（测命中）/ 全抗（测真实斩杀线）……
- 数值建议（可配）：防御/元素抗性对齐内容包怪物难度模板（战斗数值层 4.3 普通/精英/BOSS 三档取值）
- 校验器：木桩 HP/防御/抗性非负；不要求每怪 ≥1 弱点（该约束对木桩不适用）
```

### 15.4 入口：/木桩 <档位>

```
- 战斗外指令：/木桩 → 列出可挑战档位（序号+名称+防御/元素抗性摘要）；/木桩 <序号或名称> → 进入木桩战斗
- 与普通战斗共用引擎（木桩 = 特殊 enemies 引用）；锁定/进入地图等流程不适用（木桩不在地图内）
- 战斗中指令与普通战斗一致（/攻击 /技能 /防御 …）；战后展示伤害构成（战斗数值层 §八），
  木桩模式可选实时展示（每回合一行摘要，可配）
- 指令表 7.1 登记由收尾统一执行（本批不碰框架主文档）
```

### 15.4.1 调整木桩（覆盖怪物面板）

```
- /调整木桩 <怪物名>：木桩属性覆盖为对应怪物面板——从 enemies.json 读取该怪物的 def_base/elem_res/弱点/抗性复制到木桩（HP 仍为木桩极大值，不复制攻击/行动：木桩不反击）
- /调整木桩（无参）：重置为基础木桩（§15.2 默认档位面板，清除覆盖）
- 怪物名不存在 → 黄提示「怪物『xx』不存在，去怪物页添加」（只建议不限制，不硬拦）
- 覆盖持久化：dummy_override 存 settings/世界状态（可配），重启保留；覆盖后下次 /木桩 进入即用新面板
- 用途：模拟"打该怪物"的真实手感与伤害，配合伤害构成统计（战斗数值层 §八）验证配装针对效果
- 编辑器：木桩页补"调整木桩"表单（怪物下拉引用 + 重置按钮 + 当前覆盖显示）
```

### 15.5 与伤害构成统计衔接

```
- 木桩战报 = 伤害构成统计的展示场景一（战斗数值层 §八）：战后按来源汇总 + 占比 + 存档 dummy_log（最近 N 次）
- 普通战斗同样收集（数据供战报分享卡/平衡教练），默认不展示明细（防刷屏，作者可开）
```
