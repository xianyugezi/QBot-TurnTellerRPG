## 一、① 装配层接线（A 系列 · 地基，5 任务）

> 现状铁证：`grep "Router(" qbot_rpg/` 零命中；九指令组 register_xxx_commands（battle/basic/quest/shop/checkin/register/shortcut/status/explore）全部 `make_context=None → 【待接线】`（gm 壳亦待 M12 后端）；processing.py 注释「批次6/7 装配层在指令入口注入 repo/queue 并驱动」未兑现；无任何 bot/启动入口。

### A-01 make_context 工厂（装配层核心）
- **职责**：NoneBot 事件（group_id/user_id/message）+ 依赖（Repository/GameWorld/SessionManager/registry/settings）→ 完整玩家 ctx dict。单一工厂，各指令壳按消费契约取字段，缺省兜底。
- **ctx 字段全景**（汇总各指令壳消费契约，**权威 = 各指令壳 docstring 真实消费字段，本表为代表 + 关键形态**）：
  - 玩家基础：registered / player（Player dataclass）/ name / job_id / level / exp / hp / mp / location / title
  - 属性：stats / attributes（PlayerAttributes 三层）/ attr_final（calc_all_final_attributes）/ exp_next / level_cap / conditional_rules / attr_types / imprints
  - 背包与装备：**inventory = {item_id: count} 计数映射**（任务引擎 quest.py L410/条件引擎消费，非展示形态）+ **inventory_items = ItemInstance 列表**（/背包 展示，acquired_at 倒序）；equipment / worn_refs
  - 效果：active_effects（{effect_id: {effect,turns,refreshed}}）/ effects（展示形态）
  - 任务：quest_engine（core.quest 注入）/ quest_active / quest_completed / quest_daily / longline_counters / event_counts
  - 商店：shop_engine / current_shop_ref（shop_refs[0] 地图级状态）/ **currencies（复数，全代码统一键名）**/ world_stock / world_sold_out
  - 签到：checkin_engine / checkin state（persistent_state["checkin"]）
  - 快捷：shortcuts（可变表）/ shortcut_max（缺省 20）/ **gm_commands 集合（绑定校验注入）**
  - NPC：npc_delivered（intel:ref_id 键）/ heard（dialog info_key 键）/ npcs（当前地图 visible 列表，GameWorld.get_npcs）/ npc_interactions hook
  - 对话：dialog_active（bool）/ dialog_session（DialogSession 快照）/ settings（max_dialog_depth）
  - 环境：season / period / weather（时间/天气引擎当前值）
  - 战斗：battle_engine / battle_session（SessionManager）/ target / turn / battle_reward_fn / battle_rewards / battle_hint / battle_status_changes
  - 世界：game_world / map_def / monster_pool / prefix_settings / prefix_extra
  - 工具：rng（确定性）/ now / today（dayroll）/ group_name / per_channel / channel / to / qq_id / is_gm
- **依赖注入**：装配层持有 Repository（storage）+ GameWorld（world）+ SessionManager + registry（content）+ settings；make_context 为工厂函数，测试可注入 mock。
- **幂等与事务**：read 走 Repository 快照；写操作由各引擎在事务内完成（对齐 D2 幂等三件套）。

### A-02 Router 构造与全指令注册
- **职责**：构造 Router 实例，注册全部指令组到统一 Registry。
- **注册清单**：battle_commands / basic_commands / quest_commands / shop_commands / checkin_commands / register_commands / shortcut_commands / status_commands / **explore_commands（/进入 /休息，M5 已建待接线，parsers 白名单已含）** + 本里程碑新增（N-01 dialog_commands、F 系列 log_commands/investigate_commands）+ 后续里程碑预留（**gm_commands 归 M12 补充**——现有 gm 壳依赖 ctx["gm_backend"]（M12 后端未注入），M7 不注册；仅「日志」spec 由 log_commands 统一注册，见 ADR-09）。
- **配置装载**：快捷表（玩家绑定）/ 指令别名（settings command_aliases）/ 指令白名单（parsers）/ GM 权限表 / 前缀模式（prefix_only/combat_shortcut/require_at）/ 免前缀配置（command_mode）。
- **会话路由**：接入 route_message 的 dialog_active 会话路由（① 会话 → ② 快捷 → ③ 别名 → ④ 白名单 → ⑤ 忽略）。
- **校验**：注册后自检（指令名冲突/白名单缺注册/注册缺白名单）→ 装配冒烟断言（router.names()/whitelist_names() 一致性比对，装配层独立函数）。

### A-03 processing 驱动与发送出口
- **职责**：接入 M6 批2 的幂等入口 + per-player 串行队列 + 发送出口闭环。
- process_message（幂等键三元组 + 队列 + 同事务提交 + sender 闭包）真正驱动：指令解析 → make_context → handler(tx) → COMMIT → 发送。
- **发送出口**：sender.send（CQ 转义/长度分条/重试）+ apply_message_prefix（前缀注入，M5 已建）+ 分片（4000 字上限，对齐 QQ 平台）。
- **错误兜底**：异常 → TPL-12 统一错误模板 + 日志（logging_utils）+ 事务回滚（无孤儿键）。
- **清理调度**：cleanup_idem_keys 调度（D2 IDEM-7，7 天窗口）+ PerPlayerQueue 超时（D2 POOL-4，装配层新增，见 ADR-08）。

### A-04 NoneBot 插件入口（可选适配层）
- **职责**：NoneBot2 插件包（不混入 qbot_rpg 内核，独立目录如 qbot_rpg_bridge/），on_message/on_command 桥接 → A-03 process_message。
- **零 NoneBot 内核铁律**：qbot_rpg/ 内零 NoneBot import（G0 架构门禁），桥接层单独目录独立测试。
- **事件字段映射**：NoneBot 事件 → (group_id/user_id/message) → route_and_expand → 指令分发。
- **后端开关**：无 NoneBot 环境（CLI/测试）可走纯函数驱动（装配冒烟脚本），NoneBot 仅运行时可选。

### A-05 world 装配
- **职责**：GameWorld 实例装配（registry 注入 loader 装载 + hot_reload 接线）、SessionManager（战斗/对话会话）、world_state 持久化（load/to_world_state）、换区/追击/续战（snapshot_resume registry_generation 世代绑定）接线。
- **启动链路**：启动装载（loader 全量校验红拦 → registry 快照）→ GameWorld.load(world_state) → watcher 调度（热重载 WIR，M6 已建）→ 指令入口就绪。
- **世界级状态**：world_stock（全服库存）/ 地图级状态（当前商店/天气可见）/ 跨群隔离。

## 二、② NPC 对话接线（N 系列 · 4 任务）

> 现状：npc.py（751 行 发牌员三策略+10 动作）/ dialog.py（954 行 会话状态机）/ npc_models.py（1185 行 schema）M4 已实装，三套测试全绿；缺指令壳与装配。

### N-01 /对话 指令壳（dialog_commands.py）
- **职责**：/对话 无参列表（render_npc_list 序号+名字+类型图标）/ /对话 N·名称（parse_dialog_command → DialogSession.step）/ 会话中纯数字·继续·结束词·选择N（route_session_input 送状态机 mode=session_digit）/ 交互菜单渲染（render_interaction_menu ≤6 折叠 + N.离开）/ 恢复简报（build_resume_brief）。
- **动作分发**：DialogSession._on_exec → dispatch_action（quest/shop/heal/give_item/buff/repair/teleport/intel/tutorial/reply）→ 结果渲染（✅/❌ 业务文案 + 统一入账提示）。
- **一次一物**：mark_delivered/is_delivered 读 ctx["npc_delivered"]；信息类置灰「已听」。
- **注册**：parsers 白名单 + Router 注册；/对话 需 / 前缀（M4 接缝裁决：可快捷绑定、不可免前缀直发）。

### N-02 世界层 NPC 挂载
- **职责**：GameWorld 提供当前地图 NPC 列表（map_def.npcs 引用 + npc registry 解析 + 可见性过滤 visible）；/对话 列表以此为准。
- **当前商店连接**：NPC 对话 shop 动作 → 当前商店（shop_refs[0] 地图级状态，2b3 §四）；离开地图清除 → 全局默认商店；同地图 /商店 直接回店（中断不丢）。
- **quest 联动**：NPC 发任务（dealer 牌池 quest 卡 + available_quests 过滤已领/已完成）→ quest_accept 接取。
- **图鉴联动**：intel 情报交付 → codex 条目点亮 + 图鉴回看出口（置灰不死胡同）。

### N-03 事件写入契约
- **职责**：补齐覆盖审计 #39 缺口——[事件:NPC对话:ID] + 5 个预置事件写入侧全契约。
- **6 个预置事件**：`[事件:NPC对话:ID]`（dialog 完成时写）/ `[事件:副本通关]`（dungeon 结算）/ `[事件:任务完成]`（quest_complete）/ `[事件:签到]`（checkin）/ `[事件:怪物击杀]`（battle 结算）/ `[事件:等级提升]`（levelup）。
- **双表写入管线**（ADR-05 修正版，防条件断链）：
  - `longline_counters`（3.7.1 ③ 只增不减，冒险日志累计）——3f D-01 日志数据源
  - `event_counts`（条件引擎读取源，condition_engine L570-571 `[事件:*]` 求值）——NPC/任务/隐藏要素条件消费
  - `bump_event(ctx, key)`：两表同写 + 事件实例日志（见下）
- **事件实例通道落点**（P1-4 收口，零新列零新表）：players.persistent_state["event_log"]（JSON 数组，环形 300，可配；条目=3f E-01 模型含 snapshot/first_seen/ts）——冒险日志 6 类记录（3f R-02）与 300 环形（3f E-01）存储地基，删除「可选」措辞。
- **消费方**：条件引擎读 event_counts；冒险日志读 event_log + longline_counters；与结算同事务 + message_id 幂等（3f R-02 写入原子性）。

### N-04 会话持久化与恢复
- **职责**：DialogSession 快照（to_snapshot/from_snapshot）落 ctx/玩家存档；中断恢复简报（「上次的『XX』未完成」+ 菜单层中断重显菜单 + 长叙述分段 page 索引恢复）。
- **已交付标记**：落玩家存档（不落会话快照，30 天回收不清，O03/O07）。
- **会话收尾**：结束词三词同义（离开/再见/退出）+ 菜单 N.离开；收尾清 dialog_active + 释放会话。
