## 一、副本结构（整体体验：一场完整的战斗/小游戏）

> **核心视角（用户拍板）：副本游玩 = 一场战斗/一次小游戏，是整体体验，不拆分看**
> 换区/子任务/探索版都是这场体验的内部节奏，不是独立模块
> **引导哲学（事件牌组参考）：主线引导进入新地区 → 事件牌组差异化支线 → 熟悉后自由行动 → 主线兜底拉回**

```
【整体体验单元】
副本（BOSS 版）= 一场完整战斗：
  进入 → 探索推进 → 精英遭遇 → BOSS 换区（随机区域）→ 玩家凭地图知识追击 → 决战
  · 玩家状态全程延续（HP/MP/资源/印记不重置）
  · 换区 = 这场战斗的阶段切换（残血逃跑→玩家走通道追击→继续打）
  · 子任务 = 这场体验的前菜（探索版先行熟悉）

副本（探索版）= 同一地图的"练习赛"（无 BOSS）
  · 熟悉通道链接/捷径/机制 → 为正式"比赛"（BOSS 版）准备
  · 是整体体验的一部分（同一赛场，两种赛制）

【节奏编排（事件卡组启示）】
平静（探索/熟悉）→ 升压（精英遭遇）→ 高潮（BOSS 换区追击）→ 决战（阶段机制）
放空（探索版松弛感）↔ 紧张（BOSS 战）——整体设计，不是散装模块
```

### 地图结构：网状（怪猎式，用户拍板）

```
❌ 线性：入口 → 回廊 → 核心 → BOSS 房（一条线，追 BOSS 无选择）
✅ 网状：多区域互相连通（节点+边，方向制）
   ┌─ 入口 ─ 回廊 ─┬─ 核心 ─ 龙王巢穴（BOSS）
   │              ├─ 熔岩坑道（捷径，单向门）
   └─ 岔道 ─ 矿洞 ─┘（绕路/宝箱/精英）

【通道结构（用户拍板：4 方向编辑）】
- 每地图编辑 4 个方向（上/下/左/右）的通向地图
- 双向 = 地图1↔地图2 互相有通道
- 单向 = 地图1→地图2 只有一边
- 捷径 = 绕路连通（地图1→地图2 单向，地图2→地图3→地图1 绕回）
- 隐藏通道 = 满足条件才显示/可走（可选）
```

### 示例：熔岩洞窟（网状地图）
```
探索版（练习赛）：熟悉网状结构（哪通哪/捷径/单向门/陷阱）
BOSS 版（正式赛）：BOSS 残血换区 → 提示"逃向了熔岩坑道"
  → 熟悉地图的玩家：走回廊→坑道捷径直追
  → 不熟悉的玩家：绕矿洞岔路（错过追击窗口/遇到精英）
```

## 二、换区机制（怪猎式：BOSS 战斗体验的一部分，用户拍板）

```
【换区 = BOSS 战斗体验的一部分（不是独立机制）】
- 换区条件：每 BOSS 独立配置（不同 BOSS 换区条件不同，可单独设计）
  · 血量阈值（残血换区）/ 阶段切换 / 特定行动后 / 自定义条件
  · 未配置换区条件 = BOSS 不换区
- 换区目标：策划配置候选区域列表（会去的地方）
  · BOSS 随机逃到候选区域之一（玩家凭地图知识判断去向）
  · 未配置候选区域 = 不换区
- 换区流程：
  BOSS 触发换区 → 提示"BOSS 逃向了 XX 区域"（随机候选）
  → 玩家 /进入 <方向> 走通道追击（网状地图路径选择）
  → 地图熟悉度 = 追击资源（熟悉=快追到，不熟=绕路/错过窗口）
- 找到 BOSS → 继续战斗（血量保持残血 + PV 恢复一半 + 开场技）
- 【退出规则（用户拍板）】：
  · 战斗进行中退出/超时/锁屏 = 战斗快照续玩（ai_state+combo_state 全保留，套内也可续）
  · 非战斗状态（已离开副本区域）离开 = 副本重置（下次满状态重打）
  · 恢复入口明示"战斗中断可续玩，离开副本将重置"
  · 安全区 /休息 ≠ 离开副本：不触发重置、不打断副本进度（见 §2.1 安全区恢复机制）
```

### 2.1 安全区恢复机制（/休息 指令）

> /休息 为战斗外指令（已登记框架 7.1 指令表），完整语义见效果系统定稿 §3.1【/休息 指令语义】；本节约定其在副本内的适用边界

【安全区定义】
- 安全区 = 进入副本的起始区（入口区）＋ dungeon.json 标记 safe_zone:true 的特定区域（可配）
- 安全区是副本内唯一的恢复点（§五 续航压力"副本内 HP/MP 不恢复"的唯一例外）

【安全区内使用 /休息】
- 可用性：仅安全区内可用 /休息；安全区外（普通区域/战斗进行中/BOSS 房）不可用
- 效果（与效果系统定稿 §3.1 一致，数值全部可配）：
  · HP/MP 部分恢复（默认各 20%，可配，倾向百分比）
  · 冷却缩减：当前冷却中的技能/特效冷却 −N 回合（默认 3，可配）
- 次数限制（防刷）：
  · 计入 /休息 每日使用次数（默认 3 次/天，可配，0=不限，随存档持久化）
  · 参考语义"副本安全区每副本一次/进入自动结算一次"保留为可配项
    （rest_per_dungeon：每副本 /休息 次数上限；rest_auto：进入安全区自动结算一次，默认关=手动使用）
- 与"退出=重置"衔接（§二 退出规则）：
  · 安全区休息 ≠ 离开副本：不改变位置、不退出副本、不触发重置
  · 副本进度/BOSS 血量/快照（ai_state+combo_state）全程保留，休息后继续推进不受影响
  · 仅"非战斗状态离开副本区域"触发重置
- 配置落点：dungeon.json（safe_zone/rest_per_dungeon/rest_auto 均为可配字段，缺省=入口区为安全区、手动使用）

### 2.2 副本内死亡处理（修复缺漏批2C）

> 死亡 ≠ 战斗中断：战斗中断（退出/超时/锁屏）= 快照续玩（§二 退出规则，ai_state+combo_state 全保留）；副本内死亡 = 战斗结算败北（HP 归零/全灭），按本节处理

```text
【死亡结算（默认建议，全部可配）】
- 复活点：退回副本入口（默认）；可配 dungeon.json death_policy.revive_point 指定区域（如 checkpoint 区）
- 复活点即"死亡后的安全区"：复活后可 /休息（按 §2.1 次数限制），虚弱结束后可继续推进
- 进度处理（可配三档）：
  ① checkpoint 回退（默认建议）：副本进度回退到最近 checkpoint（已清区域/BOSS 血量回到 checkpoint 记录状态），掉落/素材/已领奖励保留
  ② 重置副本：整个副本进度重置（下次满状态重打，与"离开=重置"同口径）
  ③ 无惩罚：仅复活，进度/BOSS 状态原样保留（低难探索副本适用）
- 副本未配置 checkpoint 时：checkpoint 回退自动降级为重置副本（最简兜底，不悬空）

【BOSS 状态（可配）】
- 保留（默认建议）：BOSS 血量/阶段保留（半血 BOSS 不重置）——死亡后重进继续打残血（配合 checkpoint 回退，挫败感最低）
- 重置：BOSS 满状态重打（与"离开=重置"统一，防反复试错磨血）
- 判定：boss_state: keep / reset，按 BOSS 独立可配（不同 BOSS 不同待遇）

【与"离开=重置"衔接（§二 退出规则）】
- 死亡 ≠ 离开副本：玩家仍算在副本内，进度按本节规则处理（不自动触发重置）
- 死亡后主动离开副本 = 重置（§二：非战斗状态离开副本区域 → 副本重置）
- 死亡惩罚=重置副本 时：等价于离开副本重置（下次进入满状态重打，入场限制正常结算）

【虚弱衔接（框架 3.12）】
- 复活后进入虚弱（默认 1 分钟，可配，框架 3.12）：期间可待在复活点/入口/安全区，不可进入非安全区区域（含 BOSS 房）——防立刻送死
- 虚弱期间副本进度/BOSS 状态按本节规则保持（不因虚弱额外重置）
- 配置落点：dungeon.json（death_policy: {revive_point, penalty, boss_state} + checkpoints 列表，可配；缺省=入口复活 + checkpoint 回退 + BOSS 保留）
```

### 换区配置（enemies.json / dungeon.json）
```json
// BOSS 换区配置（每 BOSS 独立）
"zone_change": {
  "trigger": { "type": "hp_below", "value": 30 },   // 换区条件（每 BOSS 自定义）；阶段阈值表见 enemies.json per-entity phases（档数不定死，默认 3 段示例值，见五）
  "targets": ["熔岩坑道", "矿洞"],                    // 候选区域（策划配，随机选一）
  "pv_recover": 0.5                                   // 换区后 PV 恢复一半
}
```

## 三、子任务探索（无 BOSS 地图熟悉）

### 3.1 设计目的
```
让玩家在无 BOSS 压力下探索熟悉副本地图：
- 地形/通道/捷径（哪里能走哪里不能走）
- 地图机制（落石/陷阱/机关/场地效果）
- 怪物分布（哪里有什么怪）
- 宝箱/采集点位置
- 提前学习：BOSS 房的机制预告（如"前方有灼热气息"）
```

### 3.2 子任务形式（quest.json）
```
- 探索任务：到达指定区域（"探索熔岩回廊的尽头"）
- 收集任务：收集地图特产（"采集 5 个熔岩矿石"）
- 清剿任务：击败该图精英（"击败熔岩甲虫"）
- 机制学习：触发地图机制（"成功躲避落石 3 次"）
- 情报任务：解锁图鉴情报（"收集熔岩霸王龙情报"）
奖励：经验/金币/素材/副本入口道具/图鉴进度
```

### 3.3 价值
```
1. 提前熟悉 → BOSS 战不迷茫（信息即资源）
2. 无压力探索 → 学习成本低（小白友好）
3. 奖励驱动 → 探索有回报
4. 图鉴情报预埋 → BOSS 机制预告
```


```
- 地图机制（落石/场地效果）两副本共用——探索副本先学会，BOSS 副本直接用
```

## 五、BOSS 房设计（高难 15 分钟+）

```
- BOSS：PV 200-500 + 行动表 4-6 招 + 特殊行动 2-4 个（阶段机制）
- 阶段机制（血量阈值）：阈值表进 enemies.json per-entity `phases: [{hp_from, hp_to, behavior}]`（HP% 区间：hp_from=高血端上限，hp_to=低血端下限；档数不定死，默认 3 段示例值）：
  phases: [
    { hp_from: 100, hp_to: 60, behavior: "阶段1·常规行动表" },
    { hp_from: 60, hp_to: 30,  behavior: "阶段2·狂暴（行动表强化+新招+换区 PV 恢复一半）" },
    { hp_from: 30, hp_to: 0,   behavior: "阶段3·绝境（大招循环+印记反制+连招锚点加速）" }
  ]   // 2/4 段 BOSS 内容包可增减档（档数不定死），换区 trigger 仍每 BOSS 自定义
- 高难博弈（战斗数值层 4.4 联动）：
  · PV 门禁：先破防再 debuff 爆发
  · 锚点连招：读招闪反（"火球后防尾扫"）
  · 印记反制：BOSS 叠印/清印（玩家消除博弈）
  · 续航压力：副本内 HP/MP 不恢复（长盘资源规划）；唯一例外=安全区 /休息（§2.1，有限次数，可配）
  · 换区 PV 恢复：BOSS 阶段切换重新破防
  · 死亡处理：BOSS 房死亡按 §2.2（复活点/checkpoint 回退/BOSS 状态保留或重置，全部可配）
```

```
掉落经济：副本素材 = 高级锻造/炼金材料来源
```

## 八、风险与简化

| 风险 | 对策 |
|---|---|
| 副本过长（15 分钟+ 碎片化冲突） | 中途退出进度保存 + 换区点续玩 + 子任务分段 |
| 副本内死亡挫败 | 复活点 + checkpoint 回退默认 + BOSS 残血保留（可配重置）+ 虚弱防送死（§2.2，全部可配） |
| 换区 PV 恢复挫败 | 换区提示明确（"防护值恢复了一半"）+ 破防爆发奖励节奏 |
| 子任务变主线负担 | 子任务可选（奖励驱动，不做也能打 BOSS） |
| 副本难度失衡 | 推荐等级（展示提示）+ 模拟器试算 + 难度档仅作默认值来源 |
