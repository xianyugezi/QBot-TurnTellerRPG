## 〇、机制定义（用户原话转译）

> **行动条** = (玩家敏捷 + 怪物敏捷) ÷ 2
> **差值** = |玩家敏捷 − 怪物敏捷|，累积记录给**敏捷高的一方**
> **触发**：当敏捷高的一方累积差值 ≥ 行动条数值时，该方**额外获得一次行动机会**

**直觉**：敏捷差距不是"每回合+几点先手"，而是累积成**行动频率优势**——你比怪快，打着打着就能多打一下。双方敏捷越接近，额外行动越少；差距越大，高敏方滚雪球越狠。

---

## 一、数学模型（已推演验证）

**定义**：设 A=玩家敏捷，B=怪物敏捷，T=行动条=(A+B)/2，d=|A−B|，acc=高敏方累积差值。

**触发频率公式**（近似）：
```
每触发一次所需回合 n ≈ T / d = (A+B) / (2|A−B|)
```

**60 回合实测（溢出保留模式）**：

| 敏捷比 | 例(A,B) | 行动条T | 差值d | 60回合额外行动 | 行动增幅 |
|---|---|---|---|---|---|
| 1.0 | (30,30) | 30 | 0 | 0 | +0%（无差距无额外） |
| 1.1 | (33,30) | 31.5 | 3 | 5 | +8% |
| 1.2 | (36,30) | 33 | 6 | 10 | +17% |
| 1.5 | (45,30) | 37.5 | 15 | 24 | **+40%** |
| 2.0 | (60,30) | 45 | 30 | 40 | **+67%** |
| 3.0 | (90,30) | 60 | 60 | 60 | **+100%**（每回合多动 1 次） |
| 0.8（怪快） | (24,30) | 27 | 6 | 13（给怪） | 怪 +22% |
| 0.5（怪快） | (15,30) | 22.5 | 15 | 40（给怪） | 怪 +67% |

**关键结论**：
1. **收益非线性递增**——敏捷差距越大，额外行动收益越陡（1.5 倍敏 +40%，2 倍敏 +67%）。这是设计意图（敏捷=行动频率资源），但要注意别让"堆敏捷"成为唯一最优解
2. **对称**：怪快则怪获得额外行动——公平，且让高敏怪有威胁（符合"只建议不限制"，玩家可堆敏反制或堆其他属性）
3. **敏捷相等 → 无额外行动**——差值 0 不累积，机制静默

## 二、触发结算规则（核心细节）

### 2.1 累积时机
- 每**回合末**结算一次：acc += d（给敏捷高的一方）
- 怪物回合结束后统一结算（不打断当前行动流程）

### 2.2 触发与消耗（★ 已拍板 2026-08-25：扣除制·溢出保留）

| 模式 | 行为 | 效果 |
|---|---|---|
| ~~A 清零制~~ | 触发后 acc 归 0，重新累积 | 节奏固定（每 n 回合一次） |
| **B 扣除制（溢出保留）✅ 拍板** | 触发后 acc −= T，余量保留 | 手感平滑不浪费；2 倍敏 = 60回合 40 次 |

### 2.3 额外行动形态（★ 已拍板 2026-08-25：立即行动）

| 模式 | 说明 |
|---|---|
| ~~A 下回合待行动~~ | — |
| **B 立即行动 ✅ 拍板** | 触发当下立刻多执行一次行动（当轮行动数 +1） |

### 2.4 行动机会转移语义（★ 已拍板 2026-08-25：核心表现）

> **触发回合 = 行动机会转移**：每回合正常节奏 = 玩家 1 动 + 怪物 1 动（共 2 个行动位）。当高敏方触发行动条时，**该回合高敏方 +1 行动、低敏方 −1 行动**——即总行动位不变，触发回合变成高敏方 2 动、低敏方 0 动。

**具体表现（用户原话拍板）**：
- **玩家敏捷 > 怪物，触发时** → 那个回合**怪物不返回攻击消息**（玩家连动 2 次，怪物 0 次）
- **怪物敏捷 > 玩家，触发时** → 返回**两条怪物行动消息**（怪物连动 2 次，玩家 0 次）

**回合消息流示例（玩家敏高，正常 vs 触发）**：

```text
正常回合：  玩家消息「你行动…」→ 怪物消息「怪物攻击…」
触发回合：  玩家消息「你行动…」→ 玩家消息「行动条满！你再次行动…」→（无怪物消息）
```

## 三、与现有战斗引擎的衔接

### 3.1 时序（对齐 M1 战斗核心）
```
回合开始 → 玩家行动（先手）→ 怪物反击槽（怪物行动）→ 回合末：行动条结算 acc += d
                                        ↓ acc ≥ T（当轮末结算，转移下轮行动位）
                                    下回合：高敏方 +1 动 / 低敏方 −1 动
```
> **注**：行动条在回合末结算，转移效果体现在**下一回合**的行动位分配（正常 1/1 → 触发后 2/0）。玩家敏高触发 → 下回合玩家 2 动、怪 0 动（无怪物消息）；怪敏高触发 → 下回合怪 2 动（两条怪消息）、玩家 0 动。

### 3.2 影响面
| 引擎模块 | 影响 | 落地 |
|---|---|---|
| M1 行动结算 | 行动次数 +1（当轮） | 战斗回合循环加"额外行动队列" |
| 怪物 AI（1f） | 怪物也能触发额外行动（高敏怪多动） | 怪行动计数 +1 |
| 伤害公式（M1 damage） | 无直接改动 | 额外行动=多一次伤害结算 |
| 快照/续玩（1g3） | acc 值需入存档快照 | ai_state 加 action_bar 字段 |
| 属性系统 | 敏捷新增"行动频率"维度（原=闪避/身位） | 敏捷价值上升，见 §五 |

### 3.3 存档字段（新增）
```
battle.action_bar = { acc: 累积差值, owner: "player"|"monster" }
```

## 四、边界与异常（实现者踩坑清单）

| # | 情况 | 处理 |
|---|---|---|
| E1 | 敏捷相等（d=0） | acc 恒 0，机制静默（不产生额外行动）——正常 |
| E2 | 敏捷差值极大（d ≥ T） | 每回合都触发（3 倍敏 = 每回合 +1 动）——高敏碾压合法，数值把关 |
| E3 | 额外行动时怪物已死亡 | 额外行动不执行（目标无），acc 清零 |
| E4 | 额外行动时玩家已死亡 | 不执行，战斗结束 |
| E5 | 多怪战斗（若框架支持） | 行动条按"每只怪单独"或"取最高"？——**待定**（框架当前 1v1） |
| E6 | 额外行动可用防御/闪避 | 允许（战术价值：多一次防御=高敏的生存面） |
| E7 | 与"先手权/行动顺序"其他规则冲突 | 本机制只加行动次数，不改顺序；先手仍按现有规则 |

## 五、平衡影响分析（职业设计联动）

### 5.1 敏捷属性价值重塑
- 原：敏捷 = 闪避（等效）/ 身位（命中修正）
- 新增：敏捷 = **行动频率**（额外行动）
- 后果：敏捷从"防御/机动副属性"升级为"攻防一体的成长属性"——**主敏职业（刺客/游击流）的收益大幅上升**

### 5.2 对已有职业的影响
| 职业 | 影响 |
|---|---|
| 主力量职业（巨剑士等） | 敏捷低 → 不触发额外行动，但面板倍率高（等价换行动）——定价对称 |
| 主敏捷职业（双剑客/刺客） | 天然多行动 → 高频输出，但单发低倍率——符合"高频 vs 高倍率"设计光谱 |
| 怪物高敏（如蜂群/风系） | 玩家会被多打——反制=堆敏或控怪 |

### 5.3 对百式灵武（连招职业）的联动
- 灵武若走**主敏捷**（风缠游击流），行动条机制让每回合多一段连招积累 → **连招成型速度加快**（跨回合累积的核心痛点被缓解）——这是本机制与连招机制的最佳化学反应
- 建议：百式灵武流派 C 可标注"主敏捷吃行动条红利"
