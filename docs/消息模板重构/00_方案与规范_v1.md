## 三、手机QQ 排版规范 v1（强制）

**宽度体系**：全角字符 = 2、半角 = 1（单位：半角当量）。
**单行安全预算 B = 28 半角（14 全角）**——2026-09-12 用户实机标定：14 全角可完全显示、15 全角折行；
结构化行按 14 封顶设计（能 13 以内更稳），大数值场景见「数值政策」。

**分类规则**：
- **结构化行**（列表行/键值行/数值行/状态行/提示行/分隔行）：必须 ≤ B，**禁止依赖自动换行**；
  超宽必须重排：拆行 / 精简 / 去对齐空格。
- **介绍类文本**（地图介绍、物品描述、风味叙事、教程引导段落）：不限宽，自然折行**允许**。
- **对齐**：禁止空格对齐（手机非等宽渲染）；字段默认「分行」呈现——**少用 ｜，多换行**（2026-09-12 拍板）；
  ｜ 仅作少量并列短字段的最后手段，禁止依赖 ｜/空格 挤宽。
- **标记**：✅❌【】「」｜ 保留；零装饰 emoji（既有铁律）。
- **拆行优先序**：① 多字段行 → 每行一字段；② 长句 → 按语义断句；③ 冗余词精简（不改变语义/语气）。
- **数值政策（大数值防爆宽）**：数值行按「可达百万/千万级」设计——数值与单位/标签不可被拆断；
  数值独立行（7~9 位数字独立行仍可单行容纳）；仍超宽时用紧凑记数（如 128.4万）；验收含大数值样本压测。
- **指令书写**：新文案一律免斜杠（对齐全局免前缀模式）——「发 注册 名字 职业」「发 任务 领取 <序号>」；
  参数占位写 <…>，多选一写「或」（替代 ｜）。旧文案 /斜杠 写法属旧规范，重做时去除（GM/管理类可保留）。
- **错误行**：❌ + 原因（+ 需要时「下一步」）；单行 ≤14，必要时拆两行。
- 分隔线长度 ≤ 12 全角；行首尾不留多余空格。

**重做原则（三条）**：
1. 文案按本规范独立撰写，**不照抄旧文**（旧版仅用于确认信息要素与场景，非文案来源）；
2. **信息要素逐条核对**：占位符集合与触发场景以代码为准，不丢字段、不改语义；
3. 功能等价：不新增、不删减机制信息；key 名保留（兼容 835 处渲染调用）。

**示例（旧版将清除 → 新版样例，按规范重做）**：

```
【示例① 注册收尾】
旧版：职业：脊剑士（推荐新手） ｜ 位置：龙骨驿站
      下一步：发 任务 领取 1 接见面礼；发 位置 看出口，进入 下 去骸骨草场，发 怪物 锁定 1 开战。
新版：职业：脊剑士（推荐新手）
      位置：龙骨驿站

      发 任务 领取 1 接见面礼

【示例② 战斗状态行（少｜多换行 + 大数值预留）】
```
