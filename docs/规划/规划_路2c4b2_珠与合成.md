## ① 珠体系（装饰珠数据模型 + 珠三合一升阶）

- **定稿章节**：炼金定稿 §六 装饰珠专项（6.1 规格 / 6.2 两套词条 / 6.3 珠规则）；§10.1 字段映射表（珠三合一升阶 = 合成引擎 kind=upgrade 配置实例）；§10.3 items.json 扩展（type 补「装饰珠」/ base_effects）；§10.5 存档（珠实例堆叠键 = ID+品质档+特性集）；§10.6 settings alchemy 段（gem.珠升阶=10）。
- **实现要点**：
  - 数据模型：items.json `type` 补「装饰珠」；slots.json 补 `slot_level`；珠等级 = 品质档（普通/精良/史诗/传说）；槽级→珠档映射：1 级=普通、2 级=精良及以下、3 级=全部（§6.1）。
  - 两套词条（§6.2）：`base_effects`（珠基础效果，固定数值，标准珠=只有这个）；`traits`（继承特性，品质浮动 + 可继承，炼金珠独有）。
  - 珠三合一升阶（§6.3 + §10.1 映射表）：合成引擎 `kind=upgrade` 配置实例——inputs = 3×同档珠（普通→精良→史诗→传说），cost = 宝石 10（settings `gem.珠升阶` 可配），output = 珠 +1 阶、**原数值不变**；**档位链连续**：普通×3→精良 → 精良×3→史诗 → 史诗×3→传说，传说为终点（滚雪球终点）。
  - 珠规则（§6.3）：绑定默认（防交易刷珠）；同名递减=**乘法叠加**（第 2 颗 ×50%、第 3 颗 ×25%）；触发上限=战斗内特效触发 ≤3 次/场（按珠 ID 计、排除被动常驻，计数落战斗快照，与 `battle_alchemy_used` 同层）；战斗中不可插拔（战前换珠=核心策略）。
  - 存档（§10.5）：珠实例堆叠键 = ID+品质档+特性集。
- **验收标准**：三同档珠 + 10 宝石 → 高一档珠且原数值不变；档位链逐级连续可升到传说，传说再升被拒并提示已达最高档；珠数/宝石不足原子全拒并提示差异（对齐 §3.2）；标准珠仅含 base_effects（无 traits 断言）；同名珠第 2 颗 ×50%、第 3 颗 ×25% 乘法叠加数值正确；战斗内特效触发 ≤3 次/场且计数入战斗快照、中断恢复不清零。

## ② 复制（量贩复制）

- **定稿章节**：炼金定稿 §5.2#10（量贩复制：大师解锁，先 /登记 后 /复制，消耗宝石+材料，量产标准版）；§9 指令总表（/复制 /登记：大师+宝石）；§1.3 边界铁律（深度层产物不绕过玩法；标准版无特性）；§3.2 原子校验（材料+金币全量满足才执行）；§10.6 settings（gem.复制=0.2 = 制作成本 ×20% 宝石，可配）。
- **实现要点**：
  - 指令：`/登记 <道具>` 注册可复制模板（先登记后复制，未登记报错模板「未登记复制」）；`/复制 <道具>*<数量>` 量产标准版（数量分隔符 `*` 按统一规范）。
  - 消耗：宝石 = 制作成本 ×20%（settings `gem.复制` 可配）+ 材料 = 配方 materials × 数量；原子校验全量满足才执行，不足全拒并提示差异。
  - 产出：标准版（无特性/无超特性/无进化/无核心类，对齐 §1.3 边界铁律「合成只产标准版」）。
  - 结算：单条消息零会话，走「SQLite 事务 + message_id 幂等 + version」防双扣（V11 同款）。
- **验收标准**：未登记 /复制 →「未登记复制」错误模板；登记后复制成功、产出为标准版（无特性断言）；宝石按成本×20%、材料按配方数量全量扣除；任一不足全拒并提示差异；同 message_id 重发不双扣；大师以下不可用。

## ③ 成品合成

- **定稿章节**：炼金定稿 §5.2#5（成品合成：宗师解锁，/成品合成 A+B，两成品+材料 → 更强成品，消耗宝石+材料）；§5.4 深度流程示例（`/成品合成 炼狱爆弹·改 ×2 → 灭世爆弹（宝石 10）`）；§10.1 字段映射表（成品合成 = kind=upgrade：inputs=两成品+材料、cost=宝石 10+材料、output=更强成品）；§10.6 settings（gem.成品合成=10）。
- **实现要点**：
  - 指令：`/成品合成 A B`（两成品 + 可选材料参数）；宗师解锁；宝石 10/次（settings `gem.成品合成` 可配）。
  - 配置：合成引擎 `kind=upgrade` 配置实例——inputs = 两成品（+材料），cost = 宝石 10 + 材料，output = 更强成品（效果按配置，如 炼狱爆弹·改 ×2 → 灭世爆弹）。
  - 原子校验：两成品 + 材料 + 宝石全量满足才执行，不足全拒并提示差异；单条消息零会话 + message_id 幂等（V11 同款）。
- **验收标准**：指定组合（两成品+材料+10 宝石）→ 更强成品入包且效果按配置提升；任一不足全拒并提示差异；同 message_id 重发不双扣；宗师以下不可用；输出物品质量/效果与配置一致。

## ④ 配方合成

- **定稿章节**：炼金定稿 §5.2#11（配方合成：专家解锁，/配方合成 A+B，两配方已学，消耗宝石，预置组合表解锁新配方）；§10.1 字段映射表（配方合成 = kind=upgrade：inputs=两配方（已学）、cost=宝石 5、output=新配方解锁）；§10.4（玩家级配方解锁表：SQLite，配方ID+解锁来源+条件；配方合成表：预置组合表 2输入+1输出+条件）；§10.6 settings（gem.配方合成=5）；§13 编辑器校验器（引用校验/无环）。
- **实现要点**：
  - 指令：`/配方合成 A B`；专家解锁；宝石 5/次（settings `gem.配方合成` 可配）。
  - 前置校验：A、B 均已学（查玩家级配方解锁表 SQLite）→ 按预置组合表（2 输入+1 输出+条件）命中 → 解锁新配方（永久写入玩家级解锁表）；未知组合 → 提示无此组合。
  - 幂等：目标配方已解锁 → 提示「已解锁」且不重复扣宝石（对齐 §4.6 幂等语义）。
  - 配置校验（§13）：组合表输入配方引用存在、输出唯一、条件可判定、进化线无环。
- **验收标准**：A、B 已学 + 5 宝石 → 新配方永久解锁（写入玩家级解锁表断言）；未学会其一 → 拒绝并提示；重复合成 → 已解锁提示、零扣费；未知组合 → 明确提示；专家以下不可用；组合表违规配置被校验器检出。

## ⑤ 特性合成

- **定稿章节**：炼金定稿 §5.2#17（特性合成：宗师解锁，/特性合成 A+B，两同系特性，消耗宝石+材料，融合升级为更高位特性——高品質Lv1×Lv2=更高级，极限 build 天花板）；§5.4 示例（`/特性合成 攻击+15% + 攻击+10% → ✅ 攻击+25%（更高位特性）`）；§10.1 字段映射表（特性合成 = kind=upgrade：inputs=2 同系特性、cost=宝石 20+材料、output=更高位特性）；§10.2 traits.json（group 互斥组：组内最多 1 项；repeatable；rarity normal/super）；§10.6 settings（gem.特性合成=20）。
- **实现要点**：
  - 指令：`/特性合成 A B`；宗师解锁；宝石 20/次 + 材料（settings `gem.特性合成` 可配）。
  - 规则：两特性须同系（同 group/同系判定）；结果 = 更高位特性（示例对齐：攻击+15% × 攻击+10% → 攻击+25%）；稀有度继承规则按配置（normal/super）。
  - 冲突规则（§10.2）：产出特性落位时校验 group 互斥组（组内最多 1 项）与 repeatable；与特性继承同套校验。
  - 原子校验：两特性 + 宝石 + 材料全量满足才执行，不足全拒并提示差异；单条消息零会话 + message_id 幂等。
- **验收标准**：两同系特性 + 20 宝石 + 材料 → 更高位特性（示例逐字对齐：攻击+15%+攻击+10%→攻击+25%）；非同系 → 拒绝并提示；宝石/材料不足全拒；宗师以下不可用；产出特性满足 group 互斥（组内最多 1）与 repeatable 规则。

## ⑥ 镶嵌 / 镶核心

- **定稿章节**：炼金定稿 §6.1（开槽：锻造/掉落/炼金产出开槽道具，可配；槽级→珠档映射 1=普通/2=精良及以下/3=全部）；§6.3（指令 `/镶嵌 <珠> <装备>` `/拆珠 <装备> <槽位>`：无损；绑定默认；战斗中不可插拔）；§5.2#4（核心镶嵌：大师解锁，/镶核心 消耗核心物品 → 品质上限+X/属性适配，可换）；§9 指令总表（/镶核心：大师、会话中；/镶嵌 /拆珠：通用、槽级≥珠级）；§10.5（珠实例堆叠键）。
- **实现要点**：
  - `/镶嵌 <珠> <装备>`：槽级≥珠级才可镶嵌（槽级映射查 slots.json slot_level），绑定入装（珠绑定默认防交易刷珠）；战斗中拒绝插拔（战前换珠=核心策略）。
  - `/拆珠 <装备> <槽位>`：无损拆下（珠按堆叠键返还，无损耗）。
  - `/镶核心 <核心>`：大师解锁、调合会话中执行；消耗核心物品（核心消耗）；效果=品质上限+X/属性适配（按配置）；**可换**：替换旧核心按配置处理（消耗/返还）。
  - 生效挂载：同名珠乘法递减（第 2 颗 ×50%、第 3 颗 ×25%）与战斗内特效 ≤3 次/场计数随镶嵌生效（复用任务①）。
- **验收标准**：槽级≥珠级才可镶嵌、槽级不足拒绝并提示；/拆珠 无损返还珠；战斗中 /镶嵌 /拆珠 被拒；/镶核心 消耗核心、装备获得品质上限+X/属性适配且可换；大师以下 /镶核心 不可用；镶嵌后同名递减与触发上限正确生效。

## ⑦ 分解（分解回炉）

- **定稿章节**：炼金定稿 §4.5（第 2 层开放低级分解；回收率随等级 40%→60%，档位曲线=称号档跳变，可配；分解对象限制：仅炼金/深度炼金产出可分解，标准版不可分解或回收减半——防商店套宝石漏洞；返还=配方材料×回收率向下取整）；§5.2#9（分解回炉：大师解锁，/分解 任意炼金成品 → 回收 40-60% + 产出宝石）；§5.3 宝石经济（宝石=炼金专属货币：分解产出+挑战奖励+部分怪掉落；分解基础值：普通 1/精良 3/史诗 8/传说 20）；§10.6 settings（decompose_rate：正式 0.4/精通 0.45/专家 0.5/大师 0.55/宗师 0.6/王 0.65；gem.分解）。
- **实现要点**：
  - 指令：`/分解 <道具>`；门槛=仅炼金/深度炼金产出可分解（标准版不可分解或回收减半，按配置；非炼金产出拒绝）。
  - 返还：配方材料 × 回收率**向下取整**（对齐 §4.5）；回收率按称号档跳变查 settings `decompose_rate`（正式 0.4 → 王 0.65，可配）。
  - 宝石产出：按成品品质档基础值（普通 1/精良 3/史诗 8/传说 20，settings `gem.分解` 可配）；宝石=炼金专属货币，与 gem 消耗（升阶/复制/合成）闭环。
  - 结算：道具移除、材料+宝石入包同一事务；单条消息零会话 + message_id 幂等。
- **验收标准**：炼金产出分解 → 材料×回收率向下取整 + 按品质档基础值宝石入包、道具消失；标准版分解被拒（或回收减半，按配置）；非炼金产出被拒；回收率随称号档跳变正确（如 正式 0.4→精通 0.45）；宝石数额与品质档基础值一致；同 message_id 重发不双份返还。

## 实施顺序建议（依赖拓扑）

1. ①珠体系（数据模型 + 珠升阶 upgrade 实例）→ ②③④⑤ 四类 upgrade 合成指令（共用「原子校验 + message_id 幂等」结算管线）；
2. ⑥镶嵌/镶核心（依赖①的珠实例与槽级模型）；⑦分解（独立，依赖品质注册表与配方材料回溯）；
3. 各 upgrade 配置实例统一落 recipe.json（kind=upgrade），校验器复用 §13 编辑器校验规则（引用存在/无环）。

## 不变量（跨系统硬约束）

- 合成引擎 = 框架机制（代码），本系统 = kind=upgrade 配置实例（JSON）——机制与内容分离，四类合成（珠升阶/特性/成品/配方）字段映射统一走 §10.1 表（inputs/cost/output）；
- 品质四档唯一注册表 = items.json（normal/fine/epic/legendary），分解宝石基础值与珠档位只引用不重复定义；
- 结算防双扣统一走「SQLite 事务 + message_id 幂等 + version」（V11 同款，与路2b C5 / 路2c3 B4 同模式）；
- 复制产出 = 标准版（无特性/无超特性/无进化/无核心类，§1.3 边界铁律）；
- 分解对象限制写死（仅炼金/深度炼金产出），防商店套宝石漏洞（§4.5）；
- 战斗内珠特效计数与即时调合限次同落战斗快照（`battle_alchemy_used` 同层），中断恢复不清零。
