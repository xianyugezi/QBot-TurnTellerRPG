## 一、三路交叉结论（一句话）

1. **它是一条"并列的新产线"，不是 `forge` 的补丁** —— 但我们**不需要新造第二套**：材料/套装/客制/强化数值层/词条键空间/孔位镶嵌/实例化/分解回收，**七个既有件都能复用**（A 路）。
2. **但有两个"地基缺失"必须补，否则后面全是空中楼阁**（C 路）：
   - **装备实例没有落档的唯一键** —— 同 `item_id` 的两件随机词条装备，跨存档/重登后**会聚合错实例的词条**（`data/item.py:20-39`、`data/player.py:57-69` 均无 uid；`core/equipment.py:43-46` 自述这是"未解项，登记 M9 前置"）；
   - **随机流不可推进** —— `ctx["rng"]` 按 qid 定种、每条指令重建同 seed ⇒ 同一玩家反复打造会走出**同一条随机序列**（"每次打造随机"直接落空）。**同一个坑当年战斗 AI 踩过**（黑盒实测"泽骨鳄单招 19 连"），现成的修法是引擎侧 `rng_state` 持久化 + 逐指令推进（`core/battle.py:5316,5409-5424`）。
3. **数值上最大风险不是强化，是品质乘区**（B 路）：装备已占面板 40%（白值7:装备8:buff5 口径），品质系数若做 0.7–1.8，面板总倍率会到 0.755–1.195 → **建议压到 0.80–1.50**。
4. **你给的品质概率表可以补全且自洽**（B 路）：铜表 10 行 + 你给的 3 行，恰好构成**13 行共享行号阶梯**；银/金/彩 = 铜表整体上移 1/2/3 行；**每行概率和 = 100 ✅、色序期望单调 ✅、红色只在第 10 行起出现且铜行10 = 5% ✅**（与你说的"红只有 10 级 5%"完全一致）。

## 三、设计骨架（A 路 schema 草案的摘要）

**复用（不新造）**：`forge`（材料/套装/客制/设置段）· `enhance`（强化数值层）· `items`+`gear_stats`（词条键空间，**新增词条=注册表加一行**）· `slots`+`jewel`（孔位与镶嵌）· `ItemInstance`（已有随机词条位）· `gem_wallet`（分解回收）· `max_hold`（唯一图纸"不可交易/唯一"）

**新增（核心）**：
1. **图纸 `blueprint`**（作为 `items` 的一种：固定材料槽 + 自由槽数 + 图纸档 铜/银/金/彩 + 等级带 + 相性 + 固定 1~3 属性 + 0~2 随机位 + 套装词条 1 固定 + 0~2 随机 + 固定被动）
2. **材料相性词缀**（材料带相性值：月光/冰晶/炎火…；相性间**冲突（减）/增幅（加）/反转（转换）**；**按投入顺序结算**）
3. **相性池**：`通用池 + 专属池`（**特殊联动触发时覆盖专属池**）；随机属性/套装词条/强化词条**从主相性池抽**；工程形态 = **单池 + "可用词条集"过滤**（即你说的"本质一个池子，没相性就抽不出来"）
4. **符文**（三孔 / 三阶 / 3 合 1 进阶 / 同符文按装备类型差异 / 1 阶纯数值、2 阶起特殊、3 阶偏向）
5. **淬炼**（按装备等级给总上限 + 单项上限；消耗精粹；精粹来自分解）
6. **打造参数**（品质经验、cost、等级加权、随机条数、概率表）

**已可"纯配置先行"**：图纸作为物品 + 不可交易（复用 `bind`/`max_hold`）✓

## 四、品质经验规划（B 路 · 你点名要的那件）

**模型提案（可算、可调）**：
```
单次打造品质经验 = Σ over 投入材料 [ 材料品阶基数 × 相性加成系数 × 件数边际 × 互动乘子 ] × 全局衰减
投入 cost 约束 = 总 cost 上限（按图纸档缩放）+ 每材料 cost（数量×单价）
```
- **你要的玩法完整保留**：玩家在**满足 cost 的前提下堆高经验**（这是"取舍"，不是"无脑堆"）。
- **⚠️ 必须补两条约束，否则出现"单一最优解"**（B 路实测推演结论）：
  1. **图纸声明等级带 + 主材料槽**（否则纯经验最大化会用**低阶便宜材料填满预算** → 装备等级被压低但品质却很高）；
  2. **cost 上限随图纸档缩放**。
- **时间黑洞风险可控**：第 10 级阈值 ≈ **4040 cost**，而合理上限 4200 → **超投空间只有 ~4%**；教训是**把总 cost 上限钉在"刚好到 10 级 + 少量冗余"**。
- **概率表补全**：13 行阶梯（银/金/彩 = 铜表上移 1/2/3 行），每行和 100 ✅，可直接落成数据。
