## P1（行号引错或引用不承载所声称语义，内容为细化自行推导却挂在他人行号上）

### P1-1 D-06「quest 不配置 board 即天然不上板（对齐 2b4 quest.board 默认值兜底）」——与 2b4 实际默认值语义相悖
- **出错位置**：细化 §0.3 D-06（L54）、§三 3.3 载体（L248）「quest 不上任务板（D-06：不配置 board 即天然不上板）…（对齐 2b4 quest.board 默认值兜底）——零新字段」。
- **2b4 实际**：`细化_2b4_任务引擎契约.md` §1.3 L99/L105：`board.slot` 枚举仅 `daily|weekly|event`，**无 none/off 值**；L105 明示「**default 板兜底：漏配 board = {slot:"daily", refresh:"daily", limit:0, accept_limit:5, daily_limit:10}**（D-07）」；§1.5 L123 兜底清单中 board 不在 null 之列。即按 2b4 语义，**不配置 board 的任务默认上每日板**，恰与「天然不上板」相反；且 2b4 亦无任何"不上板"开关字段（slot 无 none、无 off-board 标记），实现侧无零新字段可达该语义的路径。
- **影响**：定稿 L26 明确要求「quest 不上任务板」（隐藏任务不上板是隐藏性的核心），细化忠实转述了定稿，但把实现依据错误挂在 2b4 默认值兜底上——若照此接线，隐藏任务会出现在每日任务板，直接违背不提示原则（【单机】L5/L19/L26）。需显式收敛（如给 2b4 board.slot 增 `none` 值/或校验器对隐藏类任务上板黄提示/或为本包新增 off-board 显式标记），不能声称"零新字段+对齐默认值兜底"。对定稿本身无失实，属同族细化交叉口径事实性错误，计 1 条 P1。
