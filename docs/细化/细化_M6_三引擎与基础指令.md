### 0.3 接缝裁决（B-x，段落式；对母契约留白/跨契约交叉处本档取点，不重复裁决）

**B-1（经验曲线默认值）**：定稿仅定义「经验曲线/职业成长率：内容包配置」（【框架】L126）未给数值；本档取点：内容包未配曲线时用默认曲线 `exp_to_next(lv) = 100 × lv`（lv=当前等级，1 级升 2 级需 100，线性可配）【工程补白】。等级上限默认 45（对齐定稿 L296 示例「如 45 级」），内容包 settings 可配。依据 L126/L296。

**B-2（装备引擎消费接口形态）**：`basic_commands.py` 命令壳现消费 `equip_wear(index, ctx)` / `equip_remove(slot_id, ctx)` → `{ok, message}`（文件头「消费接口」段 L36-39）；core 骨架签名是 `equip(player, item, slot)` / `unequip(player, slot)`。本档裁决：**core EquipmentEngine 以骨架签名为主接口（纯逻辑，player 入参）**，命令壳通过薄适配层调用引擎后组装 `{ok, message}`，保持命令壳既有消费契约不变（不破坏 test_basic_commands 既有用例）；适配落点见 EQP-12。依据：basic_commands.py L36-39/L985-1017；【审查·批4A】1.5 实况。

**B-3（装备栏槽位引用形态）**：4b EQP-01 定义 `equipment = {slot_id: instance_id}`（引用背包行实例）；现有 `data/player.py` `Player.equipment: Dict[str, EquipmentSlot]` 为**槽位 → 槽对象内嵌冗余**（item_id/name/slot_level/locked/gems）。本档裁决：**引擎操作以 data/player.py 领域类型为准（3a D-03 唯一落点）**，槽位引用形态差异登记为既有实现事实，引擎穿/脱时同步维护背包行 `ItemInstance.slot` 与 `Player.equipment` 两者一致（双向一致性见 EQP-05/EQP-12）。依据：data/player.py L89；【4b】EQP-01；3a D-03。

**B-4（inventory 超上限双口径并存）**：4b INV-R04（单次入包数量上限 99 截断+提示）与 INV-R05（背包格数 capacity 默认不限、可配）两口径并存。本档裁决：**add_item 的「数量截断」作用于单次 add 的 count 参数；「格数上限」作用于背包总行数**，两条独立校验、互不替代，实现按 INV-R04/R05 各自落位（INV-09/INV-11）。依据：【4b】L344/L218。

### 1.3 边界异常（LVL-E1 ~ LVL-E4，段落式；不计入规则数）

**LVL-E1（amount = 0 或负数）**：幂等拒绝，不抛异常，`{ok: False, reason: "exp_amount_invalid"}`。依据 LVL-02。

**LVL-E2（满级后再次入账）**：经验不增长，`{ok: True, level_ups: 0, exp_next: 0}`（不提示升级）。依据 LVL-03。

**LVL-E3（自由加点非法属性）**：拒绝并提示「属性不存在」（值域文案，不走 TPL-12 指令错误）。依据 LVL-08；【3b】ADR-05。
