## 二、瀑式解锁依赖（CASC）

> 依据：【炼金】§1.1 L16-28（三层漏斗）、§1.2 L30-41（资源循环）、§1.3 L43-47（边界铁律）、§2.1 L58-61（熟练/等级/区间）、§2.3 L81-89（每级解锁明细+王称号）、§2.4 L91-98（能量条）、§3.1 L104-107（合成解锁/synth_allowed）、§4.6 L184（会话分离）、§5.2 L195-218（机制四要素）、§九 L318-342（指令门槛）、§十四 L498-510（风险）。编号 CASC-01 ~ CASC-10。

### 2.1 瀑式解锁总链（CASC-01 ~ CASC-02）

```text
合成层（保底通道，任一制造/资源技能达标即开）
  │  CASC-01：合成每个成品 = 配方等级 ×1 熟练；熟练经验来源=制作(合成/炼金/锻造)+采集+战斗 → 推动职业等级成长
  ▼
炼金层（炼金职业见习起步：投料/品质/一键投料/单批量 + 能量条）
  │  CASC-02：职业等级与角色等级独立；job_tier_map 称号↔配方等级区间（见习1-5→…→大师31-40→…→王51+）
  │  炼金产出/熟练持续累积 → 等级晋升（精通属性刻度显现 → 专家触媒/配方合成 →）
  ▼
深度炼金层（炼金职业等级 ≥ 大师：完全体机制）
  └─ 王（图鉴全点亮 → 终极称号炼金王 + 专属配方 + 称号加成）  （CASC-06）
```

| # | 规则 | 行为 | 引用 |
|---|---|---|---|
| CASC-01 | 合成是瀑式的熟练入口 | 合成给熟练经验（每个成品 = 配方等级 ×1，可配）且不耗能量，作为长线可重复的成长通道；熟练经验来源=制作（合成/炼金/锻造）+采集+战斗，打通「合成 → 熟练 → 等级 → 上层解锁」链条 | 【炼金】L59 / L97 / L116 / L120 |
| CASC-02 | 等级独立+区间映射 | 职业等级与角色等级独立；`settings.json job_tier_map`：称号→配方等级区间（见习 1-5/正式 6-10/精通 11-20/专家 21-30/大师 31-40/宗师 41-50/王 51+）——配方 level 落在当前称号区间才可调合/合成 | 【炼金】L60-61 |

### 2.2 防跳层规则（CASC-03 ~ CASC-10）

> 定稿原则：**深度必须经炼金层达标**——深度炼金解锁条件写死为「炼金职业等级 ≥ 大师」（L25/L192），不存在从合成层直接获得深度产出的路径（CASC-03/CASC-04）；不允许用合成层产出代替炼金层产出去推动深度层进度（CASC-05/CASC-06）；深度层操作全部有独立指令门槛与会话类型（CASC-07/CASC-08）；炼金层深化技能随等级逐级开放（CASC-09）。

| # | 防跳规则 | 行为 | 引用 |
|---|---|---|---|
| CASC-03 | 深度必须经炼金层达标 | 深度炼金解锁条件 = 炼金职业等级 ≥ 大师（写死，非「任一职业达标」）；合成层通用达标逻辑（CASC/LAY-01）不适用于深度层 | 【炼金】L25 / L85 / L192 |
| CASC-04 | 深度配方合成拦截 | 深度层配方 `synth_allowed` 默认 false（可配）；默认态 /合成 深度配方 → 拒绝（错误模板「深度未解锁」类）；若内容包改为 true → 可合成但必须提示「此深度配方可被合成，将绕过深度炼金玩法」（提示不阻断，防跳语义已显式向配置者暴露） | 【炼金】L47 / L106 / L503 |
| CASC-05 | 进化计数防跳 | 配方进化线前置 = 「低阶配方**炼金产出** N 次（**合成不计**）」；玩家用 /合成 刷 N 次 → /进化 条件不满足，拒绝 | 【炼金】L200 / L326 |
| CASC-06 | 王称号防跳 | 王 = 终极称号（炼金王）条件 = 该职业**图鉴全点亮**（与等级区间解耦）；图鉴成长仅由炼金/深度炼金产出点亮（合成图鉴仅小加成，不点亮炼金图鉴条目）；未全点亮 → 不授予/无专属配方/无称号加成 | 【炼金】L87 / L89 / L120 / L210 |
| CASC-07 | 指令门槛防跳 | 指令表门槛列逐条落地：/深度炼金=大师+能量；/进化=宗师+炼金产出 N 次；/挑战=宗师+材料×2；/即时调合=大师+能量（限 1 次/场）；/镶核心 /加成=大师/宗师；/成品合成 /特性合成=宗师+宝石；/配方合成=专家+宝石 | 【炼金】L325-332 / L335-336 |
| CASC-08 | 会话类型分离 | /深度炼金 与 /炼金 为**不同会话类型**（分开），深度层机制操作必须在深度会话内进行；挑战调合/挂起恢复不得跨层混用 | 【炼金】L184 / L325 / L335 |
| CASC-09 | 特性继承等级化 | 特性继承位随等级逐级开放（正式 1 项 → 精通 2 项 → 专家 3 项），见习无继承位——炼金层深化能力不可一步到位；SP 面板另可解锁特性位+1（可多次） | 【炼金】L81-84 / L70 |
| CASC-10 | 能量软门槛 | 每次炼金/深度炼金消耗 1 格能量，上限随职业等级提升（见习 5 → 王 20，可配），30 分钟回 1 格——软节奏防无限刷；能量空不强卡：/合成 保底通道不耗能量、永可用 | 【炼金】L91-98 / L416 |
