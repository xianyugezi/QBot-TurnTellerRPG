## 一、分隔符全集（7 种）

> 总纲一句话：**空格分参数，`*` 连数量，`,` 列列表，`=` 键值，`+` 标等级，`-` 表连招，`>` 指路径** [L6]。
> 记忆口诀：空格是“切”，`*` 是“乘”（数量），`,` 是“列”，`=` 是“定”，`+ - >` 是“状态”（等级/连招/路径）[L23]。

### 1.1 分隔符语义表

| # | 符号 | 名称 | 职责 | 语法 | 合法示例 | 禁止用法（反例） | 引用 |
|---|---|---|---|---|---|---|---|
| D01 | 空格 | 参数分隔符 | 分隔指令名与参数、参数与参数（**唯一**） | `指令名 参数1 参数2`（位置参数 ≤2） | `/攻击 2` · `/镶嵌 火珠 铁剑` | 不用空格表达数量（`/使用 药水 10` 为旧格式，仅兼容回退） | L15、L46-51、L238-239 |
| D02 | `*` | 数量连接符 | 物品/材料/目标 与 份数 绑成一个参数 | `对象*数量`（**`*` 后必须为纯数字**） | `/使用 经验药水*10` · `/购买 药水*5` · `/投料 火晶石*2` · `/出售 铁矿*20` | 不用于分隔参数；`/强化` 禁止 `*`（批量=连点爆装风险）；数量上限默认 ≤99 可配 | L16、L31-34 |
| D03 | `,` | 列表分隔符 | 材料/特性/多目标列表（**全角/半角等价，不空格**） | `项1,项2,项3` | `/投料 赤铁矿,火药,硫磺粉` · `/继承 灼烧强化,回复量+5%` · `/镶嵌 火焰之珠,炎剑Ⅱ` | 不用于数量；旧「空格列表/`+` 分隔/`×2`」写法全部废除，只保留 `,` 与 `*` | L17、L42-43 |
| D04 | `=` | 键值修饰 | 参数修饰（触媒/代采等） | `键=值`（值可再含 `*` 数量） | `触媒=爆裂壶` · `代采=矿石*5` · `/雇工 助手名 代采=矿石*5,代调=药剂*2` | 不用于分隔 | L18、L49 |
| D05 | `+` | 等级/数值标记 | 装备强化等级、词条数值 | `对象+N`（N 为纯数字） | `/强化 铁剑+5` · 词条 `攻击+3` | 不用于数量；`+` 是等级标记不是 `*` | L19、L34 |
| D06 | `-` | 连招/序列符 | 连招序列、序号区间 | `1-2-3`（序列）/ `1-3`（区间，展开为 1,2,3） | `/攻击 1-2-3` · `/背包 1-3` | 不用于数量 | L20、S2 |
| D07 | `>` | 路径/派生符 | 派生链路径、连续移动 | `A>B>C` | `/锻造 铁剑>铁剑Ⅱ` · `/进入 1>2`（连续移动） | 不用于数量 | L21 |

### 1.2 数量开关判定（`*` 有无即区分）

| 输入形态 | 判定 | 解析结果 | 引用 |
|---|---|---|---|
| 参数含 `*` | → 数量 | 拆为 `对象 + qty`；`*` 左侧**先精确匹配名称，失败再按序号** | L36、L70 |
| 参数不含 `*` | → 序号/名称 | 纯数字=序号（`/攻击 2` = 2 号技能，`/进入 2` = 2 号地图）；汉字=方向/名称 | L35-36、L112 |
| 整串纯数字且无指令词 | → 会话子词/快捷 | 见 §五 会话路由与 §四 快捷 | L149-152、[2b2·R1] |

### 1.3 命名铁律（前置防歧义，注册/存储时检查）

| # | 规则 | 说明 | 引用 |
|---|---|---|---|
| N01 | 物品/配方/装备/特性/珠/套装/技能/行动名：**禁止空格、禁止 `* , = + /`**（保留字符） | 保证 1.2 判定无歧义 | L58 |
| N02 | 允许 `·`、`Ⅱ`、`-`、数字 | `炎剑Ⅱ`、`炼狱爆弹·改`（`·`/`Ⅱ` 按普通字符整体匹配） | L59 |
| N03 | 保留字符检查 → **黄色提示（不拦截，只建议不限制）** | 存名含保留字符时注册/使用均提示，不拒绝 | L60、L246 |

## 二、紧凑与空格双认 + 前缀模式

### 2.1 command_mode 三模式（settings.json，用户/机主可配，默认全局免前缀）

| 模式 | 取值 | 战斗内 `攻击2` | 战斗外 `攻击2` | `/攻击 2` | 快捷名触发 | 引用 |
|---|---|---|---|---|---|---|
| 需要前缀 | `prefix_only` | ✗ 必须 `/` | ✗ 必须 `/` | ✓ | `/1` | L92、L177 |
| 战斗内免前缀 | `combat_shortcut` | ✓ | ✗ 必须 `/` | ✓ | 战内 `1` / 战外 `/1` | L93、L177 |
| 全局免前缀（**默认**） | `global_shortcut` | ✓ | ✓ | ✓ | `1` | L94、L177 |

- 配置键：`settings.json → command_mode: "global_shortcut"`；不同群/机主可各自设置，机主 `/设置` 切换 [L96-97]。
- 触发方式与模式正交：`require_at: false`（默认）直接发；开启后需 `@机器人 攻击2`，**快捷名同样跟随**（`@机器人 1`）[L102-104、L178]。

### 2.2 紧凑 + 空格双认（解析器）

| 写法 | 示例 | 引用 |
|---|---|---|
| 紧凑（粘合） | `攻击2` / `道具3` / `使用经验药水*10` / `进入上` / `进入2` | L109 |
| 空格 | `攻击 2` / `道具 3` / `使用 经验药水*10` / `进入 上` | L110 |
| 双认规则 | 两种都认，解析结果等价；**提示时展示紧凑格式**（“下次可以这样写：攻击2”） | L111 |
| 判定规则 | 指令名后紧跟数字=序号；含 `*`=数量；汉字=方向/名称 | L112 |
| 永久兼容 | 粘合写法（`背包2`）正则回退**永久兼容**，不随版本移除 | L240 |

## 三、解析器状态机（token 流 → ParsedCommand）

> 解析器为**全系统唯一入口**：任何输入（普通指令/快捷触发/别名/GM）都从 S0 进、逐级走到 S8 或中途移交（会话状态机 / 忽略）。

### 3.0 状态机总览（S0–S8）

```
S0 RAW   原始消息（raw text + 会话上下文标记）
 │ ① trim；② require_at 开启时剥离 @机器人；③ 按 command_mode 剥离 / 前缀（GM 白名单除外，GM 强制保留 /）
 ▼
S1 PRE   预处理完成
 │ 检查「是否有会话激活（对话/战斗）」→ 有：执行 §五 路由判定（子词送状态机，解析中止）
 ▼
S2 ROUTE 会话路由二选一 ──子词命中──▶ 移交「激活会话状态机」【session_route=true，本解析链中止】
 │ 无会话/带指令词 → 继续
 ▼
S3 SHORTCUT 快捷表精确匹配（完整消息匹配快捷名）[L149①]
 │ 命中 → 替换为完整指令串（expand_count=1）→ 回到 S1 续走（不再回 S3，防无限展开，S7 裁决）
 │ 未命中 → 继续
 ▼
S4 ALIAS 指令别名层（全局配置）[L150②]
 │ 命中 ← 行为原指令名，display_name=别名（keep_original:false 时原指令在 S5 不命中）
 ▼
S5 MATCH 指令白名单 开头匹配 [L151③]
 │ 未命中 → IGNORE（忽略，非指令消息）[L152④、L126-127]
 │ 命中 → 取指令名 + 剩余串
 ▼
S6 TOKENIZE 拆分 token 流：紧凑（指令名与参数紧贴）/ 空格 双认 [L109-112]
 ▼
S7 SUBPARSE 参数内子解析（顺序写死：, → * → =）[L69] + 后置修饰（+ 等级 / - 连招区间 / > 路径）+ 名称优先 [L70] + 固定子词抽离 [L71]
 ▼
S8 BUILD 组装 ParsedCommand → 交指令管线（物品校验/冷却/MP/权限/频率/会话路由照常）[L169-170]
```

**状态明细**：

| 状态 | 输入 | 处理 | 输出 | 去向 | 引用 |
|---|---|---|---|---|---|
| S0 RAW | 原始消息 | trim；`@机器人` 剥离（require_at 开启时，L104、L178）；`/` 前缀剥离（按 command_mode，GM 白名单除外 L128） | 预处理消息 + 上下文标记（是否会话激活） | S1 | L92-97、L128 |
| S1 PRE | 预处理消息 | 无逻辑，路由检查前置 | 上下文标记 | S2 | — |
| S2 ROUTE | 上下文标记 | 会话激活 + 输入 ∈ 子词集（纯数字/继续/退出/选择 N）→ 移交；否则继续 | 移交或原消息 | 会话状态机 / S3 | [2b2·R1-R5]、§五 |
| S3 SHORTCUT | 原消息 | 完整消息精确匹配快捷表 [L149①]；命中则替换、expand_count+1、**限制 ≤1**【工程补白】(S7 裁决) | 指令串（命中时）/ 原消息 | S1（命中，跳过 S3）/ S4（未命中） | L145、L149 |
| S4 ALIAS | 指令首词 | 查 `command_aliases` [L150②]；命中→ command=原指令名、display_name=别名；keep_original:false 时记「原指令已隐藏」 | 规范化指令名 | S5 | L208-215 |
| S5 MATCH | 指令首词 | 白名单（框架+内容包注册指令）开头匹配 [L151③]；GM 指令仅 `prefix_only` 形态可命中 | 指令名 + 参数剩余串 | S8-BUILD/移交指令管线 / IGNORE | L121、L128、L152 |
| S6 TOKENIZE | 指令名 + 剩余串 | 紧凑/空格双认 [L109-112]：`攻击2`→[攻击,2]；`攻击 2`→[攻击,2]；`使用经验药水*10`→[使用,经验药水*10] | token 流 | S7 | L109-112 |
| S7 SUBPARSE | token 流 | 见 3.2 子解析顺序 | 结构化 token（名称/数量/列表/键值/等级/连招/路径/固定子词） | S8 | L69-71 |
| S8 BUILD | 结构化 token | 组装 ParsedCommand；错误模板 4 类判定 [L72]；非拦截提示挂载（数量超限 L73 / 紧凑回写 L111 / 黄色建议 L60） | ParsedCommand | 指令管线 | L68-73 |

### 3.1 参数内子解析顺序（写死，S3 裁决背书）

``` 
统一解析模板：/指令名 [位置参数1] [位置参数2|固定子词] [键值列表]        [L68]
参数内顺序固定：先按 , 拆列表 → 再按 * 拆数量 → 再按 = 拆键值           [L69]
名称优先：* 左侧先精确匹配名称，失败再按序号                             [L70]
固定子词表（追加/预览/自动/查看/确认/放弃/续）为内置常量，优先于物品匹配 [L71]
错误模板统一 4 类：缺参/超参/未知分隔符/保留字符违规                     [L72]
数量超限提示（默认 ≤99，仅提示不拦截）                                  [L73、L33]
```

**示例走查：`/雇工 助手名 代采=矿石*5,代调=药剂*2`** [L49]

```
① 空格切分 → [雇工, 助手名, 代采=矿石*5,代调=药剂*2]
   位置参数 = [助手名]（≤2 合法，第 3 个起为键值列表形态）               [L46-51]
② token3 按 , 拆列表 → [代采=矿石*5, 代调=药剂*2]                      [L69a]
③ 每项按 * 拆数量 → [代采=矿石 | 5]、[代调=药剂 | 2]  （右侧纯数字合法）[L69b]
④ 剩余按 = 拆键值 → {key:代采, value:矿石, qty:5}、{key:代调, value:药剂, qty:2} [L69c]
⑤ 名称优先：矿石/药剂 为物品名精确匹配，命中（失败才按序号）            [L70]
```

**后置修饰（`+ - >`）**：在 ③④ 基础 token 上检测——`铁剑+5` → level=5 [L19]；`1-2-3` → seq=[1,2,3]，`1-3` → seq=[1,2,3] 展开 [L20]；`铁剑>铁剑Ⅱ` → path=[铁剑,铁剑Ⅱ] [L21]。

- 内容包注册指令时声明参数位：`{pos, 名, 类型: target/qty/seq/level/path/keyword, 可选}` [L81]

### 4.2 触发解析顺序（写死，含别名层）

## 五、会话路由（对话 / 战斗激活时的输入分派）

> 规范正文未定义会话路由（S4 裁决）；本段以 2b2 对话会话路由（R1-R5）为既有基线，**泛化应用到战斗会话（【工程补白·战斗侧】）**。路由层只做「这串输入送状态机 / 送正常指令解析」二选一判定 [2b2·L96]，消费侧由各激活状态机按自身状态处理（对话=2b2 T03/T07/T09/T11/T13/T14；战斗=1g 系列状态机按当前状态消费）。

### 5.1 统一路由判定表（R1–R5 泛化）

| # | 场景 | 输入样例 | 判定 | 去向 | 引用 |
|---|---|---|---|---|---|
| R1 | 会话激活中发子词 | 纯数字 `1/2/3`、`继续`、`退出`（含 离开/再见），`选择 N` | **送激活会话状态机**（选选项/翻页/推进/逃跑/确认） | 对话=2b2 状态机；战斗=战斗状态机【工程补白·战斗】 | [2b2·R1、L120] |
| R2 | 带指令词照常解析 | `攻击1`、`使用1`、`背包2`、`防御` | **正常指令解析**（玩家会话中也能“使用1”吃药再“继续”） | 对应指令管线 | [2b2·R2]、L151 |
| R3 | 会话优先于快捷 | 已绑“快捷 1=攻击”，会话激活中发 `1` | **选选项，不触发攻击**（路由优先于快捷表 ①） | R1 送状态机 | [2b2·R3]、L149① |
| R4 | 无会话时快捷生效 | 无激活会话发 `1` | 跳过状态机子词匹配，走快捷表/别名/白名单 | 快捷 ① → 别名 ② → 白名单 ③ → 忽略 ④ | [2b2·R4]、L149-152 |
| R5 | 菜单底固定退出 | N = 选项数 + 1 | 菜单末尾固定「N. 离开」，与路由子词严格一致 | 状态机 END 路径 | [2b2·R5] |

### 5.2 战斗会话路由明细【工程补白·战斗侧】（由 R1-R5 泛化，消费归战斗状态机）

| 输入 | 判定 | 消费示例（战斗状态机按当前状态处理） |
|---|---|---|
| 纯数字 N（`2` / `3`） | 送战斗状态机 | 战斗菜单选技能 N / 选目标 N（等价“选择 N”） |
| `继续` | 送战斗状态机 | 推进回合输出 / 快照续战确认 |
| `退出` | 送战斗状态机 | 逃跑/撤退流程（含失败不打断逻辑，见 1g 系列） |
| `选择 N` | 送战斗状态机 | 与纯数字 N 等价映射【工程补白】 |
| 带指令词（`攻击2`/`道具3`/`防御`/`使用1`） | 正常指令解析 | 立即行动指令，不冲突 |

### 5.3 路由优先级总表（写死，S5 裁决背书）

```
① 会话激活中 且 输入 ∈ {纯数字, 继续, 退出/离开/再见, 选择 N}  → 送激活会话状态机（R1，含会话优先 R3）
② 快捷表精确匹配（完整消息匹配快捷名）                          → 替换指令串重解析（规范 ①，L149）
③ 指令别名（全局配置）                                          → 原指令（规范 ②，L150）
④ 指令白名单开头匹配                                           → 正常指令解析（规范 ③，L151）
⑤ 忽略（非指令消息 / 无白名单匹配）                            → 不响应（规范 ④，L152、L126-127）
```

> 路由判定的前置 = 是否「某会话激活」。对话会话激活区间 = 建会话 → 会话收尾（与 2b2 会话快照生命周期一致 [2b2·L135]）；战斗会话激活区间 = 战斗开始 → 战斗结束/逃跑成功（1g 系列定义）。判定收敛点：**会话子词只在激活区间内具语义**，区间外与普通消息同权（R4）。
