现状三层硬编码：① combatant 映射白名单 10 键（玩家/敌方）② 战斗消费点写死键名
（命中读 foc/spd 等 7+3 处）③ formula.json 生产侧零消费（battle L332-336 注释明言）。

**好消息**（勘察确认）：公式纯函数层（damage.py hit_rate/block_rate/defense_factor/
total_damage）全部数值入参无键名硬编码；DamageFormulaParams 各段已参数化（hit/crit/
block/defense 段对象齐全）；公式引擎 EvaluatorCtx 变量空间全量透传（_combat_map dict 全键）。
**只差**：取数侧的键名参数化 + 生产侧装配链。

## 目标形态（做完全貌）

```
formula.json（内容包可配）:
{
  "damage_base": "atk * 2 - def",        # 既有（公式引擎用）
  "stat_map": {                           # 新增：语义键 → combatant 键
    "hit_focus": "foc", "hit_spd": "spd", "crit_luck": "lck",
    "block_focus": "foc", "def_con": "con",
    "atk_atk": "atk", "mag_int": "int",
    "enemy_str": "str", "enemy_con": "con", "enemy_spr": "spr", "enemy_agi": "agi"
  }
}
```
缺省 stat_map = 现值（零破坏）；内容包覆盖即换键。玩家/敌方 combatant 全量透传
（玩家 attrs 合成全键、敌方 stats 全键 + 语义映射可配）。
