## 二、逐条明细（23 条）

### 1. /合成（第 1 层·跨职业快捷生产）

- **【指令名】** `/合成 <配方名> <数量>`（数量分隔符 `*`，如 `/合成 魔力药水*10`，上限 ≤99）
- **【参数格式】** 配方名 + 数量；无会话态；不可批量叠加 `+N`（`+N` 是强化等级标记）
- **【流程】** 无会话 → 解锁校验（任一制造职业/资源技能达到配方等级，且 `synth_allowed=true`；深度层配方默认 false，开启仅提示「此深度配方可被合成，将绕过深度炼金玩法」）→ **原子校验**：材料+金币全量满足才执行，否则全拒并提示差异（"缺 水结晶×5 + 金币 30"）→ 产出标准版（品质固定、无特性、无过程；标准珠仅带固定 `base_effects`）→ 熟练经验 = 配方等级 ×1（可配）→ 合成图鉴点亮（小加成）→ 不消耗调合能量（保底通道永可用）
- **【定稿章节】** 炼金定稿 §1.3（边界铁律）、§3.1-3.3（解锁/流程/定位与成长）、§2.4（不耗能量）、§9 表行 1、§10.1（`synth_allowed`）、§10.6（`synth_exp`）

### 2. /炼金（第 2 层·职业专属，开启调合会话）

- **【指令名】** `/炼金 <配方> [触媒=<触媒> | 自动]`（触媒键值 `=`；`自动` = 一键投料）
- **【参数格式】** 配方名 + 可选 触媒/自动；开启会话态；能量 ≥1 格
- **【流程】** 校验炼金职业（见习起步）+ 能量 → 开启调合会话（§4.6 状态机：无会话→会话中→挂起(战斗)→恢复→确认/放弃终态；单玩家全局仅 1 个调合会话互斥；私聊+多群同样互斥）→ 展示面板（材料清单/属性刻度/特性位/PP/投入次数预算）→ 投料→继承→/确认 链 → 结算品质 = 材料品质 × 档位系数（普通 0.8/精良 1.0/史诗 1.2/传说 1.5，可配）；未达标刻度 = 品质降级（绝不吞材料）；链式投料 ≥3 段触发连锁奖励（深度层）
- **【定稿章节】** 炼金定稿 §2.4（能量条）、§4.2（调合流程）、§4.3（机制 1/2/4/5/6/7）、§4.4（反馈与悬念）、§4.6（会话管理）、§9 表行 2、§10.6（quality_tiers/quality_coef/energy_*）

### 3. /投料（第 2/3 层·链式投料）

- **【指令名】** `/投料 <材料1>,<材料2>,… [追加]`（材料列表分隔符 `,`；追加如 `/投料 追加 龙牙`）
- **【参数格式】** 材料名列表（, 分隔）+ 可选「追加」标记；会话中才有效
- **【流程】** 无会话 → 错误模板（"当前没有调合会话，先 /炼金 <配方> 开始"）→ 逐项入料（槽位上限校验，深度层 6 槽/3 普通+1 金）→ 计算连锁段数 = 相邻同属性对数（触媒改变后按新属性判定）→ 段数→效果等级映射（1 段=1 级…6 段=6 级，可配；≥3 段触发连锁奖励）→ 属性刻度累计 → 反馈附可继承特性清单；稀有金色素材投料 → 金色超特性候选（第 4 位独占）；✨觉醒素材 → 隐藏效果候选；成品/装备可入料（全物入料，专家）
- **【定稿章节】** 炼金定稿 §4.2、§4.3#5（链式投料）、§4.4、§5.2#3/#6/#20、§5.4（深度流程示例）、§9 表行 3、§10.6（chain_map）

### 4. /继承 /继承超（第 2/3 层·特性继承）

- **【指令名】** `/继承 <特性1> <特性2> …`；`/继承超 <金色特性>`
- **【参数格式】** 特性名列表（普通特性默认 ≤3 项，可配 1-6）；/继承超 限金色超特性、第 4 特性位独占（gold_slot_exclusive 可配）
- **【流程】** 会话中 + PP 校验（普通 1/超 2，PP 会话重置）→ 冲突规则：traits 加 group（互斥组内最多 1 项）+ repeatable（可否重复）→ 负面特性规则（宗师）：继承强力特性需承受 1 个负面词条（build 取舍）→ 超量/PP 不足 → 错误模板（"继承超 3 项"/"PP 不足"）
- **【定稿章节】** 炼金定稿 §4.3#3（特性继承）、§5.2#3（金色超特性）、§5.2#19（负面特性）、§10.2（traits.json：group/repeatable/rarity/source）、§9 表行 4、§4.6（错误模板）

### 5. /确认 /放弃 /调合续（第 2/3 层·会话终态）

- **【指令名】** `/确认`；`/放弃`；`/调合续`
- **【参数格式】** 无参数；会话中才有效
- **【流程】** /确认：全量校验材料仍在背包（不足拒绝并提示差异）→ 结算产出（品质/特性/刻度结算）→ 终态幂等（会话 version 号；重复确认 → "已结算"）。/放弃：退出会话（终态）。/调合续：恢复挂起(战斗)会话；已有活跃会话 → "已有一个调合会话进行中"。30 天无操作 → 僵尸会话回收（材料返还）。战斗中收到 /投料 /继承 等 → "战斗中使用 /即时调合 <配方>（不进入调合会话）"
- **【定稿章节】** 炼金定稿 §4.6（完整状态机/幂等/僵尸回收）、§4.2、§9 表行 5、§七（会话互斥）

### 6. /深度炼金（第 3 层·大师解锁）

- **【指令名】** `/深度炼金 <配方>`
- **【参数格式】** 配方名；开启深度会话（与 /炼金 会话分开，不同会话类型）
- **【流程】** 炼金职业 ≥ 大师 + 能量 → 解锁公告 + 逐条教学 → 开启深度会话面板（6 槽/核心槽/3 普通+1 金/刻度/进化线）→ 深度层全机制可用（连锁奖励/核心镶嵌/分解/复制/图鉴/即时调合…）→ /确认 结算；P2 机制（13-16）默认开启，内容包可关
- **【定稿章节】** 炼金定稿 §5.1（解锁与教学）、§5.4（完整流程）、§4.6（会话类型分开）、§9 表行 6

### 7. /进化（第 3 层·配方进化线）

- **【指令名】** `/进化 <配方>`
- **【参数格式】** 配方名；无会话态
- **【流程】** 宗师 + 低阶配方炼金产出 N 次（合成不计；多级链逐级计次）→ 消耗 材料+宝石 → 永久解锁下一级（继承槽位余量 + 投入次数 + 平均品质；特性不继承）；示例：/进化 爆弹 → 地狱火弹 → 继承 2 额外槽（6 槽）
- **【定稿章节】** 炼金定稿 §5.2#2（配方进化线）、§10.1（`evolve_to{id,condition:{count,source}}`）、§5.4、§9 表行 7、§13（进化线无环校验）

### 8. /镶核心 /加成（第 3 层·核心镶嵌 / 加成道具）

- **【指令名】** `/镶核心 <核心物品>`；`/加成 <道具>`
- **【参数格式】** 核心物品名 / 道具名；会话中才有效
- **【流程】** /镶核心：大师 + 核心物品（核心消耗）→ 品质上限 +X / 属性适配；可换（核心不匹配 → 错误模板）。/加成：宗师 + 加成道具（限 1 次/调合）→ 大幅提品质/改属性；示例：/加成 贤者之石 → 品质+30
- **【定稿章节】** 炼金定稿 §5.2#4（核心镶嵌）、§5.2#8（加成道具）、§5.4、§9 表行 8

- **【定稿章节】** 炼金定稿 §5.2#5、§10.1（kind=upgrade 字段映射表）、§5.4、§10.6（gem.成品合成=10）、§9 表行 9

## 三、实现层附注（跨指令约束）

- **指令分隔符统一规范**：数量 `*`（/合成 魔力药水*10）；材料列表 `,`（/投料 赤铁矿,火药,硫磺粉）；键值 `=`（触媒=爆裂壶）；/强化 禁批量 `*`（`+N` 是等级标记）——炼金定稿页首注。
- **错误模板全集**（框架 7.5 复用）：材料不足/等级不足/深度未解锁/会话过期/投料超槽位/继承超 3 项/PP 不足/触媒无效/核心不匹配/宝石不足/未登记复制/挑战失败/能量不足（"能量 0/10，等 30 分钟回 1 格，或 /合成 保底"）——炼金定稿 §九 表下注。

- **原子性与幂等**：所有消耗类指令走 材料/宝石/金币全量原子校验（不足全拒并提示差异）+ SQLite 事务 + message_id 幂等 + version（对齐 V11、路2b/路2c3 同款，路2c4b2 同规）。
- **合成引擎归属**：合成/成品/配方/特性四类「N 入→1 出」= 框架合成引擎 `kind=upgrade` 的配置实例（JSON），机制与内容分离（§10.1）。
