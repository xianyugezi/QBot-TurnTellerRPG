## 一、公式口径

```
命中率   = foc/(foc+敌spd) clamp [10%,95%]
会心     = √lck 三档 ×2.2/×1.7/×1.3（斩击+5%）
格挡     = min(40%, 敌foc/(敌foc+150))，魔法无视
物理通道 = atk×mult×弱点×会心×100/(有效con+100)，K=100
总伤     = (物+元)×乱数[0.9,1.1]×格挡0.5×防御0.5
技能 mult = power/100
```
