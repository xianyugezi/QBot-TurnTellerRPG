# 蚀脉猎师（QBot-TurnTellerRPG）玩家指令手册

> 适用范围：veinborn 内容包（当前实机）。群内直接发送指令词即可（免 `/` 前缀；带 `/` 也可用）。
> 列表 5 条/页，超页发「指令 页码」翻页。`<参数>` 为必填，`[参数]` 为可选。
> 本文档按「当前内容包实际可用」标注：✅ = veinborn 有数据、实机可用；⚠️ = 框架已实现但 veinborn 未配数据，发出会给空内容/未实装提示。

## 一、角色与基础（冒险组）

| 指令 | 功能 | 说明 |
|---|---|---|
| `注册 <角色名> [职业]` | 创建角色 | 首玩必发；职业缺省取推荐职业（脊剑士）。已注册重发 → 提示当前角色 |
| `注销` | 删除当前角色 | 确认后清档 |
| `角色 [页码]` | 属性面板 | 等级/经验/生命/魔力/三维属性 |
| `角色详细 [页码]` | 完整属性明细 | 白值/加成/临时三层 |
| `我的状态` / `状态` | 状态查询 | 当前属性状态 |
| `帮助` / `帮助 <组名>` / `帮助<组名><页数>` | 指令总览/分组 | 如 `帮助 冒险`、`帮助冒险2` |
| `日志` | 冒险日志 | 最近冒险记录 |

## 二、背包与装备

| 指令 | 功能 | 说明 |
|---|---|---|
| `背包 [页码]` | 查看背包 | 每页 5 条 |
| `背包筛选 <类型> [类型 <子类>] [品质 <品质>]` | 筛选背包 | 如 `背包筛选 装备` |
| `使用 <序号\|物品名>` | **穿戴装备 / 使用消耗品** | 穿戴唯一入口：`使用 1` 或 `使用 砺脊刃`；药品等消耗品同样用它 |
| `背包 查看 <序号\|物品名\|部位>` | 查看物品/装备详情 | 材料介绍/药剂效果/装备属性面板；`背包 查看 武器` 看已穿戴部位详情 |
| `装备` | 查看当前穿戴 | 查看各部位装备（不含穿戴功能——穿戴用「使用」） |

| `任务 放弃 <序号>` | 放弃进行中任务 | |

## 四、探索与地图

| 指令 | 功能 | 说明 |
|---|---|---|
| `位置` | 当前地点 | 地图介绍/活动怪物/通道 |
| `地图` | 地图列表 | 非隐藏地图 + 通道 |
| `进入 <方向\|序号\|名称>` | 前往其他地图 | 如 `进入 上` |

## 五、战斗

| 指令 | 功能 | 说明 |
|---|---|---|
| `锁定 <序号\|怪物名>` / `锁定怪物` | 对当前地图怪物开战 | 如 `锁定 1`、`锁定怪物 脊冢幼兽` |
| `攻击 [技能名\|序号]` | 战斗行动 | 战斗中发：普攻或指定技能；序号=技能列表序号；无参=普攻 |
| `技能 [页码]` | 查看技能列表 | 只显示当前可用技能；含「可派生成」指向 |
| `我的技能` | 查看技能（别名） | 同 `技能` |
| `技能详情 <序号\|名称>` | 技能完整信息 | 类型/消耗/效果/派生指向 |
| `技能派生 <序号\|技能名>` | 查看派生链 | 可派生技能+派生条件（连用次数/部位破坏积累） |
