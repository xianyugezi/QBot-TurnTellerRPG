> 仓库：QBot-TurnTellerRPG（新仓库）｜阶段：2a2 细化规划｜范围：怪物换区追击的完整交互流程（触发→逃跑→追击→续战→离开重置）
> 依据（严格引用）：《怪物模块设计定稿.md》（下称【怪物】）+《副本系统设计定稿.md》（下称【副本】）
> 定位：换区 = BOSS 战斗体验的一部分（不是独立机制）——「残血逃跑 → 玩家走通道追击 → 继续打」是同一场战斗的阶段切换（【副本】L25）

## 0. 总览

### 0.1 一句话流程

```
BOSS 血量 ≤ 残血阈值(回合结算判定) → 触发换区事件[逃跑换区]
  → 提示「逃到了 XX 地图」(候选随机) → 玩家退出战斗、处于副本地图态
  → 玩家 /进入 <方向> 走地图通道追击（网状路径选择）
  → 追到（进入 BOSS 所在目标图）→ 触发遭遇 → 继续战斗
      · 怪物血量保持残血（不重置）｜PV 恢复一半（向下取整）｜换区后第一回合开场技
→ 非战斗状态离开副本 → 副本重置（下次 BOSS 满状态重打）
```

## 1. 换区触发规则

### 1.1 触发判定（R1 / R2 / R5）

- **判定条件**：怪物当前血量百分比 ≤ 触发阈值 → 残血才换区；不残血绝不触发（逻辑闭环）（【怪物】L93）。
- **阈值口径**：百分比（【副本】L143 `"trigger": { "type": "hp_below", "value": 30 }` —— value=30 表示血量 ≤ 最大血量 30% 时触发）。血量口径统一为百分比，避免绝对数值随配置档漂移。
- **每 BOSS 独立配置**：不同 BOSS 换区条件可单独设计——血量阈值 / 阶段切换 / 特定行动后 / 自定义条件（【副本】L68-69）。本细化聚焦 `hp_below`（残血换区）为主路径；其余类型沿用同一换区结算管线。
- **判定时机**：怪物回合行动结算完成后判定一次（与行动数据库「特殊行动触发」同节奏）；玩家回合内即使血量被打到阈值以下，也到怪物回合行动后统一结算——保证换区发生在「一次完整交换回合边界」，不与怪物本回合行动冲突。
- **未配置 = 不换区**：`zone_change` 缺失或 `targets` 为空 → 怪物永不换区（【副本】L70/L73）。

### 1.2 逃跑行为（R3 / R6）

- **击杀优先**：判定时刻 hp=0 → 直接击杀结算，不进换区（残血方换区，hp 已归零则无「残血逃跑」语义）（【怪物】L93 推导）。
- **必发流程行为**：条件满足即触发「逃跑换区」，无逃跑成功率/概率博弈（定稿无此设定，保持最简单：条件命中即必换区）。
- **结算顺序**：怪物逃跑换区 → 本次战斗结束结算（我方发放回合内已完成的出手，不额外惩罚）→ 玩家切回副本地图态。逃跑不产生击杀奖励/不掉落（此战未分胜负，奖励语义归后续续战击杀结算）。

### 1.3 提示语（R7）

- 触发瞬间对玩家输出的统一提示模板：
  - 普通逃怪：`【换区】<怪物名> 逃到了 <地图名>！它已是残血，追击吧。`（【怪物】L94「提示『逃到了 XX 地图』」）
  - 副本 BOSS：`<BOSS名> 逃向了 <随机候选区域名>！`（【副本】L75「提示『BOSS 逃向了 XX 区域』」）——副本语境推荐用本模板，与【副本】L57 示例措辞一致。
- 目标地图名 = 命中候选区域的地图 `name`（细化_2a1a §1.2）。提示同时显式告知「可 /进入 <方向> 追击」（【副本】L76）。

### 1.4 候选区域（R8）

- 从 `zone_change.targets`（候选区域列表，策划配置）**随机选一**作为逃跑目标（【副本】L71-72/L75/L144）。
- target 必须是本副本内连通节点（细化_2a1a 校验：target 存在且可达），未被配置则返回 R4。

## 2. PV 恢复规则

### 2.1 恢复量：一半（向下取整）（R9）

- 换区后怪物 **PV 恢复一半，向下取整**（【怪物】L98；【副本】L145 `"pv_recover": 0.5`）。
- **基数口径（工程解读）**：恢复「配置满值 PV × 50%」，而非「当前缺失量的一半」。理由：PV 是 debuff 门禁（破防前 debuff 效果打折），半值恢复的意图是「重新加压门禁」——若按缺失量恢复（破防后 PV=0 时恢复 0），门禁直接失效，与【怪物】L98「重新加压 debuff 门禁」矛盾。故取满值口径。
- **公式**：`new_pv = floor(pv_max × pv_recover)`（支持配置非 0.5，可配百分比）。
  - 例：BOSS 满值 PV=300（【怪物】L101 区间 200-500）→ 换区后 PV = floor(300×0.5) = **150**。
  - 例：满值 PV=201（奇数）→ floor(201×0.5) = **100**（向下取整验证）。
  - 例：普通怪满值 PV=15 → floor(15×0.5) = **7**。
- PV 满值档位：普通 0-20 / 精英 50-100 / BOSS 200-500（可配）（【怪物】L101）。

### 2.2 恢复时机（R10）

- **换区事件结算瞬间**（怪物逃跑到目标图的同时）完成 PV 恢复，恢复后数值随换区状态落库（快照/副本 BOSS 状态）。
- **不等玩家追到再恢复**：追击途中（玩家尚未 /进入 目标图）怪物 PV 已按半值就绪；玩家追到开战时直接以恢复后 PV 进入战斗。避免「追得晚 = PV 恢复晚」的时序歧义。

### 2.3 门禁语义（R11）

- PV 恢复一半 = 换区后 debuff 门禁重新生效：追击续战时，玩家需先把 PV 打至 0（破防），此前施加的 debuff 仍按「效果减半」（**层数保留**/概率减半/数值减半，【怪物】L72/L79——破防后全量爆发）处理。
- 衔接防御/破防系统：破防状态（此前战斗中已破防）不跨换区延续——换区后以半值 PV 重新建立门禁；玩家需再次破防完成击杀。

## 3. 血量保持规则

### 3.1 不重置（R12）

- 换区后怪物血量 = **换区触发瞬间的血量（残血）**，不重置为满、不回复任何比例（【怪物】L97「怪物【血量保持残血】（不重置——玩家打残血才换区，残血继续打）」；【副本】L78）。
- 血量与 PV 解耦：血量只保持、不回血；PV 单独按 §2 恢复一半——两条资源口径互不干扰。

### 3.2 残血续战（R13）

- 玩家追到目标图触发 BOSS 遭遇后，直接延续残血血量继续战斗（【副本】L78「血量保持残血」）。
- 残血即「下一阶段战斗的起手状态」，玩家有明确的收尾预期（已投入的输出不浪费）。

### 3.3 快照与持久化

- 换区后的 BOSS 血量/PV/换区进度随副本状态保存（配合战斗快照 ai_state+combo_state，【副本】L80）：玩家中断也可从残血续玩。存储落点 = 副本 BOSS 状态（框架 3.7 持久化语义，衔接细化_1g3）。

## 4. 玩家追随时序

### 4.1 时序总览（R14）

```
[回合结算] BOSS 血量≤阈值 → 触发换区 → 提示「逃到了 XX 地图」
→ 本次战斗结束，玩家回副本地图态（追击态）
→ 玩家输入 /进入 <方向> ×N（走通道，逐图推进）
→ 进入目标图（BOSS 所在）→ 触发 BOSS 遭遇 → 继续战斗（残血 + PV 半值 + 开场技）
```

- 追击态是副本地图态的一种（玩家处于「换区后待追击」的副本内），区别于普通漫步：可 /进入 走通道、可触发该图非 BOSS 遭遇、可 /休息（仅安全区）。追击态由副本 BOSS 状态标志 `chasing: true` 标识。

### 4.2 走通道（R15）

- 指令：`/进入 <方向>`（**空格分隔**，遵循《指令分隔符统一规范》）（【副本】L12；【怪物】L95「玩家走地图通道去找（/进入 <方向>，框架通道系统）」）。
- `/进入` 便捷指令（无参数版，自动判断唯一出口）为 P1 预留，本版本不实现（【副本】L12）。
- 方向取值对应 exits.direction：上/下/左/右（【副本】L46-47，细化_2a1a §2.1）。
- 进入成功：玩家当前图切换为 target 图；目标图有非 BOSS 遭遇即触发对应遭遇。进入失败（该方向无通道）→ 输出「此方向没有通道」提示，不消耗行动资源。

### 4.3 地图路径选择（R16 / R17）

- 网状地图：每图 4 方向出口编辑，通道含双向/单向/捷径/隐藏（【副本】L46-51；细化_2a1a exits 结构），玩家凭地图知识决定走哪条路。
- **地图熟悉度 = 追击资源**（【副本】L77）：熟悉地图的玩家走捷径直追（【副本】L58）；不熟的玩家绕矿洞岔路——错过追击窗口 / 途中遭遇精英（【副本】L59）。
- 实现层只提供「可达性」，不代玩家算路：BOSS 固定在目标区（R22），任意可达路径都能追到，路径长短 = 地图层设计的资源差。

### 4.4 追错方向（R18）

- 玩家进入 **非 BOSS 所在图** → 不触发 BOSS 遭遇；该图若有普通/精英 spawns 则正常遭遇（【副本】L59「遇到精英」）。
- 玩家可继续 `/进入` 其他方向折返，直至到达 BOSS 所在目标图。系统不强制指引（地图知识即引导），但提示语已告知目标区域名。

### 4.5 追到续战（R19 / R20 / R21）

- 进入 BOSS 所在目标图 → 触发 BOSS 遭遇 → 继续战斗（【副本】L78）。
- **换区后第一回合 = 怪物开场技**（【怪物】L99「换区后第一回合：怪物开场技」；L159「进入战斗时（第一回合、换区后第一回合）——开场技」）：与「进入战斗第一回合开场技」共用同一怪物 AI 状态机触发点（细化_1f），无需新机制。
- **玩家状态全程延续**：追击全流程玩家 HP/MP/资源/印记不重置（【副本】L24）——追击消耗的是「地图步数/时间」，不是玩家战斗资源。
- 续战胜利 = 完整击杀结算（奖励/经验掉落按常规击杀规则，即本副本 BOSS 全部产出）；此战亦可用于 BOSS 阶段机制推进（【怪物】L240-BOSS 阶段机制：血量阈值触发）。

### 4.6 原地等待语义（R22）

- 追击期间 BOSS **固定在目标区域**，血量/PV 不再随时间或玩家步数变化（不出现「追得慢 BOSS 回血/回 PV」的惩罚）。
- 追击窗口的「错过」仅体现为路径上额外的精英遭遇与时间消耗（【副本】L59），不体现为数值回涨——与 R12「血量保持」一致（工程约定，不新增策划设定）。

## 5. 离开副本重置规则

### 5.1 重置触发（R24）

- **非战斗状态（已离开副本区域）离开 = 副本重置**，下次进入 BOSS 满状态（满血 + 满 PV）重打（【怪物】L100「玩家离开副本 → 副本重置（下次 BOSS 满状态重打）」；【副本】L81）。
- 「离开副本区域」指玩家从副本最后一个地图通过出口离开副本（脱离副本地图集合）；判定点为玩家当前地图脱离 `dungeon.maps` 集合且无进行中战斗。

### 5.2 不触发重置的情形

- **战斗中断 ≠ 离开**：战斗进行中退出/超时/锁屏 = 战斗快照续玩，ai_state+combo_state 全保留，套内也可续（【副本】L80）——即换区后未打完 BOSS 时中断，回来仍从残血续。
- **安全区 /休息 ≠ 离开**：不改变位置、不退出副本、不触发重置；换区进度/BOSS 血量/快照全程保留（【副本】L83/L104-106）。
- **死亡 ≠ 离开**：副本内死亡按 §2.2 副本内死亡处理（复活点/checkpoint 回退/重置可配），不自动触发离开重置（【副本】L129；细化文档引用 §2.2 即可，此处不展开）。

### 5.3 恢复入口明示（R25）

- 所有恢复/退出入口提示统一含：**「战斗中断可续玩，离开副本将重置」**（【副本】L82），避免玩家误离开导致残血 BOSS 白打。

### 5.4 重置范围

- 重置 = 整个副本进度（BOSS 血量/PV、换区进度 chasing 标志、区域清除/推进状态）清空；下次进入按 dungeon.json 初始状态满状态重打。
- 与 checkpoint 机制（【副本】L117-121）通过配置联合生效：`boss_state: reset|keep`（【副本】L126）决定死亡后 BOSS 是否保留；「离开=重置」为固定默认行为，不受 boss_state 影响。

## 7. 附录

### 7.1 配置落点（zone_change，衔接细化_1e 怪物八段 schema）

```json
// enemies.json / dungeon.json 中 BOSS 怪物条目（【副本】L142-146）
"zone_change": {
  "trigger": { "type": "hp_below", "value": 30 },   // 残血阈值（百分比口径，R1/R5）
  "targets": ["熔岩坑道", "矿洞"],                    // 候选区域（随机选一，R8；必在本副本 maps 内，R4 空则永不换区）
  "pv_recover": 0.5,                                // PV 恢复比例（满值口径，R9）
  "max_chase": 1                                    // 工程护栏：单副本换区次数上限（默认 1，可配 0=不限，防设计事故死循环；非策划设定）
}
```

### 7.2 工程护栏（不新增策划设定，仅实现层兜底）

- `max_chase`：限制单副本内重复换区次数，防空转/死循环（默认 1；0=不限）。重复换区仍遵循 R1-R13（每次触发都重新满足阈值且 PV 每次恢复一半的满值）。
- 追击态超时悬挂：玩家长期停留追击态按战斗快照语义处理（R23），不做额外惩罚。

### 7.3 衔接边界

- 战斗中断快照（ai_state+combo_state）语义见细化_1g3；本文档仅声明「换区进度随快照保留」（R23）。
- 开场技触发逻辑见细化_1f 怪物 AI 状态机（④ 进入战斗时 / 换区后第一回合）。
- exits 通道结构（双向/单向/捷径/隐藏/校验）见细化_2a1a；本文档引用其 `/进入` 语义。
- 副本内死亡处理（复活点/checkpoint/boss_state）完整语义见【副本】§2.2（L109-137），本文档仅声明其与「离开=重置」的边界（R27、TC-23）。
