## 二、M13 核心内容（三契约摘要）

### 2.1 6a 技能库（skills.json + skill_actions.json）
- **库级结构**：skills.json = 技能条目数组；顶层可选 {version, defaults}；与 action.json 共用 ActionCore（7 字段 id/name/kind/power/attack_type/element/effects）
- **24 字段** = A 共用核心 7 + B 玩家扩展 11（type/mp_cost/cooldown/tag/armor/interrupt/chain_refs/job_restrict/job_form/revert_form/derive_only）+ C 全库补充 2 + D 细化定型 4（block_mode 等）
- **四类时机**：basic（普攻固定第 1 位）/active（主动施放）/passive（常驻装配）/trigger（条件触发 + 上限）
- **校验 13 条**：V-1 效果引用 / V-2 派生链 / V-3 印记 / V-4 元素 / V-5 职业引用 / V-6 倍率累计 / V-7 普攻每职业恰 1 / V-8~V-13（细化增补）
- **ActionCore 元数据单点**：两库同构，任何新字段必须登记元数据（V-11）

### 2.2 6b 职业库与变换引擎（jobs.json + transform 引擎）
- **39 字段**：顶层 11（id/name/difficulty/playstyle/recommended_newbie/resource_axes/mechanic_tags/weapon_types/growth/transform/…）+ growth 9 + transform 11 + state_policy 3 + 技能挂点 4 + 链挂点 1
- **变换状态机 5 状态**：NORMAL → TRANSFORMING（瞬态）→ FORM_ACTIVE → REVERTING（瞬态）→ COOLDOWN
- **3 流程**：F1 变换触发（触发技效果先结算 → 变换 → 技能位重排 + state_policy）/ F2 还原结算（三路归一：自然结束/主动 revert_form/被驱散 dispel_reverts）/ F3 快照写入与恢复（job_form+remaining+cooldown 随 battle_state 持久化）
- **ADR 6 条**：D-01 transform 单例 / D-02 形态状态与形态指针双轨 / D-03 兑换节奏回合 tick / D-04 battle+revert 红拦 / D-05 驱散结算时点 / …
- **校验 8 条** V1~V8 + 18 TC

### 2.3 6c 资源轴/季节/组合（8 机制 / 24 字段 / 20 TC）
- **M1 资源轴两型注册段**（10 字段：name/type/icon/base/max/reset/display/max_per_pool/pools/pool_icons）+ D-01 子池型双形态并存
- **M2 energy_gain/energy_cost**（4 字段）+ D-02 组合多重集匹配 + D-03 触发类 energy_cost 语义
- **M3 回合结清与生命周期** / **M4 resource_state 快照**（D-04 子池型池级展开）
- **M5 季节技能组**（season 字段 4 季 + 行动校验 + 展示过滤置灰）+ **M6 换季结算边界时序**（回合结束 tick 后切换 + [季节:X] 条件键互译）+ **M7 on_season_change 事件**（L2 proc +1）
- **M8 combo_table 组合表达**（7 字段：combo/name/kind/power/element/hits/effects，多重集匹配）
